# 汉服博客语境配图整改设计

**批准日期：** 2026-09-04  
**批准方案：** 混合证据方案  
**范围：** 当前 160 个双语主题配置、对应 320 篇中英文文章、文件管理器元数据及失效图片清理。

## 1. 问题与目标

当前 R3 图片清单每个主题只提供一张封面，正文生成与验收还把 `<img>` 判为结构错误。因此即使文章讨论节令、婚礼、圆领袍、马面裙或某项工艺，正文也无法出现逐段对应的视觉证据。

本次整改的目标是让每一张图回答一个明确问题：它展示什么、对应哪一段、能支持到什么程度、不能据此推断什么。图片不能只承担装饰作用，也不能用模糊古风造型冒充具体形制、朝代或民族身份。

## 2. 内容密度

- 普通主题：1 张封面，加 2 张正文图。
- 节日、婚礼、民族服饰、工艺与形制辨析主题：1 张封面，加 3 张正文图。
- 中文与英文文章共享同一视觉资产，但分别保存本地化名称、替代文本、说明与图注。
- 除中英文配对外，不允许不同主题重复引用同一个正文图片对象。

## 3. 混合证据规则

### 3.1 开放授权实拍或馆藏图

仅接收逐项可核验为 CC0、Public Domain、CC BY 或 CC BY-SA 且允许商业使用的素材。每项记录原始页面、直接来源、作者/机构、许可证、许可证网址、抓取日期和必要署名。来源页面只用于知识核验而未授予图片复用许可时，不下载图片。

### 3.2 编辑插图

在节庆现场、社区身份或冷门工艺缺少可商用实拍时，使用原创编辑插图。图注与文件管理器描述必须明确写出“AI 编辑插图 / AI editorial illustration”，且不得把插图称为历史照片、馆藏实物、特定支系身份证明或仪式等级证据。

### 3.3 教学型结构图

形制辨析允许使用原创教学图，但必须显示正文要求的关键结构。例如圆领袍需要完整圆领、袍身与右侧闭合线索；马面裙需要正面裙门与两侧褶群；襦裙必须显示上衣与下裙的组合关系。

## 4. 图片槽位模型

每个主题的正文图片清单包含以下字段：

- `slot_id`：主题内唯一标识，例如 `occasion-context`。
- `visual_role`：`context`、`form`、`craft`、`care`、`evidence` 之一。
- `anchor_h2`：插入到第几个二级标题之后。
- `source_path` 与 `object_directory`：本地源文件和文件管理器对象目录。
- `must_show`：图片必须可见的要素。
- `must_not_claim`：不得由图片推出的结论。
- `provenance`：来源类型、作者、机构、许可、来源网址、生成工具及源文件哈希。
- `locale_copy`：`zh_Hans_CN` 与 `en_US` 的 display name、alt、description、caption，状态均为人工审校。
- `relations`：主题 slug、图片槽位、视觉角色、来源记录及替换对象。

正文使用语义化 `<figure><img><figcaption>`。图片按 `anchor_h2` 放到相关段落后，而不是集中堆在文章开头或结尾。

## 5. 代表性主题的视觉要求

- `hanfu-occasions-daily-wedding-festival`：分别展示可活动的日常层次、婚礼角色与礼仪层、当代节令活动场景；不得用一张普通庭院合影代替三类场合。
- `hanfu-styles-ruqun-mamian-yuanling`：分别展示襦裙组合、马面裙裙门与褶群、圆领袍完整领圈及袍身。
- `hanfu-through-dynasties-tang-song-ming`：馆藏或传世图像与现代参考图分开标记，不允许一套影楼造型代表整个朝代。
- `hanfu-fabrics-embroidery-green-manufacturing`：分别展示纤维/织物、刺绣正反面或机绣针迹、可核验生产环节；外观不能被描述为成分证明。
- `ethnic-*-dress-overview`：以轮廓和穿着系统为主，不凭一张图认定支系、身份或仪式等级。
- `ethnic-*-occasion-craft`：场合、服装与工艺至少有两个独立视角；无法确认具体节庆时使用区域性或工艺性画面并写明限制。

## 6. 文件管理器与清理

所有图片必须先通过 `FileAssetLibraryInterface` 注册，再写入文章。资产级与中英文 locale 级元数据都必须完整，`translation_state=reviewed`、`translation_origin=manual`。发布验收需确认对象路径、文章引用和 FileManager 关系一致。

旧图只允许通过显式 allowlist 清理。清理前必须证明 Blog、Project 与 FileManager 引用计数均为零；任何一个引用仍存在就停止删除并报告具体对象。

## 7. 验收

- 160 个主题全部存在规定数量的正文图片槽位。
- 320 篇文章全部包含与段落绑定的 figure，且 alt/caption 使用当前 locale。
- 不同主题正文图片 SHA-256 不重复，中英文配对除外。
- 所有开放素材许可允许商业使用；所有 AI 图片均明确标识编辑插图。
- 圆领、马面裙、节日和民族服饰代表页通过人工视觉审查。
- `--dry-run`、`--apply`、`--verify`、`--cleanup` 依次通过。
- 在真实浏览器中检查博客列表和代表文章的桌面/移动布局、图片加载、图注与回退行为。
