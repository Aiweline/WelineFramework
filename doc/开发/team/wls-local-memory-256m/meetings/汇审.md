# 汇审 — wls-local-memory-256m

## 决议
本地 `wls.worker_memory_limit` / `dispatcher_memory_limit` = **256M**；启用 `memory_guard` + `memory_pressure` + `memory_cache` + `worker_max_requests=5000` 智能淘汰；全代重启已完成。

## 证据
- env 核验：`worker_memory_limit=256M`，guard soft70/hard85，drain 0.92，`worker_max_requests=5000`
- 全代重启：`server:stop` → 清理旧 1024M sidecar → `server:start --worker-memory-limit=256M`
- 首页 `https://p05113ef3.test.weline.com:9555/` → 200
- 新代 Worker RSS 约 100–120MB（此前单进程可达 700MB+）

## 风险
256M 下偶发大页/大语言包仍可能触 drain 或 OOM——属预期智能换血，非回退 1024M。

未改 WorkerResponseMemoryGuard 源码；未动生产。
