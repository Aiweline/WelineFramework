# 技术方案会 — wls-local-memory-256m

## 背景
本地 WLS HTTP worker OS RSS 常驻 500MB+：`worker_memory_limit=1024M` 使 memory_guard 几乎不触发；峰值后 Zend arena 不归还 OS。

## 方案（冻结）
1. `wls.worker_memory_limit` / `dispatcher_memory_limit` → **256M**（对齐 sample）
2. 启用既有智能淘汰，不新建扩展点：
   - `memory_guard`：软 70% / 硬 85% 清进程内可重建缓存；warning 80% / drain 92%
   - `memory_pressure`：整机压力减池
   - `memory_cache` + `cache.eviction_threshold`：进程内缓存 LRU
   - `worker_max_requests=5000` + stagger 500：兜底换血
