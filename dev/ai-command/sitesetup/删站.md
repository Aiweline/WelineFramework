# MCP 指令：删站

**触发词（任一即执行；须带目标站）**

- `删站`
- `删站：{站}`
- `删站 {站}`
- `删除网站`
- `清理站点`
- `website delete`
- `purge website`

用户提到上述触发词时，Agent **必须**按本文件 + 模块技能执行删站与孤儿清理。

**参数**

| 参数 | 必填 | 默认 |
|------|------|------|
| 目标站（code / 名 / id） | **是** | — |
| 位置 | 否 | **本地**；明示 `线上`/`生产`/`online`/`production` 才上生产 |

## Agent 必做

1. 工程会话：`prepare_project` → 遵守 `hard_constraints`；读技能与流程正文。
2. **无站名 → 追问，禁止开删。**
3. 位置默认本地；线上才 Read **该目标**站柜 `websites/<cabinet>/README.md` 取 SSH Host（禁止套用其它柜 / 其它 profile）。
4. 解析唯一 `(website_id, code)`；**拒绝** `website_id=0` / `code=default`。
5. 只读清点 → **备份并校验** → 结构删除 → 孤儿配置 → **交叉引用图**静态清理 → 验收汇报。
6. **禁止具象误导**：不得在计划/技能执行里把某一固定商户、域名、SSH、IP、非 0 `website_id` 写成默认目标或「永远可删」清单。

## 验收意图

- 目标站从 Catalog 消失；默认站仍在。
- 存活站商品媒体与 `file_asset` 关联缺失为 0。
- 配置仍引用的媒体仍在；`font-subset` 未误删。
- 汇报含位置、备份路径与校验、释放体积。
