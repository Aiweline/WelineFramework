# MCP 指令：建站

**触发词（任一即执行）**

- `建站`
- `建站指令`
- `site setup`
- `SiteSetup`
- `建站助手 Provider`
- `建站任务 Provider`

用户提到上述触发词时，Agent **必须**按本文件执行：为**涉及模块**建立或更新建站任务 Provider（Extends），**禁止**在建站助手浮层硬编码任务清单，**禁止**在本指令正文维护全局任务表。

权威契约：

- `Weline\SiteSetupAssistant\Api\SetupTaskProviderInterface`
- `Weline\SiteSetupAssistant\Api\AbstractSetupTaskProvider`（继承此类实现）
- `Weline\SiteSetupAssistant\Service\SetupTaskCollector`（助手只收集并调用）
- 规格：`app/code/Weline/SiteSetupAssistant/doc/开发/spec/site-setup-extends-task-providers.md`

---

## 目标

1. **抽象 Provider**：任务条目 + 检测条件都在业务模块 Provider 内。
2. **Extends 登记**：`extends.php` 挂到 `SetupTaskProviderInterface::class`。
3. **助手只编排**：浮层只渲染 Collector 结果。
4. **指令产出 = Provider**，不是任务行。

---

## 反模式（禁止）

| 禁止 | 正确 |
|------|------|
| 改 `site-setup-assistant-float.phtml` 的 `$tips` 数组加业务项 | 在业务模块新建/更新 Provider |
| 在本指令或聊天里维护「全站任务清单」当权威 | 清单由各模块 Extends 汇总 |
| 在 SiteSetupAssistant 里写 Smtp/支付完成条件 | 条件写在对应模块 Provider |
| 只覆盖 status、任务目录仍硬编码 | Provider 同时 **定义 + 自检** |

---

## Agent 必做流程

1. `prepare_project` → 遵守 `hard_constraints`。
2. 识别本回合涉及的业务模块（如 Smtp、Captcha、Payment…）。
3. 在**每个涉及模块**中：
   - 新建或更新 `extends/module/Weline_SiteSetupAssistant/SetupTask/{Module}SetupTaskProvider.php`
   - **继承** `AbstractSetupTaskProvider`，实现 `provideTasks(array $context): array`
   - 用 `$this->task()` / `$this->tasks()` 规范化条目；用 `$this->resolveStorageScope()` / `$this->backendPath()` 辅助
   - 每条含：`code`、`title`、`tip`、`status(todo|doing|done)`、`href`；可选 `category`、`module`、`scenarios`、`parent_code`、`sort`、`meta`
   - 子检查用独立 `code`（如 `smtp_transport` / `smtp_mail_template` / `smtp_mail_template_i18n`），各自独立检测
4. 在该模块 `extends.php` 登记：

```php
use Weline\SiteSetupAssistant\Api\SetupTaskProviderInterface;
use Vendor\Module\Extends\Module\Weline_SiteSetupAssistant\SetupTask\XxxSetupTaskProvider;

return [
    SetupTaskProviderInterface::class => [
        XxxSetupTaskProvider::class,
    ],
];
```

5. **不要**改助手浮层加硬编码任务；助手模板只应调用 `SetupTaskCollector::collect()`。
6. 补契约 UT（接口名、Extends 登记、禁止浮层硬编码业务 code）。
7. 更新模块 `doc/开发日志.md` / 需求；收口 Browser 看助手条目来自 Provider。

## 参考实现

- Smtp：`app/code/Weline/Smtp/extends/module/Weline_SiteSetupAssistant/SetupTask/SmtpSetupTaskProvider.php`
  - `smtp_send_path`：外部 SMTP / 自建邮局路径
  - `smtp_transport`：发信账户 + 测试确认
  - `smtp_channel_bindings`：渠道是否绑定传输
  - `smtp_mail_template`：渠道是否有模板
  - `smtp_mail_template_i18n`：站点语种 × 渠道覆盖
- Mail：`app/code/Weline/Mail/extends/module/Weline_SiteSetupAssistant/SetupTask/MailSetupTaskProvider.php`
  - `mail_engine` / `mail_domain` / `mail_dns` / `mail_account` / `mail_smtp_handoff`

## 验收意图

- UT：Collector / Provider / 浮层无硬编码业务 tips
- Browser：后台页可见 Provider 声明的条目与状态；深链可达业务配置页
- 汇审写明：本指令未直接建任务，只建/改了哪些模块的 Provider
