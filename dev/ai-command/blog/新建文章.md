**MCP：跳过**（`content_ops_skills_skip_mcp`）。勿 `prepare_project` / `get_skill`；宿主 Read 本文件 + `Blog/doc/ai/skills/weline-blog-article/`。

**硬触发**：用户要**新建/精写/审查/修**博客或文化长文（含把入口从搜索改为 `/blog/{slug}`）→ 立即执行本指令 + `weline-blog-article`。店面商品 PDP 卖点楼层 → 勿误触本指令。

用户提到博客/文化长文的**新建、精写、多语、审查可行性、入口改文章链**时，Agent 必须 Read 并遵守：

1. `app/code/Weline/Blog/doc/ai/skills/weline-blog-article/SKILL.md`
2. 本文件  
宿主薄镜像 `weline-blog-article` 只指路，**不以镜像当 SOP 正文**。

## create（必做）

1. **跳过 MCP**；Read 技能 + `methodology.md`。  
2. **写前上网查证**；落来源表；无来源不下笔。  
3. 开放许可真图 + provenance → `pub/media/blog/...`。  
4. 精写骨架（导语/历史/工艺/纹样/鉴别/当代/要点/References）。  
5. `BlogPostAdminService` 写入 zh + en；分类 `BlogCategoryAdminService`。  
6. 默认站**全部** `language_codes` 真译 locale-packs + upsert；**禁止拉起 Ollama**（用户本回合明确要求除外）。  
7. 入口部件/Catalog：`blog/{slug}` + `@url`（禁止裸 `/blog/...`、禁止 `/search?q=` 冒充文章交付）。  
8. 改主题后清 `ThemeRuntimeCacheCleaner` + `server:reload`。  
9. 探活 + Browser 禁缓存；交付 URL；关 Browser；模块开发日志。

## review（必做）

1. Read `review-checklist.md`。  
2. 对目标文逐项 pass/fail/n/a。  
3. 结论：**可发 / 需补 / 不可发** + 补救清单。  
4. 用户说「修」→ remediate；禁止只点评。

## 汇报模板（硬）

### create

- 模式 / slug 列表 / 分类  
- 来源表路径  
- 语种覆盖（默认站 codes 勾选结果）  
- 入口是否已改文章链  
- **交付地址**（每篇 Markdown 可点 URL）  
- 汇审一句

### review

- 结论档  
- 检查表摘要（fail 项）  
- 补救优先级  
- 若已 remediate：交付地址
