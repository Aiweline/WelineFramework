## Agent 必做

1. 冷启动；Read 技能 + 本指令。  
2. 解析 URL / product_id。  
3. `codes = Website::getLanguageCodes()`（+`''`）→ **打印全表**。  
4. **检测**各启用语：`name` / `description`（§6.0 字段）/ 其它本品 locale 文案 → 缺口表。  
5. 缺口 **字段级真译**落盘（自模型；禁无明示启 Ollama）。  
6. 验收：≥1 非中英 `/{locale}/product/` 禁缓存；正文非英非中（专名除外）。  
7. 汇报（标明 **子·翻译优化**）。
