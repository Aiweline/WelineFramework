### 顾问决策（父必写进子 prompt）

默认：`ai_full_model=approved`——**衣锁死本品**（`reference_image_paths`=原图/1688；禁改衣），只换人+景；覆盖 main+gallery+**variant**+详情含人。  
落盘后 **必须新 `object_key`（如 `ai-lock-{sha16}.webp`）+ 升 revision**——同路径覆盖会因 `/pub/media` `immutable` 一年缓存让买家仍见旧图。  
交付图终态 **WebP** + 按展示尺寸压缩（长边 ≤1600px、单图 ≤250KB；不放大）；原图只作 reference，**禁止**直上页面或交大 PNG/JPG。  
目检：衣=原款；HTML 含新文件名。改衣或同路径交付 = FAIL。否决时：`ai_full_model=denied`。

权威：`weline-image-pipeline.md` **§0‑B（最短路径）/ §0‑A / §1‑M（含 M6）**。

## Agent 必做流程（父）

1. 跳过 MCP；Read 父技能 + 本指令。  
2. 落盘顾问决策 `ai_full_model=…`（默认 approved）+ **§0‑B 最短路径**。  
3. 跳过规则见父技能；缺口仍派 ①/③；**② 不得仅因 `data-weds` 跳过**——须过详情套件 **§5.2** 与 **§5.4**；含人未换 AI（approved）视为 ①/② 缺口。  
4. **并行启动 3 子智能体**（prompt 含技能路径+硬闸+product_id/URL+顾问决策+§0‑B）。  
5. **审查#1**：按父技能对照表逐槽 PASS/FAIL；槽①抽检含人是否 `ai_full_model`；槽②重点看 Browser 杂志排版 + 含人详情图是否已换；FAIL → 返工写清「槽位 + 技能条款 + 现象/路径」。  
6. 返工回收后，缺项槽重审直至 **审查#1 全 PASS**。  
7. **审查#2**：重新对照表复扫（含抽检主图 AR、含人换图、详情无烤字、`/{locale}/product/`）；FAIL 同样点名返工，直至 **审查#2 全 PASS**。  
8. 交付；关 Browser；开发日志；汇报（必须含两轮审查表 + 顾问决策）。
