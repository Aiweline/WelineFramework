**硬触发**：店面 URL 含 **`/product/`**，且含上述父触发词（或「优化主图+详情 / 整品优化」）→ 立即执行本指令。仅贴链接无优化意图 → 勿误触。

## Agent 必做流程（父）

1. 跳过 MCP；Read 父技能 + 本指令。  
2. 跳过规则见父技能；缺口仍派 ①/③；**② 不得仅因 `data-weds` 跳过**——须过详情套件 **§5.2**（无可见 HTML 杂志排版 / 大图竖墙 = 强制重做）。  
3. **并行启动 3 子智能体**（prompt 含技能路径+硬闸+product_id/URL）。  
4. **审查#1**：按父技能对照表逐槽 PASS/FAIL；槽②重点看 Browser 是否「左右栏+双列+文图交错」而非「一张大图从上到下」；FAIL → 返工 prompt 写清「槽位 + 技能条款 + 现象/路径」。  
5. 返工回收后，缺项槽重审直至 **审查#1 全 PASS**。  
6. **审查#2**：重新对照表复扫（含抽检主图 AR、详情无烤字、`/{locale}/product/`）；FAIL 同样点名返工，直至 **审查#2 全 PASS**。  
7. 交付；关 Browser；开发日志；汇报（必须含两轮审查表）。
