## Agent 必做流程（子）

1. 冷启动；Read **子技能** `ecommerce-detail-suite/SKILL.md`（冲突以子技能+图管线为准；必读 **§5.2 / §5.2‑D / §5.3 / §5.4 / §5.5**）。  
   **同回合必 Read 设计三件套**：`frontend-design`（审美细节）+ `ui-ux-pro-max`（风格质感）+ `interaction-design`（交互）；任一读不到 → 改读仓内 `companions/hanfu-brand-tonality.md` 兜底，不得空手交稿。  
2. 解析 URL / product_id / 详情 HTML。  
3. **跳过闸（严重）**：有 `data-weds="xq"` / `<!--weds:xq-->` **不够**；必须再跑技能 **§5.2 A+B+D**（结构 + Browser≥640 可见排版 + **contain 不裁脸**），并对照 **§5.3**（Flex/Grid 意图、文字安全、行宽、**三件套质感**）与 **§5.4**（滚轮入场、高级感、品牌感、**interaction-design**）。仅全 PASS 且无强制 → 可跳过。不认 1688。  
   **强制 / 自动强制**：`强制重做` / `--force` / 点名糊图·相册·**没有任何排版**·**排版太弱**·**没有布局效果**·**全是大图**·**一张大图从上到下**·**被裁减**·**裁脸**·**翻译没做**·烤图仍 JPG·**诗句侧栏**·**文图拼版**·**竖排烤字**·**原创声明**·**设计灵感**·**抄袭盗版烤字**·**布局太单一**·**没用上排版**·**没动画**·**滚轮没效果**·**没有高级感**·**没有品牌感**·**页面死板**；或 **§5.2/5.2‑D / §5.4 / §3.2‑C FAIL**（即使已有 `data-weds`）→ **必须重做详情 HTML 杂志排版（含动效+三件套+烤字清板）**（可 `--skip-images` 仅调图文）。  
4. **详情图+正文**（先图后排版）：信息烤图 textify；**§3.2‑B / §3.2‑C**；**含人→§1‑M（衣锁死+只换人景+M6 URL bust；与画廊同一套衣）**；静物 outpaint/HD；**源图本身糊（宽 < 页面 CSS 宽 ×1.5）→ 图管线 §3「升清实做」**（更大源 → Real-ESRGAN → 2× LANCZOS+USM）**并换新 object_key**，糊图直上 = FAIL；卖点；**§五 + §5.2/D/5.3/5.4**；多语：  
   - **仅本指令触发** → 仍须按套件 §六字段级真译；  
   - **由父产品优化派发** → 版式/`data-weds` 本槽负责；启用语**检测与补全**以父槽 ③「翻译优化」为准（本槽不得阻拦并行，也不得宣称已代替 ③）。  
   闸过才写 `data-weds`（父并行时：与 ③ 对齐后再写，或本槽写结构后由 ③ 补译再确认标记）。  
5. 验收：交付 URL；**Browser 禁缓存**确认杂志排版、**诗侧栏/feature 不裁脸**（`objectFit===contain`）、**滚轮可见 ≥3 楼层入场**、观感非排版太弱；**§5.5‑E 剥壳自检**（curl 渲染 HTML 数关键 class，源码有而店面为 0 = FAIL）；改过 `product-info.phtml` 须清 **`view/tpl`**；父任务时须等 ③ 完成 `/{locale}/product/`；关 Browser。  
6. 日志；汇报（标明 **子·详情优化②**；须含 `排版闸§5.2/D：PASS|FAIL` · `§5.4动效：PASS|FAIL` · `§5.5剥壳：class 存活 n/n` · `三件套：frontend-design+ui-ux-pro-max+interaction-design|缺失(仓内基线兜底)`；若未跑父图/翻译写明）。
