# 技能与角色索引（宿主 `~/.agents/skills/`）

> **用途**：把宿主扁平的技能库按 **工程团队席位 / OPC 角色 / 工具箱** 归类，并给出第一层路由映射。
> **宿主发现约束（HARD）**：加载器对每个根做**单层扫描**——每技能目录必须直接含 `SKILL.md`，不递归。因此技能**禁止**物理搬成嵌套子目录；本文件用「前缀分组 + 分类表」承担归属与导航。
> **第一层路由**：见 [意图路由.md](./意图路由.md) §0（先判意图；路由到运营/内容 → 禁止碰 `app/code/**` 业务码）。

## 6. 消歧与组合规则（匹配器 `McpSkillCatalog::resolve`）

**打分**：触发词按具体度加权——泛词（≤2 字）0.30 / 一般（3–4 字）0.50 / 专有长词（≥5 字）0.70；纯 ASCII 触发词按**词边界**匹配（`ui` 不命中 `build`）；名称 0.85、技能 id 0.90、整句命中 1.0。

**组合（bundle）**：命中施工面时补齐同组技能，兜底分 **0.60**（高于泛词、低于专有长词）；已由触发词命中但分低者抬到 0.60；同分时**直接触发优先于组合补齐**。

| 触发组合 | 必选（bundle 补齐） |
|---|---|
| 模板/`phtml` + 文案/翻译 | `template_i18n` |
| 翻译/文案/i18n/CSV/语言包 | `module_i18n_csv` |
| 露中文/露英文/英文环境/漏译 | `translation_engineer` |
| 后台/管理页/管理后台 | `frontend_development` + `taglib_ui_control` |
| 列表/表单/筛选器 **且** 带后台语境 | `frontend_development` + `taglib_ui_control` |
| 部件/widget/轮播 | `frontend_development`（部件本体仍由 `widget_development` 主导） |
| 主题/CSS/样式/颜色/间距/排版/token | `design_taste` |

**消歧**：

- **i18n 按产物分流**：改 CSV/语言包 → `module_i18n_csv`；模板文案与 `__()`/`@lang` → `template_i18n`；英文环境露中文/漏译巡检 → `translation_engineer`。三者可同时进场，按产物定主次。
- **部件**：`widget_development` 主导部件本体，`frontend_development` 是基座（版心/Token/BinQuery），不是替代。
- **席位名双命中不算碰撞**：`文档工程师`、`数据分析`、`API席` 等同时命中 `engineering_team` 与专席，属**预期双命中**（团队 + 专家都要加载）。
- **负向词**：用户明确说「不要翻译 / 无需翻译 / 不用翻译 / 不需要翻译 / 无需 i18n / 不改文案」时，三个 i18n 技能整体不进候选（`exclude_triggers`）。

**回归**：`php app/code/Weline/Ai/Mcp/tests/skill-routing-accuracy.php`（金标集 23 条原话，断言 top-6 覆盖 + 首位归属 + 负向排除，覆盖率门禁 ≥90%）。
