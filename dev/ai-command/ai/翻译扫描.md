# MCP 指令：翻译扫描

**触发格式（硬 · 必须指定站点）**

```text
扫描翻译：{站点}
扫描翻译 {站点}
翻译扫描：{站点}
线上扫描翻译：{站点}
```

示例：`扫描翻译：长安汉服` / `扫描翻译 changanhanfu` / `translation scan: daocharms`。

**站点必须指定。** 无可解析站名 → **禁止开爬**，追问：例「扫哪个站？`扫描翻译：长安汉服`」。  
分隔符：`：` / `:` / 空白均可。

---

## 目标（硬闭环）

对**点名站**做线上漏译爬取，并**当场译修**：

1. **随机**选用该站一个**非默认**已启用 locale 做扫描语种（见下「扫描语种」）
2. 非动态路由全扫；动态路由每类只抽 1 条
3. 找出问题词（该 locale 页仍露出中文 UI/导航等源串）
4. **立刻**把每个问题词译成该站**全部已启用语种**并落盘（不得只扫不译、不得只译扫描语种）

## 扫描语种（硬 · 随机非默认）

1. 解析**该站**已启用 `language_codes`（线上扫描 → 该站生产/源站库；本机柜站无生产 → 本机对应 website）。  
   - 始终把 `zh_Hans_CN` + `en_US` 纳入「全语种译修」集合（站未启用 en 也保留基线）。
2. **默认语种** = 该站 default / 基线简中（通常 `zh_Hans_CN`）。  
3. **扫描语种** = 从「已启用且 ≠ 默认」的 locale 中 **随机抽 1 个**（如 `bn_BD`、`hi_IN`、`ar_SA`…）。  
   - 用户本回合**显式点名**某 locale → 用该 locale（仍须 ≠ 默认；若点名默认语种则改抽一个非默认并说明）。  
   - 若站只有默认语种、无法抽非默认 → **停止扫描**并报告，禁止用默认中文页假装漏译巡检。
4. 报告头必须写：`scan_locale`（本次随机/指定）+ `site_locales`（全量译修列表）+ 随机种子说明（可选）。

**禁止**固定死只用 `en_US` 或会话附图语言而不随机（除非用户显式指定扫描语种）。

---

## 执行步骤（硬顺序）

1. **解析站点** → Read README → 定公网 Host。  
2. **拉该站语种列表** → 定默认语种 → **随机**选 `scan_locale`（非默认）。  
3. **探活** Host；用 `/{scan_locale}/…` 爬：  
   - sitemap 该 locale 分片 + 静态壳全量  
   - 动态每类 1 URL  
4. **抽问题词**（可见文案 + `aria-label` / `placeholder` / `data-i18n-*` / 内嵌 copy）：  
   - 汉字 UI/导航/空态等 → 问题源串（中文 source）  
   - 白名单：品牌专名（「汉服」「长安汉服」等）；**禁止**把「零售车」「继续购物」「登录」等 UI 当白名单  
5. **分层报告**落盘：`dev/tmp/translation-scan-{site}-{scan_locale}-{YYYYMMDD}.md`  
   - A 导航壳 / B chrome UI / C 机制性 / D CMS / E 噪声  
6. **全站全语种译修（硬 · 与扫描同回合）** — 对去重后的每个问题源串：  
   - 译出 `site_locales` **每一个** locale 的真实译文（第二列/展示 ≠ 中文 source）  
   - **模块 `__()` / 模板源串**：中英写所属模块 `i18n/zh_Hans_CN.csv` + `en_US.csv`；其它 locale → **系统词典**（`LocaleDictionary` / import + `publishLocale`）；改 CSV 后 `php bin/w i18n:collect {Module}`  
   - **导航/CMS/实体文案**：写入该内容归属的 locale 字段/词典路径（禁止新建非中英模块 CSV）  
   - **机制性漏译**（如 API label 中文塞进已译模板）：除词条外须修机制（或记入报告并同回合能修则修）  
   - Agent **直接译写**；**未要求禁止启动 Ollama**  
7. **抽检**：用 `scan_locale` 再打开 ≥1 问题页，确认问题词不再露中文；另抽 ≥1 个非中英、非 scan 的 locale 抽检词典/展示。  
8. **生产写入**：仅当用户明示部署/改线上时；默认译修落**本机仓** + 词典，报告待部署项。禁止未备份改生产。
