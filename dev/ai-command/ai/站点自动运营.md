# 指令：运营某个站点（站点自动运营）

**触发词（任一即执行）**

- `运营某个站点`
- `运营 <站点名|域名|slug>`
- `自动运营 <站点>`
- `每天更新 5 篇博客`
- `站点自动运营`
- `daily site ops`

技能：`~/.cursor/plugins/local/my-opc-os/skills/opc-site-autopilot/SKILL.md`
（宿主镜像 `~/.agents/skills/opc-site-autopilot` → 同路径）。
工作流：`~/.cursor/plugins/local/my-opc-os/skills/my-opc-os/references/workflows/site-daily-ops.yaml`。
MCP：本指令属运营/内容，**跳过** `prepare_project` / `resolve_skill` / AOCI；宿主直接 Read 技能与站柜文件。

---

## 做什么（首次 = 建自动化）

1. **解析站点**：`~/OPC/sites/registry.md` 唯一匹配 → `local_path`（`python3 ~/OPC/scripts/_opc_resolve_site_root.py "<站点>"`）。不在册先登记，禁止猜。
2. **建站级配置**：`{local_path}/opc/daily-ops/config.json`（授权范围/数据源/发布通道/约束）
   + `{local_path}/opc/playbooks/site-daily-ops.md`（按模板实例化）。
3. **装定时**：
   `~/.cursor/plugins/local/my-opc-os/scripts/install-site-daily-ops-launchd.sh install --site <slug>`
   （先 `--dry-run`；默认每天 `09:00` Asia/Shanghai，mode=formal）。
4. **跑首轮**：`~/OPC/scripts/site-daily-ops.sh --site <slug>`（用户说「明天开始」则跳过）。
5. **登记**：`~/OPC/sites/registry.md` 该站 notes + `opc/reports/YYYY-MM-DD-site-autopilot-setup.md`。

已建站时的管理口令（查看/改时间/暂停/恢复/补跑）见技能 §3。

---

## 每日闭环（OPC 全员 · 一角色一真子智能体）

需求挖掘**恰好 5 个**用户痛点 → 发布 **5 篇**博客并逐篇公开核验 → 读本站 **GSC + GA4**
（已登录外部 Chrome，复用不新连、不抢焦点）→ 有数据启发才优化（`evidence_gate.verdict=pass`）
→ 当日运营需求复核 vs 站点（数据支撑的改站评估）→ 报告（Money 置顶）+ `status.json run_complete=true`。

---

## 硬规则

- 一角色一真子智能体；`02_invocation_trace.json` 缺 `subagent_id` 本轮作废。
- 禁造数：GSC/GA4/SERP/需求热度要么真实取回（带 `retrieved_at`/`source_urls`），要么 `n/a`/`blocked`。
- **所有改站必须有数据支撑**；无 gate pass 禁止改站/主题/站柜；`app/code/**`、主题结构/模板/路由一律交 `R_obc_pm`（OPC 只做内容级）。
- `mode=simulate` 或 `authorization.daily_blog_publish=false`：只产草稿+提案，禁发布/禁改站（`posts_published=0`）。
- 外部社媒/邮件/付费永不自动；站内博客发布按用户授权（config.authorization）。
- 幂等：同日 `run_complete=true` 不重跑；禁止一日重复发博客。
