# 意图车道路由（顶层）

> 脊柱总览见 **[AI流程总览.md](./AI流程总览.md)**（闭环=真机验收）。  
> 硬规则：`intent_lane_router` → 再 `requirement_engineering_grade_gate`。  
> 插件：`weline-lane-router`（`/lane-route`）· `lanes.yaml`。

## 日常入口（先对这句话）

机器目录：插件 `references/lanes.yaml` 的 `entries` + 各 lane `skill_pack`。  
判完只 Read `load_now`；`load_when` 命中再开；`skip` 禁止打开。

| 你说 | entry | lane | 立刻打开 | 不要打开 |
|------|-------|------|----------|----------|
| 编码 / 改代码 | `coding` | `engineering` | `prepare_project` + AOCI；组队才开工程团队。主题/支付/部件等席位技能命中该面再开 | OPC / 社媒全树 |
| 部署 / 上线 / 站柜 | `deploy` | `website_ops` | `weline-website-deploy` + `websites/SKILL.md` + 该站 README | AOCI、OPC（改码切片才切工程包） |
| 运营 / 社媒 / 注册 | `ops_social` | `opc_obc` | `my-opc-os`；社媒再加 `social-content` | AOCI、`prepare_project`、工程团队 |
| 运营某个站点 / 自动运营某站 | `site_autopilot` | `opc_obc` | `opc-site-autopilot`（建/管每日自动化）→ 再 `my-opc-os` + `site-daily-ops` | AOCI、工程团队、内容技能全树 |
| 产品 / 详情 / 主图 / 文章 | `content` | `content_ops` | 命中的那一个内容技能 | MCP、AOCI、OPC |
| 闲聊 | `chat` | `chat` | 无 | 技能正文 |

交叉只此两处：运营要改框架 → `R_obc_pm` 交接后才加载工程包与 AOCI。编码里项目经理/电商顾问要做运营设计再交技术 → 只加 `obc-project-manager`，不预载 OPC 全树。

## 目录 → handoff

| lane | 入口 | 闭环 |
|------|------|------|
| `engineering` | `weline-engineering-team` + `prepare_project` + AOCI | 真机 UC / WB-OP / 正式 e2e |
| `opc_obc` | `my-opc-os`（无 AOCI） | 运营证据；改框架 → `R_obc_pm` → 工程双层真机验收 |
| `content_ops` | Read `dev/ai-command/**`（跳过 MCP / AOCI） | 内容技能自验 |
| `website_ops` | `weline-website-deploy`（默认无 AOCI） | 站柜探活 +（授权后）线上复验 |
| `chat` | — | 无交付 |
