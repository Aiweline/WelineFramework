# MCP 指令：提取技能

**触发词（任一即执行）**

- `提取技能`
- `list skills`
- `mcp skills`
- `技能列表`
- `技能索引`

用户只要**提到**上述触发词，Agent 必须把本文件当作硬指令执行：从各模块 `doc` 技能目录/索引提取开发技能到 MCP 技能目录，并**列清楚全部技能与指令**。

会话打招呼 `hi` / `你好` / `hello`（且无编码任务）时，同样输出 MCP 技能 + 指令清单（见硬约束 `greeting_lists_mcp_skills_and_commands`）。

---

## 工作原理

1. **Workflow 技能**：由 MCP `GuidanceWorkflowCatalog` surfaces 编译（如 `frontend_development`、`webui_browser_closeout`、`requirement_clarify_use_case`）。
2. **模块 doc 技能**：只读扫描（**不写**仓库 Skill 投影，不复活 `auto_generate_skills`）：
   - `app/code/{Vendor}/{Module}/doc/ai/INDEX.json` → `skills[]`
   - `app/code/{Vendor}/{Module}/doc/ai/skills/*/SKILL.md`
   - 有 `doc/AI-INDEX.md` 但无 file-backed skill 的模块 → MCP 内存合成 `doc-index:{module}` 定位技能
3. **指令清单**：扫描 `dev/ai-command/**/*.md`（含本文件、`审图.md`、`需求澄清与用例规格.md` 等）。
4. 结果进入 `prepare_project.agent_guidance.mcp_skills`，并用 `resolve_skill(list_all=true)` / `task=提取技能` 列出。

---

## Agent 必做流程

1. 工程会话：`ensure-project-guidance` → `prepare_project`（读 `agent_guidance.mcp_skills`）。
2. 调用：

```text
resolve_skill(repository=…, readiness_id=…, client_session_id=…, list_all=true)
```

或 `task=提取技能`。
3. 面向用户输出两节（必须完整）：
   - **MCP 技能**：按 `kind` 分组列出 `skill_id` / `name` / `module` / `path`（workflow + module_doc / module_ai_index）。
   - **MCP 指令**：列出 `dev/ai-command` 下每条指令的标题、触发词、路径。
4. 需要正文时再 `get_skill(skill_id=…)`。
5. **禁止**：把结果写回仓库 `doc/ai/skills` 投影；禁止借本指令改业务码（仅列技能/指令目录）。
