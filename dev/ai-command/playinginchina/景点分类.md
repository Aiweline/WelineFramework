# 指令：PlayingInChina 景点分类

**站点专属**（海外玩中国 / PlayingInChina）。  
权威技能（Git）：`dev/ai-command/playinginchina/SKILL.md`  
主题本地镜像（可能 gitignore）：`app/design/Weline/playinginchina/doc/ai/skills/playinginchina-destination-classify/SKILL.md`

**触发词（任一即执行，无需再确认范围）**

- `景点分类`
- `线路主题分类`
- `主题旅行分类`
- `整理未分类景点`
- `丝绸之路分类`

- `classify destinations`

用户只要**提到**上述触发词，Agent 必须把本文件 + 权威 SKILL 当作硬指令执行：扫描并整理 **没有主题标签** 的景点，重建 style / region / flagship 索引。  
**不要**只口头解释；**不要**套用 `产品分类修复`。

---

## Agent 必做流程

1. **Read** 权威 SKILL（上表路径）+ 本指令。
2. Dirty-load：
   - `app/design/Weline/playinginchina/data/destinations.json`
   - `…/data/route-themes.json`
   - `…/data/index-destination-themes.json`
3. 扫描未分类：

```bash
php app/design/Weline/playinginchina/scripts/build-route-themes.php --report-untagged
```

4. **主任务 = 整理未分类**  
   - 缺 region → 补景点 `region` 或扩展 region match  
   - 缺 style → 调 `seed_dests` / `match`，或按类型补 `types`/`scenery` 后重建  
   - 主题旅行（含丝绸之路）变更写进 `build-route-themes.php` 的 `$themes`  
   - 目标：每个景点至少 1×region + 1×style；旗舰包保持精选
5. 重建：

```bash
php app/design/Weline/playinginchina/scripts/build-route-themes.php
```

6. 抽检 ≥3 个新挂靠点 + 丝路锚点（`mogao-caves` / `terracotta-army` / `potala-palace`）。
7. `doc/开发日志.md` 记数字。
8. 汇报：`total / tagged / untagged / rescued` + 样例；未改店面 UI 勿宣称页面已展示。
