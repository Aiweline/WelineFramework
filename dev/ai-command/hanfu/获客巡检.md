## Agent 必做流程

1. **Read** 权威 SKILL（上表路径）+ 本指令。
2. **判档**：读 `~/Documents/HanfuLeadOps/state.json` 与当前时间，判定 A / B / C 档。
   - A 档（09:00、21:00）→ 全量挖掘
   - B 档（其余整点）→ 只查回复，不做新检索
   - C 档（周一 09:00，并入 A）→ 额外跑海关名录 + 失效升级
3. **读状态**：`leads.jsonl`（去重基线）+ `state.json`（阻塞项、策略、计数器）。
4. 按档执行 SKILL 的对应步骤；每条候选按 5 轴打分，**≥6 才触达**。
5. **触达前查通道**：MailMaster `Account` 表是否含 `contact@changanhanfu.com`。
   不可用 → 写 `outbox/` 草稿并标 `blocked:sender`，**只首次上报**。
6. 写回 `leads.jsonl` + `state.json`，`runs_total` 递增。
   入库 `w_ai_acquisition_lead` 时 **`entry_channel` 必须为 `skill`**（获客技能录入，见 SKILL「录入渠道标记」）；不得写成 `default`、不得覆盖已有的 `browser_model` / `ai_select`。
7. 有实质变化才发简报；无变化静默。
8. `consecutive_zero_runs` 达 3 → 换策略；达 6 → 暂停挖掘并要 ICP。

## 关键约束（易错点，务必遵守）

| 易错点 | 正确做法 |
|---|---|
| 用通用网页搜索找买家 | 从 Reddit RSS / Alibaba RFQ / `site:` 定向检索起手 |
| Reddit 用默认 UA | 必须带浏览器 UA；默认 UA 与 `/search.json` 均 403 |
| 「必须出现汉服二字」才合格 | 改 5 轴打分，相邻品类（旗袍/中式婚礼/古装 Cos）计 1 分 |
| 把供应商营销页当线索 | 一律排除：Alibaba / 1688 / newhanfu / accio / 目录站 |
| 怀疑 `contact@changanhanfu.com` 不存在 | 口令指定 + 自有邮局，**权威，不得替换** |
| 连续零产出仍原样重跑 | 3 轮换策略，6 轮暂停并要 ICP |
