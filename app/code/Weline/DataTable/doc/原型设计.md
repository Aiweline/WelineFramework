# DataTable 原型设计与响应式验收

## 设计原则

DataTable 是高密度后台工作组件，不建立独立视觉系统。颜色、间距、字号、圆角、边框和状态全部来自 Weline Theme token；组件沿用 `w-button`、`w-input`、`w-select`、`w-dialog`、`w-table`、`w-pagination` 和 `w-icon`。

信息顺序固定为：主动作与配置 → 全局搜索 → 导出与统计 → 筛选 → 表头/数据 → 摘要、每页数量与分页。加载期间设置 `aria-busy` 并禁用动作；错误使用 `role=alert`；普通状态和计数使用 polite live region。

## 关键状态

| 状态 | 可见结果 | 可操作性 |
|---|---|---|
| loading | 状态条显示加载文案，表体降低强调 | 所有表格动作和分页选择禁用 |
| ready | 表头、数据、统计和分页一致 | 仅服务端 capability 允许的动作出现 |
| empty | 解释暂无数据，并提示刷新或在有权限时新增 | 刷新仍可用 |
| filtered-empty | 明确没有匹配搜索/筛选条件 | 搜索、筛选重置可用 |
| error | danger token 状态条、`role=alert`、toast | 原筛选值保留，可重试 |
| write-plan blocked | 全字段计划仍展示，缺失必填集中提示 | 确认按钮禁用，返回修改 |
| write-plan ready | 展示步骤、资源、字段、依赖、事务范围、有效期 | 确认只可触发一次 |

## 响应式规则

### 1440 px（宽屏桌面）

工具栏同一视觉行组织动作、搜索、导出和统计；表格保持数据密度，操作列 sticky end，选择列 sticky start。字段配置和写入计划使用中/大号 dialog。

### 1024 px（小桌面/横屏平板）

工具栏允许换行，搜索占完整下一行；单元格间距从 `space-4` 收紧为 `space-3`。表格仍使用横向滚动，不把每一行强制转成卡片，避免破坏列比较。

### 768 px（平板）

工具栏与 footer 改为单列网格；统计分布到可用宽度；分页与每页选择左对齐并可换行。表单字段从双列变单列。

### 375 px（手机）

工具栏使用紧凑 token 间距，点击目标最小高度 2.75rem；筛选控件、每页选择占满宽度；计划元数据和字段从两列改为单列。表格本身横向滚动，sticky 操作列不得遮挡正文。

## 键盘与可访问性

- 表头排序使用原生 button 和 `aria-sort`；Shift+点击可多列排序。
- 行可聚焦，ArrowUp/ArrowDown 在当前页逐行移动。
- pagination 使用原生 button，当前页设置 `aria-current=page`。
- dialog 继续由 Weline UI 管理焦点；写入计划打开后焦点落到确认按钮。
- 所有交互控件用主题 primary focus ring；`prefers-reduced-motion` 下关闭平滑滚动依赖。
- 不用颜色作为唯一信息：警告、错误、缺必填和变更都带文字。

## 字段配置与列组合

字段配置是次级工具动作，但在允许配置的表格上必须始终可发现。显示字段列表为每个已选字段提供“独立显示 / 合并到…”选择：

- 主字段使用正文层级，合并的辅助字段使用较小的 muted 标签和值。
- 辅助字段可逐一解开并恢复独立列；重置恢复全部默认列。
- 375/768 下合并选择器换行占满可用宽度，1024/1440 下与字段名和排序按钮同排。
- 合并是浏览器显示偏好，不改变排序、筛选、导出、写入或 API 数据结构。
