# DataTable 特殊用法：本地模式 / 勾选 / 操作列悬浮

> **AI 硬约束入口。** 涉及 `mode="local"`、`selectable`、`sticky-actions`、`row-actions`、表头 `type="image"` 时，必须先读本文，再改模板或抄业务页。  
> 证据源：`Taglib/Table.php`、`view/statics/js/datatable-manager.js`、`view/statics/js/datatable-common.js`。  
> 业务参考（只读范例，勿当通用 CRUD 模板）：`Weline_Product` → `view/templates/backend/catalog/index.phtml`（商品列表）。

## 两种模式怎么选

| 模式 | 何时用 | 数据从哪来 | 能否增删改 |
|---|---|---|---|
| **api（默认）** | 标准 Model CRUD、REST 分页筛选、弹窗/行内编辑 | `Weline.Api` → DataTable REST | 可以（`editable` / `modal-edit`） |
| **local** | 服务端已算好行数据；分片表/`forWebsite` 模型；只要展示+勾选+链接操作 | `<script type="application/json">` + `local-data-el` | **不要**开 CRUD；关掉 `editable`/`modal-edit` |

**默认永远用 api。** 只有「模型不能直接 `w_obj(Model)->select()`」或「行里已有派生字段（如主图 URL）」时才用 local。

## local 模式契约（必遵）

### 必写属性

```phtml
<script type="application/json" id="my-local-rows"><?=
    json_encode($rows, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_HEX_TAG | JSON_HEX_AMP) ?: '[]'
?></script>

<w:d-table
    model="Vendor_Module\Model\SomeModel"
    scope="unique-scope-id"
    mode="local"
    local-data-el="#my-local-rows"
    editable="false"
    modal-edit="false"
    inline-edit="false"
    show-toolbar="false"
    show-config="false"
    show-pagination="false"
>
    <w:t-header>
        <!-- 列必须在源模板里写死；禁止 PHP foreach 生成 <w:field> -->
        <w:field belong="t-header" name="sku" sortable="true">SKU</w:field>
    </w:t-header>
    <w:t-body></w:t-body>
</w:d-table>
```

说明：

1. **`model` 仍必需**（Taglib 校验），但 local 下 **不会** 用它拉 REST 数据；仅作声明/兼容。分片 Model 也可以写，只要不指望自动字段发现。
2. **`scope` 全局唯一**，禁止复制粘贴同一 scope 到多个页面。
3. **`local-data-el` 指向 JSON `<script>`**，用 `JSON_HEX_TAG|JSON_HEX_AMP`；禁止把大 JSON 塞进 HTML 属性。
4. **表头字段必须在 `.phtml` 源码静态写出**。Taglib 在编译期解析 `<w:field>`，运行时 `foreach` 拼出来的标签 **不会生效**。
5. local 下列表 **不要** 开 `editable` / `modal-edit` / `inline-edit`（否则会去调 Model CRUD API，分片/派生行会炸）。
6. 改完 `view/statics/js/*.js` 后必须 `php bin/w resource:compile welineUi`，否则线上仍是旧 bundle。

### 勾选列

| 属性 | 含义 |
|---|---|
| `selectable="true"` | 首列勾选；表级 `data-w-sticky-start` |
| `select-field="product_id"` | checkbox 的 value / `data-record-id` 字段名（默认 `id`） |

已选数量：页面上放 `[data-w-datatable-selected-count]`，DataTable 会同步数字。

### 操作列悬浮 + 自定义链接

| 属性 | 含义 |
|---|---|
| `show-actions="true"` | 强制显示操作列（即使关闭 CRUD） |
| `sticky-actions="true"` | 末列悬浮（默认 true；配合 foundation `data-w-sticky-end`） |
| `row-actions='[...]'` | JSON 数组；`type:"link"` + `hrefTemplate` 占位 `{field}` |

`row-actions` 示例（属性值需 `htmlspecialchars`）：

```json
[
  {
    "type": "link",
    "label": "编辑",
    "hrefTemplate": "/backend/.../edit?website_id=0&product_id={product_id}",
    "testId": "product-edit-button",
    "icon": "edit",
    "tone": "primary",
    "variant": "outline"
  }
]
```

`hrefTemplate` 里的 `{product_id}` 会按行字段替换并做 `encodeURIComponent`。不要手写第二套悬浮 CSS。

### 主图列（防破裂图）

表头：

```phtml
<w:field belong="t-header" name="main_image" type="image" width="64">主图</w:field>
```

行为（`datatable-common.js`）：

- 仅 `http(s):` / `blob:` / `data:` 视为可展示 URL。
- 空值或加载失败 → 内置 SVG 占位，**禁止**留给浏览器显示破裂图标。
- 业务侧若已有相对路径且无主题/媒体基址，应在塞进 local JSON **之前** 清空或换成绝对 URL（参见商品列表的 `displayableImageUrl`）。

## 明确禁止（AI 反例）

1. **禁止** 对分片 Model / 需 `forWebsite()` 的表直接用默认 api 模式指望 `DataTable::postData` 能查到数据。
2. **禁止** local 模式仍保留 `modal-edit="true"` / 工具栏「新增」去打 REST。
3. **禁止** 用 PHP `foreach` 动态输出 `<w:field belong="t-header">`。
4. **禁止** 手搓 `position:sticky` 操作列，绕开 `sticky-actions` / foundation sticky。
5. **禁止** 把 local JSON 写进 `row-actions` 或任意超长 HTML 属性。
6. **禁止** 只改 `DataTable/view/statics/js` 却不跑 `resource:compile welineUi`。
7. **禁止** 把商品 catalog 页整段复制成「所有后台列表」模板；先判断该不该用 api CRUD。
8. **禁止** 为「好看」给每张表都开 `selectable`；没有批量语义就不要勾选列。

### 编译注意（动态属性）

`w:d-table` 上若出现 `row-actions="<?= ... ?>"` 等**动态属性**，模板会走 **runtime** 编译。Framework 已保证 `OwnsChildCompilation` 父标签收到**原始** `<w:t-header>` 子源码（先建立 table 上下文再编译子标签）。若仍出现 `t-header标签必须指定model属性或位于d-table标签内`，先清模板缓存并确认 Framework `CodeGenerator` 已带 OwnsChildCompilation 运行期修复；不要靠给每个 `t-header` 手写 `model` 糊弄过去。

## 与 foundation 表格的关系

- DataTable 根上仍是 `table.w-table`，悬浮依赖 Theme foundation 的 `data-w-sticky-start` / `data-w-sticky-end`。
- 纯展示且无 DataTable 交互时，可只用 `w-table` + sticky 属性；**一旦**需要勾选同步、本地 JSON、row-actions、image 占位，用 `w:d-table`，不要平行发明第三套表格。
