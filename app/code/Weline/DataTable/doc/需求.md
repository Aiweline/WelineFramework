- 来源与确认：2026-08-28，用户要求字段配置可将 B、C 合并显示到 A，并明确“只是显示，和数据没关系”“合并也能解开”。
- 业务边界：合并仅影响浏览器单元格布局；源字段、查询、排序、筛选、导出、表单、API 和数据库保持不变。
- 交互：辅助字段可选择任意独立主字段作为显示目标；选择“独立显示”立即解除；重置恢复所有默认独立列。
- 安全与兼容：偏好按表格 scope/id 保存在浏览器；默认无合并，旧表格渲染完全兼容；禁止链式与循环合并。

### `REQ-DATATABLE-0004` 至 `REQ-DATATABLE-0008` 统一后台 DataTable

- 来源与确认：2026-08-27 至 2026-08-28，用户要求审查并完善框架 DataTable，符合主题 UI、响应式完整，作为后续后台管理统一组件。
- 业务边界：Taglib 只声明 UI 与稳定资源；默认 Provider 只服务显式注册 Demo 资源。业务模块通过自己的 QueryProvider 和 ACL 接入，禁止浏览器用 PHP 类名或 adapter 类名获得通用 CRUD。
- 写入规则：多模型默认事务；提交前必须生成完整安全字段计划，缺必填不签发 token；确认后载荷摘要必须一致，token 单次使用；显式 `write-order` 不能违背依赖拓扑。
- local 规则：只读，浏览器内搜索/字段筛选/稳定多列排序/分页；偏好仅 localStorage，不调用远程配置、CRUD 或导出。
- UI 规则：只使用 Weline Theme token；加载时禁用动作；错误使用 alert live region；空状态可行动；键盘可排序、翻页、逐行移动；保留横向滚动和 sticky 操作列。
- 验收证据：DataTable PHPUnit 80/80、653 assertions；隔离 SQLite 集成与当前配置 PostgreSQL 均验证依赖回填、单次 token、载荷绑定和第二步失败回滚；`resource:compile welineUi` 与 section 规范检查通过；专用 WLS 的公开 Demo、local 搜索/筛选及 375/768/1024/1440 截图通过。后台 DataTable 路由能进入 ACL 登录重定向，但当前 `Weline_Admin` 登录 URL 返回 404，因此计划 dialog 的后台可视点击证据保持 blocked，不用服务层或单元证据冒充。
