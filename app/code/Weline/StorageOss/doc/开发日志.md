# Weline_StorageOss 开发日志

## `1.0.1` — 当前代码基线

- 模块通过 `storage.driver_provider.oss_aliyun` 发布 `AliyunOssProvider`。
- 当前源码包含 OSS Driver、URL Adapter、SDK Client Factory、multipart 上传与清理债务处理。
- Provider 将凭据字段声明为 secret，并在创建磁盘时解析 Request/Fiber 作用域资源，避免常驻 Worker 持有请求资源。
- 本次 `Weline_Ai 1.2.0` 迁移仅补齐长期知识文档，不改变 OSS 运行时、配置、数据库或发布状态。

## 验证状态

- 文档事实已按 `etc/module.php`、`composer.json` 和当前源码入口复核。
- 本次未连接真实阿里云 OSS，也未执行上传、签名 URL 或 multipart 清理的外部验收；这些能力仍须在配置好的隔离环境验证。
