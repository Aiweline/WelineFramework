- 改动：`TaglibLocalFormService` 通过 `w_query('websites','getWebsiteLanguageCodes')` 解析当前站点关联语言，与已安装激活 Locale 求交集；`buildFormPayload` / `aiTranslate` / `isFieldFullyTranslated` 共用该边界；站点无关联语言时禁止回退全量目录。
- 契约：`TaglibLocalFormServiceContractTest`、`TaglibLocalFormServiceBulkTranslateTest`。
- 文档：`local标签与LocalModel指南.md`、`README.md`。

## 2026-08-28 — LanguageSelect 防 multiple 泄漏

- 现象：网站编辑页默认语言选择器出现可移除标签（多选 UI），保存后回到 `en_US`。
- 根因：同模板前序 Taglib 写入的 `Taglib__multiple` 泄漏；`LanguageSelect` 在属性未声明时仍读取该变量。
- 修复：`AttributeCodeCompiler` 每次编译先清理 `Taglib__*`；`LanguageSelect` 在未声明 `multiple` 时强制 `$Taglib__multiple = false`。
- 契约：`LanguageSelectFieldNameLiteralContractTest`。

## 2026-08-27 — 多语言抽屉跨 iframe 保存

- 现象：父页点「保存」报 `Translation form is unavailable.`，iframe 内表单可见。
- 根因：父窗口对 iframe 内节点使用 `instanceof HTMLFormElement`（跨 realm 恒为 false）；且 `pub/static` 仍在提供旧 JS。
- 修复：`weline-local-translation.js` 改为 `tagName` 识别；表单增加 `data-w-local-form`；同步源文件与 `pub/static` 发布副本。
- 保存 500：`description[locale][field]` 扁平 payload 未还原为数组，导致空 insert；`I18nAdminQueryProvider::normalizeActionPayload()` + JS `assignNestedFormValue()` 修复。
- 保存 500（EAV）：表单 hidden 可能带 `set_id`/`group_id` 等父级别名，LocalDescription 表实际列名为 `id`；`TaglibLocalDescriptionNormalizer` 入库前 remap + 过滤未知列。
- 保存 500（主键）：`w_eav_*_local_description` 误用单列主键 `(id)`，无法按 locale upsert；模型补 composite PK + migration 改为 `(id, local_code)`。
- 保存 500（bin-query）：`taglib-local-save` 不应走 i18n 词典资源变更发布；`invokeController` 改走 `AdminControllerBridge` 以正确识别 JSON 异步请求。
- 契约：`Theme/test/Unit/View/LocalTranslationCrossIframeContractTest.php`、`I18n/test/Unit/Query/I18nAdminQueryProviderPayloadContractTest.php`、`I18n/test/Unit/Service/TaglibLocalDescriptionNormalizerTest.php`。

## 2026-08-28 Local 母本语言星标与空母本反哺

- 指定母本：网站 `default_language`（面板行标 ★）。
- 有效翻译源：母本有内容用母本；母本为空则取站点关联语言中第一个已填语言，反哺其它语言（含空母本）。
