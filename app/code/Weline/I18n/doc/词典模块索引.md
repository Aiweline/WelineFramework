# 词典模块索引

`Weline_I18n` 1.0.51 在 `Model/Locale/Dictionary.php` 通过现有 `#[Index]` 声明追加非唯一 BTREE 索引 `idx_locale_module(locale_code, source_module)`。`GlobalDictionaryProvider::wordsByModule()` 的语言等值与模块 `IN` 查询可共同使用这两个字段；批量预取、单模块懒加载和空模块列表语义保持不变。

保留现有 `idx_code(locale_code)`，继续服务 `words($locale, [])` 等整语言维护查询。组合索引的左前缀也能支持语言筛选，但本次不删除较窄的旧索引；是否替换应依据实际查询计划与写入成本另行决定。新增、删除词条及修改索引字段需要维护额外索引。既有 `idx_code` / `idx_locale_module` 不包含 `word`、`translate` 文本；1.0.157 新增的 `idx_locale_word` 包含 `word`，仍不含 `translate`，也不改变按 `md5` 主键读取精确词条的方式。

## AI 翻译待译词索引（1.0.157）

`Model/Locale/Dictionary.php` 增加 `idx_locale_word(locale_code, word)`，服务 `AiTranslationService` 的待译词反连接：`l.locale_code = ? AND l.word = d.word`。`AiTranslationService::getUntranslatedWords()` 同时改为 `d.word > 上一页末词` 的 keyset 分页，避免 `OFFSET` 每页重算；`countUntranslatedWords()` 用单条 `COUNT(*)` 聚合。

`idx_locale_word` 含 `word` 文本，不含 `translate`；反连接命中索引后仍需回表判断 `TRIM(translate) <> '' AND translate <> d.word`。`idx_code` 保留：它更窄，继续服务只按语言过滤的维护查询。写入侧会多维护一个约 117 MB（175 万行本机实测）的索引，升级时 `CREATE INDEX` 会短暂持锁，应放在维护窗口。

本机 PostgreSQL（`w_i18n_dictionary` 42,809 行、`w_i18n_locale_dictionary` 1,751,237 行）`EXPLAIN ANALYZE`：索引前单页反连接 1.95 s；加索引后同页 54 ms；1000 词选择（旧 OFFSET 10 页）379 ms → keyset 216 ms；旧计数分页（新索引下）1.38 s → 单聚合 28 ms。

### 索引创建与“重建”边界

- `setup:upgrade --model -m Weline_I18n` 是索引创建/补建入口：`SchemaDiffStage` 比对声明索引与物理索引，`SchemaMigrationExecutor::ensureCreateIndexes()` 补建缺失索引。1.0.157 已在本地执行，`idx_locale_word` 存在。
- `php bin/w index:reindex` / `AbstractModel::reindex()` 最终走 `REINDEX TABLE`，只重建已存在索引，**不能补建缺失索引**；不要把它当 schema 索引创建步骤。已用临时表验证：删掉一个索引后 `REINDEX TABLE` 不会把它建回来。
- SchemaDiff 在 Model 源指纹全命中时会跳过扫描；正常发版的新 `#[Index]` 会改变指纹并触发扫描。若人工删了索引且源码未变，生产需走一次受控的 Model 源变更（正常发版的新声明即会改变指纹），DEV 可用 `--force-schema-rebind`；不要手写 DDL。

## 正式升级与验证

Model 属性和 `etc/module.php` 版本须同批提交。通过框架正式升级应用数据库索引，不手写 DDL、不绕过 Schema 归属校验：

```bash
php bin/w setup:upgrade -m Weline_I18n
vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php --colors=never app/code/Weline/I18n/test/Unit/Model/Locale/DictionarySchemaTest.php
vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php --colors=never app/code/Weline/I18n/test/Integration/AiTranslationPendingKeysetIntegrationTest.php
```

待译词集成测试走 `test/fixtures/ai-pending-keyset.php` 的真实 pgsql 连接；没有 pgsql 或没有待译词 fixture 时标记 skipped。

定向测试使用真实 `SchemaParser` 解析真实模型索引属性，不实例化模型或连接数据库；它只证明声明正确。实际验收还须确认数据库存在新组合索引，并对相同语言、模块和词条结果运行 `EXPLAIN (ANALYZE, BUFFERS)` 与页面冷词典请求对照。

2026-09-13 修改前，只使用 `idx_code` 的 `en_US` / `Weline_Cart` 查询扫描 36,738 个索引项，返回 70 行，命中 1,328 个共享缓冲块，执行 9.046 ms；`zh_Hans_CN` 同模块扫描 33,713 项、返回 0 行、命中 1,180 块，执行 5.926 ms。两者均无磁盘读取，说明语言内大量行过滤是已观测成本。升级后的耗时应以相同查询的真实结果为准，不用声明测试或页面整页缓存命中推断冷请求收益。
