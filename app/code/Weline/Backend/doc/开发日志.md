## 2026-09-17 — Api/worker redirect 熔断防风暴（1.4.19）

- 现象：`Weline.Api`/`weline-api-worker` 直打会 302 的 HTML 表单 URL（如 `websites/admin/website/edit`）→ worker `redirect:manual` 报错 → 无上限重试打满 WLS。
- 改：worker/directFetch 将 3xx 标为稳定 `code: http_redirect`（含 location）；同 `METHOD+pathname` 飞行闸门 + 失败冷却；默认拒绝 `websites/admin/website/(edit|add)`（需显式 `allowHtmlForm:true`）；默认附带 `Accept: application/json` / `X-Weline-Api: 1`。
- 测：`BackendApiCircuitBreakerContractTest`。
- 版本：`1.4.18` → `1.4.19`。

## 2026-08-29 — BinQuery backend auth_error（SessionFactory 双实例）

- 现象：后台 Worker `eav_admin.adminRequest` 等 `auth: backend` 调用返回 403「不满足操作授权要求。」；同 Cookie 直连 HTTP 控制器正常，`backend-bootstrap` 可为 200。
- 根因：`FrontendWorkerBackendAttestationProvider` 用 `SessionFactory::getInstance()` 恢复登录态，而 `FrontendQueryGateway` 用 ObjectManager 注入的另一 `SessionFactory` 读 principal；QueryBin 已置 RequestContext 后 Gateway 跳过二次 restore，principal 为空触发 `denyAuthorization`。
- 修复：AttestationProvider 构造注入 `SessionFactory`，与 Gateway 共用同一请求级实例。
