## 验收证据

- UT：`MediaReferenceIdentityBuilderTest`、`MediaReferenceProtocolContractTest`（含商品/分类/MM 面板/widget-param/后台 Logo 契约）
- 契约：hard_constraints 含 `media_reference_identity_protocol`；skill 可经 MCP INDEX 加载
- Web：选图 URL 带 identity；Theme Ambient；MM 引用管理模式左栏标签筛 + 关站

## 残留风险

- Smtp 三区背景图若走 Theme brand URL 而非选图器，需在对应配置声明 `type=image` 后才走 ConfigEmbed 身份链
- 引用管理「左树」仍为标签表单（非可折叠树）；可后续可视化加深
- MCP 本会话曾 `MCP_RUNTIME_STALE`：需新 Agent turn / Reload 后重新 `prepare_project`

## 结论

协议主链与业务 Ambient 缺口已补齐：构造只走 `w_scope`，换图只卸引用，实体删靠 changed，物理删走垃圾箱/运维入口。
