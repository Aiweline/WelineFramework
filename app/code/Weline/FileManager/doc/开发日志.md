## `1.1.2` — 嵌入式文件选择器底部可达

- 当前状态：`implemented_pending_runtime`
- 需求 ID：`REQ-FILEMANAGER-0003`
- 根因：外层弹窗的 iframe 同时受 flex 布局与脚本像素高度约束；弹窗头部、视口或浏览器可用高度变化后，旧的 `height/min-height/max-height` 会把 iframe 撑出 body，并被外层 `overflow: hidden` 裁掉。
- 实现：弹窗使用 `90dvh` 上限和 `flex: 1 1 0` 高度链；body/iframe 允许收缩，iframe 不再写入测量像素高度；通过正式 `theme:compile welineUi` 更新主题派生资源。
- 验证：JS/PHP 语法通过；嵌入式滚动定向契约 `1 test / 11 assertions`、完整 MediaManager 视图契约 `17 tests / 289 assertions` 通过；真实登录态浏览器 375/768/1024/1440 因浏览器控制连接中断而待执行。
