### `REQ-FILEMANAGER-0002` FileAsset、多语言图片语境与统一渲染

- 来源与确认：用户于 2026-08-22 确认统一文件类、驱动存储、图片专用标签、必填 alt/描述与资源多语言方案。
- 目标版本：`1.1.0`。
- 数据：FileAsset 保存 `asset_id/disk_code/object_key`、原名、MIME、大小、SHA-256、宽高、默认语言、可见性、metadata、时间与软删除；FileAssetLocale 以 `(asset_id,locale_code)` 唯一并保存名称、默认 alt、描述、caption 和翻译审核来源。
- 图片语境：CMS/Theme 只保存含 `asset_id` 的版本化 ImageUsage；资源默认文案只在选择时预填，页面 alt/caption 是独立快照。信息图必须 `confirmed` 非空 alt，装饰图必须显式 `decorative=true`；机器翻译和跨语言复制为 `needs_review`，禁止发布。
- 公共能力：资源访问、URL 解析、引用索引、发布校验和 `<w:file:image>`；使用处须设 UI `width`/`height` 或 `aspect_ratio`（HTML 占位防 CLS），主题 CSS `max-width:100%;height:auto`（见 `doc/file-image-cls-尺寸与响应式.md`）；FileManager 发布稳定的 FileAsset 查询、上传和多语言元数据写入接口，消费模块不得注入 FileManager 具体 Model/Service；动态业务内容不再保存 `<img src>`，`@static` 不变。
- WLS/安全：不缓存授权、签名 URL 或当前资源；所有读取走 Storage Handle；软删除不会级联删除仍被引用的物理对象。
- 验收：同一页面混用本地与 OSS asset；语言、alt、权限、缺失资源和 URL Adapter 故障正确阻止发布；渲染含正确 alt/loading/decoding/srcset 与 width/height（或元数据回退）及 class `w-file-image`。
