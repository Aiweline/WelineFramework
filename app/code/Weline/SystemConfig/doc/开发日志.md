## Hotfix — 2026-09-10：保存后失效清错池，配置脏读（Captcha API Key）

- 问题：库内 `captcha/google/api_key` 已是 `AIza…`，运行时仍读到旧 Secret Key（`6L…`）。`var/cache/database` 残留 module rows；`cache:clear system_config` 清不掉。
- 根因：`AbstractModel::__init` 先把 `_cache` 设为 `database`；`SystemConfig::__init` 用 `!isset($this->_cache)` 导致读写落在 `database`，而 `ConfigCacheInvalidationService` / `w_changed` 只删 `system_config` 池。
- 修复：`__init` 无条件绑定 `w_cache('system_config')`；`invalidateNow` 对 `system_config`+`database` 双池删同一逻辑键（兼容历史脏键）。
- 版本：`1.3.40` → `1.3.41`
