# 规则 40 · 集成与运维

> 分册正文。上位索引 [AI硬规则索引.md](../AI硬规则索引.md)。本册覆盖 壳+Provider（支付/货源）、图片与媒体、AI 生图、Visitor 像素与数据分析、Cursor 调试工具链、运行状态查询。

## 1. 壳 + Provider 同构（`shell_provider_business_isomorph`）

适用范围：万能支付、货源代发、对接供应商 / 支付方式、「业务写在 Controller」味道的实现。

| 允许 / 必须 | 禁止 |
|------|------|
| **Extends Provider 一文件**按能力接口实现；壳**只编排** | 在壳 Controller/Service **重写**某供应商 API/凭证解析/履约/目录/支付生命周期 |
| 对接交付 = **Provider + 配置模板** | 为每个供应商新写一套业务控制器；绕过 Provider 接口硬编码网关 |
| 退款走 `Provider.refund` + 壳 Ledger | 壳碰卡号；密钥明文；回调非纯函数 |

**支付域必上场专席**（`payment_engineer_for_payment_work`，**强制**）：

- `Team:支付开发工程师:` + `payment_development`（`weline-payment-development`）；
- **禁止**支付域只派后端 / 通用 Provider 不上场支付开发工程师；
- **`payment_browser_e2e_closed_loop`**：改完**必须**拉起 `Team:测试:` 用**真 Browser** 过触及支付全流程并留证据，才允许 review pass；
- **禁止**只改代码不拉测试席、不用真浏览器过全流程就宣称过手。

权威：[支付开发.md](../../../../../../dev/ai-command/ai/支付开发.md)、[payment-shell.md](../../../Payment/doc/payment-shell.md)、[provider-development.md](../../../Payment/doc/provider-development.md)、[dropship-shell.md](../../../Dropship/doc/dropship-shell.md)、[provider-development.md](../../../Dropship/doc/provider-development.md)。

## 2. 图片：选图 vs 出图（`image_explicit_width_height_css`）

| 场景 | 做法 | 禁止 |
|------|------|------|
| **选图**（已有素材选择） | `<w:file-manager>` 或 `WelineMedia`；Theme 部件 `media_image` 用 `value_mode=file-image` + `usage=1` | 把 `file:image` 当选图器 |
| **出图**（动态业务图） | `<w:file:image>` 设 `width`+`height` 或 `aspect_ratio`（HTML 占位防 CLS）+ 主题 CSS `max-width:100%;height:auto` | 只写响应式 CSS 不写 HTML width/height；无尺寸裸 `<img>`；裸 `<img src>` 替代 `<w:file:image>` |

验证：源码含 width/height 或 aspect_ratio；主题 `.w-file-image` / foundation `height:auto`。权威：[file-image-cls-尺寸与响应式.md](../../../FileManager/doc/file-image-cls-尺寸与响应式.md)、[选图与出图分工](../../../FileManager/doc/file-manager-选图与file-image出图.md)。

## 3. 媒体引用身份（`media_reference_identity_protocol`）

| 允许 / 必须 | 禁止 |
|------|------|
| 用 `w_scope` / `window.w_scope`；换图只**卸引用**；`resource.scope` 可选（CLI 必传） | 手拼 `identity_path`；合成 `scope~sku`；换图**物理删文件** |

权威：[media-reference-identity-protocol.md](../../../FileManager/doc/media-reference-identity-protocol.md)；skill `media-reference-identity`。

## 4. AI 生图默认 WebP（`generated_images_prefer_webp`）

| 允许 / 必须 | 禁止 |
|------|------|
| **默认落盘 WebP**；`output_format=webp`；返回 png/jpg 须**转码后再交付**；落盘后路径与库引用一致 | 默认交付大 PNG/JPG；生图工具返回 PNG 却不转码就当终态；`pub/media` 长期留 jpg/png 店面图 |
| PNG 仅：用户明示 / 确需非 WebP 透明 / `favicon`·`ico` | 用 PNG 当默认店面图格式 |

运行时落点：MediaManager `AiDrawService`（默认 webp + `ensurePreferredRasterFormat` 后处理）、Ai `AiService` 身份资产默认 `output_format=webp`。权威：[weline-image-pipeline.md](../../../Product/doc/ai/skills/ecommerce-detail-suite/companions/weline-image-pipeline.md) §6.5。

## 5. Visitor 像素与数据分析（`analytics_engineer_for_visitor_work`）

**整模块归属**：`Weline_Visitor`（含本模块 `event.xml` / 像素桥接 Observer / 报表）。

| 允许 / 必须 | 禁止 |
|------|------|
| `Team:数据分析:` 双轨；skill `visitor_data_analytics`（`weline-visitor-analytics`）；技能引用 `frontend_development` + `taglib_ui_control` + 像素指南 | **只派前端/后端代写 Visitor**；把像素当成框架「事件」席，把 Visitor `event.xml` 甩给事件席 |
| Vendor + `cspDirectives`；GTM/GA4 **互斥**；转化去重 + 事件链注册 | 旁路 dataLayer / 私接三方；开 GTM 仍开 GA4 直连；旁路去重 |
| `<w:scope>` 与 `scope_json` 概念分离 | 站店渠与路径过滤混淆 |

> 「≠ Team:事件:」是**禁产品混岗**，不是禁碰文件。

权威：[像素拓展使用指南.md](../../../Visitor/doc/像素拓展使用指南.md)、[像素事件供应商管理-定稿合同.md](../../../Visitor/doc/像素事件供应商管理-定稿合同.md)、[事件链注册.md](../../../Visitor/doc/event/事件链注册.md)、[conversion-event-dedupe.md](../../../Visitor/doc/开发/spec/conversion-event-dedupe.md)。
