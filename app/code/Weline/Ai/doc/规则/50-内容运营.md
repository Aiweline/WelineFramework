| 必须 | 禁止 |

**关键词**：产品优化、商品优化、PDP `/product/` URL。

先读父 [产品优化.md](../../../../../../dev/ai-command/product/产品优化.md) + `Product/doc/ai/skills/ecommerce-product-optimize/`。

| 子线 | 必读 | 技能 |
|------|------|------|
| ① 主图 | `weline-image-pipeline.md` | `ecommerce-product-image` |
| ② 详情 | [详情优化.md](../../../../../../dev/ai-command/product/详情优化.md) | `ecommerce-detail-suite` |
| ③ 翻译 | [翻译优化.md](../../../../../../dev/ai-command/product/翻译优化.md) | `ecommerce-product-i18n` |

**执行**：父开**并行 3 子智能体** → **审查 #1 → 点名返工 → 审查 #2**，两轮均 PASS 才收口。

| 禁止 | 验证 |
|------|------|
| 把父与任一子写成同义词；父未开满 3 智能体；子回报完成即交付（跳过双轮审查）；FAIL 不点名返工；只做详情 / `--skip-images` 却声称完成；裸 `/product/` 无意图全跑；主图未 1:1 / 启用语漏译却整单跳过；**对本任务 prepare_project** | 父→并行 ①②③；审查两轮 PASS；①锁 AR；②`data-weds`；③启用语真译 + `/{locale}/product/`；类审 0 BAD；Browser 禁缓存 |

同时遵守 `product_optimize_triggers_detail_suite`。

## 4. 用户提到「翻译」→ 默认站全语种（`user_mentions_translation_all_default_website_locales`）

**关键词**：翻译（含附图漏译 chrome）、漏译、多语言文案。

先读 [模块翻译CSV规范.md](../../../I18n/doc/模块翻译CSV规范.md)「默认网站全语种」。

| 必须 | 禁止 |
|------|------|
| 查本地 DB `WebsiteLanguage::getWebsiteLanguageCodes(Website::ID_DEFAULT)`（`website_id=0`），对**每一个已选语种**写真实译文 | **只译 en_US**；不查默认网站 `language_codes` |
| 模块 CSV **仅** `zh_Hans_CN` / `en_US`；**其它语种进系统词典** | 非中英语种写进模块 CSV |
| 中英改完后 `php bin/w i18n:collect` | 非中文 locale 译文仍是中文 source 占位 |
| 用户可显式收窄语种；未要求则不启动 Ollama | 自作主张扩/缩语种范围 |

同日另有硬规则 **`translation_engineer_for_i18n_work`**（工程侧）：新文案 / 漏译 / i18n `in_scope` / 改用户可见文案须上场 `Team:翻译工程师:`（别名 `i18n`）+ skill `translation_engineer`；`collect` 后对比；模块 CSV 仅 zh+en；其它已选 locale → 系统词典 / 实体；**禁止**「其它语种默认不做」误导。该条属工程团队范畴，条文见 [规则/10](./10-工程流程与验收.md) §4.5。

- **免除学习知识冲突门禁**（`session_learning_knowledge_conflict_gate` 豁免）。
