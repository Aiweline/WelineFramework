## 1. Taglib 优先于手写控件（`taglib_before_hand_rolled_controls`）

| 允许 | 禁止 |
|------|------|
| 先查 [场景映射表.md](../../../Taglib/doc/场景映射表.md) + [标签全量索引.md](../../../Taglib/doc/标签全量索引.md) + [4-内置标签/README.md](../../../Framework/doc/4-内置标签/README.md) | **未先查标签库**就手写 `<select>` / ISO text / 自造 chips；能用 `<w:*>` / `<lang>` / `<w:hook>` 时用裸 HTML |

无现成标签 → 在**数据拥有模块**新增 Taglib；**禁止**业务页临时拼装。选择性控件（下拉/单选/多选/chips/枚举）架构上优先标签。

## 2. Taglib 实现三条禁令

1. **禁止**在 `w:*` / Taglib **标签属性**里写 `<?=`、`<?php`。
2. **禁止**在 Taglib `callback()` / `runtime_callback()` 返回的 HTML 里写裸 `@static(...)`（`taglib_no_literal_at_static_in_callback`）——`.phtml` 源 AST 才解析 `@static`，callback 字符串按原样烘焙，浏览器 404 `.../@static(Module::css/foo.css)`。改用 `Template::fetchTagSource(DataInterface::dir_type_STATICS, Module::path)`（参考 `I18n\Taglib\Local::resolveModuleStaticUrl`）或 callback 内 `echo`。
3. 动态文案用 `@lang` / Hook，或在 PHP 块赋值后写到 **HTML 元素属性**（须 `htmlspecialchars`）。

权威：[如何自定义Tag.md](../../../Taglib/doc/如何自定义Tag.md)、[static-resource-versioning.md](../../../Framework/doc/static-resource-versioning.md)、[09-static标签](../../../Framework/doc/4-内置标签/09-static-template-js-css标签使用指南.md)。验证：浏览器 Network 无 `.../@static(` 字面量。

## 3. 站内跳转必须走 URL 模块 / url 标签（`storefront_internal_url_via_url_helper`）

**禁止拼接。** 站内 href/action/data-*-url / 店面 JSON 链接只能由官方 Url 入口生成。

| 层 | 推荐 | 允许 | 禁止 |
|----|------|------|------|
| **前端模板** | `@url{'path'}` / `<url>` 等同族标签 | 数据准备块 `$this->getUrl` 族 | HTML 硬编码 `/path`；属性内 `<?= $this->getUrl() ?>`；`Url::getPrefix().$path`；`'/' . $route` |
| **后端 PHP** | `Url::getUrl` / `getFrontendUrl` / `getBackendUrl` | `$this->getUrl` 族；薄封装且内部必须调 Url API | `'/' . $route`；`getPrefix()`/mount 字符串拼接；手写 `/module/action` |

说明：`Url::getPrefix()` 只含语种/货币，**不含** website mount（如 `/daocharms`）；用它拼 href 会丢站点基本地址。外链 http(s) 可原样。权威：[06-url标签使用指南.md](../../../Framework/doc/4-内置标签/06-url标签使用指南.md)。

## 6.1 Runtime 编排层禁止硬编码业务数据（`runtime_orchestrator_no_business_hardcode`，严重）

> **严重错误**：Framework Runtime / WLS 控制面是**编排层**，不是业务目录所有者。在 `WlsRuntime`（及同构的 FPC deferred warmup、READY、keep-warm、bag-prime 调度）里粘贴站点分类/商品/博客 slug、演示 SKU、商户专用店面路径，或「fallback」业务路径数组——**一律禁止**，即使用于性能热修也不豁免。

| 允许（编排） | 禁止（业务硬编码） |
|------|------|
| 调度 / 预算 / cap / owner 选举 / Fiber yield | 在 Runtime 写死 `/category/women`、`/product/sku-xxx`、某站专用 locale×path 矩阵 |
| 消费 `FpcWarmupProviderInterface` / `ViewWarmupContributionProviderInterface` / env `wls.worker.fpc_warmup_paths` | 用「稳定 fallback」名义把 catalog slug 数组塞进 `WlsRuntime` |
| 仅按**已文档化的路由形态**筛选（如 path 以 `/category/` 开头——形态，不是具体 slug） | Runtime 发明或复制归属模块的实体列表 |

**正确归属**：业务路径由**拥有模块**发布——例如 Product 从 `StorefrontAllMenuCategoryTreeService::navTree`（或等价活索引）写入 `ViewWarmupContribution`；Theme `FpcWarmupProvider` 聚合 contribution；Framework 只密封 Provider 给出的路径。

权威：[architecture/04-performance-budget.md](../../../Framework/doc/architecture/04-performance-budget.md)（warmup 路径已从硬编码演示商品/分类收敛为 Provider/env）；MCP `runtime_orchestrator_no_business_hardcode`；协同 `framework_decoupled_only`。

## 6.2 网站 / 设计主题概念禁止侵入框架模块（`website_concept_seed_not_in_modules`，严重·上下文携带·抽象）

> **严重错误（抽象门禁，不是站点黑名单）**：`app/code` 下的模块是**领域内核**。凡归属「某一个网站 / 某一个设计主题 / 某一个品牌开场」的分类树、SKU 货架、开站种子脚本、站专属 `*CatalogSeeder` ITEMS、站导入/挂架/Sample 开场器——**一律不得**放进任何框架模块。本条约束**当前与未来一切**新站、新主题；禁止用「只是示范站」「先塞模块以后再搬」开先例。N 站 ⇒ N 份主题/站柜包，绝不能变成 N 份模块污染。

| 允许（模块·全局领域） | 禁止（站/主题概念侵入模块） |
|------|------|
| **与具体 website code / 设计主题无关**的领域默认：Tax/Shipping seed-defaults、Setup/Install schema、系统 EAV | 绑定某一站或某一主题的开站种子、货架矩阵、分类树、站专属 Seeder/ITEMS、站导入与挂架脚本、站 Sample 开场包 |
| 模块对外的**通用** Mutation / Repository / 读写 API（供设计主题脚本调用） | 在模块内硬编码某站 SKU/文案/图、拒 default 且只接受某一 website code 的开站脚本 |

**正确落点**：版本化站/主题概念 → `app/design/{Vendor}/{theme}/data|scripts/`；生产运维事实柜 → 本机 `websites/<site>/`（gitignore）。设计主题脚本可调用模块通用 API，**不得**把站/主题 ITEMS 写回模块。

权威：MCP `website_concept_seed_not_in_modules`；协同 `runtime_orchestrator_no_business_hardcode`（编排层禁业务路径；模块层禁站/主题概念货架）。

## 7. 配置与范围

### 7.1 统一配置中心（`systemconfig_unified_config_terms`）

| 允许 | 禁止 |
|------|------|
| 业务配置走 SystemConfig；业务页用 `<w:config:embed>` | 自造业务配置表 / 私有 Config Service / 平行设置页；把「配置」落到 MCP host / `env.php` / 模块 `etc` 语义而忽略统一配置中心 |

权威：[SystemConfig README](../../../SystemConfig/doc/README.md)、[config-embed标签使用指南.md](../../../SystemConfig/doc/config-embed标签使用指南.md)。

### 7.2 配置嵌入声明一致（`systemconfig_config_embed_declared_keys`）

embed `field` / `fields` 字符串 **≡** Extends 模板声明的 `<w:config:field key>`；**先声明再消费**。**禁止**自造短名、未声明就 embed、与其它模块（如 Affiliate「分销」）混用货源键。范例：Affiliate / B2B / Dropship `Backend/Config`。

### 7.3 业务范围层级（`weline_business_scope_hierarchy`）

| 允许 | 禁止 |
|------|------|
| 工具条左上 `<w:scope>`；文案含继承；路径控件命名「路径过滤」 | 把「范围」当成 URL 路径通配；忽略 **channel ← store ← website ← global** 继承；把站店渠塞进 `path_include` / `scope_json`；手写站店渠 `<select>`；跨模块依赖 ShippingConfigScopeService |

权威：[store-saleschannel-scope.md](../../../Websites/doc/store-saleschannel-scope.md)；SystemConfig `getFallbackScopes`。

## 8. Query / REST / BinQuery（`api_rest_in_owning_module`）

| 允许 / 必须 | 禁止 |
|------|------|
| **一律 QueryProvider** | 壳内重写 Provider 业务；手写 query-bin |
| Attribute **默认拒绝**（`external/frontend=false`）；公开须显式 opt-in + `auth` | 靠 Attribute 默认暴露；缺 `auth` 当已鉴权 |
| 薄 REST = `#[Acl]` + `w_query`；每入口**独立权限矩阵** | REST 有 Acl 而 query-bin 无 `backend_acl`；缺 `@Document`/Acl |
| Rest **只落归属模块** | 跨模块代写 Rest；**在 I18n 写 Website API** |
| 站内业务走 BinQuery；对外走 REST | 站内业务手写 REST / native fetch |
| 写操作 external 须 Key；敏感读不进 CDN 公开 | 写操作 external 无 Key；CDN 公开敏感读 |
| 改 Rest/BinQuery 须上场 **API 席**（`Team:API:` 双轨）；文档同变更集 | 改 Rest/BinQuery 不上场 API 席；只改代码不更文档 |

验证：BinQuery 须 `compile` 且可 `query:help`。权威：[API接口开发规范.md](../../../Framework/doc/3-开发/API接口开发规范.md)、[BinQuery/Provider开发指南.md](../../../Framework/doc/BinQuery/Provider开发指南.md)、[api-seat-charter](../开发/team/api-seat-charter/meetings/align-freeze.md)。

| 允许 | 禁止 |

## 12. 缓存与性能（`performance_engineer_for_design_and_review`）

| 允许 / 必须 | 禁止 |
|------|------|
| 可缓存事实走 Framework **缓存类**：进程内存储 → 驱动存储；**同 key** 读写与清理同步；单次读命中进程内则不再打驱动 | **业务类再自做一层进程内缓存**（绕开 CachePool/Adapter）；读写/清理 **key 不一致**；清理只清驱动不清进程内（或反之） |
| 复杂 team 热路径须 `Team:性能检查工程师:` 设计检查 + 开发后复审 | 可变 Model / 个性化 HTML / 草稿 / 未提交事务读进共享缓存；**热路径设计不上场性能检查工程师** |
| 查出问题/缺口须立刻 escalate `@项目经理：请立刻组队解决` | **查出问题不立刻 escalate**；跨样本伪加速比 |
| 优化方向落在 HotCache / 框架约束内 | **把拆 header/footer/必装 widget 当优化药方**（主题席有驳回权） |

`cache_lookup_tier_process_shared_db` **已取消**——勿再当 MCP 硬规则要求业务类自做三层。权威：[统一缓存范围与性能优化.md](../../../Framework/doc/统一缓存范围与性能优化.md)、[性能检查.md](../../../../../../dev/ai-command/ai/性能检查.md)。

## 13. ORM / 版本升级（`module_version_bump`）

改 Model / Controller 字段或路由必须 bump `etc/module.php` version：

```bash
php bin/w setup:upgrade -m Weline_Module          # 字段/Schema
php bin/w setup:upgrade --route                   # 仅路由图
```

**禁止**不 bump version 就改字段；**禁止**手改 `generated/`；**禁止**在 `Setup/Upgrade.php` 做字段 CRUD。权威：[模块版本与升级门禁.md](../../../Framework/doc/3-开发/模块版本与升级门禁.md)、[模块开发完整指南.md](../../../Framework/doc/3-开发/模块开发完整指南.md)。

## 14. Controller / 路由（`no_generated_no_routes_xml` / `controller_url_action_not_http_prefix`）

- **禁止** `routes.xml`；路由由控制器发现（`setup:upgrade` 同步，仅路由图变更时 `--route`）；**禁止**改 `generated/`、`view/tpl/`。
- URL 动作是 **`edit` / `add` / `save`**，**禁止**写 `getEdit` / `getAdd` / `postSave`——`get*`/`post*` 前缀只约束**请求方法**，不拼进 URL。

对照 [03-自定义控制器.md §HTTP方法](../../../Framework/doc/2-快速开始/03-自定义控制器.md)。

## 15. 注释与代码风格

| 规则 id | 允许 | 禁止 |
|---------|------|------|
| `no_php_tags_in_comments` | 普通注释掉语句如 `// $x = 1;` | **注释**（`//` `#` `/* */` `/** */` `<!-- -->`）内出现 `<?=` / `<?php` / 短开标签；文件头残留生成器短回显；用 `<?php /* ?>…<?=…*/` 包死代码 |
| `chinese_comments_friendly_style` | 新增说明性注释 / PHPDoc 用简体中文；命名清晰、控制流扁平、与周围风格一致 | 英文堆砌；过度巧妙 / 过度抽象 / 工业式套话导致难读；无视既有风格 |

验证：检索注释内开标签；Diff 抽查注释语言与可读性。权威：[开发标准与验收.md](../../../Framework/doc/3-开发/开发标准与验收.md)。

## 16. 模块 i18n CSV（`module_i18n_csv_collect` / `active_locale_must_show_target_language`）

| 允许 / 必须 | 禁止 |
|------|------|
| 源串默认**简体中文**（正确）；模块 CSV **仅** `zh_Hans_CN` + `en_US`；改后 `php bin/w i18n:collect Weline_Module` | **模板/菜单英文当源串**；只改 CSV 不 collect；缺 `en_US`；**en_US 第二列仍为中文 source 占位**；**默认/活跃语非中文却仍显示中文**；非中英语种写进模块 CSV |
| 非中文 locale 必须显示对应译文；交付前抽检活跃/默认 locale 用户可见词条 | 前后台词条不对齐 |

`user_mentions_translation_all_default_website_locales` 见 [规则/50-内容运营.md](./50-内容运营.md)。权威：[模块翻译CSV规范.md](../../../I18n/doc/模块翻译CSV规范.md)。
