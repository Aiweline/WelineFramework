## 分级

- **complex / team**：上表细节字段全填（单项可 `N/A`+≥24）。
- **simple / 监工**：可用一条 `implementability_simple_skip`≥24 覆盖 feasibility/nfr/lld/milestones/release 集群；路径 + `dev_tasks` + `acceptance`（行为变更时真机 UC）仍必填。

## 闸门边界

- 缺清单 → 自审 `不通过` / 禁止开工；**不**否决 align-freeze。
- Codex `plan_content_contract.detail_must_include` 仅为委派同步；**宿主主闸门**是本规则 + `rules[]`。
- 用户聊天简述；清单默认不进聊天正文。
