# Weline 文档索引

> 轻量索引树：用于 AI 与维护者**快速定位**权威文档，不替代正文。派生检索仍走 MCP SQLite。

## 三层落点（先看这里）

| 层 | 路径 | 放什么 | 不放什么 |
|----|------|--------|----------|
| **权威** | `app/code/{Vendor}/{Module}/doc/` | 需求/现状/开发日志/耐久 spec/指南 | 会话计划、team 纪要、截图证据 |
| **AI / 流程** | `Weline/Ai/doc/` + `dev/ai-command/` | 硬规则、交付流程、技能指令 | 业务模块实现契约 |
| **橱窗** | `dev/docs/` | 对外入门、多语 README、架构导览、操作 guides | 第二套框架圣经、team、evidence |
| **工作** | `dev/session` · `dev/team` · `dev/tmp` | 会话/纪要/证据（默认不入 Git） | 耐久规范正文 |

`dev/docs/archive/` 仅留说明（过期大全/旧计划已清空，勿再堆第二套规范）。

**入伍门禁（先过再写）**：[文档组织与入伍门禁.md](./文档组织与入伍门禁.md) — R1→R5 轮次收紧；错误类禁止入权威树/橱窗。

## 模块三文档契约

每个 `app/code/Weline/{Module}/` 知识单元：

| 文件 | 作用 |
|------|------|
| `doc/README.md` | 定位、入口、专题导航 |
| `doc/需求.md` | 当前有效需求与验收 |
| `doc/开发日志.md` | 实现、复审、测试、发布记录 |
| `doc/AI-INDEX.md` | AI 导航入口（自动快照，`dev/ai/scripts/generate-module-docs.php`） |
| `doc/功能现状.md` | 代码能力快照（自动快照，同上；证明存在，不证明已验收） |
| `dev/session/{slug}.md` | 工程计划 / 任务勾选 / SESSION 总控（仓库根 `dev/`，默认不入 Git；**禁止**再写模块 `doc/开发/plan.md`/`task.md`） |
| `doc/开发/spec/{slug}.md` | 耐久功能规格（EARS/UC；可入 Git） |

全仓规模与缺口巡检见 [模块文档总览.md](./模块文档总览.md)（自动生成，覆盖 `app/code/*/*/doc/`）。
