## 模块三文档契约

每个 `app/code/Weline/{Module}/` 知识单元：

| 文件 | 作用 |
|------|------|
| `doc/README.md` | 定位、入口、专题导航 |
| `doc/需求.md` | 当前有效需求与验收 |
| `doc/开发日志.md` | 实现、复审、测试、发布记录 |
| `doc/开发/plan.md` | 模块计划（可选但推荐） |
| `doc/开发/task.md` | 任务勾选清单（可选但推荐） |

## 按任务类型查哪里

| 任务 | 先查 |
|------|------|
