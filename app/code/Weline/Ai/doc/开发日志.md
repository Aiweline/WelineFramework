## 2026-09-08 — 本机 Ollama 关闭后翻译请求快速失败（1.2.35）

- 观察：强制关闭 Ollama 后，正在 `curl` 的 `queue:run`（LocalModel）约 5–10s 自行退出，不会无限挂死；随后 cron 仍可能再派发，但无模型时也会较快结束。
- 根因：(1) `TranslationService` 传的 `timeout_seconds` 在 `AiService::generate` 未映射为 `timeout`，实际仍按默认 900/120 空等；(2) curl `Operation too slow` / `Couldn't connect` 被当成可重试错误，最多再拖 3 轮。
- 修复：`generate` 映射 `timeout_seconds`；翻译显式 `low_speed_time=45`、`connect_timeout=5`；OpenAI 兼容提供者对连接失败与低速超时不重试。
- 验收：`ProviderTimeoutPolicyTest`、`TranslationConcurrencyGateContractTest`；本机关 Ollama 后 worker 自行退出。
- 版本：`1.2.34` → `1.2.35`
