- 架构：通过。`image` 位于 provider-neutral 媒体契约；核心未引入 `GuoLaiRen_PageBuilder` 依赖，透明化、OCR/Vision、品牌字合成仍归调用模块。
- 缺陷：通过。媒体 allowlist 在运行时路由参数之后独立合并，新增值不会覆盖运行时字段；删除该项会稳定触发聚焦测试失败。

- 用户批准延期：none。
