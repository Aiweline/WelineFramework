# 后台智能体管理

后台入口：`ai/backend/agent`

## 行为边界

- 智能体只能通过 `extends/module/Weline_Ai/Agent/` 代码注册，后台不能新建自定义智能体。
- 目录通过 `agentCatalog` 读取，包含源名称/描述、覆盖字段、场景、工具快照与状态（启用 / 禁用 / 缺失）。
- 扫描（`agentScan` / `ai:agent:scan` / `setup:upgrade`）更新源字段与工具参数 Schema，不覆盖 `name_override`、`description_override`、智能体 `is_active`、工具 `is_enabled`。
- 代码中消失的智能体或工具标记为缺失（`is_present=0`），保留覆盖；缺失项不能重新启用。
- 运行时治理仅对 `AiService::executeAgent()` / `AiRuntimeInterface` 生效：覆盖后的工具描述进入 function calling；禁用工具不会发给 AI。直接 `$agent->execute()` 旁路不受治理。

## 前端约束

- 页面业务请求必须走 `window.Weline.Api.resource('ai')`；不要直接使用 `fetch()`、`axios` 或 jQuery AJAX。
- 扫描确认使用后台统一 `BackendConfirm.show()` 组件。
- 新增可见文案需要进入 `i18n/zh_Hans_CN.csv` 和 `i18n/en_US.csv`。

## QueryProvider

| operation | 作用 |
|---|---|
| `agentCatalog` | 目录/详情 |
| `agentSave` | 保存名称/描述覆盖 |
| `agentSetActive` | 启用/禁用智能体 |
| `agentSaveTool` | 保存工具描述覆盖 |
| `agentSetToolStatus` | 启用/禁用工具 |
| `agentScan` | 扫描并刷新目录 |

## 验证

- 修改后至少执行相关 PHP 文件 `php -l`。
- 浏览器验证需要目标环境关闭系统维护模式，并具备后台管理员登录 Session。
