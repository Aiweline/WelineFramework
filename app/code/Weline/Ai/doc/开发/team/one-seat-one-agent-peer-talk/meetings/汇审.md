# 汇审 — 一席一智能体 + 席间互聊

- 日期：2026-09-21
- 触发：用户要求「团队每一成员都是智能体，不是一个智能体扮演；并让多个子智能体相互交流」
- 变更面：MCP 硬规则 / 工程团队指令 / skill bundle / 契约测试（无业务 PHP 行为变更）

## 决议

1. **one_seat_one_agent**：复杂 team 每上场席位 = 真实宿主子智能体；父会话仅 `Team:项目经理:`；其它 `Team:{席位}:` 只允许转述真实回报。
2. **peer_talk_via_channel**：席间经 `channel/{thread}.md` 追加消息 + resume 对端；项目经理是交换机；禁止伪造多席对白。
3. 对齐冻结 / 组件协商 / 专题会必须走真实互聊；纯单向 contracts 手递可不开通道。

## 证据

- 指令：`dev/ai-command/ai/工程团队.md` 原则 7–8 +「席间互聊协议」
- 硬规则摘要含 `ONE_SEAT_ONE_AGENT` / `PEER_TALK_VIA_CHANNEL`
- `mcp-skills-catalog` / `guidance-workflow-contract` 相关断言 PASS
- 模块版本 `1.2.95`；ToolService `0.13.14`
