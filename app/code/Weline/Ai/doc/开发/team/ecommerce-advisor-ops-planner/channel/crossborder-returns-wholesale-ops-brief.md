## 1. 零售 + 批发口径对照表

| 场景 | 零售（C 端） | 批发（B / B2B） | 店内可否写成「承诺退」 |

### 一句话 stance（贴政策页标题区可用）

> **发货后原则上不支持退换；仅因质量问题、错发漏发或运输损坏等商家 / 物流责任方可申请退换。个人原因不支持。批发订单正常范围内损耗不支持退货。本店不提供七日 / 十四日无理由退货作为店内服务。**

## 2. 推荐中文主文案（可直接贴进政策页 · 段落清单）

> 以下为**店内主规则**中文草稿，偏商家、清晰、不恐吓。开发 / 翻译席落页时保持语义，勿擅自加成「无理由福利」。

### P1 · 政策总述

本店从中国国内发往海外。汉服为跨境服饰类商品，回程运费与税费高昂，且试穿后难以二次销售。因此，**商品一经发出，原则上不支持因个人原因退换**。我们保障的是商品质量与发货准确性，而非「买了不喜欢也能退」。

### P2 · 可申请退换的情形（责任方可退）

在下列情形下，您可在收货后按指引提交凭证申请退换或补发（我们可能要求清晰照片 / 视频、订单号、外包装与吊牌状态）：

1. **质量问题**：明显做工瑕疵、污渍、破损（非买家使用造成）、与商品描述明显不符；  
2. **错发 / 漏发**：收到的款式、颜色、尺码或数量与订单不符；  
3. **运输损坏**：承运过程中导致的明显损坏（建议签收时检查，并在合理时间内提交凭证）。

我们确认属商家或物流责任后，将优先安排 **补发、换货或退款**（具体方式由客服根据库存与物流成本择优处理）。

### P3 · 不支持退换的情形（个人原因）

以下情形属于个人原因，**原则上不支持退换**：

- 不喜欢、色差观感差异（在合理工艺范围内）、选错尺码 / 颜色；  
- 轻微试穿后不想要；  
- 已穿着使用、清洗、裁剪改衣，或吊牌 / 包装缺失导致无法二次销售（质量问题除外）；  
- 无物流异常、无质量 / 错发问题的「改变主意」。

### P4 · 批发特别说明

批发 / 批量订单除适用上述质量与物流责任条款外，另适用：

- **正常范围内损耗不支持退货**（例如运输导致的可熨烫褶皱、轻微线头、约定色差 / 公差内的批次差异）；  
- 质量问题仍须按件 / 按批次提供凭证；经确认后按责任范围处理，**不以「整单无理由」方式退货**。

### P5 · 费用承担（清晰偏商家）

- 因 **质量问题 / 错发漏发 / 运输损坏** 且经确认属商家或物流责任的，合理退换相关费用按责任归属处理（以客服书面确认为准）。  
- **非质量问题** 若因适用强制性法律必须办理退货：回程运费、税费、清关相关费用由 **买家承担**（法律另有强制分配除外）。  
- 买家擅自拒收、长期不取件导致退回的，可能产生额外费用，由买家承担。

### P6 · 法定例外（仅一句弱披露 · 禁止展开成卖点）

若您所在地区的强制性法律要求提供法定冷静期或无理由退货，我们将在该强制范围内依法办理；**这不属于本店主动提供的店内无理由退货服务**，且非质量原因的回程运费与税费通常由买家承担（法律另有规定除外）。

### P7 · 禁止出现的店内承诺（开发 / 文案红线）

| 禁止文案 | 原因 |
|----------|------|
| 「支持七天无理由」「14-day free returns」作为店内福利 | 与经营事实冲突；跨境不可承受 |
| 「不满意就退」「试穿后退」 | 等同个人原因退货承诺 |
| 把法定冷静期写成促销徽章主文案 | 弱披露即可，禁止营销化 |

## 3. 信任徽章建议文案（店面 / 结算旁 · 短标签）

语气：可信、偏保障质量，**不要**用「Free Returns」「30-Day Returns」。

| 场景 | 建议短文案（中） | 备注文案（英意向，供翻译席定稿） | 备注 |
|------|------------------|----------------------------------|------|
| 主信任条 | 质量问题可退换 | Quality issues covered | 首选 |
| 辅助 | 错发漏发必处理 | Wrong / missing items handled | 可与主条并列 |
| 辅助 | 运输损坏可申请 | Shipping damage eligible | 物流页可复用 |
| 批发角标 | 批发：正常损耗不退 | Wholesale: normal wear not returnable | 仅 B2B / 批发入口 |
| **禁用** | 七日无理由 / Free returns | — | 硬禁 |

徽章旁可加一行微字（可选）：「发货后原则上不退；责任问题可申请」。

## 4. FAQ 短答（可直接入库 / FAQ Hub）

**Q1：发货后可以因为不喜欢退货吗？**  
A：不可以。本店从国内发往海外，发货后原则上不支持个人原因退换。

**Q2：什么情况可以退或换？**  
A：质量问题、破损、错发漏发、运输损坏等商家或物流责任情形，凭订单与清晰凭证申请。

**Q3：你们支持七天 / 十四日无理由吗？**  
A：本店**不提供**七日或十四日无理由作为店内服务。我们保障的是质量与发货准确性。

**Q4：批发订单有损耗能退吗？**  
A：正常范围内损耗（如可恢复褶皱、轻微线头、约定公差内色差）不支持退货；确认的质量问题仍可按凭证处理。

**Q5：如果当地法律要求无理由退货怎么办？**  
A：仅在强制性法律适用范围内依法办理；这不是本店主动福利。非质量原因的回程运费与税费通常由买家承担。

**Q6：收到货发现问题要多久联系？**  
A：建议签收后尽快检查；运输损坏请尽快提交开箱照片 / 视频，以便核对责任。

**Q7：退货运费谁出？**  
A：确认属商家或物流责任的，按客服确认方案处理；个人原因不支持退换。若依法必须退且非质量问题，回程运费 / 税费由买家承担。
