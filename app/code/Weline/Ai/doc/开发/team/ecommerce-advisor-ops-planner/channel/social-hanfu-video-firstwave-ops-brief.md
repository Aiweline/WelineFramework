## 2. 版权红线与合法路径（硬）

### 2.1 一律禁止

- **直接搬运 / 下载 / 录屏**抖音（或任意平台）他人成片，**无书面授权**二次上传到我方 YT / TikTok / IG / X。  
- 「只改 BGM / 加自家水印 / 裁前后 1 秒」仍算侵权成片，**不算原创**。  
- 把他人模特脸、店铺招牌、未授权商品图剪进自家片当「官网货」。  
- 用「公平使用 / 学习用途」当免死金牌去发商用导流视频。

### 2.2 仅允许的四条合法路径

| 路径 | 做什么 | 证据要求 |
|------|--------|----------|
| **A. 自有成片** | 自雇模特/员工/店主出镜；自有货品；自有场地或已租场地 | 拍摄日记录 + 肖像授权（口头可记备忘，优先纸质/表单） |
| **B. 授权转载** | 原作者书面同意转载到指定账号与平台 | 私信/邮件截图 + 授权范围（平台、时长、可否改字幕）存档 |
| **C. 爆款结构自拍复刻** | 只学分镜节奏/钩子句式/镜头顺序，**画面与文案全部自拍重做** | 对标笔记写「结构」，不存他人成片源文件作上传素材 |
| **D. 商品实拍** | 挂装、走秀 3 步、袖口/交领/褶影特写、上身前后对比 | SKU 编码记入发布表，便于以后挂商品链 |

### 2.3 用户坚持要用「别人那条视频」时

只允许走 **路径 B**：先发 **§6.3 私信授权模板** → 等明确同意 → 再剪辑上传，片尾标注出处与授权说明。  
**未获同意 = 不做**。顾问不提供「怎么录屏绕过水印」类建议。
