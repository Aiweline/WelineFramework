## 工单全表（P1→P2）

### P1

#### WO-HP-P1-01 · 币种与包邮门槛一致

- **做什么**：顶栏/促销「满 ¥299 包邮」与货架 `$` 价对齐为同一币种；默认美元站则门槛改为 `$XX`（或按站点币种配置驱动），禁止混用。
- **验收标准**：
  - nocache 打开验收面：可见商品价币种符号与包邮门槛币种符号一致。
  - 切换站点币种（若配置存在）后门槛数字/符号跟随，无硬编码人民币门槛残留。
  - 电商顾问口头签收「门槛与价签币种一致」。
- **建议席位**：主题开发工程师（展示/配置面）+ 前端（价签/顶栏文案绑定）+ 电商顾问（定档 `$` 门槛数值，禁写码）。
- **波次**：Wave-1 立刻开工。

#### WO-HP-P1-02 · 三货架错开选题

- **做什么**：Featured / Deals of the Day / 热销 三块不得共用同一套前 N 款；按「爆款 / 限时折扣 / 新品或场景」错开。
- **验收标准**：
  - 首屏下三块货架前 4 款 SKU 集合两两交集为空（或顾问书面豁免并记 channel）。
  - Featured 与热销前 8 款不得完全相同。
  - 空货架兜底不破坏布局。
- **建议席位**：后端（推荐规则/查询）+ 部件开发工程师（货架部件数据源）+ 电商顾问（选题策略 brief，禁写码）。
- **波次**：Wave-1 立刻开工（可与 01 并行）。

#### WO-HP-P1-03 · 评价区块去重

- **做什么**：删除或改写「穿后感言」与「买家评价」中重复的那一块；保留一块客户证言，另一块接真实评价数据或改为 UGC/明星穿搭场景。
- **验收标准**：
  - 首页仅一块「三卡同文」式证言；另一块内容与署名/星级不得字节级相同。
  - 若接真数据：至少 3 条可区分评价；无数据时有空态，不回退到复制文案。
- **建议席位**：部件开发工程师 + 主题开发工程师（布局）+ 前端（渲染）。
- **波次**：Wave-1 立刻开工（可与 01/02 并行）。

#### WO-HP-P1-04 · 语言/locale 整页一致

- **做什么**：按当前 locale 整页一致（中文站→中文标题+中文商品名/价签文案；英文站→全英）；禁止半页中半页英。
- **验收标准**：
  - 默认站当前 locale 下：导航、货架标题、商品名、评价标题/正文语言一致。
  - 切 locale 后无大面积串语；新增文案走 i18n 源串简中 + 中英 CSV + `i18n:collect`（用户若提翻译再拉默认站全语种）。
- **建议席位**：i18n + 前端 + 后端（商品名展示策略）+ 电商顾问复审。
- **波次**：Wave-2（本波暂缓）。

### P2（本周，Wave-3+）

- **验收标准**：首访 nocache 进入首页，首屏 3s 内不弹；满足延后条件后可弹且可关。
- **建议席位**：前端 + 主题开发工程师。

#### WO-HP-P2-07 · 迷你购物车包邮进度条

- **验收标准**：加购未达门槛可见差额；达门槛显示已包邮；币种与 P1-01 一致。
- **建议席位**：前端 + 后端（Cart）+ 电商顾问定档（禁写码）。
- **依赖**：硬依赖 `WO-HP-P1-01`。

- **建议席位**：原型 + UI + 主题开发工程师 + 前端 + 电商顾问 brief。
