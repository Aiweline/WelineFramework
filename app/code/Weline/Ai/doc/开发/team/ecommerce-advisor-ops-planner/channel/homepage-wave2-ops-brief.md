## WO-HP-P1-04 · 默认 locale 意图（拍板）

### 默认访客看到什么

**拍板：默认站（Website::ID_DEFAULT）默认 locale = `zh_Hans_CN`（简体中文整页）**

口径：未主动切语种的访客进站，应看到**一整页中文体验**——不是「顶栏中文 + 货架英文」的混排。  
实现席可跟当前 locale 切换渲染；运营意图的「默认访客」= **简中一致页**。

| 面 | 中文站（`zh_Hans_CN`，默认） | 英文站（`en_US`，用户切换后） |
|----|------------------------------|-------------------------------|
| 导航 / 顶栏 / 促销条 | 中文 | 英文 |
| 货架标题（Featured / Deals / 热销等） | 中文 | 英文 |
| 商品名（列表卡 / 精选卡） | **中文商品名**（有译名用译名；无译名不得长期留英文占位冒充中文站） | 英文商品名 |
| 价签数字与币种符号 | 跟站点展示币（本波已对齐 `$`）；币种符号本身不随文案语种改写 | 同左 |
| 评价区标题 + 正文 + 署名旁注 | **中文** | **英文** |
| UGC 图墙标题 / 空态引导 | 中文 | 英文 |
| Hero 主次 CTA 文案 | 中文（见 P2-08） | 英文（见 P2-08） |

### 硬禁（验收一眼看）

1. **禁止半页中半页英**：同一 locale 下，标题语言与商品名语言、评价标题与评价正文语言必须一致。  
2. 切到 `en_US` 后：禁止大面积残留中文货架标题 / 中文评价标题配英文正文（或反过来）。  
3. 本波不要求「无译名商品强制机器翻」；运营过签口径是：**默认中文站不得以英文货架+英文评价正文作为常态展示**。缺译名时实现席用既有商品多语字段策略补齐或降级展示规则，顾问不在此指定 SQL/字段名。

**顾问签收口径：** 默认访客 = 整页 `zh_Hans_CN`；`en_US` 整页全英；禁混排。

## WO-HP-P2-08 · Hero 二级路径（拍板）

### 结构

**拍板：Hero 只保留 1 主 CTA + 1 次要 CTA**（禁止再堆第三个同质「立即购买 / Shop」抢点击）。

次要路径选 **「按场景选」**（不选尺码助手作 Hero 次 CTA）：首页先解决「场合/场景发现」，尺码助手更适合商品页/导购中段，避免 Hero 过早进入工具型路径。

### 主 CTA（转化主路径）

| | 中文 | 英文 |
|--|------|------|
| 文案 | `浏览精选` | `Shop Featured` |
| 路径意图 | 落到首页 Featured 货架（锚点）或「精选/编辑推荐」集合页；一键到达可浏览的精选货盘，而非空集合 | Same: Featured shelf anchor or curated collection |

### 次要 CTA（二级发现路径）

| | 中文 | 英文 |
|--|------|------|
| 文案 | `按场景选` | `Shop by Occasion` |
| 路径意图 | 场景/场合导购入口（如礼宴 · 旅拍 · 日常等场景集合或筛选页）；若暂无独立场景页，可用带 `occasion`/`scene` 意图的类目或筛选 URL，**勿要求本 brief 改码新建路由** | Same occasion/scene discovery intent |

### 表现约束（运营）

- 主 CTA 视觉权重明显大于次 CTA（主实心 / 次描边或文字链即可；实现席定样式，顾问只定层级）。  
- 文案不得再与 Featured / Deals / 热销三块货架标题语义撞成三个「热卖」。  
- 与 Wave-1 货架错开规则兼容：主 CTA → 精选；次 CTA → 场景发现（不是再开第四块同质热销）。

**顾问签收口径：** Hero = `浏览精选` / `Shop Featured` + `按场景选` / `Shop by Occasion`。
