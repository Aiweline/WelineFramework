# Weline_Catalog — 固化 UI 原型

> **状态**：规划定稿（S1）；实现不得偏离下列区块顺序与信息架构。视觉可沿用 Backend 皮肤，但**不得删掉标注区块**。
>
> **验收**：真机 WB 须 **WB-OP（操作员路径）+ WB-VIS（截图 + 本清单）**；截图存 `doc/evidence/ch{N}/WEBUI-{id}_{breakpoint}.png`。

## 视觉清单（每屏 WB-VIS 必勾）

| # | 检查项 | pass 条件 |
|---|---|---|
| 1 | 区块完整 | 与下方 P-CAT-* 标注区块均可见 |
| 2 | Backend 皮肤 | 无裸 HTML、无大面积 unstyled、无重叠遮挡关键控件 |
| 3 | Taglib 控件 | 网站/店/渠/语言切换器为 Taglib，非手写 `<select>` |
| 4 | 树与详情区 | 左树右详情（或等价分栏）；375 下可堆叠但仍可操作 |
| 5 | 空态/加载 | 无数据时有明确空态，非白屏 |
| 6 | 交互反馈 | BackendToast/BackendConfirm；**无**原生 `alert/confirm` |
| 7 | console | 无新增 error |

## P-CAT-1 — Website 结构页

**适用 WEBUI**：001～004, 008, 009, 014, 015

```text
┌─ 顶栏 ─────────────────────────────────────────────────────┐
│ [空间▾ 产品分类]  [范围▾ Website]  [网站▾]  [搜索分类…]     │
├──────────────┬─────────────────────────────────────────────┤
│ 分类树        │ 节点详情 / EAV 面板                          │
│ [+添加子分类] │ name / code / 扩展属性…                      │
│ 拖拽把手      │ [保存] [删除]                                │
│              │ Google 映射区（S1.5，website 可见）           │
└──────────────┴─────────────────────────────────────────────┘
```

**固化规则**：

- Website 模式 **有**「添加子分类」与结构 CRUD
- 顶栏含 **空间**、**范围**、**网站** 切换（Taglib）
- 搜索框调用 Provider `searchNodes`（WEBUI-014）
- Store/Channel 模式 **无** 本屏结构按钮（见 P-CAT-2）

## P-CAT-2 — Store / Channel 展示选择

**适用 WEBUI**：005～007

```text
┌─ 顶栏：范围=Store|Channel + 网站/店/渠选择器 ───────────────┐
├──────────────┬─────────────────────────────────────────────┤
│ 只读 Website 树│ 展示配置：勾选启用 / 排序 / [保存展示]        │
│ **无**结构 CRUD │ 提示：结构仅在 Website 维护                  │
└──────────────┴─────────────────────────────────────────────┘
```

**固化规则**：

- **禁止**「添加子分类」及 save/delete/reorder 结构入口
- 树为 Website 真相只读；右侧仅展示选择配置
- store 与 channel 配置相互独立（WEBUI-006）

## P-CAT-3 — Google 管理 + AI 翻译

**适用 WEBUI**：010～012

### Google 管理页（WEBUI-011）

```text
┌─ Google 产品分类（只读参照）────────────────────────────────┐
│ 只读树 + 译名编辑                                            │
│ **无**删改 Google 结构入口                                   │
└─────────────────────────────────────────────────────────────┘
```

### 分类编辑 — Google 映射（WEBUI-010）

- Website 节点详情内：Google ID 选择/映射区
- 保存后映射回显

### AI 一键翻译（WEBUI-012）

- BackendConfirm 确认
- 后台 Queue 进度 UI（可离开页面后继续）
- **WB-VIS**：弹窗打开态 + 关闭后各 1 张截图
