### 2026-09-01 — 分类标签：商品页强制芯片回填 + 指南同步

- **问题**：仅依赖 scope-persistence 时，创建页可能出现 hidden/草稿已有 `category_ids` 但芯片空白；`getValue` 读 hidden 而芯片读 `selected`，静默写 hidden 会造成假阳性。
- **修复**：消费侧 Product `forceHydrateCategoriesFromDraft`（芯片数为 0 亦 `setValue silent`）；标签 `getValue` 改为 `selected.join`，初始化先 `hydrateFromHidden` 禁止空 selected 覆盖已有 value。指南 §5/§8 同步。
- **版本**：Catalog `1.0.10`；Product `1.0.39`
