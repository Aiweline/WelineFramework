# Weline_Catalog — 需求

> **状态**：规划定稿（章 0）；S1 分章交付。术语与 WEBUI 与主规划同步。

---

## 术语

| 概念 | 名称 |
|---|---|
| 模块 | `Weline_Catalog` |
| 分类类型 | **space**（`product` / `blog`…）；Query/URL 用 `space=` |
| SPI | `CatalogSpaceProviderInterface` / extends → **`CatalogSpace`** |
| Product 实现 | `ProductCatalogSpaceProvider` |
| EAV | 每 space 自有 `eavEntityCode()`；product = **`category`** |
| 范围 | Website = 结构 CRUD；Store/Channel = 展示选择 only |

---

## 功能需求（摘要）

| ID | 摘要 |
|---|---|
| REQ-CATALOG-0001 | 枢纽 S1：`space=product`；Hub 薄、Provider 厚 |

## WebUI 验收（REQ-CATALOG-WEBUI）

**门禁**：每含 Web 的章 Done 须 **WB-OP + WB-VIS**；截图存 [`doc/evidence/`](evidence/)（见 [`原型设计.md`](原型设计.md)）。

**前置**：`dev` 分支；`setup:upgrade`；WLS reload；后台已登录。

**主 URL**：

- Website：`/catalog/backend/category/index?space=product&scope_level=website&website_id={id}`
- Store：`...&scope_level=store&website_id={id}&store_id={sid}`
- Channel：`...&scope_level=channel&website_id={id}&store_id={sid}&channel_id={cid}`
- Google：`/catalog/backend/google-taxonomy/index`
- 旧链：`/weline_product/backend/catalog/categories?website_id={id}` → 302
