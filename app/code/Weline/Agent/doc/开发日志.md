# Weline_Agent 开发日志

## 2026-09-21 — 聊天控制台可对话（1.1.4）

- 现象：聊天页是「即将接入」占位，角色不可选、没有输入框。
- 修：BinQuery `sendMessage`/`getChatHistory`；控制台左选角色、右时间线+发送；`AiService::generateStructured` 补上引擎调用。
- 测：契约 UT 5/5；e2e chapter + plan-suite PASS；Browser 真发一条，失败时系统气泡（本地模型端口未开），非整页 JSON。
- 汇审：`doc/开发/team/chat-console/meetings/汇审.md`。
- 规格：`doc/开发/spec/backend-chat-console.md`。
- 版本：`1.1.3` → `1.1.4`

## 2026-09-21 — BinQuery 参数允许列 + HTML 安全网全模块收口（1.1.3）

- 现象：角色保存经 BinQuery 仍失败 `Unknown frontend worker param: status`；`role/models|adapters` 浏览器仍整页 JSON。
- 修：补齐 `saveRole`/`suggestRole`/`saveSchedule` descriptor 字段；`agent-admin-api.js` 对写操作自动包 `payload`；`AgentHtmlSafeMutationTrait` 统一 HTML→redirect；Skill/Session 写操作走 AdminService；列表挂 `data-agent-op`。
- 测：契约 UT；e2e chapter + plan-suite。
- 汇审：`doc/开发/team/binquery-mutations/meetings/汇审.md`。
- 版本：`1.1.2` → `1.1.3`

## 2026-09-21 — 写操作改走 BinQuery，禁止整页吐 JSON（1.1.2）

- 现象：角色/调度表单原生 POST `*/save` 返回 `fetchJson`，浏览器整页显示 JSON。
- 修：注册 `agent` QueryProvider（`extends/module/Weline_Framework/Query`）；`AgentAdminService` 承载写操作；表单经 `Weline.Api.resource('agent')` 调 `saveRole`/`saveSchedule`/`suggestRole`；控制器 HTML 提交兜底重定向列表。
- 版本：`1.1.1` → `1.1.2`

## 2026-09-21 — 源串统一中文，消除中英串列（1.0.2）

- 现象：后台侧栏/模板英文源串；CSV 中英译文对调、杂糅。
- 修：`menu.xml`、模板、`__()`、ACL、引导配置改为**中文源串**；重写 `zh_Hans_CN`/`en_US`（中文键 → 中/英译文）；`i18n:collect`。
- 运维：侧栏仍英文时因 ACL 菜单库未刷新——已执行 `php bin/w menu:collect -f -m Weline_Agent`，库内 `source_name` 已为中文；并 `cache:clear` + `server:reload`。
- 对齐：MCP 硬规则 `module_i18n_chinese_source_default`（全模块模板默认中文源串）。
- 版本：`1.0.1` → `1.0.2`

## 2026-09-09 — 修正 zh 词典倒置污染全局文案（1.0.1）

- 现象：中文后台 GEO 等模块弹窗出现 Success / Saved successfully。
- 根因：`i18n/zh_Hans_CN.csv` 将「保存成功」「成功」等中文键误译成英文，全局合并后覆盖正确译法。
- 修：纠正保存成功/成功/删除成功/状态已更新等倒置项，并补 Saved successfully→保存成功。
- 版本：`1.0.0` → `1.0.1`
