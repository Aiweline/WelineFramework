## 2026-10-19 — 部署整窗维护模式（1.1.23）

- **问题**：`deploy:release` Git 对齐时店面仍对外；默认后置 `setup:upgrade` 会抢关维护，窗未结束即恢复服务。
- **机制**：`DeployMaintenanceWindowService`（runtime gate）+ `MaintenanceModeToggleService` 分层；POST_DEPLOY 幂等注入 `--keep-maintenance`；`deploy:build` / rollback 同窗。
- **not_to_do**：部署窗禁止 `enableFull`/波次礼金；busy/soak 早退禁止半开维护。
- 版本：`1.1.22` → `1.1.23`。

## 2026-10-19 — 默认 Cron 更新、Webhook 可选关闭（1.1.22）

- **问题**：Webhook 不稳定且难控；需要默认后端 Cron 检测更新，Webhook 保留但默认可关（关则无地址/404）；禁止多更新累积入队卡死。
- **机制**：`webhook_enabled`/`cron_update_enabled` + `ensureChannelDefaults`；Route/Controller 双门禁；ExpectWatch cron 分支 `selectCronWinnerRef` + 单次 `dispatchRelease`；abandon reason `superseded_by_newer_deploy`；MachinePlan 仅 webhook 开时强制 path/secret。
- **not_to_do**：禁止 miss 路径入队；禁止 for 循环多 enqueue；禁止用 merge 默认值判断通道键是否存在。
- 版本：`1.1.21` → `1.1.22`。

## 2026-10-15 — Deploy 通知带项目路径（1.1.21）

- **问题**：同机多项目时 `webhook_miss` 等 `deploy_release` 通知只有 hostname（如 `seruJXbZMfd9MnL`），看不出是哪个部署根。
- **机制**：`DeployReleaseNotifier` 始终解析并写出 `deploy_root`（ctx → BP）；标题带 basename；ExpectWatch miss 显式传 `deploy_root`；`NotificationOriginContext` 脚注增加「项目路径」（优先 metadata.deploy_root，否则 BP）。
- **not_to_do**：禁止只靠 process_host；禁止在渠道 Adapter 硬编码站名/路径。
- **协同**：Backend `NotificationOriginContext` + i18n「项目路径」。
- 版本：`1.1.20` → `1.1.21`。

## 2026-10-14 — 新 Webhook 作废未完成旧任务 + 30 分钟 TTL（1.1.20）

- **问题**：同 tip 多次 Webhook / 卡住的 `running`/`pending` 会堆积 deferred 通知；新 tip 到来仍被旧 incomplete 挡住。
- **机制**：`DeployWebhookJobQueue::abandonIncomplete` / `abandonStaleIncomplete`（`STATUS_ABANDONED`，TTL=`STALE_INCOMPLETE_SECONDS=1800`）；AsyncDispatcher **入队前**作废全部 incomplete（含杀 pid）再发新任务；Drain 每轮先 TTL 作废；通知相位 `PHASE_ABANDONED`。
- **not_to_do**：禁止只 tip-dedupe 而不作废；禁止未标 abandoned 就并行双 release；禁止把 TTL 当「永远不让新 tip 抢跑」。
- **契约**：`DeployWebhookQueueContractTest`（abandon / supersede / drain TTL）。
- 版本：`1.1.19` → `1.1.20`。

## 2026-10-13 — 发布单飞排队（1.1.19）

- **问题**：两次 Webhook 同时 `systemd-run` → Git ref 锁冲突 → 失败任务 auto-rollback 干扰进行中发布；TG 上失败/成功交错难读。
- **机制**：`DeployReleaseFlightGate`（`var/deploy/release.lock`）；`hasInFlight` 时 AsyncDispatcher 只入队发 `deferred`；`deploy:release` 抢不到锁则 `busy` 回 pending（不 Git、不回滚）；Drain 单飞消费；Reconciler 认 `busy` trailer。
- **not_to_do**：禁止忙时标 failed/auto-rollback；禁止并行双 release 同 deploy root。
- **契约**：`DeployReleaseFlightGateContractTest`。
- 版本：`1.1.18` → `1.1.19`。

## 2026-10-13 — 公网 Webhook FPC 签章打穿 + 确认已换（1.1.18）

- **问题**：`/~wh~{random}` 走 HTML try_files / FPC 会缓存命中，攻击面与误 HIT；WLS 与 FPM 不能共用「必须带签章」硬门槛。
- **机制**：`DeployWebhookPierceGate`——WLS 才把 `w_fpc_pierce=` 拼进 setup/后台 URL；签章轮换只改 query、不必重跑 setup；`webhook_pierce_ack_hash` + 后台「确认已换」；保存配置不抹 ack；`DeployWebhookFpcBypassProvider` pierce-gated bypass。
- **not_to_do**：禁止无条件 Nginx bypass `/~wh~`；禁止 FPM URL 强制签章；禁止为换章强制 `deploy:webhook:setup`。
- **契约**：`DeployWebhookPierceGateContractTest`。
- **协同**：Server `2.0.192`（Nginx pierce∧path）；Framework `2.5.386`（FPM hard-exclude + builtin pierce rule）。
- 版本：`1.1.17` → `1.1.18`。
