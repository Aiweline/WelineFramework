# 事件：`Weline_Deploy::core_update_after`

`php bin/w core:update`（`Weline\Deploy\Console\Update\Core`）在核心文件同步、统计与最新 commit 打印完成后派发。

## 载荷

| 键 | 说明 |
|----|------|
| `branch` | 目标分支 |
| `force` | 是否 `-f` / `--force` |
| `tmp_dir` | 缓存仓路径 |
| `new_files` / `updated_files` / `deleted_files` | 同步统计 |
| `args` | 命令入参 |

## 典型观察者

- `Weline_Theme::core_update_purge_layout_entities`：删除 `var/runtime/theme-layout-entities/`（与 setup / deploy:upgrade 共享 `ThemeLayoutEntityUpgradePurgeService::runOnce`）。

仍须另跑 `setup:upgrade` 或 `deploy:upgrade` 完成静态双树铺平。
