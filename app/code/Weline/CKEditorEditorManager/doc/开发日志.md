# Weline_CKEditorEditorManager 开发日志

## 2026-09-12 — 暗色工具栏 SVG fill 强制浅色（1.0.3 补丁）

- 问题：暗色外壳下工具栏按钮 `color` 已浅，但 IconView `.ck-icon__fill` / path 仍黑 fill，图标不可见。
- 修复：`ckeditor-theme.css` 对工具栏 `.ck-icon__fill` 与黑 fill path 强制 `fill: var(--weline-theme-text)`；e2e 断言图标亮度。

## 2026-09-12 — 暗色外壳 + 内容正常模式浅色岛（1.0.3）

- 问题：暗色后台下 CKEditor 内容区白底却继承浅色字（foundation `h1–h6` / `--weline-theme-text` 泄漏），详情不可读。
- 修复：新增 `ckeditor-theme.css`（外壳跟暗色 Token；`.ck-content` 重钉浅色叶值）；`ckeditor.html` 挂载；契约测覆盖。
- 版本：`1.0.2` → `1.0.3`

## 2026-09-08 — 保留 CKEDITOR_TRANSLATIONS 至 Editor.create（1.0.2）

- 问题：`loadEngine` 在返回引擎前 `delete window.CKEDITOR_TRANSLATIONS`，`Editor.create({language})` 对空翻译做 `Object.keys` 崩溃，商品编辑详情 WYSIWYG 无法挂载。
- 修复：仅删除 `window.CKSource`，保留翻译全局供创建使用。
- 版本：`1.0.1` → `1.0.2`

## 2026-09-08 — 适配器兼容 Weline.UI context.element（1.0.1）

- 问题：`ckeditor-adapter.js` 把 `UI.define` 工厂参数当成 DOM，实际为 `{element,...}`，编辑器无法挂载。
- 修复：优先使用 `context.element`。
- 版本：`1.0.0` → `1.0.1`
