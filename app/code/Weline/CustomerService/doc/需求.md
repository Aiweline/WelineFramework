## 当前有效需求

### `REQ-CUSTOMERSERVICE-CONSOLE-006` 默认选中最近会话、侧栏优先级与收消息反馈

- 进入工作台时，若「我的会话」非空，默认选中排序后的第一项并打开聊天区。
- 侧栏「我的会话 / 转让」：有未读时等待越久越靠前；无未读时按最新消息时间靠前。
- 前端收到客户新消息（当前会话或其它会话未读增加）时，提供 toast、侧栏脉冲与标题闪烁等可见反馈。

### `REQ-CUSTOMERSERVICE-FRONTEND-001` 店面客服支持表情/图片/文件与截图发送

- 店面客服输入区上方工具条：表情、图片、文件、截图。
- 表情点选插入输入框；图片/文件选择后上传并以结构化附件发送。
- 截图：业界惯例「先框选、再截取」——点击后立即在当前页蒙层拖拽选区，确认后仅截选区并 JPEG 压至约 2MB；失败回退图片选择；支持粘贴图片发送。
- 附件协议与后台一致（`__CSJSON__`），气泡可预览图片或下载文件。

### `REQ-CUSTOMERSERVICE-CONSOLE-007` 话术库统一搜索与分类 Tab

- 话术面板顶部提供统一搜索（标题+内容，跨分类）。
- 搜索命中时跨分类定位并高亮首条；点击条目填入输入框。
- 分类以 Tab 展示；新建分类即新增 Tab；可按 Tab 过滤；空分类可保留。
- 添加话术默认折叠，不抢「选用」主路径；保存时可归属当前分类。

### `REQ-CUSTOMERSERVICE-CONSOLE-005` 工作台支持表情、图片/文件与个人话术库

- 聊天输入区上方提供工具条：表情、图片、文件、话术。
- 表情：面板点选插入输入框。
- 图片/文件：选择后上传并作为结构化消息发送；气泡内可预览图片或下载文件。
- 话术库：归属当前客服个人，可保存/选用/删除；选用后填入输入框再发送。

### `REQ-CUSTOMERSERVICE-CONSOLE-004` 消息自动同步、未读清零与转让响应时间分账

- 工作台打开会话后须轮询增量消息（`since_id`），客户侧新消息自动进入当前聊天区，并刷新侧栏预览/未读。
- 会话须持久化 `last_read_time`；打开会话或客服回复后标记已读；未读计数以已读水位为准，转让会话默认从 `transferred_at` 起算。
- 响应时间：接收方从转让时刻起算；转让方累计到转让时刻（含转让前未回复等待）。

### `REQ-CUSTOMERSERVICE-CONSOLE-003` 工作台接单确认与会话加载可达

- 「接单 / 关闭」确认不得因缺少 `BackendConfirm` 静默取消；须回退 `Weline.UI.dialog.confirm`（再退 `window.confirm`）。
- `csAdmin` POST 须正确序列化 `URLSearchParams`/`FormData` 为 `application/x-www-form-urlencoded`，禁止 `JSON.stringify(URLSearchParams)` 成空对象。
- 转让进会话点选卡片即可打开聊天区；`getMessages` 须兼容 `ChatMessage` 模型（有消息会话不得 TypeError）；加载失败须 toast，并回滚错误选中态。
- 点选会话须**立即**进入聊天壳（可显示「正在加载最新消息…」），不得长时间停在「请选择一个会话」空态。
- 首屏加载**最新**一页消息并滚到底；消息区上滑到顶时用 `before_id` 加载更旧消息并 prepend，保持视口相对位置。
- 客服发送消息：属己会话须成功；失败 toast 须展示后端真实原因（禁止只笼统「请稍后重试」）；agent 查询须 `reset()` 避免单例脏条件。

### `REQ-CUSTOMERSERVICE-CONSOLE-002` 会话侧栏手风琴：我的会话置顶、可滚动、有会话显示数字

- 侧栏分组顺序：**我的会话** → **转让分配** → **等待分配**。
- 三组均为可折叠手风琴（Weline `w-disclosure`）；**互斥**：展开一组时须关闭其他组。
- 首屏仅展开一组：有「我的会话」优先开我的；否则有转让开转让；否则有等待开等待；皆空时保持「我的」展开空态。
- 标题旁有会话时显示数量徽章（`>0` 才显示），便于判断是否展开。
- 展开后列表区内滚动，会话多时不挤垮侧栏。

### `REQ-CUSTOMERSERVICE-CONSOLE-001` 转进会话在工作台显示转让标记并分组

- 人员管理转让成功后，接收方工作台须对转进来的活跃会话显示「转让」徽章。
- 侧栏分组：**等待分配**（waiting 池）与 **转让分配**（`is_transferred` 活跃会话）分开；「我的会话」仅含非转让活跃会话。
- 「转让分配」列表须**明文**展示来源客服（如「来自客服「admin」」），不得仅依赖 hover title；无名称时用「来自其他客服」。依据 `transferred_from_agent_id > 0`。
- **`transferred_from_agent_id` = 会话转出前的归属客服**（人员页点击「转让」的那一行），**不是**当前后台登录操作者；超管代操作时亦同。
- 释放回等待池须清空转让字段；普通「接单」不得写入转让标记。

### `REQ-CUSTOMERSERVICE-ASSIGN-001` 自动分配优先在线客服

- `assignAgent` 在激活且未满员的客服中：**心跳在线优先**，其次最少活跃会话，再按 `agent_id` 稳定排序。
- 新建会话若仍为 `waiting`，客户再次发消息须重试分配（避免「客服已上线仍积压在等待池」）。
- 工作台 AJAX/SSR 会话行须带顶层 `session_id`；等待列表禁止显示 `#0`。

### `REQ-CUSTOMERSERVICE-CONSOLE-002` 聊天区为标准聊天壳（区内滚动）

- 打开会话后：**顶栏 + 消息历史 + 输入区** 组成聊天壳；消息再多也不得把整卡/整页无限撑高。
- 消息历史须在壳内纵向滚动；顶栏与输入区保持可见（钉住）。
- 视觉仅用主题 Token；桌面主工作区锁在可视高度链内。

### `REQ-CUSTOMERSERVICE-AGENT-005` 删除客服须处理未关闭会话；可转让给其他客服

- 删除客服时若仍有未关闭会话，须先**转让给其他激活客服**或**释放回等待池**，禁止静默直删。
- 人员列表提供「转让会话」：选择目标客服后批量转让未关闭会话。
- 验收：有会话时删除弹层出现目标客服选择；转让后 `agent_id` 更新；释放后回到 `waiting` 且 `agent_id` 为空。
- 转让写入 `transferred_from_agent_id` / `transferred_at`，供工作台转让标记使用（见 `REQ-CUSTOMERSERVICE-CONSOLE-001`）。

### `REQ-CUSTOMERSERVICE-BIND-001` 绑定邮箱人机验证失败中文提示并可降级本地图码

- 中文站不得弹出英文 `Captcha verification failed or expired…`；须为「人机验证失败或已过期，请重试」或降级说明。
- 当 Google/腾讯服务端校验不可用且允许本地降级时：返回 `captcha_degrade=local_image`，前端重拉本地图码供用户填写后重试。
- 人机验证挑战禁止 SSR 进店面 HTML/FPC；打开绑定弹窗必须 `no-store` 拉取新挑战；挑战接口须禁止共享响应缓存。

### `REQ-CUSTOMERSERVICE-GUEST-001` 未验证邮箱游客发消息须等回复闸门

- 未登录且会话未绑定有效邮箱时：若最新消息为顾客侧，则不可再发，须等待客服（agent）回复后才能再发一条。
- UI 须提示等待回复，并提供「验证邮箱」入口；验证/绑定邮箱后可跳过等待闸门、连续发送。
- 登录用户或已绑定邮箱的会话不受该闸门限制。
- `session` / `sendMessage` / `messages`（Query 与 HTTP）须返回 `guest_send`；拒绝时带 `guest_send_locked`。

### `REQ-CUSTOMERSERVICE-AGENT-004` 编辑客服弹窗回填当前行数据

- 点击列表「编辑」须打开「编辑客服」并回填关联用户、名称、邮箱、语言、并发与激活状态；禁止仅改标题而表单留空。
- 列表交给前端的 `agents` / `data-agent` 必须是行字段纯数组，不得 `json_encode` Model 元数据。

### `REQ-CUSTOMERSERVICE-AGENT-003` 添加/保存客服经 BinQuery adminRequest 可达且错误可读

- `customerService.adminRequest` 必须在 Query descriptor 中 `frontend=true` 且要求后台会话；表单 POST 不得被序列化成空对象；失败 toast 须给出可执行下一步。
- 后台控制器桥接必须经 `AdminControllerBridge::invoke`（禁止 `ObjectManager` 拉起 `BackendController::__init()`，否则 Query 内会 `NoRouterException` 404）。
- `csAdmin` 须把 BinQuery 结果包装成可 `.json()` 的桥接 Response（与 Eav `bqAdmin` / `wrapAdminBridgeResult` 一致）。

### `REQ-CUSTOMERSERVICE-AGENT-002` 添加客服选关联用户后自动填名称邮箱且可改

- 在「添加/编辑客服」弹窗中选择「关联后台用户」后，自动填入客服名称（用户名）与邮箱；字段保持可编辑。
- 验收：Browser 选择用户后可见 `#email`/`#name` 填入，可手动改写再保存。

### `REQ-CUSTOMERSERVICE-FOOTER-001` 页脚联系客服打开悬浮聊天

- 部件 `footer-contact-service-link` 经 `default_injections` 注入 Theme `footer-help-links`。
- 点击后调用 `__WelineLoadCustomerServiceWidget(true)`（或已加载时的 `CustomerServiceWidget.toggleChat`）打开右下角悬浮客服窗；若已打开则不重复切换关闭。
