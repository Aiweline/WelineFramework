# Weline_Admin 开发日志

## 2026-09-22 — 侧栏当前语种菜单标题预取（2.0.11）

- 问题：bg_BG 等非中英语种后台侧栏仍显示中文「仪表盘/内容管理…」；词典与 `generated/language` 已有译文。WLS 热路径去掉全语 `prefetchCrossLocaleMenuWords` 后，连**当前 locale** 标题也未预取，`resolveMenuTitleRaw` 只能读模块中英 CSV → 回退 source。
- 改：`renderMenu` 缓存未命中时对当前 `State::getLangLocal()` 一次 `Parser::prefetchWords(菜单标题)`；顶栏 `搜索配置…` 改为 `__()` 以便模板预取；仍禁止热路径全语 prefetch / `data-search-text`。
- 验：UT `MenuRenderServiceCrossLocaleSearchContractTest`；Browser bg_BG 侧栏抽检。

## 2026-09-22 — 菜单交叉搜索改 DB 索引（2.0.10）

- 问题：渲染热路径对全部启用 locale `prefetchWords` 并烘焙 `data-search-text`，WLS 后台侧栏 10–20s。
- 改：去掉 HTML 全语烘焙；`BackendMenuSearchProvider` 对齐 Faq 走 `SearchProviderIndexService`；`BackendMenuSearchIndexDocumentBuilder` 离线拼 keywords；`menu:collect` / ACL invalidate / Upgrade rebuild；侧栏 `nav-filter` debounce 调 `search.search` 按 source_id 过滤。
- 验：UT CrossLocale + Provider 契约；e2e/plan-suite 改写；timing 侧栏不再十秒级。

## 2026-09-21 — Admin 观测 Performance 头进闸门（2.0.9）

- 改：`BaseController::setPerfHeader` 仅 `performanceBreakdown` 或 `dynamicObservability` 开启时写出。
- 版本：`2.0.8` → `2.0.9`。

## 2026-09-20 — 菜单 HTML 进程缓存有界化（2.0.8）

- 问题：`$renderedMenuCache` 键含 raw `currentUrl`、仅 TTL、无 max、过期不扫；Admin `ProcessCacheResetter` 只清 FPC → WLS Worker 后台多路径浏览可无界堆 HTML。
- 改：`RENDERED_MENU_CACHE_MAX=16` + TTL 扫 + LRU；键改 `activeFingerprint`（激活 source_id 集合）；`clearProcessCache()`；soft/hard/显式清缓存均经 Resetter 回收。`$frequentMenusCache` 同步有界并一并清空。
- 验：`MenuRenderServiceRenderedMenuCacheContractTest`。

## 2026-09-20 — 菜单跨语搜索对齐 Phrase 词条预取（2.0.7）

- 问题：`getGeneratedLocaleWords` 对每个已启用 locale `include generated/language/*.php` 整本，WLS Worker 512MB OOM 掉线。
- 改：渲染前 `prefetchCrossLocaleMenuWords` → 各 locale `Parser::prefetchWords`；`resolveMenuTitleRaw` 改模块 CSV + `Parser::getPrefetchedGlobalWord`；删除整本 include。Framework 增 `Parser::getPrefetchedGlobalWord`（2.5.112）。
- 验：`MenuRenderServiceCrossLocaleSearchContractTest`（5 PASS）；e2e `ADMIN-MENU-XLOCALE-001/002` + plan-suite `ADMIN-MENU-XLOCALE-SUITE-001` PASS（admin/admin）。
- e2e 稳：plan-suite 去掉 `useProxy:false`/direct（登录态丢）；FATAL 断言去掉裸 `Uncaught`（活动流误伤）。

## 2026-03-24 — 菜单 href 走 getBackendUrl 保留切换语言（2.0.6）

- 问题：侧栏菜单地址未带当前非默认 locale，切语后点击回到默认语言。

## 2026-09-09 — 侧栏连字符路由别名匹配（2.0.3）

- 分流：`web_ui` / `ui_shot`（用户箭头「无法选中菜单」；客户组页侧栏无高亮/未展开）
- 根因：地址栏 `control-center` 与菜单 href `controlcenter` 段字面不等，`isMenuActive` / `pathMatchScore` 失败
- 修复：PHP/JS 比较前去掉段内 `-` 并小写；B2B `menu.xml` 改为连字符 pretty URL
- 单测：`MenuRenderServiceComparableUrlTest`、`BackendMenuPathMatchContractTest`

## 2026-09-09 — 侧栏 JS /index 省略匹配（2.0.2）

- 问题：`app.js` `calculatePathMatchScore` 在菜单长一段且末段为 `index` 时直接判负，keep-mounted 软导航后无法高亮。
- 修复：与 PHP `isMenuActive` / Theme `pathMatchScore` 对齐，`…/index` ↔ 省略 `/index` 视为精确匹配。
- 版本：`2.0.1` → `2.0.2`

## 2026-09-09 — 侧栏菜单 /index 省略匹配（2.0.1）

- 问题：菜单 action 为 `…/controller/index`，当前 URL 为 `…/controller` 时侧栏不高亮、父级不展开（配送分区无法定位）。
- 修复：`MenuRenderService::isMenuActive` 对去掉 `/index` 的控制器路径做精确相等匹配。
- 版本：`2.0.0` → `2.0.1`

## 2026-09-08 — 菜单标题交给框架批量预取公共译文
