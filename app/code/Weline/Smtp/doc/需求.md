## 当前有效需求

### `REQ-SMTP-0026` 编辑保存后返回渠道管理保持原位置

- 来源与确认：用户要求模板编辑保存后，返回渠道管理时保持原来的位置。
- 目标版本：`1.4.19`。
- 业务逻辑：列表状态经 URL 传递（`q` 渠道搜索、`locales` 语言多选、`channel` 展开、`focus_locale` 焦点行）；编辑页「返回渠道管理」带回上述参数；保存/重置表单隐藏字段透传，保存后仍可正确返回；列表还原筛选并 `scrollIntoView` 到渠道/语言行。
- 非目标：改发信解析；会话级服务端记忆（仅 URL/表单）。

### `REQ-SMTP-0025` 渠道搜索与语言标签多选过滤

- 来源与确认：用户要求渠道可搜索；渠道内模板按范围筛选；模板用语言标签多选快速过滤。
- 目标版本：`1.4.17`。
- 业务逻辑：顶栏「搜索渠道」过滤渠道行；「按范围筛选模板」切换 `target_scope` 重载该范围模板；**官方** `<w:i18n:language:select multiple>` 可搜索多选语言标签过滤各渠道内语言行（未选=全部）。
- 非目标：手写语言 chip 平铺；跨范围同屏混排多 scope 行。

### `REQ-SMTP-0024` 渠道语言模板搜索与默认语继承展示

- 来源与确认：用户附图指出展开后语言表不可搜；未配置语言应走网站默认语邮件模板。
- 目标版本：`1.4.16`。
- 业务逻辑：每渠道展开区提供「搜索语言模板」；未配置行显示「网站默认语 {locale}」徽章与默认语主题预览；`MailTemplateResolver` 在 Global/无网站默认语时回退平台 `zh_Hans_CN`，与发信就近向上一致。
- 非目标：改 Sales Channel；为每个语言强制建行。

### `REQ-SMTP-0023` 渠道管理：展开看各语言模板

- 来源与确认：用户指出原 `template/listing?locale=…` 应按渠道管理；渠道记录展开后才见各语言模板；旧「按语言平铺」列表语义废除。
- 目标版本：`1.4.15`。
- 业务逻辑：菜单改「渠道管理」；listing 仅按 `target_scope` 列发信渠道；`<details>` 展开显示该渠道全部已安装语言模板行（主题/来源/继承/编辑）；顶栏去掉语言切换器；编辑页回链「返回渠道管理」并带回 `channel` 以便展开。
- 非目标：新建第二套后台路由；改 Sales Channel（Websites）渠道管理；改发信 Resolver。

### `REQ-SMTP-0022` 邮件模板管理列表可发现性

- 来源与确认：用户要求「菜单管理界面」覆盖全部模板，不只密码重置。
- 目标版本：`1.4.14`。
- 业务逻辑：菜单已在「系统服务 → Smtp邮件服务 → 邮件模板」；listing 增加「邮件模板管理」页头与渠道计数；edit 增加「返回模板列表」。
- 非目标：新建第二套模板后台。

### `REQ-SMTP-0021` 编辑页作用范围可切换

- 来源与确认：用户附图指出编辑页「作用范围」仅为静态 `code` 展示，要求可切换。
- 目标版本：`1.4.13`。
- 业务逻辑：编辑页复用列表页 `<w:scope>`；切换后按 `target_scope`+`locale`+`channel` 重载（去掉 `template_id`）；品牌预览样本跟随 URL workScope。
- 非目标：手写网站 select；改 Scope Taglib 内核。

### `REQ-SMTP-0020` 预览 CTA 与编辑器按钮样式对齐

- 来源与确认：用户附图指出预览按钮呈浏览器默认蓝链，与编辑器橙色按钮块不一致。
- 目标版本：`1.4.12`。

- 非目标：改造 CKEditor 内核；为预览注入后台全局 `a` 样式。

### `REQ-SMTP-0019` 预览 Logo 对齐前台 Website brand

- 来源与确认：用户指出预览 logo 不是前台 logo（误用 Theme 默认 `logo.svg`）。
- 目标版本：`1.4.11`。
- 业务逻辑：`MailBrandContextService` 按 Scope 回退链读取 `ThemeBrandResolver` appearance brand，并显式并入 `{website}.__website__.default`（Global 哨兵 `default.default.default` 无 website 父级）；保留 `/pub/media/` 路径；禁止回退 Theme 包默认 logo。
- 非目标：改 Theme 发布继承语义；硬编码 yunshang 文件名。

### `REQ-SMTP-0018` 预览品牌信息按真实域名与 Logo 解析

- 非目标：改写 Website.url 入库；伪造未绑定域名。

### `REQ-SMTP-0017` 编辑预览变量按作用范围锁定站点地址

### `REQ-SMTP-0010` 一语言一套邮件模板 + 就近向上解析 + 技术债清零

- 来源与确认：用户锁定「channel 挂模板；一语言一套；listing 当前 scope；读取/发送就近向上；技术债转 code 注册本轮清零」。
- 目标版本：`1.4.0`–`1.4.1`。
- 业务逻辑：`SmtpMailTemplate` UNIQUE(channel, scope, locale)；Resolver 近→远 × 目标语/站默认语；通知域 `notify_*` → `notification_email`；有 channel 时模板权威；`vars` 渲染；CLI/事件显式 scope+locale；Upgrade/列表页种子。

- 非目标：LocalModel 拆正文；拖拽积木；SystemConfig 存大段 HTML。
- 验收标准：契约 UT；后台「邮件模板」listing/edit；e2e-plan-suite；Browser 禁缓存。
