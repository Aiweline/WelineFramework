## 当前有效需求

### `REQ-SMTP-0002` SMTP 按网站范围配置发件人账户

- 来源与确认：用户于 2026-09-10 要求后台 SMTP 增加网站范围，配置页菜单便于按范围配置 SMTP 账户。
- 目标版本：`1.2.0`。
- 背景/问题：原 BackendConfigStore 仅 Global，无法为各网站独立 SMTP。
- 用户与运营场景：运营在「Smtp配置」选择 Global/Website，维护多发件人；亦可从统一配置中心打开同模块声明字段。
- 业务逻辑：SystemConfig Extends 声明 `smtp_senders` 等键 `scope=global,website`；Helper\\Data 用 ConfigReader/ConfigStore.setScopedConfig 读写并继承回退；配置页 `w:scope` + 深链；`SmtpQueryProvider` 接受 `scope`/`website_code`。
- 范围：Weline_Smtp 配置声明、后台配置页、Data/QueryProvider、契约测试与文档。
- 非目标：不以 config:embed 文本为主路径维护多发件人/密码；不改 Mail 引擎。
- 验收标准：契约单测通过；配置页可见作用范围选择器；探活 URL 可达。
