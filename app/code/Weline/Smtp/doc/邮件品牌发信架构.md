# 邮件品牌发信架构（全渠道契约）

权威实现：`MailBrandContextService` + `smtp/send`（`SmtpQueryProvider`）。  
业务模块只声明 channel / 正文变量，**不得**各自拼 From 显示名或假定主题可无品牌。

## 不变量

| 面 | 契约 | 入口 |
|---|---|---|
| 发件人显示名 | 弱名称（空 / `default` / 账户 code / 邮箱本地部分 /「系统」）→ `brand_display_name`（店名优先，排除「默认网站」） | `resolveFromDisplayName()` |
| 收件箱主题 | 主题字符串必须可见品牌；已含则不重复；否则前缀 `品牌 · 原主题` | `ensureBrandedSubject()` |
| 邮件页头/页尾 | 壳内 `{{var.brand_display_name}}` + Theme 色盘 | `mergeInto()` + `shell.phtml` |

## 数据流

```
channel 模板 subject/body
    → MailTemplateRenderer
    → mergeInto(站店渠品牌变量)
    → ensureBrandedSubject（主题）
    → shell wrap（页头已含品牌）
    → resolveFromDisplayName（From）
    → SmtpSender
```

## 模块职责边界

- **Weline_Smtp**：品牌解析、Subject/From 契约、固定壳。
- **业务模块**：示范主题可不写品牌前缀（发送时由 Smtp 补齐）；也可显式写 `{{var.brand_display_name}}`（幂等，不重复）。
- **禁止**：在业务模块硬编码站点名 / 用 SMTP 用户名当品牌。

## 收件箱客户端注意（QQ 等）

- **自己发给自己**（`From` 地址 = 当前登录邮箱）：QQ 列表常强制显示**账号昵称**（如 `aiweline`），**不会**用 MIME `From` 显示名；这与阿里云「别人发给你」可显示「阿里云计算」不同。
- **验证品牌 From**：请用**另一个邮箱**收测；或在 QQ「设置 → 账户」把昵称改成品牌名（仅影响自己看自己的信）。
- 主题行品牌仍由 `ensureBrandedSubject` 保证（截图中主题已正确）。
