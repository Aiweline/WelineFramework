## 1. 产品冻结

| 项 | 约定 |
|----|------|
| 壳 | `Weline_Visitor` = 万能像素事件供应商枢纽（对齐万能支付壳，解耦：厂商不直写 Pixel 核心） |
| 后台 | 「事件供应商」列表 → 点开配置（凭证 / 模式 / 搭接 / JS） |
| 双来源 | `source=module`（extends 扫描）\| `source=custom`（人工新建，可无 PHP 类） |
| 默认模式 | `sandbox`；供应商可改 `default_mode` 与当前 `mode` |
| 搭接 | `event_map`: 我方事件 → 三方事件；seed 默认若干；可恢复默认；排除 `skip_gtm_push` |
| 自定义事件 | 进池须命名录入或事件链封录（`record`）；observe/自动发现不进池；禁止点击即记；仅高级事件链内可点击入步 |
| JS | `sandbox_js`（沙盒加载）+ 可选 `inject_js` |
| DEV 不上报 | DEV / 本地排除命中时外发硬拦（含 inject）；Pixel 仍入库；沙盒 dry_run |
| 双 inject | `ga4`+`gtm` 不可同时 `inject`（硬拦） |
| 模式语义 | sandbox = 隔离试发 ≠ Google 正反馈；inject + 非 DEV = 直播训练路径 |

## 2. Phase2 扩展点选型（框架解耦）

```text
Weline_Visitor/extends.php
  → PixelEventVendor (multiple)
  → Interface: PixelEventVendorInterface
       getCode / getDisplayName / getConfigSchema
       getDefaultEventMap / getDefaultMode / getCapabilities
  → Scanner + VendorManager upsert → pixel_event_vendor
  → 内置 Ga4Vendor + GtmVendor（模块源）
  → 自定义行：无 class，壳加载 sandbox_js/inject_js
```

禁止：模块旁路 `dataLayer.push`；跨模块直写 Visitor Model。
