# Weline_Base 需求

## `REQ-BASE-0001` 默认发行依赖聚合

- 状态：confirmed（当前 Composer 契约）
- `Weline_Base` 只负责声明 Weline 默认发行所需的 Composer 包集合。
- PHP 平台约束与默认发行模块保持一致，当前为 `^8.4`。
- 依赖包名必须使用各模块当前公开 Composer 包名；模块更名或拆分时不得保留失效别名。
- 本包不得新增运行时注册、业务服务、控制器、模型或数据库副作用。

## 验收标准

- `composer.json` 语法有效，所有 `require` 包可由配置的 Composer repository 解析。
- 默认发行模块的预期增删有明确需求和变更记录。
- Base 仍保持纯聚合包，不产生 Weline 模块运行时入口。
