# 买家秀与商品评论（边界）

日期：2026-09-23  
相关：`WO-BUYER-SHOW-03` · Theme `image-gallery` `variant=looks`

## 一句话

| 概念 | 角色 |
|------|------|
| **买家秀 / Customer Looks** | **展示面**（首页图墙等），不落独立晒单库 |
| **商品评论 `Weline_Review`** | **生产与审核源**（含图审核通过后可进展示面） |

## 接线

- 服务：`BuyerLooksGalleryInterface` / `BuyerLooksGalleryService`
- 规则：仅 `status=approved` 且至少一张 `media_kind=image` + `attached`；无图评论不进图墙
- 部件：Theme `image-gallery`（`variant=looks`）运行时优先拉聚合；聚合为空时用配置 `items`；再空才占位兜底
- 点击：图链到对应 PDP `#product-reviews`（`/product/{product_id}#product-reviews`；由 `entity_uuid`→`global_product_uuid` 解析店面 `product_id`，禁止用 identity `registry_id`）

## 禁止

- 新建平行「BuyerShow / 晒单」实体模块或媒体库（除非架构证明 Review 无法承载）
