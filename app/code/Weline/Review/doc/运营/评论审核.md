# 评论审核操作说明

## 适用范围

- 模块版本：Weline_Review 1.0.0
- 目标读者：拥有评论查看或审核 ACL 的后台运营、内容审核和支持人员。
- 功能目的：集中查看文字、图片和视频评论，并将待审核评论处理为已通过或已拒绝。

## 前置条件与权限

- 已执行 php bin/w setup:upgrade --route。
- 查看列表需要 Weline_Review::list。
- 通过或拒绝需要 Weline_Review::moderate。
- 评论类型当前默认展示商品评论；非商品类型后台聚合策略不在本版本范围。

## 操作路径

1. 登录后台。
2. 在“商品与目录”分组进入“评论列表”。
3. 使用状态筛选查看全部、待审核、AI 审核待人工、已通过或已拒绝评论。
4. 展开评论详细内容，检查评论对象、评分、评论者、文字、图片和视频。
5. 点击“通过”公开评论，或点击“拒绝”阻止前台展示。
6. 页面返回同一列表并显示操作结果；按当前筛选继续处理。

## 状态与可见结果

| 状态 | 含义 | 前台展示 |
|---|---|---|
| pending | 新提交，等待审核 | 否 |
| ai_pending_blocked | AI 无法明确判断，等待人工 | 否 |
| approved | 已通过 | 是 |
| rejected | 已拒绝 | 否 |

## 空状态、失败与恢复

- 暂无评论：列表显示空状态，不需要处理。
- 评论不存在：刷新列表，确认记录未被其他审核员处理或删除。
- 审核状态无效：只能使用页面提供的“通过”或“拒绝”。
- 操作失败：保留当前筛选，刷新后重试；仍失败时记录评论 ID、时间和可见错误交给技术支持。
- 媒体无法播放：先确认文件仍位于评论媒体目录，再检查 MIME 与浏览器支持；不要绕过媒体校验直接替换数据库路径。

## 限制与回滚

- 本版本不支持批量审核。
- 后台默认服务聚合商品评论；其他类型可在后续通过通用扩展契约接入。
- 停用后台入口时可撤销菜单与 Controller；不要删除评论表或媒体文件。
- 误操作可在同一条评论上执行相反状态操作恢复，恢复后重新检查前台可见性。

## 支持升级信息

提供以下最小信息：评论 ID、评论类型、网站/店铺、当前状态、操作时间、可见错误和是否包含媒体。不得发送评论者邮箱、会话 Cookie 或后台凭据。
