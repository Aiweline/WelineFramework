# Weline_Feed 开发日志

## 2026-10-26 — 站点 FE 专用系统邮箱（0.1.0 → 0.1.1）

- **问题**：GMC/购物目录注册平台需要本站专用邮箱；此前只有融媒体能向企业邮箱申请 `social-{站code}@`。
- **架构**：`mechanism=Query`（`feed_admin` 暴露 `get/ensure/resetScopeFeedMailbox`）；`owning_module=Weline_Feed`（按站点编排），开箱/改密经 `mail` Query，`Weline_Mail` 负责系统账号识别与删除门禁。
- **改**：新增 `FeedScopeMailboxService`（`feed-{站code}@`）；购物目录页按筛选站点显示邮箱条，可申请、复制、重置密码；`feed-` 前缀纳入 Mail 系统账号（不可删、不可改身份、可改密）。
- **not_to_do**：不在 Feed 直接 new Mail Model；不把 FE 邮箱做成可手工删除的普通邮箱。
- 版本：Feed `0.1.0` → `0.1.1`；Mail `0.2.51` → `0.2.52`。
