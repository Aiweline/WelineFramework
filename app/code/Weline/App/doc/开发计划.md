# Weline_App 开发计划（权威 · 用户指定按此文档推进）

> 用户拍板（2026-10-24）：①配置齐全即可用，缺配置单条 msg 提示（不累积）②计划记录/更新在本 doc ③团队开发，接口直接加在本模块、合理支持多语言多货币 ④iOS 本机 Mac 测试、Android 本机虚拟机测试 ⑤App UI 先做汉服站（中国风 + 海外 App 使用习惯）。

## 一、目标与范围

### V1 交付
1. **Weline_App 模块**：后台配置（站点/平台/签名/自更新开关）→ 配置齐全即一键打包；缺配置→后台单条 msg 指引（session Message，天然单条覆盖，禁止消息队列累积）。
2. **CLI**：`app:build` / `app:doctor`（工具链+网络探测）/ `app:install-deps`（自动装缺项）。
3. **cron**：系统版本漂移 → 闲时自动重打包（unlock_timeout 防重入，Queue 子进程执行）。
4. **下载部件**：前台「下载 App」部件（widget 注册 `extends/module/Weline_Widget/Weline_App/widget.php`），各端入口（iOS/Android 直装/Web PWA）。
5. **API**（本模块 Controller/Api，多语言多货币契约）：`GET app/api/config`（启动配置）· `GET app/api/version`（版本检测）· `GET app/api/download`（产物下发，读构建期发布戳，缺戳 fail-fast）。
6. **Flutter app-template**：汉服风（朱砂 rgb(177,63,60) / 奶油 / 水墨），海外习惯（底部 Tab、大标题、左滑返回、无启动广告），轻量自更新（Android 装包 / iOS 跳商店）。

### 明确不做（V1）
- 不做 iOS 热更新（合规硬边界）；不做支付闭环（V2 定）。

## 二、架构（已冻结决策）

| 决策 | 内容 |
|---|---|
| 签名 | **平台统一签名**（私钥只在官方平台；站点 APK 自更新签名永久一致） |
| iOS | **平台云编译**；V1 云编译未就绪前 iOS 入口=App Store 占位链接；测试用本机 Xcode |

## 二·B、App 形态（2026-10-25 冻结：增强壳）

> 用户拍板：**不改站点后台**，壳自己靠页面已有协议识别；底部菜单等由 App 原生实现，不是「包一层」。

| 项 | 决定 |
|---|---|
| 形态 | Flutter 增强壳：WebView 承载站点页面 + **原生 chrome**（底栏/顶栏/角标/刷新/断网页） |
| 页面识别 | `main[data-layout]`：homepage / shop / products / cart / checkout / search / not_found → 底栏高亮与顶栏形态 |
| 数据与语义 | `[weline-code]`（实测 109 处/首页）：`theme.widget.mini_cart_icon`（角标）、`theme.widget.account`（登录态）、`*.money_summary`、`*.coupon_slot` 等 |
| 网页 chrome | 隐藏 `header.weline-header`、`footer`、分销浮动件、Cookie 条（`visibility:hidden+height:0`，保留 DOM） |
| 主题继承 | `getComputedStyle(:root)` 取 `--color-primary`/`--color-surface`/`--font-family-base` → 原生顶栏/底栏换色 |
| 原生底栏 | 5 Tab：Home `/`、Shop `/shop`、Search `/search`、Bag `/cart`、Account `/customer/account`（302→登录） |
| 原生增值 | 购物车角标、下拉刷新、骨架屏、断网页、推送、生物识别、深链（支付回跳/分享）、原生分享、版本检测+强制更新 |
| 降级 | 三级：`data-layout` 缺失→URL 前缀；`weline-code` 缺失→`header/nav[aria-label]/.mini-cart`；全失败→整页兜底（原生底栏仍可用） |
| 可选静态覆盖 | `/.well-known/weline-app.json`（选择器覆盖，404 用内置默认；**不是后台机制**） |
| 不做（V2 可选） | 原生重写商城页；`pages/{handle}` 区块协议（SectionRenderer）暂缓 |
| 设计基准 | 朱砂 #b13f3c / 奶油 #f7f2ef / 墨 #2b2622；5 Tab；无弹窗浏览（详情/购物车/结算均为整页）；海外使用习惯（底部导航、大标题、无启动广告） |

## 二·D、推送 / 签名 / SSE 打包（2026-10-25 决策）

### 推送（App 模块自持表，按站点范围）

```
w_weline_app_device_token
  id, website_id, platform(android|ios), token(512), token_hash(char 64),
  locale, currency, customer_id(0=游客), app_version, os_version,
  enabled(1), last_seen_at, created_at, updated_at
  UNIQUE uk_site_platform_token(website_id, platform, token_hash)
  KEY idx_site_enabled(website_id, enabled)
```
- API（公开只读侧，guest 允许）：
  - `POST /api/weline_app/rest/v1/push/register` `{platform,token,locale,currency,customer_id?}` → upsert + `last_seen_at`
  - `POST /api/weline_app/rest/v1/push/unregister` `{token}`
- 后台：设备列表（按站点/平台/状态筛选）、测试推送、按站点群发。
- 凭据：`w_weline_app_push_credential`（scope_website_id 0=全局，platform，provider fcm|apns，credential_json 加密，enabled）。
- 发送：后台/队列按 `website_id + enabled` 拉 token 批量推送；失效 token 置 `enabled=0`。

### 签名（后台配置，按范围固定）

```
w_weline_app_signing_profile
  id, scope_website_id(0=全局), platform(android|ios), bundle_id,
  keystore_ref, keystore_alias, keystore_password_enc, key_password_enc,
  cert_ref, provisioning_profile_ref, team_id, export_method(development|ad-hoc|app-store),
  status(active|retired), created_at, updated_at
  UNIQUE uk_scope_platform(scope_website_id, platform)
```
- 私钥/证书**加密存储**（框架加密能力 + 环境密钥），API 永不回显明文，只回 `has_keystore/has_cert/expires_at`。
- 构建优先级：站点专属 profile → 全局 profile → 报错「未配置签名」。
- Android：构建前写 `android/key.properties`，gradle 使用 `signingConfigs.release`。
- iOS：`ExportOptions.plist`（teamID/provisioning/export_method）→ `xcodebuild -exportArchive`。
- 上线后签名固定：后台把 profile 标记 `active` 并锁定，构建只读不覆盖，避免签名漂移（L143）。

### SSE 打包（后台实时日志 + 下载）

- `GET /weline_app/backend/build/stream?website_id=&platform=` → `text/event-stream`：
  - `event: log` 逐行构建日志
  - `event: progress` 阶段（toolchain→config→build→sign→collect）
  - `event: done` `{build_id, size, sha256, download_url}`
  - `event: error` `{message}`
- 构建仍走 Queue 子进程（L5），SSE 只做**日志流**，不阻塞请求（读 `var/app/build/{build_id}.log` + tail）。
- 后台「打包」按钮 → 打开 SSE 面板 → 完成后直接下载产物。
- 产物下载沿用 `download` 接口（登记表 + 构建期戳，L7）。
