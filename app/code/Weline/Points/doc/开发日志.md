# Weline_Points 开发日志

## 2026-10-26 · 新建万能积分与 VIP 等级模块

- 新增模块 `Weline_Points`，版本 `1.0.0`，模块代码 `app/code/Weline/Points`。
- 赚分入口：`Weline_Order::order_paid`，观察者 `OrderPaidObserver`；退款扣回入口：`Weline_Order::order_refunded`，观察者 `OrderRefundedObserver`。
- 四张表：`w_weline_points_vip_level`、`w_weline_points_customer_state`、`w_weline_points_earn_record`、`w_weline_points_clawback`（`w_` 为当前站点表前缀）。
- 默认 VIP 等级种子：普通 / 白银 1000 / 黄金 5000 / 铂金 20000 / 钻石 50000。
- 后台配置模板：`points/earn/*`、`points/growth/*`、`points/vip/*`，全部默认关闭（等级倍率开关默认开，但 VIP 总开关默认关）。
- 可花余额仍只走 `Weline_CustomerAsset` 的 `asset_code=points`；本模块没有第二本余额，也没有新增账本事件类型。
- 退款扣回使用 `reserve()` + `commit()`，实扣不超过可用余额，差额写入 `unrecovered_points` 审计欠账。
- 为读取订单已提交资产抵扣额，新增 `Weline_Order\Api\OrderAssetAllocationSnapshotReaderInterface`，由 `OrderAssetAllocationSnapshotService` 实现；Points 只依赖 `Weline_Order\Api\*`。`Weline_Order` 版本从 `2.13.77` 升到 `2.13.78`。

## 2026-10-27 · 1.1.0：基准货币、累计积分、商品属性、结账抵扣

- 赚分改为按**站点基准货币**计算：新增 `PointsBaseCurrencyResolver`；结账币实付现金先换基准币，缺汇率整单跳过。`EarnRecord` 增加 `checkout_currency`、`checkout_cash_minor`、`base_currency`、`cash_base_minor`、`items_snapshot_json`。
- VIP 等级增加累计赚取积分依据：`CustomerState.lifetime_points`；默认 `points/vip/basis=lifetime_points`，抵扣/退款不降低累计积分。
- 商品积分属性：自动声明 Product EAV `points_earn_ratio`（`input_decimal_2`）与 `points_earn_fixed`（`input_int`），挂在 `storefront/specs`；新增 `PointsItemEarnCalculator` 逐行计算，新增后台默认比例/固定值。
- 结账抵扣：新增 `PointsCheckoutDiscountQuote`、`PointsDiscountSettlementService`、`PointsPaymentAssetPolicyProvider`、`PointsCheckoutApplySession`、`CheckoutPointsDiscountApplyObserver`、`PointsQueryProvider`；默认单笔上限 30%。
- Checkout 集成：`CheckoutOrderPaymentService` 在支付前预占、成功提交、失败/取消释放、退款按比例退回。默认 30% 上限，积分不会单独把应付降到 0，现金仍走 PSP。`CheckoutQueryProvider` 接受 `points_discount_apply_minor`，未显式传时读取 `PointsCheckoutApplySession`。
- 前端：新增 body-end Hook + `points-discount.js` + `weline.modules.js` 注册；购物车、迷你购物车、结账页有挂载点时显示积分抵扣面板，调用 `points` 查询并把 `points_discount_apply_minor` 写入表单。
- 表：新增 `w_weline_points_discount_apply`；`w_weline_points_customer_state` 加 `lifetime_points`；`w_weline_points_earn_record` 加 5 列。
- 模块版本 `1.1.0`；`Weline_Checkout` 升到 `1.5.116`（optional `Weline_Points` + `CheckoutPaymentIncentiveApplierInterface` 注入点）。
