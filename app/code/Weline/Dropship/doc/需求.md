# 需求 · Weline_Dropship

## 目标

提供万能货源/代发壳：多供应商可注入；范围启用平台；拉品首刊；价格/库存/上下架跟随；支付后按 provider 拆推单；运费分段报价；Webhook Inbox；经营面板。

## 纠偏

- 不合理：只做单一 CJ 大包、菜单叫「分销」撞 Affiliate。
- 更合理：壳 + Provider；菜单「货源代发」；CJ optional。

## 硬边界

- 仅壳写 Product/Inventory、listing 真源、Outbox/Inbox 终态。
- Provider 只返回 Snapshot / API 结果；`getCode()===source marker`。
- Observer/Cron 只入队，禁止直调远端 HTTP。
- `order_paid` Observer 须能从 Order 持久快照（`catalog_snapshot_json` / OrderItem）解析代发行，不得只依赖可能为空的 `getItems()`。
- 后台履约订单列表须对运营可读（中文列/状态语义/本站单号），禁止仅暴露英文技术键。
- 履约行须可展开查看本站订单商品信息（手风琴，异步拉取）。
- 订单商品「商品」列须展示缩略图（优先行快照图，否则 `DropshipListing.thumb_url`）；无图时占位，不破坏货号/数量/价格列。
- 一 local offer 唯一 `dropship_source`。
- 涨价比例以范围配置 `dropship/pricing/uplift_percent`（默认 30）为真源。
