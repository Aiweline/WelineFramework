# 功能现状 · Weline_Dropship

## 已实现

| 能力 | 状态 | 路径 |
|------|------|------|
| SPI + Extends 扫描 | 已实现 | `extends.php`、`DropshipProviderScanner`、`FakeDropshipProvider` |
| 范围平台/涨价比例 | 已实现 | SystemConfig `dropship/platforms/enabled`、`dropship/pricing/uplift_percent` + adapter `dropship.channels`；后台 Config 页 `config:embed` 必须用同字面 key |
| 仓映射 | 已实现 | `dropship_scope_warehouse_map` + 后台 CRUD；后台页已对齐 w-card/w-table/w:scope（供应商下拉 + 作用范围解析 ID） |
| 首刊 | 已实现 | `DropshipPublishService` → ProductAdminCommand + listing |
| 跟随 | 已实现 | `DropshipFollowService` 价策略 + `setOnHand`；Cron→Queue |
| 推单 | 已实现 | `order_paid`→Outbox 按 provider 拆单→Queue |
| 运费聚合 | 已实现 | `DropshipFreightAggregator`（壳内聚，不改 Shipping 核） |
| 可售闸 | 已实现 | `DropshipSellGate` |
| Webhook | 已实现 | `callback/notify?endpoint_code=` + Inbox + Consumer |
| 售后/面板 | 已实现 | AfterSale/Dashboard 可按 provider 筛；降价 tip 计数 |
| 菜单 | 已实现 | 「货源代发」 |

## 未做 / 已知边界

- 结账瞬间锁远程库存（不做）
- 多 CJ 账号（不做）
- Provider 取消无能力 → Outbox `skipped:unsupported`
- Shipping 核无多贡献 SPI：运费经壳 Aggregator 供结账扩展读取
