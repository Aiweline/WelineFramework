# 功能现状 · Weline_Dropship

## 已实现

| 能力 | 状态 | 路径 |
|------|------|------|
| SPI + Extends 扫描 | 已实现 | `extends.php`、`DropshipProviderScanner`、`FakeDropshipProvider` |
| 范围平台/涨价比例 | 已实现 | SystemConfig `dropship/platforms/enabled`、`dropship/pricing/uplift_percent` + adapter `dropship.channels`；后台 Config 页 `config:embed` 必须用同字面 key；`1.0.51` 起售价=原币→站点货币换汇后再 ×(1+uplift%) |
| 仓映射 | 已实现 | `dropship_scope_warehouse_map` + 后台 CRUD；后台页已对齐 w-card/w-table/w:scope；国家用 `<w:theme:address selection=single levels=country>`（禁止手填 ISO） |
| 首刊 | 已实现 | `DropshipPublishService` 真实 CREATE+PUBLISH；已刊表点击行手风琴异步本地详情/规格（`1.0.53`）；**`1.0.70` 起状态列双徽章：sync + 本地 lifecycle（已发布/已下架等）**；顶层「货源商城」+ 拼音 slug + dropship 属性集 + 来源标记；货源商品「选品」三栏工作台；DraftAdmit 拉取 pending + 批量刊登；选品原价带货币；CJ Provider 组装图/规格/描述/货源属性 |
| 跟随 | 已实现 | `DropshipFollowService` 价策略 + `setOnHand`；Cron→Queue；开关 `dropship/ops/follow_enabled` 在货源 Config 页（「启用库存/价格跟随」） |
| 推单 | 已实现 | `order_paid`→Outbox 按 provider 拆单→Queue；仓映射缺失降级空 map（`1.0.59`）不阻断推单；`1.0.65` 起 Observer 读 `catalog_snapshot_json`/`OrderItem` 与 shipping JSON（不依赖空 `getItems()`）；**`1.0.71` 起无法履约进 `dead` 终态，可选自动行级退款+安慰邮件（开关默认开）** |
| 履约订单后台 | 已实现 | `1.0.66` 人性化列表；`1.0.67` 行手风琴；`1.0.68` ensure 强制加载修复点击展开 |
| 运费聚合 | 已实现 | `DropshipFreightAggregator`（壳内聚，不改 Shipping 核） |
| 可售闸 | 已实现 | `DropshipSellGate` |
| Webhook | 已实现 | `callback/notify?endpoint_code=` + Inbox + Consumer；**`1.0.75` 起生产可复用支付 DevRelay 中继到本机** |
| Webhook 中继说明 | 已实现 | `dropship/backend/dev-relay`（开关在支付 DevRelay） |
| 售后/面板 | 已实现 | AfterSale/Dashboard 可按 provider 筛；降价 tip 计数；**`1.0.71` AfterSale 含 `dead` 与补偿态列** |
| 菜单 | 已实现 | 「货源代发」 |

## 未做 / 已知边界

- 结账瞬间锁远程库存（不做）
- 多 CJ 账号（不做）
- Provider 取消无能力 → Outbox `skipped:unsupported`
- Shipping 核无多贡献 SPI：运费经壳 Aggregator 供结账扩展读取
