## 未做 / 已知边界

- 结账瞬间锁远程库存（不做）
- 多 CJ 账号（不做）
- Provider 取消无能力 → Outbox `skipped:unsupported`
- Shipping 核无多贡献 SPI：运费经壳 Aggregator + Checkout overlay 事件供结账读取（已接）
- 壳禁止读供应商私有键（如 `params.cjOrderId`/`pid`）；一律经 Provider `parseWebhook` 产出标准块
- 货源商若某 topic 做不了：`getCapabilities()['webhook_xxx']=false`，壳仍 ack Inbox
- 未刊 listing 的 PRODUCT/STOCK：只入 Inbox，跟随入队 0 条（无本地 listing 可同步）
