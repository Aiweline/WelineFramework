## 目标

在不破坏现有 CMS 页面、Theme 布局、发布 URL、权限和网站作用域的前提下，增加：

- 网站范围内的 CMS 多语言标题；
- 英语标题驱动、对搜索引擎友好的 slug；
- CMS 语言和布局切换时，Theme 编辑器与可视预览即时跟随；
- 仅补空值、可恢复和可重试的一键翻译；
- 全局 `<w:i18n:switcher>` 的可靠真实跳转。

## 人性化原则

1. 默认保护已有内容：翻译不覆盖非空值，已发布 slug 不自动变化，手工 slug 不被标题覆盖。
2. 页面只显示所属网站支持的语言；`website_id=0` 是合法默认网站。
3. 切换语言前保留未保存输入，切回来不能丢字。
4. 布局和语言先即时刷新预览，只有保存页面才持久化布局。
5. 长任务显示真实进度；允许离页后恢复，部分成功保留并只重试失败项。
6. 浏览器业务请求只走 `Weline.Api.*` 和公开 QueryProvider。

## 数据所有权

### CMS Page

保留现有 `Page.title` 作为兼容主标题。新增：

- `source_locale`：网站支持 `en_US` 时默认英语，否则为网站默认语言；
- `slug_mode`：`auto` 或 `manual`；
- `slug_source_hash`：最后一次自动 slug 所依据英语标题的摘要。

### CMS PageLocale

新增表 `weline_cms_page_locale`，由 ORM 模型属性声明字段与索引：

| 字段 | 规则 |
|---|---|
| `page_locale_id` | 主键 |
| `page_id` + `locale_code` | 唯一 |
| `title` | 本地化标题；空值不覆盖回退标题 |
| `origin` | `source`、`manual` 或 `ai` |
| `source_hash` | AI 翻译所依据源文本摘要 |
| `created_at` / `updated_at` | 审计时间 |

没有 locale 行的旧页面继续回退 `Page.title`。源语言标题保存时同步主标题，保证旧调用方不变。

### Theme

Theme 继续拥有布局与可翻译配置。CMS 只能通过 Theme 新公开接口枚举和写入目标字段，依赖方向保持 `CMS -> Theme Api`，Theme 不反向依赖 CMS。

## Slug 状态机

1. 新草稿默认 `auto`。
2. 优先由 `en_US` 标题生成；没有英语时使用源标题并通过 PHP `Transliterator` 音译。
3. 转小写，以 `-` 合并非字母数字并去除首尾连接符；空结果才使用稳定的 `page-{id}`。
4. 自动冲突在同网站完整 identifier 后追加 `-2`、`-3`。
5. 用户直接编辑 slug 后进入 `manual`，标题不再联动。
6. 草稿且 `auto` 时英语标题变化更新 slug。
7. 发布后默认冻结；只有明确手工编辑才改变。
8. 历史随机草稿可在标题首次改变时替换；历史正常 slug 和已发布 URL 保持。
9. 手工 slug 冲突继续报错，不静默加后缀。

## CMS ↔ Theme 预览桥

协议：`weline.cms-theme-editor.v1`。

- 父页面发送 `set-context`：`pageId`、`websiteId`、`locale`、`layoutOption`。
- iframe 回报 `ready`、`context-applied`、`dirty-state`。
- 双方只接受 `event.origin === location.origin`；父页面还校验 `event.source === iframe.contentWindow`。
- 消息不传 token、Cookie、bootstrap ID。
- 桥未就绪或确认超时才用带 locale/layout 的 iframe URL 重载兜底。
- layout 消息只改变预览状态；保存页面时才走现有布局持久化流程。

## 一键翻译

- 默认源语言英语；网站不支持英语时用页面 `source_locale`。
- 目标只取页面网站支持的非源语言，只翻译 CMS 页面标题。
- CMS 通过 `Weline\TranslationService\Api\TranslationServiceInterface` 调用已发布翻译能力，不依赖具体 provider。
- 默认 `missing-only`；数据库非空值、浏览器未保存输入和源 hash 变化都阻止覆盖。
- 源标题尚未保存时明确提示先保存，不做隐式表单提交。
- 后台使用 `Weline.Api.resource('runtime_task')` 启动 `cms.page_translation` 并轮询，不使用 backend SSE 或 fetch。
- 每个 locale 记录 effect/checkpoint；成功项立即保留，失败后重新计算仍缺失目标。
- 页面刷新按 page id 恢复 task handle；终态后清理本地句柄。

## 全局语言切换

- 服务端 href 是唯一权威导航结果。
- 后台 URL 始终保留 locale 段，包括默认语言；保留随机 backend key、货币、query 和 hash。
- JS 点击只写语言偏好并导航服务端 href；只有无 href 的旧编程调用才走单一兼容 fallback。
- 同路径目标执行 reload。

## 兼容与失败

- 非网站语言由服务端拒绝。
- Theme 桥失败只回退 iframe 重载，不影响页面数据。
- AI 不可用时仍能人工维护；任务保留成功项并显示可重试错误。
- 不新增第三方 slug 包，不批量改写历史 URL，不修改生产端口 `9501`。
- 不 commit、push、部署或同步站点仓库。
