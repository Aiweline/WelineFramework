## 2026-09-27 — CF FPC 规则无法触发（1.0.7）

- 现象：汉服生产 `x-weline-fpc: HIT` 但 `cf-cache-status: DYNAMIC`；用户已配 OAuth Client，整页仍不进 CF。
- 根因：
  1. 生产 `w_cdn_account` / `w_cdn_domain` 仍为空（OAuth Client ≠ CDN 账户/Zone 绑定）。
  2. `putRules` 把 action 写成 `{cache:{ttl}}`，Cloudflare 实际要 `action=set_cache_settings` + `action_parameters`。
  3. 默认 FPC 桥接规则匹配响应头 `x-weline-cache-status` + 非法 `cache_reserve`；请求阶段 Cache Rules 无响应字段，且适配器会丢弃该 action。
- 变更：`Cloudflare::formatRulesForApi` 对齐官方 Cache Rules；`default-rules.json` 改为店面 GET `bypass_by_default`；Framework FPC HIT 出站写 `CDN-Cache-Control` / `Cloudflare-CDN-Cache-Control` + `X-Weline-Cache-Status`。
- 验收：单测 `CloudflareTest::testFormatRulesForApiEmitsSetCacheSettings`、`RulesPushDefaultsTest`；生产需账户+域名绑定后 `cdn:rules:push:defaults`，PDP 二次请求 `cf-cache-status` 为 MISS/HIT。
