# 爬虫策略三端下发（WLS / Cloudflare / robots.txt）架构方案

状态：P0/P1/P2/P4 已落代码；P3 队列/重试待做
适用：Weline 站点级爬虫 allow/block 名单
约束：Cloudflare 免费套餐（Free）

## 0. 实施状态

- P0：`CrawlerBlockCatalog` token 映射、`CrawlerPolicyEntry` DTO、`CrawlerPolicyProviderInterface`、`CrawlerPolicyProvider`、策略归一化回填。
- P1：`CrawlerPolicyRulePlanner`、`CloudflareCrawlerPolicyPublisher`、`CrawlerPolicyState`、`cdn:crawler-policy:sync|status|drift`、WAF 权限文档。
- P2：`Weline_Websites::crawler_policy_saved` 事件 + afterCommit best-effort 发布。
- P4：robots.txt 按站点 policy 输出 block 分组（allowlist 硬底不输出 Disallow；同 token allow 优先；站点 allow Google-Extended 时抑制 legacy Disallow）。
- 审查修复：CF `contains` 大小写（token 统一小写）、DB 读取失败不删边缘规则、同 Zone 其他站点规则存在时失败关闭、同 token allow 优先。
- 待做：P3 队列/退避、robots FPC 即时失效、后台状态 UI、生产 CF 实推（需人工授权）。

## 1. 目标

以 `WebsiteCrawlerPolicyService` 的 entries 为唯一事实源，同一条目产生三种表示：

| 消费端 | 使用字段 | 下发方式 |
|---|---|---|
| WLS 源站 | `pattern`（现有语义不变） | `AttackDetector` domain_overrides |
| Cloudflare WAF | `ua_tokens`（字面 token，`contains`） | `http_request_firewall_custom` entrypoint |
| robots.txt | `robots_token` / `ua_tokens` | `RobotsTxtRenderer` 输出分组 |

解决现状：CF 托管 robots.txt（Bot Preference Sync）禁止了框架 `CrawlerBlockCatalog::allowlistEntries()` 中允许的 AI 爬虫，例如 GPTBot、ClaudeBot、Google-Extended、GoogleOther、Applebot-Extended、Bytespider、CCBot、Amazonbot、meta-externalagent、cohere-ai、MistralAI、Baiduspider、PetalBot、KimiBot。

## 2. 已确定决策

| 项 | 决定 |
|---|---|
| CF 套餐 | Free；只用 `contains`，不用 `matches` 正则 |
| CF 规则容量 | block 全部 UA 用 `or` 聚合成 1 条；Free 5 条上限只约束 Zone 现有第三方规则，不按爬虫数量拆分 |
| Zone 多站点冲突 | 检测到不同策略共享同一 Zone 时失败关闭，不自动覆盖 |
| allow 是否生成 skip | 默认关闭；不生成 allow/skip 规则 |
| robots 优先级 | 站点 crawler policy 覆盖 legacy `seo.robots.google_extended` |
| 保存后发布 | P2 afterCommit best-effort（短超时）；P3 加队列/重试 |
| 状态表归属 | Weline_Cdn |
| 多 UA 条目 | `ua_tokens: list<string>` + `robots_token` 主 token |
| 共享 Zone 首次创建 | 必须人工确认；独立 Zone 可自动创建 `weline-crawler:` 规则 |
| OAuth scope | 精确 scope ID 以 CF 控制台实际可勾选值为准，代码配置化；缺失时报 `waf_scope_missing` |

## 3. 现状与根因

- 名单源：`app/code/Weline/Server/Security/CrawlerBlockCatalog.php`
- 站点策略：`app/code/Weline/Websites/Service/WebsiteCrawlerPolicyService.php`
  - 保存后同步 WLS `domain_overrides.crawler_block`
  - `normalizeInput()` 目前只保留 `pattern`
- robots：`app/code/Weline/Seo/Service/Protocol/RobotsTxtRenderer.php` 只输出通用规则
- CF 推送：`app/code/Weline/Cdn/Adapter/Cloudflare.php` 只写 `http_request_cache_settings`
- CF 托管 robots：无公开 API 开关，只能 Dashboard 关闭 Bot Preference Sync / Block AI bots

## 4. 架构原则

1. 单一事实源：WebsiteCrawlerPolicyService entries。
2. Cdn 不直接依赖 Websites 具体 Service，只依赖 Interface/Event。
3. 只替换 description 前缀 `weline-crawler:` 的 CF 规则，保留第三方规则。
4. CF 同步失败不阻断网站保存；状态可查、可重试。
5. UA 可伪造，allow 不作为鉴权；WLS `crawler_block` 保留兜底。
6. HTTP/远程副作用只在 afterCommit 或队列执行。

## 5. 组件与调用链

```
[后台 爬虫策略]
  -> WebsiteCrawlerPolicyService::saveForWebsite()
     -> WLS domain_overrides（现有）
     -> event Weline_Websites::crawler_policy_saved
        -> Cdn\Observer\CrawlerPolicySavedObserver（afterCommit）
           -> CrawlerPolicySyncService
              -> CloudflareCrawlerPolicyPublisher
                 -> http_request_firewall_custom entrypoint
           -> CrawlerPolicyState（状态/hash/错误）

Seo\RobotsTxtRenderer
  <- event Weline_Seo::protocol::robots_contribute
  <- Websites 观察者贡献 policy_groups（P4）
```

## 6. 数据模型与接口

### 6.1 DTO

`Weline\Websites\Api\Crawler\CrawlerPolicyEntry`

```php
final readonly class CrawlerPolicyEntry
{
    public function __construct(
        public string $id,
        public string $name,
        public string $action,       // allow|block
        public bool $enabled,
        public bool $builtin,
        public string $category,
        public string $reason,
        public string $pattern,      // WLS regex
        public array $uaTokens,      // CF contains + robots
        public string $robotsToken,  // robots 主 token
    ) {}

    public static function fromArray(array $row): self;
    public function toArray(): array;
}
```

校验：
- action 非 allow 一律归一为 block；
- ua token 仅可打印 ASCII，禁止引号、反斜杠、换行，长度 <= 128，大小写不敏感去重；
- pattern 保持现有 preg_match 校验；
- 旧记录缺 ua_tokens/robots_token 时按 id 从 `CrawlerBlockCatalog` 回填；找不到标记 `token_missing`，不阻断保存。

### 6.2 Provider

## 7. CF 规则生成（Free）

只消费 `action=block && enabled && uaTokens != []`：

```
(http.user_agent contains "Diffbot" or
 http.user_agent contains "SerpstatBot" or ...)
action = "block"
description = "weline-crawler:v1:block:<hash12>"
```

- allow 默认不生成任何规则。
- 前缀包含关系加否定条件，例如：
  `http.user_agent contains "Applebot" and not http.user_agent contains "Applebot-Extended"`
- 不把 WLS 正则塞进 CF。
- token 为空/非法时跳过并记录 `skipped_entries`，不阻断其他条目。

### 合并与幂等

1. GET `http_request_firewall_custom` entrypoint；
2. 过滤掉 description 以 `weline-crawler:` 开头的 ours；
3. 第三方规则原顺序保留；
4. 我们的规则放最前；
5. `desired_hash` 与远端 ours hash 相同则不 PUT；
6. `--force` 可强制重推。

### 限额

- block 全部 UA 用 `or` 聚合成 1 条，不按爬虫数量拆规则。
- Free 自定义规则上限 5 只约束“第三方规则数 + 我们的 1 条”；超限失败关闭，不删除/截断第三方规则。
- 单条表达式过长（保守 4KB）时才拆分；拆分仍按 group 聚合，不回到一条爬虫一条规则。
- 200 条 entries 只影响 token 数量和表达式长度，不影响规则条数。

### 安全

- token 白名单字符、长度上限、去重、表达式转义；
- 表达式总长度保守限制 4KB；
- 日志不记录完整 UA、Token、secret；
- 不允许后台注入任意 CF 表达式。

## 8. 权限

- Cloudflare API Token 需要 Zone WAF Edit。
- OAuth 需要对应 WAF/Rulesets 写权限；精确 scope ID 以 CF 控制台实际可勾选值为准，写入 `cdn/cloudflare/oauth_scopes`。
- 缺 scope 时返回 `waf_scope_missing`，提示重新授权，不自动重试。
- 更新 `Cloudflare-OAuth-Client-Setup.md` 与 `Cloudflare-API-Token-Permissions.md`。

## 10. 分阶段

### P0 数据模型与契约
- `CrawlerBlockCatalog` 补 `ua_tokens` / `robots_token`。
- `WebsiteCrawlerPolicyService::normalizeInput()` 保留并校验新字段，旧数据回填。
- 新增 DTO、Provider、StatusProvider。
- 单测：字段归一、回填、WLS 行为不变、hash 稳定。

### P1 CF 发布器 + dry-run
- `CrawlerPolicyRulePlanner`（纯函数）。
- `CloudflareCrawlerPolicyPublisher`（GET/PUT WAF entrypoint、合并、幂等、限额）。
- 状态表与 CLI。
- OAuth scope/文档。
- 验收：dry-run 输出表达式与 hash；单测覆盖第三方保留、幂等、限额、非法 token；不连真实 CF。

### P2 保存后自动同步
- 新增事件 `Weline_Websites::crawler_policy_saved`。
- Cdn 观察者 afterCommit best-effort，异常只写状态。
- 后台状态最小展示。
- 验收：无 scope/断网时保存成功且状态 failed；恢复后 CLI 同步成功；第二次不 PUT。

### P3 队列与漂移
- Queue consumer、重试/退避、attempts。
- 漂移检查：远端 ours 被删/改/顺序变化。
- 共享 Zone 首次创建人工确认。
- 验收：手动改 CF ours 后 drift 非 0；sync 恢复；第三方规则仍在。

### P4 robots.txt 对齐
- `robots_contribute` 增加 `policy_groups`。
- Websites 观察者按条目输出 allow/block 组。
- 站点 policy 覆盖 legacy `seo.robots.google_extended`。
- 保存策略后失效 robots FPC/边缘缓存。
- 验收：robots 中 allowlist 无 `Disallow: /`，block 条目有 `Disallow: /`。

## 12. 风险与不做

风险：
- 同 Zone 多站点策略冲突（失败关闭）。
- `contains` 前缀误伤（否定条件）。
- Free 5 条容量只影响第三方规则已占满的情况；我们的名单始终只占 1 条（超长才拆）。
- OAuth scope 需控制台确认。
- CF managed robots 只能人工关闭。
- UA 可伪造，allow 不是鉴权。
- robots 优先级需显式覆盖。
- CF 最终一致性，drift 检查需容忍时间窗。

不做：
- 不把 WAF 规则写进 cache phase 的 `default-rules.json`。
- 不用 UA allow 替代 WLS `crawler_block`。
- 不一条爬虫一条 CF 规则。
- 不覆盖第三方 WAF 规则。
- 不在网站保存事务内发 HTTP。
- 不自动调用 CF API 关闭 managed robots / Bot Fight / AI Crawl Control。
- 不执行生产 curl/探测；测试不连真实 CF。
- 不手改 `generated/`。
- 不覆盖用户未提交的其他脏改。
