# Weline_Shipping 需求基线

## 当前范围

### SHIP-RATE-TABLE-001 / SHIP-PROFILE-002（第1章）

- Local Custom rates：`weight_table` / `price_table` / `fixed`；`rate_brackets`；`max_weight_kg`；表类型不计 base_fee。
- 计费重：需配送须重量+三边；体积重 LWH/5000；合计超 max 拒报；缺重拒 weight_table。
- Profile 实体：`SEED_PROFILE_GENERAL` / `SEED_PROFILE_HEAVY`；Offer/分类绑 profile_code；空→General；>30kg 可售须 Heavy。
- 一次 seed：General 九线≤30 + Heavy 两线≤1000。
- 多 Profile：provider+name 合并或合成最低价之和；禁 Local 顶替外物流失败。
- 规格：`doc/开发/spec/shipping-ch1-rate-profile.md`。第2–4章见分章计划。

### SHIP-SURCHARGE-001 / SHIP-ADDR-CAP-001 / SHIP-HAZMAT-001（第2章）

- Local 偏远加价：`ShippingSurchargeRule`（省名/邮编前缀/国家）；免邮清零模板费但保留加价；非 local Provider 默认不加店铺偏远。
- 地址 `delivery_point_type` × 航线 `allowed_point_types`（默认不含 pobox/military）。
- 行 `shipping_hazard_class` × 航线 `accepted_hazard_classes`（空=仅普货）。
- Offer `shipping_hazard_class`（SCHEMA 4.9.0）；种子 CN 六省偏远。
- 规格：`doc/开发/spec/shipping-ch2-gates-surcharge.md`（含验收矩阵 / `ship-ch2-e2e`）。第3–4章未交付，不得宣称防漏收做完。

### SHIP-PACK-001 / SHIP-ADDON-001 / SHIP-SEASONAL-001（第3章）

- 同仓分箱：`ShippingPackingPolicy`（max 重/体积）；虚拟箱 Local 价相加；与多仓拆单正交。
- 签名/保价：`ShippingCheckoutAddon`；quote `addons`。
- 旺季/燃油：`ShippingSeasonalRule`；种子默认关。
- 规格：`doc/开发/spec/shipping-ch3-pack-addon.md`（含验收矩阵 / `ship-ch3-e2e`）。

### 验收纠偏（跨章）

- 每章规格必须含 EARS + UC 表 + `acceptance_ids`（ut/rt/wb/e2e）；计划组套 `ship-anti-undercharge-plan-suite`。
- 规格 `ready-for-plan` + 章通路 e2e PASS 后才允许章 done。

### SHIP-SPLIT-001 多仓拆单运费

- 履约按仓拆包；运费各仓相加；顾客选方案家族，各包自动取最具体可达航线。
- `WarehouseShippingOrigin` 权威绑定仓↔发货地址；Inventory `FulfillmentSplitPlanInterface` 只读规划；Shipping 不扫 Quota。
- `request_hash` 必须覆盖 packages；整单免邮则各包 0；profile 冲突 fail-closed。
- RateTemplate 仍只做公式，禁止仓×目的矩阵；后台禁止承诺按距离。

### SHIP-REGION-CATALOG-001 国家权威源为地址库

- 后台地区管理国家列表仅来自 Shipping `Region`（`TYPE_COUNTRY`），由 `shipping:addresscatalog:import` / `data/address-catalog/countries.tsv.gz` 写入。
- 禁止从 I18n `CountryRepository` 拉取或「从i18n同步国家」写入国家节点。
- 无国家数据时提示导入地址库，而非同步国际化模块。

### SHIP-REGION-LOCAL-001 地区名称 LocalModel

- `Region`（国家/省/市/区）、`Street`（街道）与 `PostalPlace`（邮编地点 `place_name`）各有 `LocalDescription`。
- 展示按当前 `local_code` 读 Local；缺翻译回退主表名。
- **翻译取源**：主表已有 `region_name`/`street_name`/`place_name` 时，即使 Local 无源语言行，也以主表名为源，经 `LocalModelTranslation` 补其它语言。不要求先写源语言 Local，也不单独为英语硬编码配置。
- `data/region-locals/*.tsv` 仅可选离线回填。
- 用户地址表（`DeliveryAddress`/`ShippingAddress`）的 `name` 为个人昵称，不做 LocalModel。

### SHIP-EMBARGO-REASON-001 禁运原因字典 LocalModel

- `EmbargoReason` 主表存 `reason_code` + 默认 `reason_name`；`EmbargoReason\LocalDescription` 按语言存名称。
- 系统禁运页提供快捷原因管理（增/删自建；种子不可删）；名称用 `<local>` 编辑多语言。
- 禁运列表「原因」列与新增下拉读取字典当前语言展示名（非裸 code）。
- 默认种子：`territory` / `no_commerce` / `sanction`；保存后可入队 `LocalModelTranslation`。

### SHIP-CHECKOUT-ADDR-001 结账收货地址部件

- 部件 `checkout-shipping-address` 经 `default_injections`（`layout_type=checkout`，`required=true`）注入结账页 `checkout-shipping-address` 槽。
- 目标槽由 Checkout `checkout-storefront-slots` 容器声明，保证 Theme 默认注入可发现；Checkout 页模板禁止裸拼国家/省/市 input。
- 模板提供已存地址选择与 `<w:theme:address code="checkout-shipping-address">` 级联。
- UX：有已存地址时默认只展示已选/默认地址并收起表单；点「更换地址」后再加载完整列表供 radio 单选；支持编辑与「使用新地址」；账单地址默认与收货一致，可取消勾选后单独填写（分段布局 + Amazon 卡片样式）。

### SHIP-FOOTER-HELP-001 页脚帮助中心配送/退换入口

- 前台提供配送说明页 `guide/shipping` 与退换政策页 `guide/returns`。
- 部件 `footer-shipping-info-link` / `footer-returns-policy-link` 经 `default_injections` 注入 Theme `footer-help-links`。
- 指南页默认正文须覆盖发货时效、配送范围、运费、物流跟踪、签收验收、异常赔付（配送）以及适用条件、不予退换、办理流程、运费、退款到账、换货与尺码建议（退换），不得仅保留三五句摘要。
- 指南页通过 Theme `layouts/guide/default` 页面包裹器渲染：主题内容宽度、亚马逊风格面板，并与页头/页脚拉开纵向间距。

### SHIP-ADDR-ACCOUNT-001 个人中心地址管理

- 已登录客户可在个人中心查看发货地址与收货地址两个独立区域。
- **顶部 Header「配送至 / 配送地址」与个人中心「收货地址」同源**（`DeliveryAddress`）；「发货地址」是店铺寄出地址（`ShippingAddress`），不得与顶部配送混为一谈。
- 账户菜单与侧栏地址入口须将「收货地址」置于「发货地址」之前，作为与顶部配送对齐的主入口。
- 发货地址空状态须提示：顶部配送地址请到收货地址查看，并提供跳转。
- **唯一地址自动默认**：客户仅有一条收货地址（或店铺仅有一条发货地址）时必须 `is_default=1`；创建首条、删除后仅剩一条、以及列表读取时的脏数据均须修复。
- 地址区域必须获得当前前台登录客户上下文，并且只允许读取和维护该客户自己的地址。
- 地址列表支持空状态、加载错误、地址卡片、新增与编辑表单，以及默认地址操作。
- 地址表单继续使用框架主题地址组件和表单组件，不在站点主题中复制字段实现。
- **与结账一致**：个人中心收货/发货地址编辑须使用 `<w:theme:address postal postal-lookup detail>`（邮编优先反查回填省市区 + 地址标签级联），禁止手写国家/省/市 select 或把邮编放在级联之后且无反查。
- 模板标签的编译结果依赖模板对象上下文；包含 `<lang>`、`<w:form>`、`<w:theme:address>` 等标签的渲染闭包不得声明为 `static`。
- 含动态属性的 `<w:theme:address>`（如 `country="<?= ... ?>"`）会走 `renderRuntimeTag`；`Weline_Theme\Taglib\Address` 必须提供 `runtimeCallback` 直接输出 HTML，禁止把编译期 `<?php ... ?>` 片段当作运行期返回值（否则会污染 Header 并吞掉后续页面主内容）。
- 只修改 `view/hooks` 等源模板，禁止修改 `view/tpl` 编译产物。

### SHIP-CARRIER-COV-001 承运商覆盖与网站可售匹配

- 启用承运商必须配置支持范围（`w_shipping_carrier_regions`）；Provider 可提供默认可改覆盖。
- 后台编辑支持范围须有明显谨慎提示；缩减覆盖会导致对应目的地失去该承运商配送方式。
- 结账配送方式主路径：系统禁运（最高优先）→ 店铺/渠道禁运 → 可售目的地（空则不限）∩ 承运商覆盖 → 按承运商 `sort_order` 推荐启用中的 ShippingService；结账方法列表须与 `listQuoteOptions`/`quoteRates` 同源（含 `shipping_profile_code` 过滤），禁止裸 `getByLocation`。
- 系统默认禁运：`scope_type=system`；后台可新增/解禁/再启用；**种子导入（origin=seed）标记为「系统」且禁止物理删除**；**后台自建（origin=manual）可删除**；仍禁 `replaceForScope(system)`；种子默认可仅国家级；后台「新增禁运」须列表主 CTA + `w-dialog`，内用 `<w:theme:address selection="single" levels="country|province" catalog="global" searchable cascade>`——**只选国家=国家级、选到省份=省级**；禁止页内整卡手写 ISO 表单。
- 费用模板只提供计费公式，不参与到达地区判定；「配送方案」= `ShippingService.service_code`（商品 Offer 可绑 `shipping_profile_code`，空=不限制）。目的地差异化定价通过多条 ShippingService（航线）配置，而非模板内地区矩阵。后台自建费用模板可删除；系统种子 `SEED_TPL_*` 不可物理删除；仍被配送服务引用时拒绝删除。
- **SHIP-LANE-001 相对当前位置航线报价（一期）**：发货锚点=店铺默认 `ShippingAddress`；**系统种子 `SEED_LANE_*` 必须绑定该当前仓发货地址**（禁止 `origin_shipping_address_id=0` 通配异地）；目的地覆盖=`w_shipping_service_regions`（国家/省/市/区，祖先命中）；结账 `quoteRates` 在禁运/可售/承运商覆盖之后按最具体航线过滤；免邮规则支持 `order_amount` / `region` / `mixed`。禁止复活 Zone。后台航线列表承运商/费用模板/发货锚点须显示可读名称（非裸数字 ID）。结账未显式传 origin 时须能回退解析默认/仓绑定/启用发货地址，避免种子航线被滤光。
- **SHIP-SCOPE-SEED-001 作用范围 + 默认可达种子**：`ShippingService` / `RateTemplate` / `FreeShippingRule` 带 `scope_type`+`scope_id`（website|store|channel）；后台页头 `<w:scope>` 切换后各范围独立配置；报价取 channel→store→website 最近非空层。默认种子：`data/default-markets/countries.tsv` 写入承运商覆盖与默认站分档航线（国内/港澳台/亚太/美欧等），排除系统禁运国。
- **SHIP-FREE-SEED-001 国际满额免邮种子**：`FreeShippingRule.origin=seed|manual`；系统种子 `SEED_FREE_{49,99,149,199,299,499}` 不可物理删除；默认仅启用 `SEED_FREE_99`，其余作可选启停模板；后台自建 `origin=manual` 可删。
- **SHIP-FREE-CONDITION-LOCAL-001 条件类型 LocalModel**：`FreeShippingConditionType` 字典 + `LocalDescription`；后台用官方 `<local>` 在「条件类型」顶部 Tab 维护多语言名称；规则列表 Tab「条件类型」列读取当前语言展示名（禁止裸显 `order_amount` 等码；同类型多行不重复挂 local，避免 ID 冲突）。页内顶部 Tab：`rules`（列表）/ `create`（新增）/ `conditions`（字典），禁止一页堆叠（`feature_ui_keep_simple_top_tabs`）。
- 网站/店铺/渠道可配置可售目的地白名单（与禁运并列）；覆盖命中支持国家优先与祖先命中。
- 地址选择器禁运打标：客户端 `embargo_countries` + 祖先继承灰下级；**禁止**把 scope 敏感禁运旗写入 4h children graph 缓存。
- `<w:theme:address selection="multi">` 用于后台批量选国家/州省/区县。
- Zone/`zone_regions` **已删除**（2.4.18）：结账仅承运商覆盖 ∩ 可售/禁运；不再保留 Zone 兜底。

### SHIP-PROFILE-001 商品松耦合配送方案（一期）

- Product 通过 SPI 发现 Shipping 配送服务目录；Shipping optional Product，禁止环依赖硬注入。
- Offer `shipping_profile_code` 空/缺省 = 全部地址可达服务；非空 = 仅该 service_code。
- PDP 仅当服务 `is_free_shipping=1` 强标「包邮」，否则「运费以结算页为准」。

### SHIP-SHELL-001 万能配送壳 + Provider

- `Weline_Shipping` 为唯一配送壳：匹配编排、配置托管、`ShippingFacade` 统一入口、Provider 扫描。
- 供应商差异一律经 `ShippingProviderInterface`；具体 Provider **必须继承** `AbstractShippingProvider` 并具备完整方法面（未支持返回 unsupported）。
- 内置 `local`（费用模板+FX+手工运单/URL 轨迹）与 `yanwen`（开放平台询价/打单/轨迹）；结账报价对每个 `provider_code` 只调 `$provider->quote()`，壳禁止按供应商分叉计价。
- `Carrier.provider_code` 绑定 Provider（空=`local`）；权威配置 `shipping/carrier/{code}/*`，禁止壳硬编码供应商 URL/签名。
- **可达覆盖由 Provider 写死**：`defaultCoverageRegions()`；燕文按 Open API 为 **国家级**（ISO），不含省市区；种子/启用按 `provider_code` 应用该目录，禁止把供应商目录混进 local 默认。
- 轨迹/打单仅经 Facade→Provider；禁止 TrackingService 内 API/手工双路径业务实现。
- 文档权威：[shipping-shell.md](shipping-shell.md)。

## 验收标准

- 发货地址与收货地址区域均可在个人中心正常加载。
- 账户菜单/侧栏中「收货地址」出现在「发货地址」之前；打开收货地址可见与顶部「配送至」同源的已登录地址。
- 仅有一条地址时自动为默认（显示默认徽章，无「设为默认」按钮）。
- 空发货地址时显示区分说明，并可跳转到收货地址；空收货地址时可打开新增表单。
- 请求不再出现 `Using $this when not in object context`、HTTP 500 或越权提示。
- 聚焦模板契约测试、PHP 语法检查和浏览器验收通过。
