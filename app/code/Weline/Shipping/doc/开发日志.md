## 2026-08-25｜Header 配送 quick-add 触发 theme:address 运行时泄漏（分类页崩坏）

- 现象：店面分类页主内容消失；Header 配送「快速添加地址」区域泄漏 Taglib PHP 源码。
- 根因：`view/hooks/.../checkout-delivery-context/quick-add.phtml` 中 `<w:theme:address country="<?= $esc($countryCode) ?>">` 走 `renderRuntimeTag`，而 `Weline_Theme` Address 标签缺少 `runtimeCallback`（编译期 PHP 被当 HTML 输出）。
- 修复归属：`Weline_Theme/Taglib/Address.php` 补齐运行期回调；本模块 hook 模板契约不变（仍用 `levels="province,city,district"`）。
- 验收：分类页无 `$Taglib__`/`Weline_Taglib_resolve` 泄漏；quick-add 仍渲染 `data-w-address`。

## 2026-08-17｜个人中心地址侧栏修复

- 需求：`SHIP-ADDR-ACCOUNT-001`。
- 现象：个人中心懒加载地址区域时返回 HTTP 500，运行日志显示编译模板在静态闭包中使用 `$this`。
- 根因：地址卡片和地址表单的源模板渲染闭包声明为 `static`，而闭包内的 Weline 模板标签编译后需要模板对象上下文。
- 实现：移除两个渲染闭包的 `static` 声明，保留纯数据辅助闭包的静态属性；不修改 `view/tpl` 生成文件。
- 回归：新增模板契约测试，防止包含模板标签的两个闭包再次改为静态闭包。
- 数据与版本：无 schema 变化，不提升 `setup_version`。
