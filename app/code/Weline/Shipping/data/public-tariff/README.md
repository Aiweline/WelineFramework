# 默认站公开标快运价快照

`standard-20260923.json.gz` 保存 2026 年 SF SE/GE+、FedEx International Priority、DHL Express Worldwide 的普通非文件包裹公开价，以及已核实的 2026-09-21 至 2026-09-27 燃油比例（仓内 gzip；`PublicTariffSeedService::loadOfficialSnapshot()` 导入时解压）。每个候选保留官方网址、年度或生效日期、区域、原始基础价和燃油依据。文件是可更新的历史价格快照，不是实时承运商接口或账号协议价。本地若保留未压缩的 `.json` 仅作开发对照，以 `.json.gz` 为准入库。

计算顺序：每家承运商按自己的重量档和进位求基础价，加该产品本期燃油，取目的国全部有效候选的最高值，最后乘 1.5 并四舍五入到人民币分。FedEx 同时纳入广东/福建和中国其他发货地区的官方公开表取高，不能将工商注册地址或占位仓库地址作为实际发货区域证明。广东/福建表香港、澳门 A 区按官方豁免燃油条款保留零燃油候选。美国采用官方州/邮区候选的国家级保守最高价，审计保留胜出区域；不能称为该地址的精确承运成本。源价格不先舍入到分。

DHL 10.5–29.5 kg 半公斤档依据官方每 0.5 kg 续重条款，由相邻整数档的固定差额推导，逐条保留 `value_origin`。已列固定档的上界包含；更高重量按原始每公斤区间和向上进位计算。SF 1000 kg 以上原表无上界的每公斤段保留，不把最后一个固定金额无限延长。价格不进行单调性平滑。

当前计费沿用系统的产品/包裹重量及体积重（cm³ / 5000）输入。实际装箱尺寸准确性仍依赖商品与履约资料。税费、偏远地址、住宅地址及特殊尺寸等条件费用未假定全部包含；本快照不叠加历史示例偏远费或已包含的燃油费。`surcharge_policy` 是本模板明确适用的规则 ID 清单，未来只有核实匹配条件后才加入相应真实规则。

`PublicTariffSeedService` 仅写默认网站的公开价模板和服务，切换默认普通配送方案的旧国际标快链接，保留国内配送、其他方案、所有生效禁运及免邮关闭状态。AX、CC、CX、EH、IM、IO、PM、PN、SJ、TK、XK 按商家最新决定暂停配送。默认站专用种子 `website0-suspended-destinations.json` 使用 website/0 禁运，原因 `merchant_suspended`（商家暂停向该目的地配送），不是系统制裁认定。原 LEGACY 服务停用并解除默认配送关联，历史运价记录保留。原表含禁运目的地不意味着该地可售。重复执行使用相同代码更新已有配置，不再次乘倍率。

运行时读取已发布模板；文件中的审计信息与倍率不输出给顾客。顾客显示最终运费。

已禁运的 KP 已从可售种子 `countries` 删除。官方原始候选、基础价和燃油依据另存 `source-audit/excluded-kp-20260923.json`，仅供来源审计，不被种子导入。后续商家明确要求上述 11 个地区全部停运，现由默认站专用种子持久化；原 7 条系统禁运不变。
