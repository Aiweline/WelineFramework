# Weline_SiteSetupAssistant 开发日志

## 文档初始化

- 由 MCP 自动修复流程补齐文档契约。
- 本记录不推断或补造模块历史；后续变更应记录版本、范围与验证证据。

## `0.3.4` — 进度状态 Tab 筛选

- 范围：工具栏「待办 / 进行中 / 已完成」改为可点击 Tab，按 `data-status` 筛选任务列表（与搜索叠加）。
- 验收：ProgressMenuContractTest；Browser 点 Tab 仅显示对应状态任务。

## `0.3.3` — 修复胶囊切站（base 相对链）

- 范围：进度页胶囊/覆盖链与筛选表单改为进度页绝对路径；避免后台 `<base href="/{prefix}/">` 把 `?website_id=` 解析到前缀根。
- 验收：契约 UT；Browser 点 `#0` 胶囊后 URL 含 `…/progress/index?website_id=0` 且 `data-dimension=site`。

## `0.3.2` — 默认全站 + 站点未完成胶囊

- 范围：浮层固定全站（不跟随仪表盘子站）；`summarizeIncompleteSites`；进度页/浮层胶囊提示各站未完成数，点击进该站。
- 验收：契约 UT；Browser 全站页见胶囊并可切站。

## `0.3.1` — 进度页补回任务搜索

- 范围：Progress 工具栏增加任务搜索（标题/模块/站点覆盖即时筛选）。
- 验收：ProgressMenuContractTest；Browser 搜索框可见且可筛任务。

## `0.3.0` — 站点维度 + 全局总览 + 继承完成态

- 范围：Progress 默认全局总览（任务×各站覆盖）；`website_id`（含 0）为单站；`resolveConfigProvenance` / 启用类默认与继承计 done（客服、像素）；Collector `collectGlobalOverview`。
- 规格：`doc/开发/spec/site-setup-site-dimension-progress.md`；需求 `REQ-SSA-0003`。
- 验收：契约 UT；Browser 全局页 `data-dimension=global` 且 14 个 coverage；`website_id=0` 单站客服/像素为 done；进度 11/14。

## `0.2.3` — 任务列表待办靠前

- 范围：`SetupTaskCollector::collect` 排序改为 status：`todo` → `doing` → `done`，同状态再按 `sort`/`code`；进度页与悬浮助手共用。
- 验收：SetupTaskProviderContractTest；CLI/Browser 进度页前 5 条均为 todo（social_platform…cdn），done 在后。

## `0.2.2` — 后台菜单「建站助手」+ 进度页

- 范围：`etc/backend/menu.xml`（父级网站服务，标题含「助手」便于搜索）；`Controller/Backend/Progress` + `view/templates/backend/Progress/index.phtml`（Collector 任务清单 + 站点选择）。
- 验收：ProgressMenuContractTest；`setup:upgrade` 后后台搜「助手」命中「建站助手」；Browser 禁缓存打开进度页可见 14 条 Extends 任务（9/14）。

## `0.2.1` — 原硬编码建站任务全部迁 Provider

- 范围：Captcha/Customer/Social/Payment/Seo/Shipping/Currency/Visitor/CustomerService/Cdn/Websites 各建 `SetupTaskProvider`；助手仍只 Collector。
- 验收：MigratedSetupTaskProvidersContractTest；CLI collect 14 条；Browser 助手无硬编码旧清单。

## `0.2.0` — 抽象 SetupTaskProvider + 删除硬编码 tips

- 范围：`SetupTaskProviderInterface` + `AbstractSetupTaskProvider` + `SetupTaskCollector`；浮层只 `collect()`；删除 `SetupTaskStatus*` 与 `$tips` 硬编码；指令 `dev/ai-command/sitesetup/建站.md`。
- 验收：SetupTaskProviderContractTest；SmtpSiteSetupTaskContractTest；Browser 禁缓存仪表盘可见「配置 SMTP / 配置邮件模板 / 多语言邮件模板」，无旧「人机验证」硬编码项。
- 需求：`REQ-SSA-0001`；规格 `doc/开发/spec/site-setup-extends-task-providers.md`。

## `0.1.2` — SetupTaskStatus Extends + SMTP 确认态（已由 0.2.0 取代）

- 范围：新增 `SetupTaskStatusProviderInterface` / `SetupTaskStatusCollector`；悬浮任务列表合并模块探测状态；SMTP 自有/继承配置为「进行中（待确认）」。
