# 站级能力天花板扩展事件

Acl **不依赖** `Weline_Websites`。下列事件供站级/租户模块裁剪超管旁路与角色有效权限。权威摘要见 `../website-entitlement-events.md`。

## 事件

| 事件 | 触发点 | 可写数据 |
|------|--------|----------|
| `Weline_Acl::role_acl_entries_after` | `AclService::getRoleAclEntries` | `entries` |
| `Weline_Acl::super_admin_bypass_check` | 超管短路前 | `allow_bypass` |
| `Weline_Acl::role_access_save_before` | Role `postAssign` 保存前 | `allowed`, `message` |
| `Weline_Acl::role_listing_filter` | 角色列表/创建前 | `role_model` 查询约束 |
| `Weline_Acl::acl_assignment_rows_after` | 分配树/标签行 | `rows` |

## 约定

- `Role.website_id` / `BackendUser.website_id` 仅为整型归属字段。
- 默认站（`website_id=0`）由集成侧自行决定是否套用站级包；Acl 引擎本身不做站判断。
