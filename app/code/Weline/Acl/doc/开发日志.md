> 按目标版本记录真实进度、调整与验收证据；不粘贴原始终端日志，不补写未经证实的历史。2026-08-18 起启用固定文档制度。

## 2026-09-20 — 菜单源缓存剥离 resource_metadata（1.1.9）

- 问题：`enabledMenuSourcesCache` 缓存整行 ACL，`resource_metadata` 单独约 15MB（393 菜单），Worker 静态诊断显示该属性约 15MB/2 键。
- 修：`projectMenuSourceRows` 只保留建树字段；进程/共享/RequestContext 读写均投影；读到旧胖条目时回写瘦身。
- 契约：`ResourceTreeServiceCacheInvalidationTest::testEnabledMenuSourcesCacheDropsResourceMetadata`。
- 版本：`1.1.8` → `1.1.9`。

## 2026-09-18 — 方法级 ACL 回填 is_backend + 防 pending 丢弃（1.1.8）

- 问题：方法级 `#[Acl]` 未写 `is_backend`；`processModule` 结束 unset `pending_method_acls` 时可能静默丢未处理项。Theme `scope_*` 升级后消失。
- 修：`collectMethodLevelAcl` / `processPendingMethodAcls` 从路由事件回填 enable/backend；模块收尾前再冲一次 pending。
- 版本：`1.1.7` → `1.1.8`。

## 2026-09-18 — 路由/角色/白名单进程缓存 + change 失效（1.1.7）

- `AclService`：`isRouteProtected` / `getRoleAclEntries` / `findRouteResource` 进程表；`RouteBefore` 白名单进程表。
- 失效：`AclCacheInvalidator`、`ProcessCacheResetter`、`WhiteAclSource` save/delete、`WhitelistService::upsertPaths`。
- 版本：`1.1.6` → `1.1.7`。

## 2026-09-08 — 菜单源请求快照随 generation 失效（1.1.3）

- 修复：`clearProcessCache`、`invalidateBackendMenuTreeCache` 和 `syncMenuTreeGeneration` 观察到代次变化时，同步清除当前请求的菜单源快照；继续复用既有 Context / 进程 / `acl` 共享缓存。
- 请求快照携带来源 generation；另一 Fiber 已推进进程代次时，旧请求快照不能重新填回菜单树。
- 角色树 role×website 隔离、TTL 和权限过滤均保持；未修改授权规则。
- 验证：4 个内存行为用例先 RED 后通过，覆盖本地失效、其他 Worker 代次变化、请求交错和进程重置；与相关 SystemConfig/ACL 测试合计 36 tests / 129 assertions 通过。
- 运行验收：待主任务在配置环境验证；本次未重启、未写运行库。
- 版本：`1.1.2` → `1.1.3`；无 Schema 变更。
