1. **主导航**：`邮箱 | 用户与账号 | 域名与 DNS` → 单一 segment / `w-tabs` 风格。  
2. **工具条一行**：左「当前邮箱」select；中「收件箱|已发送」pill/segment（次级）；右主 CTA「写邮件」打开 compose（勿用 ▶ summary）。

4. **Stalwart badge**：警告旁加「去域名与 DNS / 配置引擎」链。  
5. **禁止**并行第二套 inbox (`index.phtml` mailView) 视觉语言；以 enterprise 为准统一。
