# Weline_Server::start_after - 服务器启动后

## 事件名

`Weline_Server::start_after`

> 历史名 `Weline_Framework_Server::start_after` 已废弃，勿再监听。

## 触发时机

WLS Master 在 `ServiceOrchestrator::checkAndNotifyServerReady()` 中：全部必需服务 READY，且 `markStartupPhaseRunning` 成功将实例标为 `running` 之后，**派发一次**。

## 派发位置

`app/code/Weline/Server/Service/ServiceOrchestrator.php` → `dispatchServerStartAfterEvent()`

## 订阅示例

```xml
<event name="Weline_Server::start_after">
    <observer name="Vendor_Module::on_server_start"
              instance="Vendor\Module\Observer\OnServerStart"
              disabled="false"
              shared="true"
              sort="100"/>
</event>
```

框架内已订阅：`WarmCacheOnServerStart`、`RegisterStorefrontFpcWarmer`。

## Payload

| 字段 | 说明 |
|------|------|
| `instance_name` | 实例名 |
| `pid` | Master PID |
| `host` | 公网/绑定 Host |
| `port` | 主端口 |
| `service_count` | 服务实例数 |
| `start_time` | Unix 时间戳 |

派发失败 fail-open，不回滚 READY。
