# WLS 巨型文件拆分路线

> 守卫：`php app/code/Weline/Server/scripts/check-source-size.php`
> 默认预算 **5,000 行**；现有巨型文件以**当前精确行数**进入 allowlist，只降不升。
> 原则：先划边界，再搬家；每次拆分保持对应契约测试绿；不做一次性重写。

## 先做 / 不做

**先做**
1. `WlsRuntime`：warmup/FPC probe 边界清晰、刚加过守卫测试，先拆第一刀。
2. `SslCertificateService`：Local CA trust 已有独立判定类与测试，先搬这一块。
3. 每次拆分后把 allowlist 数字下调到新行数，禁止顺手加回。

**不做**
- 不为行数拆纯 helper（无边界、无契约的“搬家”）。
- 不把业务路径/站点名搬进 Framework 或编排层（见 `runtime_orchestrator_no_business_hardcode`）。
- 不在热路径顺手改语义；拆分 PR 只搬家 + 保持测试绿。
- 不做一次性全量重写。

## 验收

1. `php app/code/Weline/Server/scripts/check-source-size.php` → exit 0。
2. 拆分目标文件的 allowlist 行数**只降不升**。
3. 对应契约测试 PASS；全量单测无新增失败。
4. 拆分后更新本表行数与边界说明。
