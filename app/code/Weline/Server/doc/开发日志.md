## `2.0.2` — 本地化首页统一键精确进程快路径

- 需求 ID：`REQ-SERVER-0010`
- 根因：本地化首页虽已进入 Framework FPC，但 Worker 只对裸 `/` 消费 READY receipt；语言/货币路径仍反复进入完整 App/Router。同时路径货币在最终变体序列化时被 Website 选择器允许集再次校验，可将 `/USD/en_US/` 错误折叠到 `/en_US/`。
- 修复：App、Router 与 FPC 共用 `State` 的 Website 目录前缀剔除和语言/货币形状解析；路径货币作为访客 URI 权威维度保留到最终统一 key。本地化首页仅在精确 URI + 已冻结 Storefront 变体 + Process L1 receipt 同时命中时走 Worker 快路径；带剩余业务段的 `catalog` 等路由明确不进入首页快路径。
- 路由证据：`/USD/` = `zh_Hans_CN/USD`，`/en_US/` = `en_US/CNY`，两种组合顺序均为 `en_US/USD`；语义变体 token 在 CNY/USD 间分离，两种组合顺序保留不同完整 URI cache key。`/site/...` 两种顺序与本地化业务路由也在回归中锁定。
- 自动验收：FPC、路径、App 冻结顺序与 Worker 快路径共 `29 tests / 322 assertions`，全部通过；6 个相关 PHP 实现文件语法和 scoped diff-check 通过。
- 当前实测：唯一 `ai-test-localized-fpc-fresh-20260818:9859`，4 Worker，HTTP/2，4 物理 lane，c32，gzip，完整 `/USD/en_US/` 首页 10,000 请求；`10,000/10,000`、0 错误、2554.41 QPS、P50 8.009ms、P95 20.033ms、P99 102.479ms。响应逻辑体 134,682B，gzip wire body 29,495B，`cache_source=fpc:process`；Master 90782 与 4 个 READY Worker 98769–98772 前后指纹一致，quality gate PASS。报告 `var/log/wls/benchmark_report_20260817_171307_196793_usd-en-us_pid67962.json`，SHA-256 `642b2332946a55d836aaa54171d363cf39101a7d0b81d85923b2f392593455c9`。验收后该隔离实例已完整停止，9859 无监听；默认 9555 的 PID/FD 证据前后一致。

## `2.0.1` — 匿名首页 READY receipt 快路径回归

- 需求 ID：`REQ-SERVER-0009`
- 当前状态：聚焦行为测试已由 RED 转 GREEN，独立 WLS 实例 10,000 首页验收通过。
- 根因：Storefront 缓存隔离加固正确禁用了无请求级版本快照的通用 pre-router FPC；Worker 的首页回退仍只传 `full_uri/cookie_header`，丢失 READY receipt 的 `cache_key/identity_digest`，导致每次请求都进入 App/Router。
- 修复：运行时向 Worker 交付完整且已标准化的 receipt；Worker 只在同 origin、无 Cookie 根路径上优先读取该 receipt 绑定的 Process L1；Coordinator 保持 HTML Accept、GET/HEAD、gzip、HEAD 无 body 与响应安全头语义。通用 pre-router 门禁未放宽，不从 Shared L2 猜测 Store/Channel 变体。
- 修复前实测：HTTP/2、4 lanes、c32、gzip、`/`、10,000 请求，`10,000/10,000`、0 错误、55.77 QPS、P95 1522.522ms、P99 2337.615ms。报告：`var/log/wls/benchmark_report_20260817_143643_165016_root_pid76256.json`。
- 当前证据：旧实现在“已有精确 receipt + Process L1”行为夹具下返回 `null`，且无完整 receipt 解析 API；后续 TDD 又准确命中 origin/port、generic Shared fallback、同键旧 formatted body、HTML/gzip `q=0` 四个边界。最终 `WorkerFullPageCacheFastPathTest` `7 tests / 49 assertions`、`FullPageCacheCoordinatorTest` `8 tests / 67 assertions` 通过，独立复审无剩余 C/H/M/Low。
- 修复后实测：唯一 `ai-test-homepage-fastpath-20260817`、端口 9857、4 Worker、HTTP/2、4 lanes、c32、gzip、`/`、10,000 请求，`10,000/10,000`、0 错误、2506.25 QPS、P50 11.283ms、P95 16.329ms、P99 20.757ms；Master PID 47742 与 4 个 READY Worker PID 54766–54769 前后一致，日志无 fatal/error/warning/restart。响应为 Process FPC HIT，`UrlParser=0`/`UrlParserApply=0`。报告：`var/log/wls/benchmark_report_20260817_151121_715681_root_pid14916.json`，SHA-256 `92f2bb4db013843de2c3cbd27b4beef745fc1b2e057adb246cafb64e7858ba23`。验收后实例已完整停止，9857 无监听。

### 审查与整改

- 架构：反向代理数据面仅 Nginx，纯 WLS 是独立 adapter；宿主 native Launcher/Broker 只负责恢复与权限边界。
- 缺陷：唯一审查周期已通过并关闭；此前实际复现的 late-port-race 5/6 参数、derived-state `trust` canonical order 与 TEST-134 Guardian 确认夹具缺口均已定向闭合。
- 安全：继续以 fail-closed、no-follow、OS peer identity/ACL、HMAC journal/receipt/marker、PID/binary/generation 绑定为复审主线。
- 用户批准延期：无。所有未闭合项仍为发布阻断。
