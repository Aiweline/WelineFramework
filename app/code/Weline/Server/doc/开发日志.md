### 审查与整改

- 架构：反向代理数据面仅 Nginx，纯 WLS 是独立 adapter；宿主 native Launcher/Broker 只负责恢复与权限边界。
- 缺陷：唯一审查周期已通过并关闭；此前实际复现的 late-port-race 5/6 参数、derived-state `trust` canonical order 与 TEST-134 Guardian 确认夹具缺口均已定向闭合。
- 安全：继续以 fail-closed、no-follow、OS peer identity/ACL、HMAC journal/receipt/marker、PID/binary/generation 绑定为复审主线。
- 用户批准延期：无。所有未闭合项仍为发布阻断。
