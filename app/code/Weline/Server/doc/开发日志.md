## 2026-10-13 — html-disk / HTML origin 去重 Vary（2.0.194）

- **问题**：店面 HTML 响应出现两条 `Vary`（`Accept-Encoding` + `Cookie` / `Accept-Encoding, Cookie`）。

## 2026-10-13 — 静态 origin 关 proxy_cache + FPC miss 不缓存（2.0.193）

- **问题**：① `@wls_static_origin` `proxy_cache` HIT 跳过 WLS，DEV 模块前缀无法回填 FPC 盘；② 全局 `open_file_cache_errors on` 把冷 try_files miss 缓存 ~30s，叶已写出仍间歇打 WLS；③ Worker 进程 L1 HIT 早退未调 `mirrorAfterResolve`。
- **机制**：origin `proxy_cache off`；扩展名 location `open_file_cache_errors off`；L1 早退也回填；Prod `/static` 仍 `^~ /static`→`pub`。
- **not_to_do**：不为加速把模块静态再塞回 `wls_edge`；不关全局 open_file_cache（仅本 location 关 errors）。
- **契约**：`ManagedNginxConfigWriterStaticEdgeCacheTest`。
- **真机**：DEV 冷 WLS→叶，热 FPC 20/20；Prod flat/theme `/static` Disk 10/10·5/5。
- 版本：`2.0.192` → `2.0.193`。生效：`server:nginx:reload` + `server:reload -n`。
