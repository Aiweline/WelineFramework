## 当前有效需求

### `REQ-INDEX-0001` 首页接入全局颜色模式契约

- 来源与确认：用户于 2026-08-10 确认 `REQ-THEME-0001` 全局亮暗色计划；真实前台 E2E 随后证明首页私有 light/dark 色盘会覆盖显式 dark 偏好，因此首页必须接入全局契约。
- 用户场景：访客在 `system|light|dark` 任一偏好下访问首页，页面背景、正文、边框、按钮、状态卡与链接卡应与全局主题一致；显式 light/dark 不得被操作系统模式反向覆盖。
- 业务逻辑：首页可以保留 `--wf-*` 布局和品牌命名，但颜色、边框、阴影、焦点与状态只能映射到 `--weline-theme-*` 语义 Token；页面不得维护独立亮暗色盘或页面级暗色媒体查询。
- 范围：`view/templates/Index.phtml` 的首页私有样式与 Weline Theme head/runtime 的消费关系。
- 非目标：不改变首页信息架构、文案、布局、品牌方向；不在 Index 复制 Bootstrap 组件 adapter；不升级 Bootstrap；不引入数据或 schema 迁移。
- 数据/权限/安全：无新增数据写入、权限或外部请求；主题偏好与解析仍由 `Weline_Theme` 所有。
- 兼容：禁用 JavaScript时由全局 Theme CSS 的 `prefers-color-scheme` 回退；启用 JavaScript时以 `data-theme-preference` 解析结果为准。
- 验收标准：显式 dark + 系统 light 时首页仍为暗色，显式 light + 系统 dark 时仍为亮色；`system` 随系统变化；正文达到 4.5:1，焦点/边界达到 3:1；无首页专用 dark selector。
- WebUI/E2E：真实 WLS 中通过首页主题三态、刷新、系统变化和首页跨模块 Card/状态面验证；最终仍需内置 Browser 完成操作等价验收。
- 版本决定：本次不改 schema；按仓库版本规则无需仅因模板样式集成上调模块版本，保留 `1.0.0`。
