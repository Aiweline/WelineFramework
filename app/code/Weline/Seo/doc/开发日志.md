## 2026-09-06 — Google 站点属性 https 自动转为 sc-domain

- 版本：`Weline_Seo 1.2.17`。

## 2026-09-03 — SEO head 请求级幂等渲染

- 当前状态：`implemented`，真实 Browser 验收待宿主解锁后补齐。

- 回归：`HeadRendererI18nTest::testRendersHeadOnlyOnceAcrossTemplateObjectsWithinARequest` 覆盖同请求跨 Template 去重及下一请求恢复。

## 2026-09-03 — 恢复编译型页面 SEO 的国际化 head context

- 当前状态：`implemented`，真实 Browser 验收待宿主解锁后补齐。
- 根因：`PageSeoContextResolver` 的 `HeadIntegrationContextService` 是带默认值的 nullable 构造参数；编译工厂采用无参实例化，使它在真实请求中恒为 `null`，已有 `Weline_Seo::integration::head_context_resolve` 未被 dispatch。
- 变更：`resolveIntegrationContext()` 与 SEO profile registry 保持一致，在未显式注入时经 `ObjectManager` 惰性解析既有 integration service；实例化或事件失败继续返回空 context，不影响 canonical。
- 回归：新增默认构造路径黑盒测试，通过 `ObjectManager::setInstance()` 注入 integration stub，验证 locale、alternate 与 x-default 会从公开 `resolve()` 合并。
