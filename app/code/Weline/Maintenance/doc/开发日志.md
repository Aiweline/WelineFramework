## `1.1.5` — 维护波次 Theme 版本改为用户已发布主题

- **现象**：维护页 / 弹层显示 `SYS x · Theme 2.1.17`，其中 Theme 取自 `Weline_Theme/etc/module.php` 模块版本。
- **正确语义**：Theme = 用户后台发布主题版本（`ThemePublishedVersionRuntimeResolver` → `theme_scope_release`）；SYS 仍为 Framework 模块版本。
- **修复**：`UpgradeWaveService::resolveThemeVersionLabel` 删除对 Theme `module.php` 的回退；无发布版本时为 `unknown`。契约测试同步。
- **编辑路径**：宿主 MCP 目录缺 `submit_task_plan`（`HOST_MCP_SESSION_CATALOG_STALE` / `HOST_MCP_NOT_ATTACHED`），对精确路径原生编辑。

## `1.1.4` — 维护页 logo 跟随网站选择的站点品牌

- **现象**：Theme/Backend 未单独写入 brand 时，维护页 `$maintenance_logo_url` 为空，顶栏/主区显示 `W`/`!` 占位，与前台 Header 的 `SiteBrand::resolveFrontendLogoUrl`（含 Theme 默认 `logo.png`）不一致。
- **修复**：`MaintenanceStaticGenerator::resolveMaintenanceBrandUrls` 优先走与前台相同的 `SiteBrand` 级联；无 Template 时仍回退 ThemeBrandResolver → Backend `logo_*`/`site_icon` → 默认 logo。
- **验收**：dev-preview HTML 含站点 logo `<img>`；契约单测覆盖 `resolveFrontendLogoUrl`。

## `1.1.3` — 维护页内容样式改为亚马逊风格

- **现象**：独立维护页为紫黑渐变 + 玻璃拟态 + emoji，观感偏通用 AI 模板。
- **改动**：`maintenance.phtml` 内联样式改为浅色电商风（深顶栏、浅灰画布、白卡片、橙黄主按钮、青蓝链接）；信息区改为编号条，去掉浮动渐变动画。
- **保留**：语言切换、`data-lang`、恢复探测/硬刷新、wait-gift、dev 预览条、favicon 契约不变。
- **编辑路径**：宿主 MCP 未挂载 `submit_task_plan`（`HOST_MCP_NOT_ATTACHED`），本改对精确已知路径原生编辑。

## `1.1.2` — 维护解析不得 replaceServer 剥前缀路径

- **现象**：维护关闭时后台 `/…/admin/login`、`/payment/backend/method` 与 `POST /api/framework/query-bin` 整站变前台 HTML 404；扩展报 `Invalid Weline binary magic`。
- **根因**：`MaintenanceInterceptor::applyParsedRequestUri()` 用 `UrlParser` 剥掉 backend/api 前缀后无条件 `WelineEnv::replaceServer()`；后续 `Url::parser()` 把 `/admin/...` 判成 frontend。
- **修复**：仅 `UrlParser::parse()` 供维护/wait-gift 决策，**不再** `replaceServer`。
- **验收**：`admin/login` → 200；`payment/backend/method?target_scope=…` → 302；`query-bin` → `application/x-weline-query-bin`（非 HTML 404）。
