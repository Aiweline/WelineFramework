# 维护等待礼金

## 目标

- 异步 503：居中弹层安抚；不离开当前页则签发 token。
- 整页维护：道歉 + 恭喜礼金文案。
- **受众：仅 ToC（零售）**。`selling_mode` / `weline_selling_mode(_w{id})=tob` 批发客户：不展示礼金区块、不 issue、不 redeem；维护弹层仅道歉。
- **简单兑礼**：维护期把 `{token, url}` 存 `sessionStorage`；恢复后仍刷新**同一地址**才申请；地址变了作废。
- Token 绑定本轮 `upgrade_wave`；维护关闭后 **10 分钟**兑礼窗。
- 错误/失效 token：`redeem` 返回 **HTTP 404**（维护未关为 503）。
- Marketing 随机 coupon：每人一码。
- **兑礼后**：先写入浏览器 `weline.cart.pending_coupon`（7 天），再派发 `weline:maintenance:wait-gift-redeemed` 与 `weline:cart:apply-coupon`（避免 cart.js 未加载丢事件）；万能购物车 `cart.js` 应用成功后清除；过期自动删除。
- 游客购物车 session 7 天；最后一天仍访问/停留则 `renewGuestSession` 续一周。

## 关键路径

| 能力 | 路径 |
|------|------|
| 波次快照 | `Service/UpgradeWaveService.php` → `var/maintenance/current_wave.json` |
| 账本 | `Service/WaitLedger.php` → `var/maintenance/wait_ledger/` |
| API | `/maintenance/frontend/wait-gift/{issue,redeem,wave}`（主路径）；heartbeat/abandon 保留兼容但不走前端 |
| 随机券 | Marketing `Api/Coupon/RandomCouponCampaignProviderInterface` |
| 异步弹层 | `Weline_Maintenance` `maintenance-async-wait.js`：ToC 同址 issue → 恢复 reload → 同址 redeem + pending_coupon |
| 维护页恢复 | `maintenance.js` / `maintenance.phtml`：探活成功后同 URL `reload`；tob 擦除礼金文案 |

## 运营

1. 系统配置开启「维护等待礼金」并设置面额 → 同步 Marketing 规则。
2. `php bin/w maintenance:enable` 固化 wave 并生成静态页。
3. **零售**用户不离开当前地址等待 → `maintenance:disable` 开启 10 分钟兑礼窗。
4. 前端探活恢复后 `reload` 同址；正常页检测到同址 token 再 `redeem`。
5. 批发身份客户看到维护页但无礼金承诺；服务端对 tob cookie 返回 `audience_tob`。

## 验收用例设计（MCP WebUI 门禁）

前置：礼金已启用并同步 Marketing 规则；本机 WLS 可访问。

| ID | 场景 | 步骤 | 期望 | 证据类型 |
|----|------|------|------|----------|
| ACC-MW-01 | 整页维护文案 | 开启维护后打开前台首页 | 503 HTML；道歉+恭喜礼金；波次 chips；`data-w-wait-gift=1` | Browser 截图/DOM |
| ACC-MW-02 | 维护 JSON | `Accept: application/json` 请求首页 | `code=maintenance`；`data.wait_gift_enabled=true`；含 endpoints | curl |
| ACC-MW-03 | Token 签发 | 带 gate cookie `POST .../wait-gift/issue` | `success=true` + opaque token；无 gate 拒签 | curl |
| ACC-MW-04 | 异步弹层同址 | 业务页打开后维护，弹层 issue，恢复后同 URL reload | 同址才 redeem；换址不领 | Browser |
| ACC-MW-05 | 恢复兑礼 | 同址 token `POST .../redeem` | 200 + `coupon_code`；错误 token **404**；重复幂等；pending_coupon 已写 | curl + Browser storage |
| ACC-MW-06 | 换址/超时 | 换 URL 或超过兑礼窗 | 前端清存储 / 服务端 404 | curl + Browser |
| ACC-MW-07 | 批发 tob | Cookie `weline_selling_mode=tob` 后 issue/弹层 | 弹层无礼金黄框；issue/redeem `audience_tob`；wave `wait_gift_eligible=false` | curl + Browser |
