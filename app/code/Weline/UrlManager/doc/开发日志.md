## `1.0.5` — 重写查询前拒绝非法 UTF-8

- 基线版本：`1.0.4`；目标版本：`1.0.5`。
- 问题：非法 UTF-8 rewrite 路径作为 PDO 绑定参数会触发 PostgreSQL `SQLSTATE[22021]`，表现为店面 Runtime Error 500。
- 变更：`RouterRewrite` 在 `findRewriteByWebsiteAndRewrite` 前若 `Url::isValidUtf8Text($lookupUri)` 失败则直接返回，不访问数据库。
- 联防：依赖 Framework `Url::parser` 与 Server `WorkerPolicyKernel` 的入口 400；本层为 DB 前最后一道。

## `1.0.4` — URL 路径候选一次查询


- 基线版本：`1.0.3`；目标版本：`1.0.4`。
