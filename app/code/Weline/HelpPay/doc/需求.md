# Weline_HelpPay 需求

## 目标

落地三种店面能力（一期 toc only）：

| 模式 | 短链 | 归属 |
|---|---|---|
| 帮我付 `help_pay` | `/h/{token}` | 订单永远归发起人 A；B 只付款 |
| 纯分享 `selection_share` | `/s/{token}` | 朋友灌自己的车→自己结账下单 |
| 本人快捷买 `quick_pay_self` | `/q/{token}` | 本人付款（PDP「快捷购买」确认地址后进入付款页结账；**主路径不是分享**） |

## 铁律

1. **Slot 解耦**：Cart/Checkout 只声明 `cart-summary-help-pay` / `checkout-summary-help-pay`；Product 只声明 `product-purchase-actions`；HelpPay 用 `default_injections` 注入（含 PDP quiet「找朋友代付」）；禁止模板写死按钮；placement 可分别关闭（部件 `enabled`）。
2. **收货隐私**：帮付单店面（代付页、订单主详情/待付/成功）`shipping_redacted`，发起人也不见；出链前弹窗内完整确认地址；之后改址=撤销重开。
3. **billing**：卡支付时代付人可填「付款账单地址」，永不写回 shipping。
4. **禁优惠**：代付人不可用券/积分等；仅允许物流导致运费变化。
5. **会话隔离**：登录 B 打开 `/h/` 只加载 A 账单，不碰 B 的车。
6. **合规**：弹层帮助中心规则链接 + 默认勾选已阅读；代付页付款/隐私说明链接。
7. **出链双形态**：帮我付 / 纯分享等**可分享短链**成功后：复制链接 + 复制二维码图片 + 页内双展示；QR 只含 URL。本人快捷购买 PDP 主路径为确认地址后进入 `/q/` 付款；跨设备双形态仅作付款页次要入口。

## 模块边界

| 模块 | 职责 |
|---|---|
| HelpPay | 编排、代付/分享页、Slot widget、Query `helpPay`、QR |
| Payment | `PaymentLinkServiceInterface` + `weline_payment_link` |
| Cart/Checkout | 仅槽目录与模板 `<w:slot>` |
| Order | 帮付单店面投影交叉见 Order 需求 |
| Faq | `/faq/help-pay-*` 对客篇 |

## 错误码
