# 分享结果页展示当前规格

## 澄清记录

| 问题 | 答案 | 来源 |
|------|------|------|
| 展示什么？ | 商品名 + 各轴已选规格（尺码/类型等）+ 数量；可选 SKU | 用户附图 +「显示一下当前规格」 |
| 放哪？ | 「分享规格给朋友」结果步，标题/提示下方、链接与二维码上方 | 审图 ui_shot |
| 快捷购买/代付结果？ | 同结构有则展示（同源 PDP 读规格） | 合理扩展 |

## 用户故事

作为买家，在分享规格弹窗最后一步，我希望一眼看到正在分享的商品名与已选规格，以免发错链接。

## EARS

1. WHEN 用户打开规格分享结果步且 PDP 有已选规格轴，系统 SHALL 在链接/二维码上方展示「当前规格」摘要（商品名 + 轴标签/值）。
2. WHEN 仅有 SKU/数量而无轴选项，系统 SHALL 至少展示商品名与数量（及可用 SKU）。
3. IF 非 PDP 上下文无法读取规格，系统 SHALL 不展示空摘要块（不留空白占位墙）。

## 用例 UC1

1. PDP 选 L + 某类型 → 点「分享给朋友」→ 出链成功。
2. 结果步可见当前规格摘要，再是链接/扫码。
