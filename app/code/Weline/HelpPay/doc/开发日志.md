# Weline_HelpPay 开发日志

## 2026-09-11 — 快捷买短链过期修复

- 根因：`createQuickPay` 默认 TTL 仅 3600s，验收 token 过期后显示「链接不可用」。
- 默认 TTL 改为 7 天；`PaymentLinkService::load` 每次以文件仓为准，避免 Worker 内存缓存挡住磁盘复活。
- 已复活验收 token `1cc04c171a0cfb54a9b7e696b58de9fa`（30 天）；过期页文案可区分 `quick_pay_expired`。
