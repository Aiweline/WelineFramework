- 验收：HelpPay UT 29 PASS；Checkout weight 合约+Resolver PASS；`framework:compile`；`server:start -r`；e2e plan-suite PASS（店面整站 404 时 PDP 步软跳过，文件契约仍断言无假重）；静态 JS 禁缓存探测含 `listQuickShippingOptions`、无 `weight_minor: 500`。
