# Weline_HelpPay 功能现状

## 已落地（1.0.3）

- PDP「找朋友代付」第三 placement：quiet 文字链注入 `product-purchase-actions`（非 secondary 按钮）
- 结账/购物车/详情帮我付：规则步 → **可编辑** `address-pick`（选/改/增，同结账地址部件）→ `createHelpPay` → 链接+二维码；禁止只读 textarea 预览主路径
- Setup `Upgrade` 种子含 product 布局；Product 槽 max=6

## 已落地（1.0.0）

- `PaymentLinkService`（Payment）：help_pay / selection_share / quick_pay_self token；resolve 店面脱敏；revoke
- `HelpPayOrchestrator`：出链门禁（规则勾选、地址确认、toc-only）；统一 `share_delivery`
- Router：`/h/` `/s/` `/q/`
- Widget：购物车/结账 Slot 注入 + share-result 双形态
- Query：`helpPay.createHelpPay|createSelectionShare|createQuickPay|listQuickShippingOptions|qrPng|revoke`
- 快捷购买：弹窗内懒加载结账同款地址；确认后创建 `quick_pay_self` 并进入 `/q/` 付款（非分享结果网格）；付款页主 CTA「立即支付」，跨设备链接/二维码为次要折叠
- 代付页：PC **左右栏**（左金额+物流，右支付+确认，对齐结账 sticky）；窄屏单列。摘要提示「收货地址已由发起人确认。」（不说本页不展示）+ 物流 + **与万能结账同源支付方式（含图标）** + 仅需账单的方式才展示结账同款账单地址（session-isolation）；`startPayerPayment` 确认付款跳转网关 / Fake 即时成功；付款说明/隐私说明 `target=_blank` 新标签打开，不冲掉本页
- **i18n**：默认站支持语言（zh/en/hi/ar/es/fr/pt/id/bn/ur）HelpPay 模块词典已补齐；改 CSV 后须 `i18n:collect Weline_HelpPay`
- 支付方式统一源：`CheckoutPaymentMethodsProvider` → `payment.getCheckoutPaymentMethods`；HTML：`CheckoutHtmlRenderer`
- 单元/契约测：token、编排、Slot、Router、QR、模板双形态、短链 layoutType
- 短链页走 Theme `default` 布局；`helpPayShare` 经 `weline.modules.js` 加载
