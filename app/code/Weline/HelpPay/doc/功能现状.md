- PDP「找朋友代付」第三 placement：quiet 文字链注入 `product-purchase-actions`（非 secondary 按钮）
- 结账/购物车/详情帮我付：规则步 → **可编辑** `address-pick`（选/改/增，同结账地址部件）→ `createHelpPay` → 链接+二维码；禁止只读 textarea 预览主路径

## 已落地（1.0.0）

- `PaymentLinkService`（Payment）：help_pay / selection_share / quick_pay_self token；resolve 店面脱敏；revoke
- `HelpPayOrchestrator`：出链门禁（规则勾选、地址确认、toc-only）；统一 `share_delivery`
- Router：`/h/` `/s/` `/q/`
- Widget：购物车/结账 Slot 注入 + share-result 双形态
- Query：`helpPay.createHelpPay|createSelectionShare|createQuickPay|qrPng|revoke`
- 快捷购买：弹窗内懒加载结账同款地址；确认后创建 `quick_pay_self` 并进入 `/q/` 付款（非分享结果网格）；付款页主 CTA「立即支付」，跨设备链接/二维码为次要折叠
- 代付页：摘要 + 物流 + 支付 + **结账同款账单地址**（选/改/增，session-isolation，不写回 shipping）；禁优惠文案；规则链接
- 单元/契约测：token、编排、Slot、Router、QR、模板双形态、短链 layoutType
- 短链页走 Theme `default` 布局；`helpPayShare` 经 `weline.modules.js` 加载
