# 需求

## M2 目标

1. 新建 `Weline_Promotion` v1.0.0，依赖 Backend、Theme，可选 Marketing / Product / Report / CustomerService。
2. 后台「万能促销运营」运营台，ACL `Weline_Promotion::commerce:promotion:desk`，菜单挂在 `marketing_group` order 40。
3. 前台公开路由 `promotion`、`promotion/deals`、`promotion/sale`（及后台维护的其它 slug）；主题导航「今日特价」只使用路由 `promotion/deals`（不设顶级别名 `/deals`）。对外 href 必须经框架 `Url::getFrontendUrl` / `@url{…}` 生成，禁止在服务层或模板硬编码 `/promotion…` 字符串拼接。
4. `PromotionCampaignRun` 记录活动运行态与交接包。
5. Query Provider `promotion_admin` 供后台读取运营台快照与 run 状态。

## 非目标

- 不在 Promotion 内自建独立折扣引擎；活动价必须同步到 `Weline_Marketing` 自动规则并由 `DiscountQuote` 报价。
- 禁止虚构与 Marketing 规则无关的划线价 / 折扣比例。

## 活动价（Marketing 同源）

1. 主题表单配置 `deal_discount_type`（none / percentage / fixed_amount）与 `deal_discount_value`。
2. 保存主题时 `PromotionThemeDealDiscountSyncService` 通过 Marketing `ExternalDealDiscountProviderInterface::upsert` 创建/更新 automatic 规则（禁止直写 Rule 模型）；条件 `product_sku in`，动作 `matched_products`，source=`promotion_activity_theme`。
3. 前台按同一折扣配置展示活动价与原价；加购/结账走 Marketing 自动规则，保证陈列与成交同源。

## 前台活动中心呈现（主题化）

1. `/promotion`、`/promotion/{slug}` 共用 `frontend/promotion/index.phtml`；slug 由后台「活动主题」维护（默认 deals / sale / weekend / gifts）。
2. 视觉对齐亚马逊 Today's Deals：二级导航、主题化 hero、活动入口、四列商品货架。
3. 使用主题 layout token 与 `--amz-*` 卡片色板；禁止虚假折扣文案与紫色营销渐变。

## 前台上线就绪（v1.1.6）

1. 活动首页和默认主题货架只可读取当前 scope 的真实已发布、可售 Product offer；Product 不可用时显示可操作空态，不得伪造验收商品、价格或占位图。
2. 中文请求必须优先解析 `lang_local`，避免被语言简码或旧 Cookie 导向其它 LocalModel 文案；英文 / 阿拉伯语请求下前台可见默认串（含活动首页 Hero 说明、匹配商品）不得残留中文源串。
3. 内置 deals / sale / weekend / gifts 在没有人工 LocalModel 文案时，必须提供 zh_Hans_CN / en_US / ar_SA 默认文案；阿拉伯语依赖 Theme `dir=rtl` 与逻辑方向 CSS。
4. 活动中心视觉与默认汉服首页保持同一品牌系统：暖纸色、墨色文字、朱砂 CTA，使用真实汉服影像而非程序化占位素材。

## 活动主题范围（website / store / channel）

1. **一站一活动**：每条主题必须绑定具体 `website_id`；**`0` 表示「默认网站」**（真实站点），禁止把「未选择 Website」当成全站广播。
2. `store_code` / `channel_code` 空表示该 Website 下该层「全部」；配置 `channel_code` 时必须同时填写 `store_code`。
3. 前台只展示 **当前请求 scope** 下匹配的主题：Website 必须精确匹配，再按 store/channel 收窄；导航、入口卡片、动态 slug 页均走 `PromotionScopeResolver` + `PromotionActivityThemeScopeMatcher`。
4. 同一 `page_slug` 若同时存在不同具体程度的主题，**更具体者优先**（website → store → channel）。
5. 当前 scope 无匹配主题时，对应 `/promotion/{slug}` 返回 404，**禁止**用硬编码 legacy 文案绕过范围。
6. 选品（手动 / 单商品 / 条件筛选）仅在活动 Website 内解析。
7. 文案写入 `PromotionActivityThemeLocal`；保存后在 I18n「AI 翻译」补全其他语言。
8. 主题保存必须发布 `w_changed(ResourceChange v1)`（`promotion_activity_theme`）；本地清 FPC/前台缓存，CDN/SEO 由 `resource_changed` 接收方处理。
