# 按网站柜发布社媒内容

用户要发布内容、发帖、发图或发视频时，先确定是哪个站，再只使用这个站网站柜里已经在用的社媒账户，按柜中顺序逐个把这一次的图片或视频发出去。

查号、注册、补资料仍走 `weline-social-platform-register`。本技能不新开账号。

## 账号从哪来

1. 口令里要有哪个站。对不上站柜目录就问，不要拿另一个站的柜。
2. 读这个站的 `websites/<site>/README.md` 对外清单，和 `websites/<site>/credentials/social-accounts.md`。
3. 发布名单只收柜里已经在用的行：有 `https` 公开主页，并且不是「开号中 / 未开 / 别人的登录」。
4. 顺序按柜里的先后。不要另编平台，不要加入 `fake_browser`，不要把别的站的号插进来。
5. 密码留在保险箱。不要写进回复、帖子、源码或会进 Git 的文件。

融媒体后台的范围勾选用来核对这是不是这个站的号。柜里没有的平台，不要因为后台里还有别的行就拿去发。

## 逐个发布

一次任务只发一份内容。对名单里的每个账号做完再下一个。一个账号失败，记下原因，继续下一个。

1. 图片或视频只用这个站柜里已有的社媒图、品牌图，或用户这次给出的素材。没有素材就停在这一次，不要现做另一套视觉，也不要拿别的站的图。
2. 用本机 Google Chrome，放在标签组 `AI·社媒发布` 里，只操作这一组。不要把窗口抢到前台。
3. 打开发这个账号自己的平台页，用这个号把图片或视频发出去。平台只收图就发图，只收视频就发视频，两者都收时跟用户这次给的素材走。
4. 浏览器里已是别人的号：记下并跳过，不要退出别人的号。
5. 这个号还没有登录页：记下并跳过，不要为了发这一条去注册。
6. 发出后记下该平台上的公开帖子地址。写回这个站的保险箱状态行，不写密码。

## 不要做

- 不要在本技能里注册、开邮箱、改范围绑定，或打开 `publish_enabled`。
- 未开发布的账户不要送进 `createPublishBatch` 或发布队列。已开发布且凭据检测通过的账户，才可以走融媒体发布队列。
- 不要从本机对生产公网域名做 curl。
- 一个平台卡住时，不要停掉名单里其余账号。

## 收口

按柜中顺序写出每个账号：已发出的公开地址，或跳过原因。还有账号没处理，结论写未完成。密码只说「在站柜保险箱」。
