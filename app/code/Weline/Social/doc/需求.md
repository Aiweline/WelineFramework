### `REQ-SOCIAL-0002` 站点日更自动运营与浏览器扩展通道

- 来源与确认：用户于 2026-10-24 拍板「默认不发、人工开启；无 API 平台写扩展 + AI 操作流；视频默认人工审片；配乐网上找但必须许可三件套」。
- 目标版本：`1.0.19`；版本 1.0.18→1.0.19，迁移见 `Setup/Upgrade.php`。
- 背景/问题：日更计划需要按站点时段、平台能力与审片闸门自动执行；无 API 平台不能靠存 Cookie 绕过授权。
- 用户与运营场景：运营在后台开启站点计划并勾选平台；API 平台直接建发布批次，扩展平台进入用户浏览器任务队列；视频先审后发。
- 业务逻辑：`SocialAutopilotCron` 每 5 分钟扫描 `slots`；`SocialAutopilotService::runSlot()` 按 `topic_ratio` 取题、按 `mix` 生成内容、用 `SocialPublishRouter` 路由；视频且 `review_video=1` 走 `SocialReviewService::submit`；幂等键 `social:auto:{websiteId}:{Y-m-d}:{slotKey}` 防双发。
- 范围：计划读写、扩展任务列表、审片队列、运行状态、后台「日更计划」「扩展发布」「审片」页签、发布记录三列与文档安全边界。
- 非目标：不在服务端直接操作平台、不存密码/Cookie、不做关注/私信/评论自动化、不绕过验证码、不替用户确认配乐许可。
- 数据/权限/安全：计划默认 `enabled=0`；全局 `social_autopilot_enabled` 与站点 `enabled` 双开关；QueryProvider 只读查询 + 保存计划，不直接发外网；扩展离线 24 小时与审片积压标记 `needs_user`。 发布入口调用 `SocialReviewService::assertPublishable()`，音频缺许可字段时回退无配乐/图文并记 `music_unlicensed`。
- 兼容/迁移：新增 5 表与 6 列，版本 1.0.18→1.0.19，迁移见 `Setup/Upgrade.php`。
- 验收标准：`dev/session/social-daily-autopilot/tests/accept_pipeline.php` 输出 `ACCEPT PASS`；Cron 名称/周期、5 个 Query operation、页签与三列、README 安全节口径、依赖缺失返回 `missing_dependency` 均被静态断言。
- WebUI/E2E：后台融媒体管理新增三个页签；真机发布验收仍按计划 T22 单列。
- 运营与支持影响：扩展离线只累计不判失败；运行状态可查；配乐未确认不进包。
- 依赖与风险：依赖 `SocialPublishRouter`、`SocialExtensionJobService`、`SocialReviewService`、`SocialTopicService`；缺失时返回 `missing_dependency` 不 fatal。平台侧自动化策略仍可能限流或封号，需用运营账号。

### `REQ-SOCIAL-0003` 媒体类型/数量/模型选择与一条记录多平台

- 来源与确认：用户于 2026-10-25 要求每站可配置每天生成数量与媒体类型（文字/图片/视频），图片/视频必须选择支持的模型；一条发布记录可发布多个平台；部署到线上旅游站 `playinginchina.com` 并在线上后台实测扩展发布与 AI 生成记录。
- 目标版本：`1.0.20`；版本 1.0.19→1.0.20，迁移见 `Setup/Upgrade.php`。
- 背景/问题：原计划只有 `slots` 与 `mix`，不能表达每天生成数量、具体媒体类型和图片/视频模型；发布记录只按批次展示，不能看出同一记录的多平台 target 状态。
- 用户与运营场景：运营在后台设置每天 1-20 条、勾选文字/图片/视频；勾选图片时必须选择可用图片模型；视频可选图片序列或 `ai_video`（有可用视频模型时）；一条草稿发布到多个平台后，记录页按平台显示成功/总数。
- 业务逻辑：计划新增 `daily_count`、`content_types_json`、`image_model_code`、`video_model_code`、`video_source`；`listMediaModels` 只读返回 image/video/text_default；`saveAutopilotPlan` 落库前强校验，图片缺模型返回 `image_model_required`，`ai_video` 缺视频模型返回 `video_model_required`，两种错误都不写计划表；`SocialAutopilotService` 按 `daily_count` 分摊额度，`SocialMediaStudio` 生成媒体；一个 draft 一个 batch、多平台多 target；记录页平台列聚合 target 状态。
- 范围：计划字段与默认值、QueryProvider 模型清单/保存校验/计划读取、后台日更计划表单与发布记录平台列、`playinginchina.com` 生产部署与扩展真机。
- 非目标：不在服务端直接操作平台、不存密码/Cookie、不绕过验证码、不替用户确认配乐许可、不自动配置 AI 供应商账号、不对无实发能力的平台排视频任务。
- 数据/权限/安全：`listMediaModels` 仅 backend 只读；保存校验发生在 `SocialAutopilotService::savePlan()` 之前；`content_types` 白名单 text/image/video 且至少 text；`daily_count` 对外夹 1-20；后台未选图片模型时前端提示，不弹原生 alert；发布记录只展示 code 与状态，不回显凭据。
- 兼容/迁移：新增 5 个计划媒体列，版本 1.0.19→1.0.20，迁移见 `Setup/Upgrade.php`；生产环境 `setup:upgrade` 遇框架既有 Pdo `getColumnDefinition()` NPE 时按同等幂等 DDL 补列。
- 验收标准：`dev/session/social-daily-autopilot/tests/accept_pipeline.php` 输出 `ACCEPT PASS`；`php vendor/bin/phpunit --no-coverage app/code/Weline/Social/Test` 119 断言绿；图片空模型与 `ai_video` 无模型被拒绝、合法模型通过；生产后台三页签 200、扩展发布与记录平台列 PASS。
- WebUI/E2E：生产 `playinginchina.com` 实测扩展 claim→type→click→done，记录页显示 `x 1/1 ✓`；一条记录多账户 batch 2 个 target 均 succeeded。生产 AI 图片生成因未配置供应商账号降级 text 并记 `image_generation_failed`，需先配置供应商；当前 video 模型为 0，`ai_video` 禁用。
- 运营与支持影响：R2 已关闭（扩展 authorize/background 上送并回传 `website_id`，非 0 站点授权码可用）；R3 已知（扩展设备 `user_id=0` 无属主，撤销粒度弱），不阻断当前使用。
- 依赖与风险：依赖 `AiModel`、`SocialMediaStudio`、ffmpeg 与 AI 供应商账号；无视频模型时 `ai_video` 不可用；AI 生成无供应商密钥时确定性降级并记录原因；生产测试数据与最终用户验收仍需收口。
