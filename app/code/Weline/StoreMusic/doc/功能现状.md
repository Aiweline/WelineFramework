# Weline_StoreMusic 功能现状

> 自动/手写能力快照，证明入口存在，不替代运行验收。产品名：**进店音乐**。

| 能力面 | 入口 |
|--------|------|
| 配置契约 | `extends/module/Weline_SystemConfig/Config/frontend/store-music.phtml` |
| 读配置 | `Service/StoreMusicSettings.php`（playlist `intro` 为 locale map；店面 `frontendPayload` 解析为单语字符串） |
| 后台页 | `weline_storemusic/backend/config`：媒体多选、`reorder-list` 拖排序、`language:select` 按语言编辑简介 |
| 店面浮层 | 圆头像入口 + 选曲面板；× 只关面板不停播；❚❚ 停止；**最后用户操作时间戳为准**（让权 `hardSilenceMedia` 清 src，禁双曲残留）；切走标签可后台续播；离页 `pagehide` 硬拆；peer 释放后可见页软续播；音源 IndexedDB 缓存 |
| JS | `view/statics/js/store-music.js`（IDB `WelineStoreMusic` / `audio`）+ `weline.modules.js` |
| 测试 | `Test/Unit/Service/StoreMusicSettingsContractTest.php`、`Test/e2e/frontend/`（Playwright） |
