# Weline_StoreMusic 功能现状

> 自动/手写能力快照，证明入口存在，不替代运行验收。产品名：**进店音乐**。

| 能力面 | 入口 |
|--------|------|
| **主配置（部件）** | 主题编辑器 → 选中 `store-music` → **部件配置**（`widget.php` `params`：启用/曲目数组/延迟/自动播/循环/音量/头像旋转/波形） |
| **全页波形** | 浮层开关 / `waveform_default`；canvas `pointer-events:none`，z-index `2147482900`（低于客服/浮层、高于正文）；开启时挂到 `document.body` |
| **头像环频谱** | 播放时 polar bars；与头像同圆心（`bottom:50%` + origin bottom）；`R+len` 渐变内透明；峰值约 `2.6rem`；帧峰值归一化 |
| 配置契约（回退） | `extends/module/Weline_SystemConfig/Config/frontend/store-music.phtml`（Hook 兜底；部件曲目为空时回退） |
| 读配置 | `Service/StoreMusicSettings.php`（店面优先 `ScopeIdentity` typed resolve；显式 scope 字符串仍走 legacy get；部件优先，空曲目回退 SystemConfig） |
| 作用范围 | SystemConfig `global,website,store`；歌单应按 **Website** 配置。汉服在 Website(default)；DaoCharms 等站不得继承 Global 古风歌单 |
| 应用默认注入 | `extends/module/Weline_Widget/Weline_StoreMusic/widget.php` → homepage `content` **required**；与 Hook 共用模板 + `StoreMusicRenderGate` |
| 后台页 | `weline_storemusic/backend/config`：媒体多选（系统配置迁移/兜底）；文案引导优先用主题编辑器部件配置 |
| 店面浮层 | 圆头像入口 + 选曲面板；**音量/进度持久**；**播放中频谱环绕（未播放无波纹）**；进店自播/**播放中 F5 秒续**；**域名标签关光/bfcache/Cursor 关面板必停播**；进程级单例 Audio；关 Browser 加速硬停；`avatar_spin` 默认关；简介可展开；**播放列表本地搜索（曲名/简介）**；**chrome 文案运行时 `__()`（Hook 裸 include 不走 Taglib）** |
| 多语言 | `i18n/*.csv` 覆盖默认站已安装语种；曲名中文，简介跟访客语言（部件 intro 走编辑器语言；SystemConfig intro 为 locale map） |
| 默认歌单 | 现象级流行古风（SystemConfig / 导入脚本）；部件曲目为空时回退 |
| JS | `view/statics/js/store-music.js`（IDB `WelineStoreMusic` / `audio`）+ `weline.modules.js` |
| 测试 | `Test/Unit/Service/StoreMusicSettingsContractTest.php`、`Test/Unit/Widget/*`、`Test/e2e/frontend/`（Playwright） |
