# Weline_StoreMusic 开发日志

## 1.1.27 — 刷新后「不播」：预静音 + 过期 leader 锁

- 根因 A：soft `tryPlay` 在无 `userActivation` 时**先静音再播**；硬刷新后文档无手势，有声被故意关掉，听感像「刷新就不播放」。
- 根因 B：F5 竞态下旧 tab 仍在 `origin_tabs`（不可见）却占着 `leader_lock`，新页 `hasActivePeerLeader` 放弃续播。
- 修复：先试有声，仅 `NotAllowedError` 再静音降级；`clearStaleLeaderForSoloResume` + 不可见锁持有者不算 live peer。

## 1.1.26 — 刷新后不播：teardown 误写成「用户停止」

- 根因：离页 `pause`/`tearDown` 触发 MediaSession `pause` 处理器 → `stopPlayback()` → `user_stopped=1` + `want_play=0`，刷新后 `scheduleStart` 永久放弃续播。
- 次因：dying document 延迟 `broadcastForceStop` 可能掐死刚启动的刷新页。
- `clearMediaSession` 先卸 pause/stop handler；`stopPlayback` 在 `_tearingDown`/`!_docAlive` 时不改 prefs；离页不再 `broadcastForceStop`。

## 1.1.25 — YouTube 式续播：bfcache 不拆机 + 刷新不丢进度

- YouTube 硬刷新也不能真正「零间隙续传」；靠进度快照秒级接上。同站后退/前进走 bfcache 时可保持 MediaElement。
- `pagehide.persisted`：只停心跳、保留 Audio（不再 tearDown）。
- `pageshow.persisted`：若仍在播则夺回锁续 UI，禁止 remount@0。
- `saveProgress`：tearDown 后无 audio 时不写盘；保留 `_lastGoodProgressTime`，避免二次 unload 把 time 写成 0。
- 进度节流 1s；`applyPendingSeek` 等 metadata（1.1.24）。

## 1.1.24 — 刷新从头播：离页 pause 把 progress 写成 0

- 根因：`pagehide` 先 `saveProgress` 正确时间，随后 `tearDown` pause/清 src 再触发 `pause` 监听，把 `progress.time` 覆盖成 0。
- `pause`/`timeupdate`/`ended`：`_docAlive` 为 false 时不再写进度。
- `applyPendingSeek`：metadata 未就绪时保留 `_pendingSeek`（对齐 0.25s 门槛），等 `loadedmetadata`/`canplay` 再 seek。

## 1.1.23 — 无痕等再久也不播：营销 Cookie 卡死 + 死锁误判

- 根因 A：`scheduleStart` 在 marketing / Cookie 横幅未同意时直接 return，延迟再久也不会 `tryPlay`。
- 根因 B：全页跳转后旧 `leader_lock` 仍在 TTL 内，但 `origin_tabs` 已无该 tab → 误判「已在其他页面播放」且不重试。
- 进店 BGM 不卡营销 Cookie；`hasActivePeerLeader` 要求锁持有者仍在普查；`armPeerLeaderRetry` 锁过期后再试一次。

## 2026-09-14 — 默认站点九语：曲名不动，UI/简介跟语言

## 1.1.21 — 无痕首次加载：有声被拒则静音自播，手势开声

- `_awaitingUnmute` + `unmuteAudible`：首次页面手势开声；提示「点击开启声音」。

## 1.1.20 — 根因：离页 census 空窗把 want_play 写成 0，进店自播永久失效

- 真根因：单标签全页跳转时 `pagehide` → `dropOriginTab` → 200ms 后普查为空 → `setWantPlay(false)`；新页 `playIntent()==='stop'`，`try_autoplay` 与页面手势解锁全部短路。无痕「秒数到了不播」常踩此路径。
- 离页 / `domain_empty` / `tab_dead` / origin 空：只硬静音，**禁止**写 `want_play=0`；仅 ❚❚ / dismiss 写 `user_stopped`。
- `clearLegacyStopPoison`：无 `user_stopped` 的历史 `want_play=0` 清掉，恢复冷进店自播。
- 隐藏启动后首次可见：冷访问重跑 `scheduleStart`（不再只 `setNeedGesture`）。

## 1.1.19 — 无痕/冷进店：Cookie 同意后重试 + 页面手势解锁自播

- 根因 A：`scheduleStart` 遇 `show_banner` 一次失败后永不重试；无痕点「同意」后营销已放行，音乐仍静音。
- 根因 B：Chrome 无痕对 unmuted autoplay 直接 `NotAllowedError`；原先仅点头像/面板才 `userPlay`，延迟到点后无二次解锁。
- `bindConsentAutoplayRetry`：同意按钮 bubble 后轮询 `marketingAllowed`，再 `scheduleStart`（跳过进店秒数）。
- `armPageGestureUnlock`：自播待解锁时任意页面 `pointerdown`/`keydown` 触发 `userPlay`（排除 Cookie 条）。
- 提示文案 `点击开启音乐`；成功播放后解除监听。

## 1.1.18 — 选曲视图同步后音频必须跟切

- 根因：所有 `playing` 广播曾一律 `heartbeat:true`，对端只更新/忽略 UI 路径却不强制换 `MediaElement`；换轨后列表勾选已变、扬声器仍播上一首。
- `broadcastLeaderState(type, asHeartbeat)`：仅 1s 心跳为 heartbeat；切歌/抢播为真实 claim。
- `force_stop` 携带 `url/index`；新增 `selectionDiffersFromMessage` / `audioMatchesSelection` / `reconcileAudibleSelection`；`progress` storage 同步列表且播主跟切。
- `playCurrentTrackNow` 换轨强制新 `Audio`（禁复用已 silence 的 singleton）。

## 1.1.16 — 开面板/关面板/音量不再误抢播

- 根因：`markUserGesture` 仍写 `operator` + `isUserOperating`，对端心跳一刷新 lock 就会「最新操作者 reclaim + force_stop」→ 三页里点任意非播放页，正在播的页被干掉且本页未开播，全站失灵。
- 开面板 / 关面板 / 音量 / 波形只记本地手势，**不写**跨页 `operator`、**不** `acquireLeaderLock`。
- 心跳/storage reclaim 仅当本页已在播或已是 leader 才夺回；浏览态忽略对端心跳、不抢锁。

## 1.1.15 — 多页可各自操作：手势不抢锁 + 域名标签普查防误杀

- 开面板 / pointerdown 只 `markUserGesture`，**不** `acquireLeaderLock`；仅 ▶ / 选曲 / 切歌 / 停止才抢播。
- `operator` 的 storage 事件不再让权静音（曾导致「点别的页 → 正在播的页被干掉 → 全站异常」）。
- 域名标签普查：隐藏标签仍算存活；0×0 需连续多次才判定脱离；`domain_empty` 延迟确认且真标签可忽略误报。
- 让权后页面保持可操作（`_docAlive` + needGesture）；❚❚ 不再 `clearWantPlay` 污染其它页。

## 1.1.14 — 切歌硬换 Audio：禁多源叠播 / 禁换歌不生效

- 根因：波形 `createMediaElementSource` 绑定后若 `AudioContext.close()`，同一 `Audio` 再换 `src` 常失效，旧解码残留 →「多个在播、换歌无效」。
- `playCurrentTrackNow` / 换轨：`discardAudioElement` + `killRivalAudioElements` 清掉全部竞争音源，再挂载全新 `Audio`。
- 全局 registry 跟踪本模块创建的 MediaElement；开播后再断言只留当前一首。

## 1.1.12 — 关浏览器/关标签必须硬停声（禁幽灵续播）

- Cursor/部分宿主关 Browser 时 `pagehide` 可能不触发，而 `visibility hidden` 又按「后台续播」故意不停 → 关了还在响。
- 统一 `tearDownForLeave`：capture 阶段 `pagehide`/`beforeunload`/`unload`/`freeze` + MediaSession stop/pause。
- 隐藏时启动 `orphanWatch`：DOM 断开或窗口塌成 0×0 即硬拆；离页后 `leaveHammer` 短时反复清 src，防宿主二次拉起解码。

## 1.1.11 — 跨页：新标签静默 + 本页操作必接管

- 心跳 `playing.at` **禁止** `Date.now()` 冒充操作时间（曾盖过本页 ▶/切歌，导致无法切换并粘滞「已在其他页面播放」）。
- 软加载 / `scheduleStart` / `tryPlay(force:false)`：若 `hasActivePeerLeader()` 则保持静音，不叠播。
- 打开面板只清提示、不抢播；▶ / 选曲 / 切歌才 `claimLeadership(true)` + `force_stop`（最后用户操作胜出）。
- 面板打开时状态条 CSS 隐藏；`shouldShowOtherTabStatus` 避免粘滞挡播放列表。

## 1.1.10 — 恢复真实歌单 + 去掉粘滞「已在其他页面播放」

- e2e fixture 曾把店面歌单盖成「E2E 曲目甲/乙」；已恢复「高山流水 / 孤城」，并写回 `store-music-last-real.json`。
- 面板打开、回前台、本页有焦点时不再粘贴跨页提示，避免挡住真实播放列表可读性；点 ▶ 仍按最后操作抢播。
- e2e `afterAll`：若 status 仍含 `store-music-e2e` / `E2E 曲目`，强制再 `restore` `last-real`，避免验收后盖住后台真实列表。

## 1.1.9 — 硬停声 + 最后用户操作胜出（禁叠播残留 / 禁无标签幽灵播）

- 让权改为 `hardSilenceMedia`（清 src / 关 AudioContext），禁止仅 pause 留下「高山流水+孤城」残留。
- `isRemoteNewer` 改为 `>=`：同等时间戳也让权，避免双页互抢。
- `play` 事件禁止无手势 `claimLeadership(true)` 抢回；统一 `bindAudioElementEvents`。
- 关标签 `pagehide` 硬拆 MediaElement；peer 释放 lock 后可见页 `maybeResumeAfterPeerRelease`，避免必须再点进标签才出声。
- **幽灵播闸门**：仅在本页曾可见开播后才允许隐藏续播（`_heardWhileVisible`）；隐藏冷启动/无标签残留一律 `killAllPageAudio`；`_docAlive` + ghost watch 拒绝离页后再 play。
- 浮层 CSS 强制可见，防宿主工具把头像/面板隐掉。

## 1.1.8 — 最后用户操作为准（时间戳胜出）

- 让权比较 `msg.at` / `operator` 与本页 `_lastUserActionAt`：更新的用户操作永远胜出，禁止旧页抢回残留叠播。
- 心跳广播不得用 `Date.now()` 冒充操作时间；❚❚ 停止广播 `force_stop`+`clearWantPlay`。
- 可见性软恢复不再 `force` 抢播，避免对抗其它页的最后操作。

## 1.1.7 — 修双曲叠播（隐藏页必须让权）

- 隐藏/后台页不可凭「刚操作过」拒绝 yield；切走标签时清 `_lastUserActionAt`。
- 前台抢播发 `force_stop`；`silenceForOtherTab` 停掉本页与残留 shared Audio。
- 单标签后台续播仍保留；叠播残留（高山流水+孤城）为跨页未让权。

## 1.1.6 — 后台标签继续播（visibility ≠ 离页）

- `visibilitychange` 隐藏时只存进度/停波形，**不再 pause**；切走其它标签或应用仍应能听到 BGM。
- 仍在播放时后台页继续维持 leader 心跳，避免同站其它页软自动播叠音；真正离页仍走 `pagehide` hardStop。

## 1.1.5 — 跨页点选曲目同步开播（保留用户手势）

- 选曲/播放改为 `playCurrentTrackNow`：点击栈内直接用网络 URL `audio.play()`，不再先等 IndexedDB。
- 有焦点/正在操作的页面忽略过期「已在其他页面播放」，并自动把暂停中的音频拉起来。
- IDB 仅后台缓存，不挡开播。

## 1.1.4 — 当前可见页独占操作权（修点了没反应）

- 后台页停止心跳广播，避免把前台刚抢到的播控踢掉。

- 切到可见页自动续播；隐藏页暂停并放权。选曲仍立即播放。

## 1.1.3 — 本页操作立即抢播，多页以最后操作为准

- 点选曲目 / 播放：`force` 抢占 leader，立刻播放，清除「已在其他页面播放」。
- 广播曲目 index/url，其它页让出并同步选中态；停止亦广播。
- 自动续播仍不强抢（避免无操作页互相打架）。

## 1.1.2 — 换页续播未完成曲目，禁止叠播第一首

- 换页/刷新：只续播 progress 里未完成的那首（URL 归一匹配），不再因 try_autoplay 重新开「高山流水」。

- 冷启动（无进度）才延迟自动播列表头曲。
