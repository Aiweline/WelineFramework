## 2026-09-22 — 配置古风进店音乐（店面浮层修复）

- 需求：配置长安汉服店面古风进店音乐。

## 1.1.64 — 头像环频谱圆心偏离（审图）

- 分流：`web_ui` / `ui_shot`；线稿：环应与头像同圆心；问题：柱用 `top:50%` + `transform-origin:bottom` + `translateY`，柱高变化时枢轴漂离头像中心 → 环偏左下/右下。
- 原型：A 枢轴钉在头像中心 + 内段透明渐变（推荐）/ B 零尺寸 hub；落地 A。

## 1.1.63 — 头像环频谱柱太短看不见（审图）

- 分流：`web_ui` / `ui_shot`；线稿：头像 5.5rem + 环绕细柱；问题：柱高 `0.08+0.42×bar` 峰值≈0.38rem，opacity 过低。
- 原型：A 加长柱（推荐）/ B 减柱加粗；落地 A。

- 验收：契约 UT；Browser 禁缓存播放时环浪可读（柱高/头像比 ≳ 0.35）。

## 1.1.52 — 进店不自动播：window.load 竞态挂死 scheduleStart

- 修复：挂监听后立刻再检 `complete`；补 `readystatechange`；5s 硬上限兜底。
- 缓存戳 `storemusic52loadrace`。

## 1.1.16 — 开面板/关面板/音量不再误抢播

- 根因：`markUserGesture` 仍写 `operator` + `isUserOperating`，对端心跳一刷新 lock 就会「最新操作者 reclaim + force_stop」→ 三页里点任意非播放页，正在播的页被干掉且本页未开播，全站失灵。
- 开面板 / 关面板 / 音量 / 波形只记本地手势，**不写**跨页 `operator`、**不** `acquireLeaderLock`。
- 心跳/storage reclaim 仅当本页已在播或已是 leader 才夺回；浏览态忽略对端心跳、不抢锁。

## 1.1.15 — 多页可各自操作：手势不抢锁 + 域名标签普查防误杀

- 开面板 / pointerdown 只 `markUserGesture`，**不** `acquireLeaderLock`；仅 ▶ / 选曲 / 切歌 / 停止才抢播。
- `operator` 的 storage 事件不再让权静音（曾导致「点别的页 → 正在播的页被干掉 → 全站异常」）。
- 域名标签普查：隐藏标签仍算存活；0×0 需连续多次才判定脱离；`domain_empty` 延迟确认且真标签可忽略误报。
- 让权后页面保持可操作（`_docAlive` + needGesture）；❚❚ 不再 `clearWantPlay` 污染其它页。

## 1.1.14 — 切歌硬换 Audio：禁多源叠播 / 禁换歌不生效

- 根因：波形 `createMediaElementSource` 绑定后若 `AudioContext.close()`，同一 `Audio` 再换 `src` 常失效，旧解码残留 →「多个在播、换歌无效」。
- `playCurrentTrackNow` / 换轨：`discardAudioElement` + `killRivalAudioElements` 清掉全部竞争音源，再挂载全新 `Audio`。
- 全局 registry 跟踪本模块创建的 MediaElement；开播后再断言只留当前一首。

## 1.1.12 — 关浏览器/关标签必须硬停声（禁幽灵续播）
