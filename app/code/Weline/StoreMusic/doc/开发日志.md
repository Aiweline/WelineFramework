# Weline_StoreMusic 开发日志

## 1.1.9 — 硬停声 + 最后用户操作胜出（禁叠播残留 / 禁无标签幽灵播）

- 让权改为 `hardSilenceMedia`（清 src / 关 AudioContext），禁止仅 pause 留下「高山流水+孤城」残留。
- `isRemoteNewer` 改为 `>=`：同等时间戳也让权，避免双页互抢。
- `play` 事件禁止无手势 `claimLeadership(true)` 抢回；统一 `bindAudioElementEvents`。
- 关标签 `pagehide` 硬拆 MediaElement；peer 释放 lock 后可见页 `maybeResumeAfterPeerRelease`，避免必须再点进标签才出声。
- **幽灵播闸门**：仅在本页曾可见开播后才允许隐藏续播（`_heardWhileVisible`）；隐藏冷启动/无标签残留一律 `killAllPageAudio`；`_docAlive` + ghost watch 拒绝离页后再 play。
- 浮层 CSS 强制可见，防宿主工具把头像/面板隐掉。

## 1.1.8 — 最后用户操作为准（时间戳胜出）

- 让权比较 `msg.at` / `operator` 与本页 `_lastUserActionAt`：更新的用户操作永远胜出，禁止旧页抢回残留叠播。
- 心跳广播不得用 `Date.now()` 冒充操作时间；❚❚ 停止广播 `force_stop`+`clearWantPlay`。
- 可见性软恢复不再 `force` 抢播，避免对抗其它页的最后操作。

## 1.1.7 — 修双曲叠播（隐藏页必须让权）

- 隐藏/后台页不可凭「刚操作过」拒绝 yield；切走标签时清 `_lastUserActionAt`。
- 前台抢播发 `force_stop`；`silenceForOtherTab` 停掉本页与残留 shared Audio。
- 单标签后台续播仍保留；叠播残留（高山流水+孤城）为跨页未让权。

## 1.1.6 — 后台标签继续播（visibility ≠ 离页）

- `visibilitychange` 隐藏时只存进度/停波形，**不再 pause**；切走其它标签或应用仍应能听到 BGM。
- 仍在播放时后台页继续维持 leader 心跳，避免同站其它页软自动播叠音；真正离页仍走 `pagehide` hardStop。

## 1.1.5 — 跨页点选曲目同步开播（保留用户手势）

- 选曲/播放改为 `playCurrentTrackNow`：点击栈内直接用网络 URL `audio.play()`，不再先等 IndexedDB。
- 有焦点/正在操作的页面忽略过期「已在其他页面播放」，并自动把暂停中的音频拉起来。
- IDB 仅后台缓存，不挡开播。

## 1.1.4 — 当前可见页独占操作权（修点了没反应）

- 后台页停止心跳广播，避免把前台刚抢到的播控踢掉。
- 本页 pointerdown/点击即 `markUserOperating`，忽略过期「已在其他页面播放」。
- 切到可见页自动续播；隐藏页暂停并放权。选曲仍立即播放。

## 1.1.3 — 本页操作立即抢播，多页以最后操作为准

- 点选曲目 / 播放：`force` 抢占 leader，立刻播放，清除「已在其他页面播放」。
- 广播曲目 index/url，其它页让出并同步选中态；停止亦广播。
- 自动续播仍不强抢（避免无操作页互相打架）。

## 1.1.2 — 换页续播未完成曲目，禁止叠播第一首

- 换页/刷新：只续播 progress 里未完成的那首（URL 归一匹配），不再因 try_autoplay 重新开「高山流水」。
- 离开页先落盘 want_play + 进度再 pause，避免 bfcache 旧页与新页双开。
- 冷启动（无进度）才延迟自动播列表头曲。

## 1.1.1 — 选曲弹窗不停播 + IndexedDB 音源缓存 + 刷新续播

- 面板 × 仅关闭选曲弹窗，不再调用 dismiss；❚❚ 为「停止」并清除 `want_play`。
- 音源优先写入 IndexedDB，再次播放走 blob URL，后台预热歌单减少重复流量。
- 播放中刷新：恢复所选曲目并立即尝试续播（浏览器自动播放策略仍可能需一次手势）。

## 1.1.0 — 拖排序 + 简介多语言 + 选曲续播

- 后台歌单接入主题 `reorder-list`；DOM 顺序即 playlist 顺序并自动保存。
- 简介改为 locale map；Taglib `language:select` 切换编辑语言；店面 `frontendPayload` 解析为单语 `intro`。
- 店面：选曲后立即 `persistSelection`（不再要求播放满 0.5s）；刷新按 URL/index 恢复并继续尝试播放。
