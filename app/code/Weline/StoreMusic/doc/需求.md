# Weline_StoreMusic 需求

## REQ-STOREMUSIC-0001 进店音乐

- 后台可按站店渠配置：启用、曲目（含多语言简介）、延迟秒数、尝试自动播、循环、默认音量、波形默认。
- 后台歌单支持拖拽排序；曲名单语；简介按 locale map 存取，店面按访客语言解析展示。
- 前台左下角进店音乐浮层；延迟加载音频；Consent marketing 软门控；波形可开关且可降级。
- 访客选择曲目后，刷新页面应恢复该曲并继续尝试播放（localStorage 进度/选曲/`want_play`）；关闭选曲弹窗不停播，仅「停止」清除续播意图。
- 音源缓存到访客浏览器 IndexedDB，避免每次重新下载。
- 不做养成玩法、自定义形象上传；当前形态为头像入口 + 选曲播控。
