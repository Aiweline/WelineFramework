# Weline_StoreMusic 需求

## REQ-STOREMUSIC-0001 进店音乐

- **主配置面**：主题编辑器选中「进店音乐」部件，在「部件配置」中设置：启用、曲目（路径/曲名/多语言简介）、延迟秒数、尝试自动播、循环、默认音量、头像旋转、波形默认。
- **回退**：SystemConfig / 后台进店音乐页仍可维护系统级歌单；布局部件曲目为空或 Hook 兜底路径读取 SystemConfig。
- 部件歌单支持拖拽排序；曲名单语；简介随编辑器语言（i18n）或 SystemConfig locale map；店面按访客语言解析展示。
- 前台左下角进店音乐浮层；延迟加载音频；Consent marketing 软门控；波形可开关且可降级。
- 访客选择曲目后，刷新页面应恢复该曲并继续尝试播放（localStorage 进度/选曲/`want_play`）；关闭选曲弹窗不停播，仅「停止」清除续播意图。
- 音源缓存到访客浏览器 IndexedDB，避免每次重新下载。
- 不做养成玩法、自定义形象上传；当前形态为头像入口 + 选曲播控。
- 多曲目面板支持按曲名/简介关键字本地过滤播放列表；空结果有空态；清空恢复全列表；上下首仍按完整歌单索引。
