登录页视觉原型

基于现有功能重做视觉与排版：后台偏「安全控制台」，前台偏「品牌会员入口」。不改接口字段，只改布局语言与信息层级。

Backend

后台登录

左右分栏：左侧墨色品牌叙事 + 右侧纸色表单。铜强调、语言切换在卡片右上。

 Frontend

前台登录

沉浸品牌面 + 奶油卡片。记住时长改为分段控件，主色珊瑚，注册与第三方入口保留。

功能对照（均保留）

  • 后台：Logo / 站名描述、语言切换、告警、SSO Hook、账号、密码、验证码刷新、记住我、提交加载、页脚。
  • 前台：欢迎文案、用户名或邮箱、密码显隐、记住时长、忘记密码、验证码、提交加载、Providers Hook、注册入口。

设计原则

  • 品牌字级在第一屏够大（Fraunces / Cormorant），避免「居中小卡片 + 灰底」通用后台脸。
  • 禁止紫渐变、玻璃拟态堆叠、默认 Inter 唯一字体。
  • 验证码、SSO、记住我占次级权重，主路径是账号 → 密码 → 登录。
