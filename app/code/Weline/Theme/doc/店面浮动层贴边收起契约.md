# 店面浮动层贴边收起契约

> 归属模块：`Weline_Theme`（机制）。各业务 Widget 只提供内容，不写贴边几何。
> 静态资源版本：`doc/静态资源版本契约.md`（禁止在 `weline.modules.js` 的 path 上手写 `?v=`）。

## 1. 职责分层

| 层 | 负责 | 不负责 |
|---|---|---|
| **Critical CSS** | `SharedChromeService::emitFloatLayerCriticalCss()`：首帧 chip、收起 `translateX/Y(±100%)`、body 隐藏 | 业务 Widget 样式 |
| **Sheet CSS** | `view/statics/css/storefront-float-layer.css`：与 critical 同值镜像（`FloatChromeCriticalParityTest`） | 内联到页脚/主题复制 |
| **JS** | `storefront-float-layer.js`：`is-edge-collapsed`、localStorage、展开时清 inline `transform`、异步子节点内联隐藏兜底 | 收起位移 inline、24px 贴边条、手写 cache-bust |
| **模块注册** | `weline.modules.js`：`Weline_Theme::js/storefront-float-layer.js` 裸路径 | path 后缀 `?v=2026…` |

## 2. 几何（唤出按钮贴边）

1. 槽位收起：`transform: var(--w-float-dock-base,) translateX/Y(±100%)`，整块平移出屏。
2. 唤出按钮（`.w-storefront-float-edge__recall`）在槽**外侧**（如 left dock 用 `left: 100%`）。
3. **禁止**「留 24px 条 + 按钮进条内」组合——与 recall 外侧定位冲突，会产生固定宽度缝隙。

## 3. 缓存与发布

- 浏览器长期缓存靠部署构建号 / 主题代次 URL（`/_weline_dev`、 `/static/{buildId}/…`），不靠模块表手写版本串。
- 改 CSS/JS 后：`resource:compile` → `cache:clear` → `fpc:clear`（站点范围）→ `server:reload`；禁止只 `cp` 到 `generated/static/live/…` 当交付。

## 4. 异步全局区 Widget

- 占位 + 片段：`Weline_Widget` async 管线；`floatSlot` 非空才进浮层槽。
- 宿主用 `data-weline-collapse-empty` 声明「没有内容时可以不展示」；八个方向的槽位（容器）按元素数判空：槽里出现空宿主整槽隐藏（`__slot:has([data-weline-collapse-empty]:empty)`），槽本身没有元素子节点也隐藏（`__slot:not(:has(*))`）；部件注入后 `:has()` 自动恢复。不得只看 `data-weline-mount-state`——水合失败的宿主壳仍是白底气泡。
- 产品页 404 布局会导致片段内联到 body 顶：身份解析用 `Product\Http\ProductRouteIdentity`（Context 与 Request 对齐），禁止控制器 regex `REQUEST_URI`。
