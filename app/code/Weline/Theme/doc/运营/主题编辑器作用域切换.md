# 主题编辑器作用域切换

1. 打开 Theme Editor，在顶部“作用域”选择 Global、某个网站、店铺或渠道。
2. 等待页面与预览重新载入，确认选择框仍显示目标作用域。
3. 编辑 Theme、布局或部件配置；编辑器只把实际改变的字段/节点记为当前层自有，草稿不会影响前台。
4. 发布后切到父级或其他子级，检查当前层自有值保持不变、其余值继续跟随父级。
5. 对“本级修改”字段使用“恢复继承”，再次发布后确认值与来源都回到直接父链。

注意：

- 固定父链为 `Channel → Store → Website → Global → 主题包默认值`。未换 Theme、未改配置都表示继承，不复制父值。
- 空字符串、`0`、`false` 和显式空值都是合法本级值；只有“恢复继承”会删除当前路径的所有权。
- 父级发布后，子级未覆盖路径自动更新；子级已覆盖路径保持本级值。结构冲突时子级前台继续使用最后一个有效 Release。
- 虚拟布局锁定入口会禁用作用域选择，需返回普通 Theme Editor 后切换。
