## 2.1.1 — Theme Editor 四级 Scope 逐值继承

- 当前状态：`implemented_validated`；自动化与唯一 WLS + 内置 Browser 真实验收均完成。
- 需求 ID：`REQ-THEME-0004`。
- 最终语义：Scope 是编辑器最高级上下文，层级固定为 `Global → Website → Store → Channel`。Website、Store、Channel 均可独立切换 Theme；本级没有 Theme Patch 或配置 Patch 时继承直接父级，仅实际修改路径成为本级所有，恢复继承即删除该路径 Patch。
- 需求纠正：本节覆盖 2026-08-22 12:25 “不新增 Channel”以及 15:43 三层树验收的阶段性结论；它们只保留为历史过程证据，不再代表当前产品契约。
- 实现范围：公共 typed Scope/父链与权威目录、Theme workspace/revision/patch/release、Theme/布局/Meta 等 Adapter、稳定节点 UID 与结构合并、父级发布传播、迁移预检和幂等回填、Scope-first 编辑器、逐字段来源/恢复继承、容器自适应输入与浮层限界。
- 静态复审：架构边界、缺陷和安全通过；运行时只读已发布 Release，草稿预览使用受控 typed context，写入拒绝短 Scope 和伪造 ID/code，业务 target 与 Website/Store/Channel Scope 正交。结构位置所有权与节点内容所有权已分离，新增后移动和新增后删除可组合且不会制造错误墓碑。
- 调试修复：frontend iframe 改为通过预览启动 API 获取短期 Token，Scope 快速切换使用序列号丢弃过期异步响应；`ThemeData` 请求态按连接身份哈希隔离；普通 backend 无冻结 Scope 时使用显式 Global 布局身份；GET 请求会修复缺失或无效的 typed `editor_context`，对象查询值统一 JSON 序列化；外观盘复合 token 控件补齐 Grid/Flex 可收缩与换行契约。
- 单身份写边界：默认注入等布局写入只作用于当前 typed context，不向同布局其他身份批量扩散；UI 仅暴露“应用当前身份”，E2E 验证同级身份保持未修改。
- 验收证据：聚焦 Theme 集合 `118 tests / 582 assertions`；UI/请求契约 `17/267`，新增 UI/普通后台布局身份回归 `11/250`；迁移 0 碰撞/0 重复 UID/0 歧义且幂等；官方 UI 连续编译 JS/CSS 哈希稳定；唯一 WLS 9654 上五个专项 E2E 全部通过。
- Browser 证据：Global/Website/Store/Channel 四层真实切换，Store/Channel canonical Scope、继承来源与 Token 预览正确；320px 外观编辑器 `30 controls / 0 overflow`，640px（200% 等效）`31 / 0`，默认视口 `8 / 0`；Theme Editor 与 Dashboard 最终 `0 error / 0 warning`。
