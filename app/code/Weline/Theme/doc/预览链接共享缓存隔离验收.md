# 预览链接共享缓存隔离验收

2026-10-04，实际环境：`https://p05113ef3.test.weline.com/`。

## 问题与根因

未登录、没有编辑器查询参数的 `/category/hanfu` 返回 272 条带 `editor_mode` 的链接。绕过整页缓存后仍有 59 条，说明污染并非只发生在整页缓存。

导航片段缓存将绝对 URL 缩成路径，编辑器与普通页面使用同一个键；筛选面板缓存保存了请求当时生成的完整 URL，但其业务键不区分编辑器请求。编辑器链接进入共享片段后，普通请求又将这些片段发布为整页缓存。

## 修复边界

- 导航片段保留完整 URL 指纹；编辑器及预览请求的导航输出只在当前请求复用，不读写公共导航缓存，也不预取公共片段。
- 筛选面板的编辑器及预览请求只使用已有请求缓存，普通请求继续使用共享缓存。
- 导航服务是常驻进程共享对象，逐次通过 ObjectManager 获取当前请求的预览检查器，不保存某次请求的身份。
- 导航缓存键升级为 mega/sidebar v9、horizontal v3；筛选资源升级为 `product.filter_panel.v3`，旧污染产物不会再次命中。
- 通过已有 namespace generation 机制推进当前 `default/default/default/normal` 渠道的 Theme 缓存版本，实际普通分类页由旧 STALE 页面转为 MISS，污染链接降为 0。没有清空业务数据或重启服务。

## 实际验收

原生无头浏览器登录后台后交替访问编辑器与独立匿名页面，桌面 1440、手机 375 两种宽度，各两轮：

- 4 次编辑器访问，每次 613 条链接正确携带编辑上下文。
- 8 次普通首页及分类页访问，每次编辑器链接为 0，覆盖整页缓存命中。
- 实际点击分类筛选链接，保留 `af_*` 筛选参数，没有编辑器参数或编辑器模式。
- 浏览器用例通过，耗时 15.9 秒；初次用例被正常订阅弹窗挡住点击，补充正常关闭弹窗操作后重跑通过。

开发验证：导航 12 个用例、61 个断言通过，包括 URL 键碰撞、编辑器不访问公共缓存、同一常驻服务先编辑器后普通请求的身份切换。筛选本次回归用例及路径用例通过；三个修改服务 PHP 语法检查通过。

已有筛选测试中的 `testCachedPanelWarmsOnlyDisplayedWordsInBoundedBatchesAndReusesThem` 与 `testPrefetchedPanelKeepsModuleAndRequestOverridePrecedence` 仍要求此前已移除的 Phrase 批量预热，因此失败。隔离禁用本次预览分支后仍得到同样两项失败；本次未改动该翻译行为，也不声称整个筛选测试文件全部通过。
