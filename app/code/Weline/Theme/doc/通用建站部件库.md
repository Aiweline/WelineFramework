# Theme 通用建站部件库

## 范围与设计

用户选择「通用」：区块适用于内容站、企业站、活动页与商城，不把汉服业务数据写进新通用区块。已有商品、文章、表单能力继续通过原模块部件复用。

参考 [Shopify blocks](https://shopify.dev/docs/storefronts/themes/architecture/blocks) 的可重复配置、排序与嵌套机制，以及 [WordPress core blocks](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/) 的文字、媒体、布局分类。本项目沿用 Widget 注册、ParamSchema 与 Theme 可视化编辑器，不另造建站引擎。

默认视觉沿用主题现有 Amazon 风格基础：简洁标题、浅色卡片、细边框、主色按钮。颜色、字号、字体、间距、圆角、阴影都引用主题变量；区块根填满所属内容槽，不再嵌套私有最大宽度与横向页边距。

## 已注册的通用部件

所有新增部件均允许全部页面类型，按各自声明放入内容区、侧栏或页脚等插槽。列表字段使用可增加、删除、排序的 ParamSchema，不要求手写 JSON。

| 分类 | 部件 | Widget code |
| --- | --- | --- |
| 文字 | 区块标题 | `section-heading` |
| 操作 | 按钮组 | `button-group` |
| 布局 | 间距与分隔线 | `spacer-divider` |
| 布局 | 双栏嵌套容器 | `columns` |
| 媒体 | 单张图片 | `single-image` |
| 媒体 | 图片相册 | `image-gallery` |
| 主视觉 | 通用 Banner | `hero-banner` |
| 内容 | 图文卡片网格 | `card-grid` |
| 内容 | 功能与服务列表 | `feature-list` |
| 内容 | 数据统计 | `stat-grid` |

| 内容 | 步骤流程 | `step-list` |
| 内容 | 价格方案 | `pricing-table` |
| 联系 | 联系信息 | `contact-info` |

优化现有 `hero-slider`、`promo-banner`、`ad-banner`、`text-block`、`image-text`、`faq-accordion`、`testimonials` 七类部件。导航、页头页脚、商品、分类、文章和表单等已有部件继续复用原模块，不在 Theme 复制业务实现。

公共样式为 `view/statics/css/widgets/site-blocks.css`，通过 Theme 编辑器与前台 head 加载；交互通过 `siteBlocks` 模块按 `data-weline-load` 声明加载。颜色、字体、间距、圆角、阴影继承当前主题，默认沿用已有 Amazon 风格主题；`--size-hero-height` 是新增的主视觉高度变量。不会强制覆盖站点品牌色。

## 内容契约

- 图片使用 FileAsset 图片选择器；旧 URL 经过 LegacyMediaUrl 兼容层。
- 图片的非空替代文字覆盖当前使用实例的 alt，留空时保留素材说明；使用 PHP 8.4 [HTML5 DOM](https://www.php.net/manual/en/dom-htmldocument.createfromstring.php) 保留 picture/source 结构。
- 分栏的实际插槽为 `columns-left/right-{实例摘要}`，摘要来自持久化 node_uid（旧布局为 layout_id），编辑列宽或移动部件不改变子部件归属。手写模板重复放置时提供不同 `slot_key`。
- 新展示列表默认留空，不生成假团队、评价、价格、统计或媒体。空列表提供明确的配置提示。
- 既有汉服首页和织艺真实素材保持不变；新部件可放置于其他页面内容槽，不自动改写现有页面。
- 价格展示不承担结账；联系信息只提供真实链接，不实现未配置的发送表单。
