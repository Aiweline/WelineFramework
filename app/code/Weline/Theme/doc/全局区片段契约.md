# 全局区片段契约（base contributions）

> 状态：已实现并在本机店面验证。代码在 `app/code/Weline/Theme/Region/`，面板数据面在
> `app/code/Weline/Theme/Service/Region/GlobalRegionConfigService.php`。

## 1. 声明：放文件就算接入

```
主题自有  app/design/{theme}/frontend/widget/base/{region}/{group}/{nn}-{name}.phtml
模块      app/code/{Module}/view/theme/base/{region}/{group}/{nn}-{name}.phtml
```

| 项 | 来源 |
|---|---|
| region | 路径：`head` / `body_open` / `body_end` |
| group | 路径：`analytics` / `consent` / `marketing` / `ops` … |
| 顺序 | 文件名 `nn-` 前缀，其次字典序 |
| id | 路径推导：`base.head.analytics.01-pixel` |
| 默认启用 | 主题目录 = 开；模块目录 = 关（面板开） |

## 2. base 也是部件

片段保留完整部件元数据：`@widget.code / name / description / cache / share / type / area / supports`，
并**自带部件代码**——禁止在片段里 `getFetchFile()`/`ob_file()` 回头引用 `templates/frontend/widgets/*`。

位置相关的三项必须清空，否则会和全局区双写：

```
@widget.position {[]}
@widget.slot {}
@widget.default_injections {[]}
```

主题要换皮就在 `app/design/{theme}/frontend/widget/base/...` 覆盖同名片段，同样带元数据。

## 3. 默认异步，只有 eager 内联

base 组件是全局的、多数首屏不需要，因此默认异步：

```html
<div data-global-region-async="base.body_end.consent.01-banner"
     data-global-region-endpoint="/theme/frontend/widget/shell?fragment=base.body_end.consent.01-banner"
     hidden></div>
```

- 页面只多一个空节点 + 一次内联的水合器（`Theme/view/statics/js/global-region-async.js`），
  浏览器空闲时取回标记再替换。
- 需要首屏立即执行的基础设施声明 `@global-region.eager {true}`（当前仅像素引导），照旧服务端内联。
- 水合端点只渲染**已启用**的片段；关掉的片段返回 204，拿不到内容。

实测：首页 HTML `257,352 → 214,996` 字节（−42KB）；ego 复核异步节点归零，组件各自出现一次。

## 4. 开关与配置

- 四层：站点总闸 `enabled` → `regions.{region}` → `groups.{region}.{group}` → `items.{fragmentId}`；
  未配置回落路径默认值（主题开、模块关）。
- 存储：站点 env 配置 `theme/base_contributions`：

```json
{
  "items":  {"base.body_end.consent.01-banner": true},
  "config": {"base.body_end.ops.04-store-music": {"enabled": true, "tracks": []}}
}
```

- 片段渲染时把 `config.{fragmentId}` 作为模板参数传入（与 `<w:widget>` 同口径的 `fetchHtml($path, $params)`），
  面板改颜色/文案/曲目即时生效。
- 面板数据面：`GlobalRegionConfigService`（`listContributions / setEnabled / setRegionEnabled / setGroupEnabled / setConfig`），
  控制器 `Theme\Controller\Backend\Region`（`index / toggle / config`）。
- 命令行等价物：`php bin/w theme:region-status [--region=head|body_open|body_end]` —— 列出片段 id / 区 / 组 /
  eager 或 async / 开关 / 对应部件 code。新增控制台命令后要跑一次 `php bin/w command:upgrade`，
  否则命令不会进 `generated/commands.php`（表现是 `No matching command found.`）。

## 5. 禁止回潮

同名片段已启用时，旧部件的槽渲染必须跳过，否则主题残留槽 + 已物化放置会产出第二份。守卫点：

- `Widget\Taglib\Widget`
- `Theme\Service\SlotRendererService::renderWidget` / `doRenderWidget` / `renderWidgetInnerFromWrapperOpenTag`
- `Theme\Service\LayoutEntity\ThemeLayoutEntityWidgetRenderer`（轻量判定 `GlobalRegionWidgetOwnership`，不在烘焙/渲染期启动 provider）

## 6. 编译期注入（只增不改）

| 插入点 | 位置 |
|---|---|
| `head` | 第一个 `</head>` 之前 |
| `body_open` | 第一个 `<body …>` 之后 |
| `body_end` | 最后一个 `</body>` 之前 |

只增不改、跳过 `<script>`/`<style>` 与 PHP 块、以 `<!--@weline-global:{region}:begin/end-->` 包裹保证幂等；
布局已含 `GlobalRegion::render` 时不再重复注入。

**注入范围由 `GlobalRegionSourceRewriter::appliesTo()` 统一判定**（两种布局来源都要覆盖）：

| 来源 | 例子 | 是否注入 |
|---|---|---|
| 主题布局 | `app/design/{theme}/frontend/layouts/…` | ✅ |
| 主题覆写别的主题/模块布局 | `app/design/{theme}/{Module}/theme/frontend/layouts/…` | ✅ |
| 原生（框架）布局 | `app/code/Weline/Theme/view/theme/frontend/layouts/…` | ✅ |
| 固化产物（**请求实际执行的就是它**） | `generated/theme/…/pages/layouts/…` | ✅ |
| hook 片段 | `…/view/hooks/…/layouts/base/body-end.phtml` | ⛔（没有 head/body） |
| com 编译产物 | `…/view/tpl/…/com_default.phtml` | ⛔（再改写会锚点嵌套） |

**hook 与编译物的继承语义（不要混）**：

- **编译物不继承**：每个模块各自编译自己的 hook（`{Module}/view/tpl/…/com_*.phtml`），是最终物，不会被别的模块覆盖；同一模块的已编译实现在 HookReader 里优先于文件扫描。
- **hook 可继承**：同一 hook 名可由多个模块各自实现，按优先级**合并全部渲染**；`HookReader::mergeRegistryWithFilesystem()` 保证「不完整/过期的注册表不会吞掉模块对硬 hook 的覆写」。实测 `Weline_Theme::frontend/layouts/base/body-end` 有 13 个模块各自实现，各自都有独立编译物。
- 全局区契约**不改写 hook**（`appliesTo` 排除 `/view/hooks/`），因此 hook 的继承与覆写语义不受本契约影响。

## 7. 本机验证口径

```bash
php bin/w theme:update --force -t hanfu
rm -rf generated/html/generations && mkdir -p generated/html/generations   # FPC 磁盘代次必须清
php bin/w framework:compile
php bin/w server:stop --all && sleep 10 && php bin/w server:start default   # restart 不换 worker
S=$(cat generated/framework/fpc_pierce_secret)
curl -sk -H 'Host: p05113ef3.test.weline.com' "https://127.0.0.1/?w_fpc_pierce=$S"
```

判据：页面 200、`data-global-region-async` 占位与启用项一致、像素内联出现一次、每个组件页面内只有一个实例。
