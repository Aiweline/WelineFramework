# 旧布局绑定 v2 迁移方案已废止

> 2026-09-25：本页原有“保留旧文件与旧读取兼容”的操作方案停止使用。业务代码尚待新方案实施；此声明不表示旧命令或旧文件已经从代码/环境删除。

执行新的[主题固化物实施方案](./spec/layout-entity-per-version-isolation.md)，不再按本页旧命令进行 v2 迁移。

旧方案的 tv 外共享 `s{hash}`/`configs`、页面 `r{release}`/`d{revision}`、`current.json`、缺少草稿基线时保留旧读等约定全部被替代。相同结构跨版本必须共用同一路径的验收要求撤销；目标为版本独占路径、明确继承才可硬链不可变字节。

实施时删除 `Console/Theme/Layout/MigrateBindings.php` 及 `theme:layout:migrate-bindings` 注册入口、对应旧测试和旧读取分支。新的一次性转换器只读取旧持久数据作为输入，输出新版本/修订映射；它不保留运行双读。

切换步骤、旧代码/文件/缓存/API 删除清单、无法证明的历史数据处理和实际运行验收，均以新方案为准。业务 DB 原始内容和主题源模板不属于派生物 purge 的删除范围。
