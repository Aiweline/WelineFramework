# Theme 零网站领域依赖与简化外观管理

## 已确认需求

Theme 是可独立工作的主题资产与内容模块。网站自己选择 Theme，并提供自己的范围；Theme 具有通用范围区分能力，不拥有网站范围树或激活状态。三个宿主入口为网站外观、主题库、后台外观，常用动作简化，技术身份隐藏但内部必须完整。

详细架构与实施顺序见仓库根 dev/prototypes/theme-scope-activation/方案.md 与实施计划.md。这里只维护耐久外部行为，不存会话进度。

## EARS 与验收用例

| UC | 触发条件 | 系统应有行为 |
|---|---|---|
| UC-1 | 网站选择主题／版本 | Websites保存完整对象、模式、区域下的应用引用，展示实际主题和来源；不写Theme资产激活字段 |
| UC-2 | 用户保存对象内容 | Theme只更新传入中性身份的内容、修订与PHTML；不改变网站引用或主题默认资产 |
| UC-3 | 本级没有应用引用 | 使用方沿权威父链解析最近引用；Theme不主动查父网站或渠道 |
| UC-4 | 本级显式选同名主题，随后上级更换 | 本级继续固定自己的主题与版本；恢复跟随只删除本级应用引用，内容历史仍保留 |
| UC-5 | 后台外观切换 | 系统配置保存全局backend引用，网站选择及内容不变 |
| UC-6 | Theme新增资产版本 | 当前使用方仍使用原版本；Theme单独启用可编辑资产、生成PHTML及示例预览 |
| UC-7 | 编辑／Token／示例预览后访问正式页面 | 正式链接及缓存不含编辑参数；有效业务筛选参数保留，不进入编辑模式 |
| UC-8 | 迁移与重复升级 | 数据身份准确映射、升级幂等、历史与卸载意图不丢失；正式运行不存在旧激活兜底或双写 |
| UC-9 | 历史Token后续保存并清编译缓存 | 使用对应历史资源依据，不借最新草稿或最新祖先；依据缺失时报告真实错误 |
| UC-10 | 不同范围／模式／语言／option／target或并发保存 | 参数、部件顺序和产物不串用；保存互斥使用owner和实际修订，页面与公共部分输入一致 |

## 固化约束

沿用PHTML-only：保留原模板PHP、Hook、分支、Partial与动态业务；两种插槽、嵌套实例、组件／虚拟／Block分派、语言差异与显式空值正常。固化命中不查询数据库重新播种位置。必装注入在没有人工卸载记录时存在，人工卸载不复活，卸载全部仍有有效编辑意图。派生产物无结构JSON／JS侧车。

## 操作要求

网站先选设置对象，展示当前主题和单独／跟随来源；主要动作为编辑内容、预览网站、换主题。版本和环境在更多设置，非正式环境持续可见提示。换主题确认显示对象、前后主题及受影响下级数量，独立下级保留原配置。正式编辑器保留新增／移动／卸载／语言及参数能力，不能只实现原型的标题演示。

## 范围边界

公开接口属于各资源所有模块；不跨模块依赖内部模型或直调Controller。复用现有Framework provider、QueryProvider、Scope控件、Template和框架缓存。不新增发布状态机、永久修订目录或跨DB／文件系统分布式事务。源模板及部件实现仍随代码升级；版本固定编辑意图与配置。

## 验收依据

聚焦行为测试只是开发证据。UC-1..10最终在当前已配置本地系统执行，保留实际主题／版本引用、保存修订、产物与真实页面截图。上线不属于本需求默认授权。
