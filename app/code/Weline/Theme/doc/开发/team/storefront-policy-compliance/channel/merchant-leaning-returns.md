# 商家友好退换口径（2026-09-22）

## 经营事实
- 卖家在**中国国内**履约，主要面向**海外买家**（跨境回程贵、汉服试穿后难二次销售）。
- 店内承诺若主打「七日/十四日无理由」，跨境个人原因退货压力极大。

## 口径（运营决策）
1. **本店退换政策以质量问题为主**：破损、做工瑕疵、污渍、明显不符、错发漏发等。
2. **个人原因（不喜欢、轻微试穿后不想要、选错色码）原则上不支持退换**。
3. **法定例外仅作底线披露**：仅当买家所在地/适用强制性法律要求无理由或冷静期时，在该强制范围内从其规定——**不作为本店营销卖点**，且非质量原因的回程运费、税费、清关费由买家承担（法律另有强制分配除外）。
4. **质检**：已穿着使用、吊牌缺失、影响二次销售 → 拒收/不退（质量问题除外）。

## 法律提示（非律师意见）
无法用站内条款在所有市场「取消」强制消费者冷静期；但可以、也应该把**店内主规则**写成质量问题导向，避免把无理由写成默认店内福利。
