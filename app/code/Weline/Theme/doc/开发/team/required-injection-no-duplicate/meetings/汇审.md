# 汇审：required injection 整区替换（框架禁部件叠渲）

- 日期：2026-09-21
- 模块：Weline_Theme 2.2.511（主）/ Marketing 1.3.3 / Checkout 1.5.10
- 结论：**通过（契约）**；本机维护 wait-gift 开启，店面 HTML 探活被 503 挡，未做活页 Browser

## 框架根因

`RequiredDefaultInjectionStorefrontOverlay::executeOne` 原 `$html . $inner`：槽内已有 bake/soft 内容但 presence（`data-testid`/`data-widget-code` = widget code）未命中时，再前置注入 → **任意 required 部件双渲**（收货地址、优惠券同构）。

## 修复

- Overlay：**整区替换** `replaceRegionInner(..., $html)`，禁止拼接。
- 优惠券 marker 对齐 `checkout-coupon`；摘要槽加 `exclusive`。
- 契约：`RequiredDefaultInjectionOverlayExecuteTest::testExecuteOneReplacesMismatchedBakeInsteadOfPrepending` + Coupon Widget UT。

## 证据

- UT Theme overlay + Marketing coupon：**6/6 PASS**
- 活页：`maintenance/wait_gift` + `system.maintenance` = true → worker `503`；待维护关闭后复验优惠券 `controls=1`
