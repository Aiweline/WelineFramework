- 日期：2026-09-20

## 1. 结论

| 项 | 结果 |
|----|------|
| 验收 | **PASS**（本机 PDP：加购 / 立即结账 / 快捷支付 PayPal 均可见） |
| 根因 | 非「注册表随机丢失」；是 **结构有、HTML 空（幽灵）** + **page-config 缺 module/code** + **同名嵌套槽 splice 取最深空壳** 叠加 |
| 终态 | 仍走 `RequiredDefaultInjectionStorefrontOverlay`；failsafe 仅过渡；未把 CTA 硬嵌进 Product |

## 2. 根因验证（对应技术方案 H1–H6）

| 假设 | 实机证据 | 处置 |
|------|----------|------|
| H1 嵌套槽空 | `product-express-payment` 仅 `data-wslot` 空壳 | 壳层二次 overlay + ghost drop |
| H2 Overlay 未进嵌套 | CLI 对壳 HTML `append` 可注入；店面 splice 后缺二次保证 | `SlotFiller` splice 后再 `append` 壳层 |
| H4 空渲染当丢失 | express 早期 `return` 无壳 | 空方法/关闭/询价保留空壳 |
| H5 FPC | bypass 后仍空 → 非仅缓存 | `server:reload` + `x-wls-fpc-bypass` |
| 额外 | `page-config.json` 仅参数无 `widget_module/code`；structure 有身份 | `ConfigStore`/`WidgetRenderer`/`prime` 从 structure 补全 |
| 额外 | 同名槽 deepest-first 用空嵌套盖住已填浅层 | `extractSlotInner(preferDeepest=false, preferNonEmpty=true)` |

## 5. 补记 — buybox 拥挤/不等宽 CTA（2026-09-20 晚）

| 项 | 结果 |
|----|------|
| 现象 | 加购与结账贴缝、宽度阶梯；红框「太挤也很丑」 |
| 根因 | splice/`overlay` `replaceSlotInner` 按 marker 整段替换，拆掉 `.product-native-detail__actions`；孤儿 CTA 无全宽 CSS；failsafe 再造一套 |
| 处置 | SlotFiller + Overlay 优先 `replaceWrapperInner`；failsafe 见根级 CTA 即移除；`coalesceBuyboxPurchaseActions` 去重并收拢；buybox/actions gap → `--weline-space-4`；HelpPay 安静链同行 wrap |
| 验收 | CDP：`addW=buyW=246`，`gapY=16`，`addCount=1`，failsafe 已移除；UT 3 PASS |

## 6. 补记 — PayPal 快捷支付 / 默认注入（2026-09-20 晚）
