## 根因

### QA-10 · 维护弹层挡首屏（P0）

- `app/etc/env.php` 中 `system.maintenance` 已为 `false`，但本机 WLS Worker 曾残留维护门禁 / 升级波次 `var/maintenance/current_wave.json` 停留在过期 `redeem_window`。
- 弹层 `#weline-maintenance-wait-modal` 由 Frontend `maintenanceHandler` 在 API 返回显式 `code=maintenance` 时懒加载 `maintenance-async-wait.js` 注入；非 HTML 内嵌。
- 未明示「测维护态」时，本机验收应保证框架标志关闭 **且** WLS Worker 同步禁用（`WlsMaintenanceSync`），否则会出现首屏可点偶发被挡。

### QA-12 · 登录 referer 双重编码（P1）

- `Customer\Controller\Account\Index` 游客跳转写成：  
  `redirect('/customer/account/login?referer=' . urlencode($currentUrl))`
- `PcController::redirect` → `Url::getFrontendUrl` → `extractedUrl` 会把 path 上已有 query 再 `http_build_query` 一次 → `https%3A` 变成 `https%253A`。
- 登录后 `CustomerAuthReturnUrlService::decodeTarget` 最多 rawurldecode 两次，回跳可能仍能解出，但 URL 脏且易踩坑。

### QA-13 · 政策短链 / 注册别名 404（P1）

- Theme 公开壳走 `layout_resolve` 路径↔布局 1:1；`/privacy` 等短链无布局文件 → 404。
- 历史曾有 `defaultPublicRouteMap` 别名表，已拆除；页脚主链已是 `/policy/*`，但布局内仍有 `@url{'privacy'}` 等短链，FAQ/旧链仍会点到短路径。
- `/customer/account/create` 无生成路由；正确入口为 `register`。
