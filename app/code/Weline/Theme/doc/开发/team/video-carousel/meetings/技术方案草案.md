## 1. ArrayType 扩 `product_picker`

**问题**：`ArrayType::renderItemField` 无 `product_picker` 分支 → 退化为文本框；编辑器 `renderFallbackArrayItemField` 同缺口。

**机制落点**：

1. `Weline\Widget\Ui\ParamType\ArrayType::renderItemField`  
   - 对 `type=product_picker`（及注册别名）**委托** `Weline\Product\Ui\ParamType\ProductPickerType`（或 `ParamTypeRenderer` 已注册类）渲染 HTML。  
   - 项内 name/path 须带数组索引前缀，与 `.w-param-array` hidden JSON 同步。
2. **值协议**：与顶层一致——逗号分隔 product id 字符串；保存进 `video_carousel_items[i].product_ids`。
3. **编辑器**：数组表单唯一入口继续走 `paramrender/form` → `getConfigForm` → ArrayType HTML（media-item-fields 决议）；**禁止**失败回退本地 text fallback。
4. **前端**：`Weline.Widget.Params` 克隆 template / 序列化时识别 picker DOM，避免丢值。
5. **契约测**：ArrayType 项 schema 含 `product_picker` 时输出含选品控件标记（非裸 `<input type=text>`）。

**非本需求**：静默改写其它已声明但未按 ID 取卡的部件行为（如 featured）——可另开债务项。

## 2. VideoEmbedResolver + bilibili CSP

**机制落点**（三处同扩，禁止只改一处）：

| 点 | 文件/类 | 变更 |
|----|---------|------|
| Resolver | `Weline\Theme\Helper\VideoEmbedResolver` | 增 bilibili ID/URL 解析（页面 URL、`b23.tv` 短链若可安全归约、`player.bilibili.com/player.html?bvid=` / `aid=`）；`trustedEmbedHosts()` 累加受信主机 |
| Sanitize | `video-player` 与新建 `video-carousel` 模板共用信任列表 | iframe `src` 仅受信主机；无效 → 诚实空态 |
| CSP | `ThemeVideoEmbedCsp` | `frame-src` / `img-src` / `connect-src` 同步累加 |

**建议受信主机（技术方案会可微调，须写进 contracts）**：

- `player.bilibili.com`
- （若封面/静态资源需要）`i0.hdslb.com` / `i1.hdslb.com` / `i2.hdslb.com` 等 **img-src** 子集——以实际嵌入所需最小集为准，禁止盲目 `*.hdslb.com`

**平台枚举**：`youtube` | `vimeo` | `bilibili` | `self` | `embed`（与规格 Q3 一致）。`self` 仅消费已配置可播 URL + `poster`；不做转码流水线。

**测试**：扩 `VideoEmbedResolverTest`、`ThemeVideoEmbedCspContractTest`；轮播与单播共享 Resolver，禁第二套解析。

## 3. ParamSchema `video_carousel_items`

**新建**：`app/code/Weline/Theme/Ui/ParamSchema/video_carousel_items.php`

```text
base_type = array
sortable  = true
max_items = 合理上限（建议 12，计划可调）
item_schema:
  video_type     select   (youtube|vimeo|bilibili|self|embed)
  video_url      url      i18n=false
  embed_code     textarea i18n=false
  poster         media_image i18n=false
  author         string   i18n=true（源串简中）
  description    textarea i18n=true（或字段名 summary，不得砍能力）
  product_ids    product_picker i18n=false
  title?         string   i18n=true（可选）
```

部件级可选：区标题、自动播放/静音——对齐 `video-player` 体验，非争论项。

登记：`widget.php` 路径项 + 必要时 params 覆写 `type=video_carousel_items`（仿 hero-slider）。刷新：`php bin/w widget:refresh`（施工波执行，本草案不跑生产变更）。

## 5. Catalog 按 ID

**新建公共方法**（建议签名，查询席可微调名但须冻结契约）：

```text
StorefrontProductWidgetCatalog::cardsByIds(list<int> $productIds, int $limit = 24): list<card>
```

- 内部：`publishedOffersForProductIds($productIds, …)` → 既有 map + review 聚合。  
- **排序**：按入参 ID 顺序输出（缺失 ID 跳过，不补推荐池）。  
- **过滤**：显式选品 **不**再套 HF-* 强制过滤（与推荐池 `cards()` 策略分离）。  
- Theme 部件经 ObjectManager / 既有注入取 Catalog Service；**禁止**模板直调 Repository。

读品时机（与查询席对齐，架构默认）：

- **默认 SSR**：服务端按项 `product_ids` 取卡，写入各 dialog body（或 data 岛 + 同页 DOM）。  
- 若后续要异步：仅 BinQuery / 既有 QueryProvider；**禁止**原生 `fetch`。
