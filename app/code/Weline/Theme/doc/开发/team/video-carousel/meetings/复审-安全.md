## 3. 证据清单

### 3.1 iframe / embed sanitize（通过）

`default.phtml` `$sanitizeEmbedCode`：

- 仅允许 `iframe` / `video` / `source` / `embed`；`script` / `style` / `object` 整节点移除且不 unwrap 子节点。
- 剥离 `on*`、`style`、`srcdoc` 及非白名单属性。
- `src` / `poster` 经 `VideoEmbedResolver::safeHttpUrl`；**iframe** 再校验 `trustedEmbedHosts()`，无 src 则删节点。
- 输出 iframe 强制 `sandbox="allow-scripts allow-same-origin allow-presentation"` + `referrerpolicy=strict-origin-when-cross-origin`。
- YouTube / Vimeo / Bilibili 结构化分支：`video_id` / `bilibili_src` 经 `$esc()` 写入固定托管路径，不回放原始 HTML。

### 3.2 trusted hosts + CSP（通过）

`VideoEmbedResolver::trustedEmbedHosts()`：

- `youtube.com` / `www.youtube.com` / `youtube-nocookie.com` / `www.youtube-nocookie.com` / `player.vimeo.com` / `player.bilibili.com`

`ThemeVideoEmbedCsp::contribution()`：

- `frame-src`：`https://www.youtube.com`、`https://www.youtube-nocookie.com`、`https://player.vimeo.com`、`https://player.bilibili.com`
- `img-src` / `connect-src` 与平台资源域一致

`safeHttpUrl` 拒绝 `javascript:` / `data:text/html` / `vbscript:`、协议相对 `//`、非 http(s) scheme。  
`isTrustedEmbedSrc` / UT 覆盖 evil.example → false（`VideoEmbedResolverTest`）。

### 3.3 XSS 文本面（通过）

区标题、副标题、项 title/author/description、CTA、dialog 标题/关闭、`data-dialog-target`、`dialog id` 等用户可见字符串均经 `htmlspecialchars(..., ENT_QUOTES, 'UTF-8')`。  
`poster` 走 `LegacyMediaUrl::sanitize`（禁控制字符、非 http(s)、userinfo）。  
`product_ids` 解析强制 `(int)` 且 `> 0`，防非数字注入进查询键。

### 3.4 禁原生危险脚本 / 业务 IO（通过）

`video-carousel.js`：

- 无 `fetch` / `XMLHttpRequest` / `eval` / `innerHTML` 写业务。
- 关联商品依赖模板 SSR 进 `<dialog>`；注释与契约一致。
- 交互仅 class/`aria`/`inert` 切换 + `Weline.UI.dialog.open`（降级 `HTMLDialogElement.showModal`）。

模板内无内联事件处理器、无原生 `alert`/`confirm`。

### 3.5 dialog 安全（通过）

- 壳：`<dialog class="w-dialog" data-w-component="dialog" …>`，`id=theme-video-carousel-products-{uid}-{index}`；`$uid` 已 `preg_replace` 限制字符集。
- CTA：`data-dialog-target="#…"` 服务端拼装并 `$esc`；JS `root.querySelector(selector)` 优先根内查找。
- 关闭：`data-w-action="dialog.close"` / `data-w-close`；空 `product_ids` 不渲染 CTA/dialog（诚实空态，无 alert）。
- 卡内容：`<w:product:card>` 既有 Taglib，非把商品字段当 HTML 拼接。

### 3.6 ArrayType `product_picker`（通过 · 编辑器面）

- `case 'product_picker'` → `ProductPickerType::getHtml`；异常/缺类降级文本框，`value`/`data-field` 均 `htmlspecialchars`。
- sync hidden 去 `name`、打 `data-field`，值协议为逗号分隔 product id；店面再 `(int)` 收敛。
- 无在数组项路径引入裸 `script` 或未转义属性拼装。

## 4. 残余（非否决 · 不 escalate）

| ID | 说明 | 风险 | 建议归属 |
|---|---|---|---|
| SEC-VC-R1 | sanitize 对 **`embed`** 的 `src` 仅 `safeHttpUrl`，**未**套 `trustedEmbedHosts`（iframe 已套）。恶意运营配置可塞非白名单 http(s) embed。 | 低（需后台写配置；CSP `frame-src` 对 iframe 仍挡；embed 历史插件面） | 后续纵深：embed 同 iframe 主机白名单，或直接禁 `embed` |
| SEC-VC-R2 | CSP `frame-src` 未列裸 `https://youtube.com`（无 `www`），与 trusted 列表略不等。 | 极低（结构化分支写 `www.youtube.com`） | 可选对齐 CSP |
| SEC-VC-R3 | `querySelector(data-dialog-target)` 依赖属性可信；当前属性服务端生成且转义，**无**访客可控面。 | 信息 | 保持勿把未净化用户输入写入该属性 |

以上均非致命漏洞，**不触发生产码热修、不 escalate**。
