## 品牌语气（汉服古风商城）

- **人格**：店员把规矩讲清楚——温和、具体、可执行；不是法庭诉状。  
- **可逛可买**：政策页首屏先回答「和我有什么关系」，再列细则。  
- **禁止**：恐吓式「不同意请离开」、空洞「充分理解并同意全部内容」、顶栏绝对营销。  
- **章节标题**：优先「我们收集哪些信息」「如何退换」；可保留编号，但弱化「一、二、三、」公文排版感（可用「1 / 收集哪些信息」或白话小标题）。

## 「过硬」模式清单（抽样自 `layouts/policy/*.phtml`）

| 模式 | 示例硬句 | 软化方向 |
|------|----------|----------|
| A. 审阅强制令 | 「请您仔细阅读」「请仔细阅读，以了解…」 | 「下面用白话说明我们怎么处理订单与个人信息」 |
| B. 协议构成腔 | 「本政策/条款**构成**您与本网站之间的协议/重要说明」 | 「这份说明和购物、账户规则一起适用；有疑问可找客服」 |
| C. 推定同意 | 「使用本网站即表示您已充分理解并同意接受本条款的全部内容」 | 保留必要同意场景（Cookie/结账勾选）；政策页勿用浏览即全盘推定 |
| D. 公文目录 | 通篇「一、二、三、」+「1.1/2.2」密集编号 | 白话小标题为主；编号可留作锚点但不主导阅读节奏 |
| E. 禁令堆叠 | 「不得…不得…不得…」「由您自行承担」连发 | 先说「请这样做」，再短句说明风险与例外 |
| F. 绝对保证/免责对撞 | 「绝对连续性」「同等法律效力」 | 责任限制可保留事实，改「我们会尽量…但不能保证永不中断」 |
| G. 对抗式护商 | 「亦不得仅以『感觉偏慢』主张违约」「不单独构成丢件认定」 | 保留事实边界，改「延误常见原因…我们会帮查，但不按固定日自动退款」 |
| H. 法律向页脚 | 「本页为法律向配送政策」 | 「本页是配送规则说明；操作步骤见配送指南」 |

**非过硬、必须保留的合规句型（可软写，不可删）：**

- 隐私 4.2：境内为主 + PayPal/Stripe 等境外必要共享告知  
- Cookie：「非必要统计/营销类 Cookie 将在获得同意后再启用」  
- 退换/退款：质量问题为主 + 个人原因通常不支持 + 强制法例外底线 + 回程费用规则  
- 配送：时效为参考、非保证送达日；关税默认收件人承担（未明示卖方承担时）

## 逐页改写 brief

### 1) `/policy/privacy` · privacy.phtml

| | 内容 |
|--|------|
| **保留要点** | 收集类别；使用目的；共享情形；**境内为主+境外支付/物流告知**；权利清单；未成年人；Cookie 交叉引用；更新与联系 |
| **改写/删除硬句** | 「请仔细阅读…」→ 软开场；「本政策构成您与本网站之间…」→ 店员说明体；「服务协议」可改为「为完成订单与服务」 |
| **推荐软句样例（中文）** | 「我们会认真保护您的个人信息。下面说明：我们可能收集什么、用来做什么、何时会与支付/物流伙伴共享，以及您如何查询或更正。」 / 「信息主要在中国境内处理。为完成付款和跨境配送，必要时会把订单所需信息交给 PayPal、Stripe 等伙伴，并按法律要求告知或征得同意。」 |
| **禁止项** | 删掉境外支付告知；写成「绝不跨境」；「我们保证永不泄露」等绝对宣称 |

### 2) `/policy/term-condition`（及 terms 路由）· term-condition.phtml

| | 内容 |
|--|------|
| **保留要点** | 服务说明、账户保管、禁止违法用途、交易与知识产权、联系方式 |
| **改写/删除硬句** | 「请您仔细阅读…使用即表示充分理解并同意全部内容」→ 改为欢迎+「请重点看账户安全与购物规则」；弱化「构成协议」起句 |
| **推荐软句样例** | 「欢迎逛店、下单。使用本站前，请花一两分钟看看账户安全与购物规则；有不清楚的地方，随时问客服。」 |
| **禁止项** | 浏览即推定全盘同意（Cookie/营销同意须独立）；恐吓式拒客句作首屏主文案 |

### 3) `/policy/refund` · refund.phtml

| | 内容 |
|--|------|
| **保留要点** | **商家友好退换口径全文精神**；与退换政策关系；质量/错发/运输损坏可退；个人原因通常不支持；强制法例外；流程与时效；回程运费规则 |
| **改写/删除硬句** | 「不单独构成自动退款事由」等对抗句 → 说明原因+帮查；密编号可白话化 |
| **推荐软句样例** | 「我们从中国发往海外，跨境回程成本高，所以店内售后以质量问题、错发漏发、运输损坏为主。单纯不喜欢或选错色码，通常不好办理退换。」 / 「若您所在地法律要求冷静期或无理由退货，我们会在强制范围内办理；非质量原因的回程运费、税费一般由买家承担。」 |
| **禁止项** | 改回「七日/十四日无理由」作默认卖点；删强制法例外句；与 FAQ/顶栏口径打架 |

### 4) `/policy/cookies` · cookie.phtml

| | 内容 |

### 5) `/policy/shipping` · shipping.phtml

## 成功标准（ops_acceptance · 运营如何验收）

施工 closed 后，本席亲自禁缓存 Browser（或等价）抽检，**全部满足才 pass**：

1. **语气**：七页政策首屏/导语不再以「请您仔细阅读 / 构成协议 / 充分理解并同意」开场；读感像店员说明，不像律师函。  
2. **合规未回退**：隐私境外告知、Cookie 同意句、退换「质量为主+强制法例外」、配送「时效非保证」均仍在且语义完整。  
3. **商家友好口径**：任何页/FAQ/顶栏**未**把「无理由退货」写成默认店内福利。  
4. **禁止项**：无「售后无忧」「保证 X 日必达」「绝不泄露」等绝对宣称。  
5. **多语**：默认站至少抽检 `en_US` + 1 个非中英语种，政策关键句为目标语（非中文 source 残留）。  
6. **古风商城感**：政策页仍可逛可读，不破坏现有布局壳；仅文案气质达标即可（本波不验收视觉改版）。

`ops_acceptance=pending` 直至上述签收；缺签收不得汇审宣称完成。
