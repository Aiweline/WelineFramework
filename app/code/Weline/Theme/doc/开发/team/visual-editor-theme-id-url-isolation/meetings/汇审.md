# 汇审补记：迁至 url_generate_params（2026-09-20）

## 用户纠偏

1. 不能挂 `url_generate_rewrite`：干扰 Seo；且不走重写的 URL 带不上参。
2. **最好办法：在最终输出 URL 那一刻追加想要的东西。**

## 决议落地

`Url::extractedUrl` 末尾：

1. `seo=on` → `url_generate_rewrite`（仅 Seo path）
2. **始终** → `url_generate_params`（Theme 只追加 query）

## 产品 /product/{id}

禁用 Theme rewrite 观察者后首页仍为 `/product/{id}`：与本钩子无关（Product 无 slug 直出 ID；rewrite 表无 product 规则）。另案处理。

## 汇审

### 做了什么（已纠偏）

1. Framework `Url::extractedUrl`：**最终输出前**始终 `url_generate_params`；`url_generate_rewrite` 恢复仅 seo=on。
2. Theme 只挂 `UrlGenerateParamsCarryEditorThemeId`（追加 query，不改 path）。
3. 已从 rewrite 卸载 Theme 观察者。

### 反攻记录

| # | 问题 | 处置 |
|---|------|------|
| 1 | 初版 `isLink()` 跳过同站绝对 URL | 改为仅跳外站 host |
| 2 | Token 只查 query | 改 `getTokenFromRequest()` |
| 3 | `event.xml` 未进注册表 | `event:rebuild` + `event:cache:flush`；`setup:upgrade` 曾被锁 |
| 4 | Worker 旧进程 | `server:reload` 后 SSR 生效 |
| 5 | 单测 mock final 类 | 改反射注入 |

### 验收证据

- UT：`UrlFrontendBatchTest` 3 PASS；`UrlGenerateRewriteCarryEditorThemeIdTest` 7 PASS。
- SSR curl（画布 query）：`/products`、`/category/women` 含 `theme_id=1&editor_mode=1&shell=theme-editor`；正式态 `with_theme=0`。
- Browser WB：画布 URL 打开；HTML `theme_id=` 约 257 处；部分重复 `/products` 仍无参（硬编码/其它生成路径）。

### 残留（不挡主交付，记问题单）

1. 语言切换器 href 自建 path，未走注入。
2. mini-cart `/cart` 硬编码。
3. 个别重复导航链无参。

### 运维注意

改 `event.xml` 后需 `php bin/w event:rebuild`（或 upgrade）+ `php bin/w server:reload`，否则 Worker 不吃新观察者。
