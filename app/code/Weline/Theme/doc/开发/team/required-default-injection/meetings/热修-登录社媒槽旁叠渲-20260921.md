# 热修：登录社媒槽旁叠渲

- 日期：2026-09-21
- **状态：保证层方案已废**；权威见 [同身份 XOR](./技术方案会-同身份XOR-20260921.md)

## 现象

登录「快捷登录」下 Google/Facebook 与政策链接各两套。

## 根因

`login.phtml` sibling `fetch` + 空槽 required injection 同身份双路径。

## 修复（现行）

| 层 | 手段 |
|----|------|
| 结构 | 登录页只留空槽；`account-social-login` `placement=injection` |
| 静态门禁 | `frontend:check-required-injection-sibling-fetch` |
| **禁止** | `pageHasWidgetPresent` / `countWidgetPresent` / `assertSlotHasAtMostOne` 运行时「只留一份」 |
