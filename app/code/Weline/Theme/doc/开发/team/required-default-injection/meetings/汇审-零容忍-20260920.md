# 汇审：有槽必注零容忍（2.2.496）

- 日期：2026-09-20
- 触发：用户「必须杜绝…人工没有卸载时注入失败」「这个问题不能容忍」
- 席位：项目经理 / 架构师 / 后端 / 测试

## 决议

| 项 | 结论 |
|----|------|
| 静默空槽 | **禁止**。有 slot 边界且未 `user_deleted@{versionId}` 时，渲失败必须抛 `required_default_injection_*` |
| 假阳性 | presence 只认 `data-widget-code` / `data-testid`；空 module seed 不得压制 required |
| 嵌套同 id | 每一区域缺标记都补；二次扫用 `anySlotRegionMissingWidget` |
| 实体缺失 | 对壳 HTML overlay（禁止 `append('')`）；soft-path 仍跑 `fillRequiredDefaultsOnShell`，成功则交付 |

## 证据

- UT：`RequiredDefaultInjectionContractTest` + GhostSlot + SidecarHydration + SlotFillerContract → **18 PASS**
- 命令：`php vendor/bin/phpunit --no-configuration --bootstrap app/bootstrap.php app/code/Weline/Theme/test/Unit/LayoutEntity/RequiredDefaultInjection*.php …`

## 残余

- 模块整模块禁用导致 definition 缺失 → **硬失败**（页面报错），不再静默空槽；属运维/依赖问题，不属「假注入成功」。
- bake/snapshot 审计对齐仍为双保险，非店面唯一保证。
