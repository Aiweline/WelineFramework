# 用户纠偏：同模块 XOR + 跨模块只走 JSON（非硬强制必注）

- 日期：2026-09-21
- 席位：用户口头纠偏（主 Agent 落盘；晚间再澄清「同模块 / 跨模块」）
- 架构结论：result=closed → `REQ-THEME-0036` / MCP `theme_layout_widget_owner` / Overlay soft-skip

## 正确语义（务必按此理解）

| 规则 | 含义 |
|------|------|
| **同模块 XOR** | 同模块下：布局已用 `<w:widget>` / `fetch(.../widgets/...)` 直接引用该部件 → **禁止**再在 JSON `default_injections` 里写该部件。二选一：要么布局内嵌（删 JSON），要么空槽 + JSON。 |
| **跨模块禁布局互调** | 不同模块之间：**禁止**在布局/partial 里互相调用对方部件。外国部件**只能**通过拥有模块的 JSON `default_injections` + 目标空槽进入。 |
| **未填软跳过** | Overlay 尽力注入；未出现 **不得** `required_default_injection_unfilled` 500 |

## 禁止误读

- ❌ 「槽里已经有任意部件就不能再 JSON」（跨模块 JSON 进同槽合法，只要不是同身份双路径）
- ❌ 「声明了 required 就必须店面硬必入」
- ❌ 「Theme 可以在布局里 fetch 别的模块部件」
- ✅ 「相同模块相同部件不能布局 + JSON 各来一次」
- ✅ 「跨模块进槽只许 JSON，不许布局互调」
