# 技术方案会：同身份 XOR（布局 vs 注入）

- 日期：2026-09-21（第三轮）
- 席位：架构师
- 架构结论：result=closed

## 决议

布局内嵌 与 `default_injections` 是**同一身份的二选一**，不是运行时「只留一份」：

| 选择 | 布局/宿主 | widget.php |
|------|-----------|------------|
| **injection（推荐）** | 只留空 `<w:slot>` | `placement=injection` + required `default_injections` |
| **layout** | 已 `fetch` / `<w:widget>` | `placement=layout` + **清空** `default_injections` |

## 禁止

- 页级 presence / 槽内 count / HTML tip 等运行时去重补丁来「只显示一个」
- 布局已内嵌仍保留 default_injections（或空槽仍再 fetch）

## 门禁

`frontend:check-required-injection-sibling-fetch`：双路径致命；修复方向按上表二选一。
