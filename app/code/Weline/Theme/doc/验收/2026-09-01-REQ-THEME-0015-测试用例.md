## 详细用例

### TC-U-01 Publish placeable（unit）

- **前置**：源码含 `Controller/Backend/Ai.php`
- **步骤**：契约断言 `postPublish` 含 `toWidgetArray()` 与 `'widget' => $widget`
- **期望**：固定返回可放置载荷（`module/type/code/default_config/is_ai_generated`）
- **证据**：`ThemeAiPublishPlaceableContractTest`

### TC-U-04 悬停不再绑 virtual layout（unit）

- **步骤**：截取 `handleWidgetAiAction` 函数体
- **期望**：无 `apiVirtualThemeBlockAction`；含 `apiThemeAiPublish` + `placeWidgetFromProvider`
- **证据**：`ThemeEditorUiCapabilityContractTest`

### TC-P-01 编辑器探活（probe）

- **URL**：`https://p05113ef3.weline.test:9555/{backend_prefix}/theme/backend/theme-editor`
- **期望**：`200`（已登录）或 `302`（未登录）；滚动重启中允许短暂 `503`，稳定后须恢复
- **注意**：探活 URL = 交付字面 URL

### TC-B-01 虚拟部件 AI 编辑（browser）P0

- **前置**：后台已登录；页面上有 `source_type=virtual` 的 theme_component 节点；记录当前 `layout_option`
- **步骤**：
  1. 悬停 → AI 编辑 → 填指令 + 选 agent → 确认
  2. 等待 SSE 完成与 toast
  3. 检查预览槽位与网络面板
- **期望**：
  - 请求链：`prepare-refine` → `refine-stream` → `publish` → save/remove-widget（replace）
  - **无** `virtual-theme/block-action`
  - `layout_option` 不变
  - scoped 该槽变为新/更新后的 `theme_component`
  - DB：`theme_component.is_ai_generated=1`（或同 code 新版本 published）

### TC-B-02 重建（browser）P0

- **步骤**：悬停 → AI 重建 → 确认
- **期望**：走 `component-stream`（非 refine）；新 `component_code` 或新版本；replace 成功；`layout_option` 不变

### TC-B-04 非虚拟源（browser）P0

- **前置**：选中文件/模块部件（非 virtual）
- **期望**：`component-stream` 带 `reference_component_code`；publish 后 replace；原模块 widget 被同槽替换为虚拟部件

### TC-B-05 失败不落库（browser）P0

- **步骤**：故意无效指令或断开 SSE / mock agent 失败
- **期望**：错误 toast；无成功 publish；页面节点与 `layout_option` 不变

### TC-B-06 Catalog 复用（browser）P0

- **前置**：TC-B-01/02 成功后
- **步骤**：部件库搜索/筛选找到 AI 部件 → 拖到另一合法槽
- **期望**：可放置；两处均可渲染

### TC-B-07 / TC-B-08 类型筛选（browser）

- **步骤**：
  1. 只选「通用」「基础」→ 列表为 widgets API，`library_tabs` 生效
  2. 再点「应用部件」→ 通用/基础 chip 清除，进入 applications + `install_mode`
  3. 打开「AI生成」→ 仅 AI 项；卡片可见 AI 徽章
- **期望**：互斥成立；无双源合并分页错乱；`has_more` 语义正常

### TC-D-01 / TC-D-02（doc）

- **检查**：`doc/需求.md` REQ-THEME-0015、`doc/开发日志.md`、`weline-ui-2-capability-matrix.md` TE-CAP-021
- **期望**：与实现一致；边界（自动 publish、i18n 不迁移）成文
