# Theme PHTML 固化改造验收

验收日期：2026-10-04。范围：当前本地配置系统、主题编辑器、正式页面及 Token 预览。动态商品详情和 Blog 按站点、主题、布局及语言选择代表页面，不重复穷举实体 URL。

生成链路为原模板、开发默认注入和数据库编辑意图生成派生 PHTML；访问选择对应 PHTML 后统一通过正常 Template、Taglib 和语言 com_* 渲染。调用和实例子槽表达顺序及父子关系，基础参数与语言差异显式冻结。正常访问不重新播种位置；业务查询、数据库历史和语言缓存保留。
