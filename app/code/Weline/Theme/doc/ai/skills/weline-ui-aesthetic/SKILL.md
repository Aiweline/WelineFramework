# UI 审美 · 只消费主题变量

审美发生在**已有主题变量**上：选哪个表面、哪级字、哪档间距、哪一个强调色。不另起一套设计系统。

写任何可视化 `.phtml` / CSS 之前：读本技能 + 主题技能 + 上表变量文档。色、距、字、圆角、阴影只写 `var(--…)`。

## 动手前（审美计划，只点名已有变量）

先看当前 `area`（`frontend` 或 `backend`）的变量盘，再写一行计划。计划里**禁止**出现新的 `#hex` / `rgb()` / `px` 色距。

1. **地面与抬起**：页面底用哪一个背景变量，卡片/面板用哪一个更浅或更实的表面变量。两者必须能分开，禁止整页同一块灰。
2. **墨色**：主文、次文、禁用各用哪一个文字变量。次文要比主文弱一档，不要全文一个颜色。
3. **唯一强调**：整屏只允许一个强调变量（已有 accent / primary）落在主操作上。其余按钮走次级/幽灵表面，不要处处强调色。
4. **节奏**：区块之间用较大的间距变量，组内用较小的一档。禁止把所有缝都写成同一档。
5. **字阶**：标题、正文、辅助说明各用已有字号变量，逐级下降。禁止再引入新字体家族。
6. **圆角与影**：控件、卡片、大面按店面消费约定取已有半径变量；阴影只用已有 shadow 变量。不要为了「精致」再写一套 `rgba` 阴影。

后台页先套 Weline UI 2.0 壳（`w-backend-page`、`w-card`、`w-field`、`w-input`、`w-button`、`w-table`），再在壳内做上面的取舍。禁止裸 `h1` + 裸表单堆。

## 审美动作（允许做的）

这些才是审美，而且全部用变量完成：

- **一个焦点**：主标题或主按钮是这一屏唯一被强调的东西，周围收静。
- **对齐**：同一组控件左缘或基线对齐；工具条横排、限制宽度，不要搜索框竖着撑满卡片。
- **疏密**：相关的靠拢（小间距变量），无关的分开（大间距变量）。
- **层次**：靠字号变量和字重变量分清标题 / 正文 / 元信息，不靠再涂一种新颜色。
- **分组**：用表面变量和边框变量把一组字段收进一张卡片；不要一屏十张一模一样的卡。
- **文案**：按钮写出动作结果；空态说明下一步。源串用简体中文。

## 禁止（看起来像没审美，或审美跑偏）

- 自造 4～6 个十六进制色、奶油底、陶土色、荧光绿、近黑底单强调色。
- 自造 `px` / `rem` 间距、圆角、阴影阶梯，或 `var(--token, 16px)` 这种带字面量的退路。
- 每个区块都加全大写眉题、`01 / 02 / 03`、中间点拼接、箭头尾巴按钮。
- 所有圆角、所有阴影、所有卡片同一规格，没有主次。
- 把 inverse 下的浅色 raised 纸面钉改成 `var(--color-text-primary)`。纸面钉保留，见 `theme_inverse_raised_paper_ink_pin`。
- `@media` 断点里写 `var(--breakpoint-*)`。断点保持字面像素。
- 默认主题层用 `!important` 抢视觉。

## 写完自检

1. 样式里普通颜色、间距、字号、圆角、阴影都能在主题盘找到叶子。
2. 这一屏能指出：地面、抬起、主墨、次墨、唯一强调、大节奏、小节奏。指不出就是还没审美。
3. 截图后用眼睛看：有没有挤成一字竖排、裁切、大片空白却主操作不突出。有就用变量档位改，不要加新色。
