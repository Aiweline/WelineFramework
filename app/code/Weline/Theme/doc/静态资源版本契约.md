# 静态资源版本契约（主题开发必读）

> 运行机制见 `app/code/Weline/Framework/doc/静态资源版本与FPC代次方案.md`。
> 本文只约束**主题开发**怎么写静态资源 URL。

## 1. 三条硬规则

1. **模板禁止裸写 `/static/...`**
   - 模块/主题资产统一走 `PublicStaticUrl::fromDevWebPath()`、`PublicStaticUrl::fromModuleSource()` 或 `<theme:css>` / `<theme:js>` 标签；
   - 已有绝对路径（如设计主题里的手写路径）必须包一层
     `\Weline\Framework\Deploy\StaticBuildId::versionedPath($url)`。
2. **主题 CSS 只用相对 `url()`**
   - 例：`url('../images/ink/paper.webp')`；
   - 禁止 `url('/static/...')`：CSS 通过主题标签/包发布时会带 `/static/{buildId}/` 前缀，相对路径自动跟随；
     绝对路径会绕过构建代次，被 immutable 缓存钉死。
3. **JS 里的静态 URL 必须带版本**
   - 相对模块路径用 `new URL('./x.svg' + new URL(import.meta.url).search, import.meta.url)` 继承脚本版本；
   - 手写 `/static/...` 时走 `PublicStaticUrl` 或 `StaticBuildId::versionedPath()`。

## 2. 运行时表现

| URL 形态 | 缓存 |
|---|---|
| `/static/{12位构建号}/...` | 一年 immutable（可长期缓存） |
| `/static/Weline/...`（legacy） | `max-age=0, must-revalidate` |
| 32~64 位 hex 文件名（内容寻址） | 一年 immutable，不需要构建前缀 |

发布时 `deploy:upgrade` 生成新构建号；旧代目录保留至 GC，旧页面继续自洽。

## 3. 自检门禁

`app/code/Weline/Theme/test/Unit/View/ThemeStaticVersionContractTest.php` 会扫描：

- `view/theme/{frontend,backend}` 的 `.phtml/.php`：禁止字符串形式的 `/static/...`；
- `view/statics/**/*.css`：禁止 `url(/static/...)`；
- `weline-ui.js`：图标 sprite 必须继承 `import.meta.url` 的版本查询。

新增主题或改默认主题后跑：

```bash
vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php --no-coverage \
  app/code/Weline/Theme/test/Unit/View/ThemeStaticVersionContractTest.php
```

## 4. 设计主题（app/design）

`app/design/**` 不在本仓版本控制内，但同样适用本契约：

- 模板里的手写 `/static/Weline/<theme>/...` 必须经 `StaticBuildId::versionedPath()`；
- CSS 内的图片用相对路径；
- 图标/脚本等运行时 URL 继承模块脚本的版本查询。
