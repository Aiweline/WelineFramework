# Weline_Inquiry 开发日志

## Hotfix — 2026-08-31：供应商申请国家字段改用全球目录

- 当前状态：`implemented`
- 变更：`country` 字段默认 `validation.catalog=global`；`theme:address` / region API 支持 `catalog=global`（Symfony Intl 全球国家，不限已安装国家）。
- 版本：`1.0.4` → `1.0.5`。

## Hotfix — 2026-08-31：供应商申请国家字段改用 theme:address

- 当前状态：`implemented`
- 变更：`FormSchemaService` 增加字段类型 `country`；`InquiryRenderer` 挂载官方 `data-w-address` + `address-loader.js`；`InquiryFormBootstrap` 将 `supplier-application.country` 升级为 `country` 并重新发布。
- 版本：`1.0.3` → `1.0.4`。

## Hotfix — 2026-08-31：询盘后台菜单路由前缀纠错

- 当前状态：`implemented`
- 问题：菜单/模板写成 `weline_inquiry/backend/...`，实际路由前缀为 `inquiry`，导致后台入口 404。
- 变更：`menu.xml` 与 Backend 列表/编辑模板统一为 `inquiry/backend/inquiry/*`。
- 版本：`1.0.2` → `1.0.3`。

## Hotfix — 2026-08-31：供应商申请表单默认亚马逊风格

- 当前状态：`implemented`
- 变更：`InquiryRenderer` 支持 `skin=amazon`；`inquiry/suppliers` 默认加载 `supplier-application-amazon.css`（对齐登录页 Amazon token：卡片边框、黄 CTA、输入框 focus）。
- 范围：仅供应商申请页；全局询盘默认灰框不变。
- 版本：`1.0.1` → `1.0.2`。

## Hotfix — 2026-08-31：供应商申请页 Taglib 原文泄漏

- 当前状态：`implemented`
- 问题：`suppliers.phtml` 在 `<w:inquiry code="<?= ... ?>">` 内嵌短标签，编译后 PHP 被当成 HTML 转义输出。
- 变更：与 Widget 一致，改为 `InquiryRendererInterface::render()` 直出 inline 表单。
- 版本：保持 `1.0.1`。

## Hotfix — 2026-08-31：供应商申请表单与前台页

- 变更：种子并发布 `supplier-application`；前台 `inquiry/suppliers` 嵌入询盘表单；Install/Upgrade 共用 `InquiryFormBootstrap`。
- 版本：`1.0.0` → `1.0.1`。
