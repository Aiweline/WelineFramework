# Weline_Inquiry 需求

## 目标

让后台可以可视化配置、发布和管理任意询盘/报价表单，并让同一份已发布表单通过 Taglib 或 Widget 嵌入任何位置。

## 已确认能力

1. 每份表单有稳定唯一 `code`；首次发布后 code 不可改。
2. 表单支持字段增删、复制、排序和预览；字段由 schema 驱动，不硬编码到主题。
3. 文案支持多语言：表单标题、字段标签、placeholder、帮助文字、选项、按钮和反馈语；逐字段回退。
4. 发布产生不可变版本；提交同时保存 schema 和内容快照。
5. 可通过 `<w:inquiry>` 或 Inquiry Widget 嵌入；Widget 可以搜索并选择已发布表单。
6. Widget 支持 inline、modal、外部 trigger ID/selector，以及实例 CSS；可信 JS 受 ACL 与系统总开关双重限制。
7. 公共提交必须使用 CSRF、服务端校验、幂等键和基础反垃圾；附件通过受控票据引用。
8. 首个业务样例为 `motorcycle-dealer-quote` 中英双语报价表单；只有框架模块验收后才允许按逐文件确认表同步到摩托车项目。

## 明确不做

- 不依赖或改造 PageBuilder。
- 不实现价格计算、报价 PDF、CRM 或订单能力。
- 不把 `Weline_Product` 作为模块硬依赖。
