## 2026-09-23 — 网站树编辑表单 w:form 拆分导致 ParseError（1.8.50）

- 现象：`/websites/admin/website/index` 报 `syntax error, unexpected token "endif"`（栈落在 `com_tree-editor-panel`→`form`）。
- 根因：`form.phtml` 用 `if/else` 分别打开原生 `<form>` / `<w:form>`，再 `endif` 后共用正文；`w:form` Fiber `try{` 不可跨越 `endif`。
- 改：预解析 `$websiteFormAction`，单一连续 `<w:form>…</w:form>`；合约 UT 防回退。
- 验：`Template::fetch` panel/form OK；`WebsiteAdminTemplateContractTest` pass。
- 版本：`1.8.49` → `1.8.50`。

## 2026-09-22 — 项目 Host 支持 sub_path 多站（1.8.48）

- 根因：`p{hash}.test.weline.com` 被一律绑默认站，且 match 缓存 path 恒为 `/`，导致同 Host 下 WebsiteDomain `sub_path`（如 `/e2e-mso3wfcu-1`）无法命中。
- 改：`DetectWebsite::resolveMatchedSite` 在 reserved project Host 上先匹配非空 sub_path 域名，再回落默认站；match 缓存按真实 path；`findSiteByWebsiteDomain` 允许 project Host 的非空 sub_path。
- 本机数据：e2e 站 1/2 入口改为 `https://p05113ef3.test.weline.com/e2e-mso3wfcu-1` 与 `…/e2e-mso3wvvv-2`，sitemap 为 `{入口}/sitemap.xml`。
- 版本：`1.8.47` → `1.8.48`。
