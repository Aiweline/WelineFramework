## 2026-10-08 — 后台 Session Cookie 误用 Website ID 值切 jar（掉线）（1.8.82）

- **现象**：grocery 主题编辑器隔一会儿 `no_access_reason=not_logged_in`；`auth.log` 几乎全是 `theme/backend/theme-editor` + `cookie_present=false` + `cookie_name=WELINE_SESSID_w0`。
- **根因**：`CookieScopeResolve::websiteId()` 把 `WELINE_WEBSITE_ID_w0=544` 的**值**当成 jar 后缀（切到 `_w544`），并读取编辑器 `?website_id=544`；随后 `HeaderCollector` 把 `_w0` 当遗留别名 Expire → 登录 Cookie 被清。
- **架构**：jar 身份只认 Cookie **名**后缀；后台忽略 GET/POST `website_id`（编辑目标 ≠ 会话 jar）。Framework `HeaderCollector` 跨 `_wN` 写 Cookie 保持 exact，不 remap 清兄弟站 jar。owning=`Weline_Websites` + `Weline_Framework`；not_to_do=禁止再用 Website ID cookie 值驱动 Session 名后缀。
- **契约**：`CookieScopeResolveTest`（忽略 editor query / cookie 值≠后缀）；`HeaderCollectorTest`（跨站 Expire 不误杀 active jar）。
- 版本：`1.8.81` → `1.8.82`（Framework `2.5.271`）。
