- 当前状态：`implemented`
- 问题：后台跳过 CookieScope 使用 `WELINE_SESSID_{port}`；前台发 `_w{id}` 时 Expire 无后缀别名，把后台登录 Cookie 清掉 → `auth.log` 大量 `cookie_present=false` 掉线。

## 2026-08-28 — 编辑网站 website_id=0 误进 offcanvas 错误页

## 2026-08-28 — 默认路径误用关联语言首项 en_US

- 当前状态：`implemented`
- 现象：默认网站 `default_language=zh_Hans_CN`，无语言前缀路径仍被 `Url::parser` 解成 `en_US`。
- 根因：`Url::parser` 在匹配网站前用 `State::getLang()` 预填 `WELINE_USER_LANG`；无 WebsiteData 时回落到 `preferredLanguageCodes()[0]`（关联表插入序常为 `en_US`），站点匹配后因非空未覆盖。
- 修复：站点匹配前不再预填；匹配后无路径语言时强制写入 `website.default_language`；`getWebsiteLanguageCodes()` 将默认语言排到首位。
- 验收：`UrlParserDefaultLanguageContractTest`；CLI `Url::parser` 断言 `language=zh_Hans_CN`；默认路径 HTML `data-lang=zh_Hans_CN`。

## 2026-08-28 — 编辑网站默认语言无法保存

- 当前状态：`implemented`
- 现象：高级选项里改「默认语言」保存后仍回到 `en_US`；默认货币空态文案也误显示「可多选」。
- 根因：同一表单先渲染 `domain:select multiple=true`，`AttributeCodeCompiler` 未清理 `Taglib__*`，后续默认语言/货币选择器未声明 `multiple` 却继承了 `true`；单选字段按多选提交时 PHP 只保留同名最后一项，常落回 `en_US`。
- 修复：Framework 编译器隔离标签属性；LanguageSelect/CurrencySelect 对省略的 `multiple` 强制 `false`；Website add/edit 归一化标量默认值并保证默认码进入关联列表。
- 验收：AttributeCodeCompiler / LanguageSelect / CurrencySelect / Website 表单契约测试；WLS 后台编辑网站保存后回读 `default_language`。

## 2026-08-18 — 后台请求不套用前台 Cookie 站点隔离

- 当前状态：`implemented_validated`
- 需求 ID：`REQ-WEBSITES-0002`
- 根因：登录页与后续后台页解析 CookieScope 的时机不同，Session Cookie 会在 `WELINE_SESSID_9555` 与 `WELINE_SESSID_9555_w0` 之间切换；后者还会过期前者，表现为刚登录即 `not_logged_in`。
- 实现：`CookieScopeResolve` 在 `backend`/`rest_backend` 或 `is_backend` 时不贡献 `name_suffix`/`expire_unscoped_aliases`。
- 验收：`CookieScopeResolveTest::testBackendAreaDoesNotQualifySessionCookieOrExpireUnscopedAliases` 通过。热重载后后台登录与 ACL 均只发 `WELINE_SESSID_9555`，不再 Expire 无后缀名。2026-08-18 内置 Browser：登录后 ACL 角色 / 媒体 / ACL 新增 / 仪表盘连点保持登录。

## 2026-08-17 — 默认网站货币跟随应用配置

- 当前状态：`implemented_validated`
- 需求 ID：`REQ-WEBSITES-0001`
- 根因：默认网站行与货币关联硬编码为 CNY，导致本地站点的 USD 配置在初始化后被回写。
- 实现：`DefaultWebsiteService::defaultCurrency()` 从 `Env::system('currency', 'CNY')` 读取并校验三位字母币种；默认行与必备关联统一使用该值。
- 数据处理：摩托车项目的默认站点已通过正式 Service/Model 接口归一为 USD 且只保留 USD；这是项目数据，不是核心服务的删除策略。
- 验收：聚焦契约测试通过；WLS 完整重启后回读为 `system=USD / website=USD / allowed=[USD]`；商品/搜索/详情/购物车/结账前置页浏览器验收通过。
