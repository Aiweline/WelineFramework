## `REQ-WEBSITES-0001` 默认网站货币跟随应用配置

- 来源与确认：2026-08-17 商城默认路由验收发现，`DefaultWebsiteService` 每次初始化都将站点写回 CNY；用户同意修复并同步核心。
- 业务逻辑：新建或修复 `website_id=0` 的默认站点时，`default_currency` 与必备货币关联均使用 `system.currency`；配置无效时安全回退 CNY。
- 范围：`DefaultWebsiteService` 默认数据与关联保证逻辑。
- 非目标：不删除管理员显式为网站配置的其他允许货币，不改 schema、汇率或价格换算。
- 验收标准：应用配置 USD 时，初始化和 WLS 重启后默认站点仍为 USD；不再自动补回 CNY 关联；配置为非三位字母时回退 CNY。

### `REQ-WEBSITES-0002` 后台 Session Cookie 跟随请求网站隔离

- 来源与确认：2026-08-18 曾为避免登录后 Cookie 名抖动改为后台不加 `_w{id}`；2026-08-30 日志取证证明前台 Expire 无后缀 `WELINE_SESSID_{port}` 会清掉后台 Cookie，用户要求后台识别 Cookie 跟随请求的网站 / 端口 / `website_id`。
- 业务逻辑：`backend` / `rest_backend` 与前台一样按当前请求 `website_id` 加 `_w{id}`（端口仍由 Session 名解析器处理）；后台 `mount_path` 固定为 `/`（管理路由不在店铺挂载路径下）；继续 Expire 无后缀别名以便迁到站点 Cookie。
- 范围：`CookieScopeResolve`；ACL `cookie_present` 诊断对齐 `SessionCookieNameResolver` 候选名。
- 非目标：不改前台挂载 Path 隔离语义；不引入独立的 backend-only Cookie 前缀。
- 验收标准：后台在 `website_id=0` 下发出 `WELINE_SESSID_{port}_w0`；同站前台请求不再把后台登录 Cookie 当成无后缀别名清掉；单测 `CookieScopeResolveTest`。

## `REQ-WEBSITES-0003` 向 SystemConfig 贡献权威 Scope 身份目录

- 来源与确认：2026-08-22 框架完整路由升级发现 Websites 与 SystemConfig 重复注册 `ScopeIdentityCatalogInterface`；用户要求缺少即修复。
- 业务逻辑：Websites 作为 Website/Store/Channel 身份所有者，通过 `system_config.scope_identity_catalog.Weline_Websites` 能力贡献权威目录，不再替换 SystemConfig 的公共接口 Provider。
- 范围：`etc/module.php` 的 Provider 声明与既有 `Integration/SystemConfig/ScopeIdentityCatalog`。
- 非目标：不把 Websites 设为 SystemConfig 的隐式必需实现，不放宽重复 Provider 门禁，不改变 Scope 数据或目录查询语义。
- 验收标准：编译后的 Provider Registry 同时包含 SystemConfig 唯一接口入口和 Websites 前缀贡献，完整路由升级不再报告重复实现。
