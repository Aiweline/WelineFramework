## `REQ-WEBSITES-0001` 默认网站货币跟随应用配置

- 来源与确认：2026-08-17 商城默认路由验收发现，`DefaultWebsiteService` 每次初始化都将站点写回 CNY；用户同意修复并同步核心。
- 业务逻辑：新建或修复 `website_id=0` 的默认站点时，`default_currency` 与必备货币关联均使用 `system.currency`；配置无效时安全回退 CNY。
- 范围：`DefaultWebsiteService` 默认数据与关联保证逻辑。
- 非目标：不删除管理员显式为网站配置的其他允许货币，不改 schema、汇率或价格换算。
- 验收标准：应用配置 USD 时，初始化和 WLS 重启后默认站点仍为 USD；不再自动补回 CNY 关联；配置为非三位字母时回退 CNY。

### `REQ-WEBSITES-0002` 后台请求不套用前台 Cookie 站点隔离

- 来源与确认：用户于 2026-08-18 报告后台刚登录就会间歇回到登录页。
- 业务逻辑：`backend` / `rest_backend` 是主机级管理域，CookieScope 不得加 `_w{id}` 后缀，也不得过期 `WELINE_SESSID[_port]`。前台挂载隔离保持不变。
- 范围：`CookieScopeResolve` 在后台区域直接返回，保持 Framework 事件字段中立。
- 非目标：不改前台多站点 Cookie Path 隔离，不改记住登录 Cookie。
- 验收标准：后台登录页与 ACL 角色页发出同一 Session Cookie 名；后者不得再 Set-Cookie 过期前者。
