# Weline_Blog 功能现状

| 能力 | 状态 | 入口 |
|------|------|------|
| BlogArticle 统一模型 | 已实现 | `Api/Data/BlogArticle.php` |
| CMS URI 显式豁免 | 已实现 | `Observer/ClaimBlogNamespaceUriBefore.php` |
| 内容解析 | 已实现 | `Service/BlogContentResolver.php` |
| slug 冲突 guard | 已实现 | `Service/BlogSlugConflictGuard.php` |
| 前台列表/详情 | 已实现（1.0.16 列表 locale 走 getLangLocal；1.0.14 getUrl） | Theme `blog_category` / `blog` 布局；Amazon 卡片与文章样式；`public_url` 仍为相对 `/blog/{slug}`，渲染层补 locale；路径 `en_us` 可映射到 Post.`en_US` |
| 文章关键词多语言 | 已实现（1.0.15） | `Post\LocalDescription` + `<local>`；展示优先 Local，回退 `BlogKeywordLocalizer` 脚本过滤 / `__()` |
| 万能评论（博客） | 已实现 | `blog-reviews` 默认注入 Theme `blog` 槽 + `BlogReviewTypeProvider`；Upgrade 发布到前台 |
| 分类页 | 已实现 | `/blog/category/{slug}` → `Controller/Frontend/Category.php` |
| SEO Profile | 已实现 | `extends/.../BlogSeoProfileProvider.php` |
| Sitemap | 已实现（1.0.13 按目标网站输出完整 loc；真实同步验收见 SEO 开发日志） | `extends/.../BlogSitemapUrlProvider.php` |
| Search Provider | 已实现（仅索引） | `BlogSearchProvider` 只读 `search_provider_document`；侧栏分类经 `SearchScopeOptionsProviderInterface`；命中卡片渲染；Cron 定时重建；禁止 SQL 回退 |
| 后台 CRUD | 已实现（S1 最小） | `Controller/Backend/Post.php` |
| 搜索分类 scope | 已实现 | `BlogSearchCategoryScopeService` → 侧栏 `type=blog` 子节点；`category_id` 过滤 |
| 分类 CatalogSpace | 已实现（S2） | `BlogCatalogSpaceProvider` + EAV `blog_category` 多语言 name；**二级树** `parent_id`（限深 2） |
| 前台分类筛选 | 已实现 | `category-filter.phtml` 可展开；父级页聚合子分类文章 |
| 中国民族服饰子分类 | 已实现 | `china-ethnic-dress` 为父，56×`ethnic-cn-*` 为子；种子 `seed-china-ethnic-categories.php` 会 remount |
| 页脚了解我们扩展 | 已实现 | `footer-blog-link` / `footer-news-link` 均默认注入 `footer-about-links`（新闻指向 `news` 分类） |
| 页头导航扩展 | 已实现 | `header-blog-link` 默认注入 `header-nav-extensions`（分类后方） |
| 汉服男装分类 | 已实现 | `hanfu-mens` + 男装入门/圆领袍清单图文 |
