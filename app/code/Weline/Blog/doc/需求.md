# Weline_Blog 需求

## 2026-09-09 — 作者深字段（E-E-A-T）（1.0.29）

文章可配置 `author_url` / `author_bio` / `author_job_title` / `author_same_as`；SEO 输出深 Person；仅姓名时 SEO 面板严苛 tip 提示浅作者。

## S1 验收标准

- [ ] `GET /blog` 200，列表 SEO 为 `blog_list` + ItemList；页面大纲 H1 唯一且不在 chrome `<header>` 内；列表区仅一个 H2，卡片标题非 heading；canonical 与当前语言 hreflang self 对齐；列表输出 `og:image`/`image_alt`/`twitter:card=summary_large_image`；H1 与 SEO title 叶语义对齐
- [ ] `GET /blog/{post-slug}` 200，BlogPosting JSON-LD，`canonical=/blog/{slug}`
- [ ] `GET /blog/category/{slug}` 200，Theme `blog_category` 布局 + 分类筛选 + 卡片网格；分类页 canonical 走 `getUrl` 本地化路径
- [ ] 博客分类支持二级树（`parent_id`，限深 2）；前台筛选可展开；父级列表聚合子分类文章
- [ ] `china-ethnic-dress` 下挂 `ethnic-cn-*` 各民族子分类（万能分类 `space=blog`）
- [ ] 博客详情使用 Theme `blog` 布局（亚马逊文章风格）
- [ ] CMS `path_group=blog` → `GET /blog/{slug}` 200，BlogPosting（非 WebPage）
- [ ] slug 冲突保存失败，i18n 错误提示
- [ ] `/blog/*` 时 CMS `ProcessCmsPageUriBefore` 不改写 path
- [ ] `GET /search?q=…&type=blog` 使用 Blog hit 模板
- [ ] sitemap 每个 `/blog/{slug}` 仅 1 条完整 loc，使用目标网站规范基址并保留端口/部署路径；前端 publicUrl 仍可为相对路径
- [ ] 发布/更新触发 `UrlChangeNotifier`
- [ ] PHPUnit 契约测试通过
- [ ] 文章关键词走 LocalModel（`Post\LocalDescription`）；英文详情页不混显未翻译中文标签
- [x] 页头 `header-nav-extensions`：Blog `header-blog-link` 默认注入，右侧大簇（与快捷导航同簇）可见「博客」入口

## 分类树读取性能（2026-09-08）

- 分类数量增加不得按分类×字段产生 SQL；统一 EAV 读接口按值表批量读取。
- 同请求同 website/locale 复用分类树，保存后可重新读取；名称语言回退、cleared、slug/path 和二级树结构保持。
- typed EAV 独立写失效规范未接入前，仅请求内复用其结果，不将博客事实版本冒充属性版本。
