# 博客文章可行性审查表

用于 **review** 模式。对每篇给出 `pass` / `fail` / `n/a`，并汇总结论。

## 结论档

| 档 | 含义 |
|----|------|
| **可发** | 无 fail；或仅有不影响可信度的 n/a |
| **需补** | 有 fail，但补来源/图/语种/链接后可发 |
| **不可发** | 无来源臆造、假实物图、重图（篇内同一张图出现两次，或跨篇复用同一张封面/正文图）、严重事实错误、主体不可核对，或通篇 AI 腔 / 不可见水印未清 |

## 检查项

### A. 选题与路由

- [ ] A1 内容适合 Blog 长文（非 CMS 落地页、非商品详情楼层）
- [ ] A2 slug 稳定、可公开；locale 行命名符合后缀规则
- [ ] A3 分类存在且与主题一致

### B. 查证与事实

- [ ] B1 存在可核验来源表或 References（≥2 条真 URL）
- [ ] B2 工艺/史实/非遗表述均可回溯到来源
- [ ] B3 无「绝对化虚假背书」（未证实却宣称官方唯一/包治等）

### C. 精写结构

- [ ] C1 结构跟题型走：谱系文要有定义、脉络、工艺与用途；试穿/礼俗/洗护用自己的步骤或限度，不必套谱系九步
- [ ] C2 收束跟题型走，禁止每篇都用「要点速览」
- [ ] C3 有 `editorial-sources`（或等价参考文献块）
- [ ] C4 篇幅达到精写下限（中文约 ≥1500 字去标签；或课题约定下限）
- [ ] C5 已声明本篇专业身份，口吻与该行当一致（非百科/客服/导师/口号腔）
- [ ] C6 无可见 AI 水印：无套话连接、无课件式「首先/其次/最后」、无等长「总—分—升华」、无三连排比；外语无对等套话
- [ ] C7 无不可见水印：正文无 U+200B / U+200C / U+200D / U+FEFF、无 BOM、无私用区、无无来源同形字
- [ ] C8 在推自家的货或做法时，写了弊端，以及谁合适、谁不合适；没有兜成「大家都合适」

### D. 配图与许可

- [ ] D1 封面存在且路径在 `media/blog/`（或项目约定媒体根）
- [ ] D2 文内 figure（若有）含藏品/来源/许可信息
- [ ] D3 无 AI 纹样冒充实物；若为编辑插画已明确标注
- [ ] D4 无重图：封面与正文、以及正文 figure 之间，没有同一文件 / 同一 URL（忽略 query）/ 同一 source_url。封面已展示的图不得再出现在正文。该站其它文章的封面和正文图也不得再被本篇占用。相关文章卡片除外

### E. 多语言

- [ ] E1 `zh_Hans_CN` 与 `en_US` 已发布
- [ ] E2 默认站其余 `language_codes` 均有独立正文行（或明确用户收窄范围）
- [ ] E3 抽检外语标题/导语为真译，非中文/英文粘贴残留

### F. 入口与缓存

- [ ] F1 站内导流（部件/Catalog/相关推荐）指向 `/blog/{slug}` 而非主题词搜索（若该文有入口职责）
- [ ] F2 改模板/Catalog 后已清主题运行时缓存并 reload（否则记 fail：线上仍旧链）

### G. 验收证据

- [ ] G1 本机 URL 探活 200/30x
- [ ] G2 Browser 或契约测试有证据（审查-only 可 n/a，但须注明）
