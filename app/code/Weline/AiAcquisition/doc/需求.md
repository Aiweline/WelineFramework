# Weline_AiAcquisition 需求

## 当前需求（2026-10-23）

在 AI 运营域新增「AI 获客」：

1. 存放从公开网络找到的当前网站客户记录：五大洲/国家地理位置、公司、来源 URL、邮箱、AI 推断的客户偏好与商业业务方向。
2. 自动获客智能体：使用当前系统获客自动化提示词，具备 web 查询能力。
3. 浏览器查询工具：前端 JS 扩展 + SSE 交互，直连用户浏览器执行；智能体内核以 WASM 在浏览器运行；可选择 AI 模块可用模型，并给出花销。
4. 后台可管理线索、提示词、运行与成本；可签发浏览器票据并查看运行记录。

## 边界

- 只采公开页面与公开商务联系方式；不绕过登录/付费墙/验证码。
- 不自动发信；触达由人工或后续邮件模块推进。
- 站点专属提示词通过「提示词档案」录入，不写进模块代码。

## 验收

- `setup:upgrade -m Weline_AiAcquisition` 成功，5 表存在。
- `query:help ai_acquisition` 列出 operations；后台菜单/路由可解析。
- `ai:agent:scan` 注册 `ai_acquisition`（4 工具）。
- 单测、WASM 构建/冒烟、模板渲染通过。


## 2026-10-23 追加：后台 UI

- 后台「客户线索 / 获客智能体」两页必须按已确认的 A 方案实现：顶部 KPI + 一行筛选 + 全宽表格 / 双栏运行工作台。
- 前端修改必须先审丑、先草图、原型确认后再写生产模板/CSS。
- 只消费 Weline 设计 Token；交付附 `taste` 六问与 1440/1024/768 截图。


## 2026-10-23 追加：归属与网站画像

- AI获客必须归属 `业务运营 → AI运营`，不是 AI 中心。
- 「让智能体去找」必须先选择网站；网站画像（身份、运营画像、类目/商品、价格带、语种、证据缺口）是系统提示词的一部分。
- 默认站 `website_id=0` 合法；运行记录、线索、画像均按网站归档。
- 通过 `Weline_Ops` 的 Lane 扩展接入 AI运营台，代码保持独立模块边界。


## 2026-10-23 追加：三种模型模式与扩展下载

- 浏览器扩展必须提供 ZIP 下载，不能再要求用户自己去模块目录找 extension/。
- 模型运行方式三选一：AI 模块云端、本地电脑 Ollama/OpenAI 兼容、浏览器端侧 Chrome 内置模型。
- 本地/浏览器模式不计 AI 模块费用；只回传 assistant/tool_calls/usage 记账。
- 扩展卡片长 URL/步骤文字必须换行，不得冲出卡片。
