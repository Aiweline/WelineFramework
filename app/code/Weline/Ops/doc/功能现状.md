# Weline_Ops 功能现状

- 模块版本：`1.3.1`
- 车道深链：`OpsLaneDeepLink` 统一附带当前 `website_id`（社媒附 scope_key；Visitor 双写 websiteId）
- 画像提取：`OpsWebsiteContextReader` 证据包（站身份/分类树/商品抽样/政策·CMS·Theme 默认/FAQ/语种）→ `ops_persona_ai_v4`；Desk `<w:theme:sse-progress>` 流式看进度；SSE：`refresh-persona-stream`
- **AI 运营默认关闭**：`OpsWebsiteProgram.enabled` 列默认 0；新建 `getOrCreate` 写 0；仅 Desk「开启 AI运营」可打开；日更/派工检查 enabled
- 建站助手：`OpsSetupTaskProvider`（`ops_ai_program_policy` 必读 + `ops_ai_program_enable` 引导手动开启，深链 Desk）
- 后台：`weline_ops/backend/desk/index`（运营台）；`weline_ops/backend/task/index`（调度任务管理）；菜单组 `Weline_Backend::ai_ops_group`
- 表：`weline_ops_website_program` / `weline_ops_persona` / `weline_ops_session` / `weline_ops_task` / `weline_ops_run_log`
- 智能体：`website_ops`（调度）/ `ops_analyst`（日更分析）/ `blog_publish` / `social_ops`
- 队列：`OpsTaskDispatchQueue`（分析成功→done；博客/社媒→awaiting_approval）
- Cron：`ops_daily_dispatch`（按 program.daily_time 小时触发 acceptConfig）
- 车道：Site/Content（Ops）+ Growth/Social/Seo/Visitor/Promotion（域模块贡献）
- 规格：`doc/开发/spec/ops-async-agent-dispatch.md`（分析分发队列，合并原 P2/P3）；`ai-ops-website-program.md`（P1 画像）
- 不含：向量 RAG；无审批自动外发
