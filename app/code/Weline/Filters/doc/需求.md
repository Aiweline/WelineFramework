## 当前有效需求

### `REQ-FILTERS-0001` 分类侧栏经部件 default_injections 注入

- 来源与确认：2026-09-03 用户要求分类布局左侧留下 slot，由 Filters 模块应用部件注入。
- 业务逻辑：Theme `category` 布局仅保留 `category-filters` slot/预览占位；`category-filters` 部件由 `Weline_Filters` 拥有并通过 `default_injections` 注入；禁止布局内嵌 `w:widget` / Product `getHook` 占槽。
- 验收标准：布局源码无 `filters-sidebar` getHook；部件声明 `default_injections→category-filters`；店面侧栏由 Filters 部件渲染。

### `REQ-FILTERS-0002` 侧栏须含价格与 EAV 属性筛选

- 来源与确认：2026-09-03 用户要求属性筛选要有。
- 业务逻辑：基于当前列表报价构建价格桶与 `AttributeFilterService` 可筛属性；URL 参数 `price` / `af_<code>`；控制器应用属性筛选后输出列表。
- 验收标准：侧栏可见价格与属性组（有可筛属性时）；勾选后列表结果收敛。

### `REQ-FILTERS-0003` 选中分类后部门树展开并高亮

- 来源与确认：2026-09-03 用户反馈分类详情页部门树未展开、误以为 Filters 未注入。
- 业务逻辑：`StorefrontFilterPanelService` 按 listing URL 解析当前分类，沿 `activePathIds` 展开子节点并标记 `current`；模板按 `depth` 缩进。
- 验收标准：`/category/women` 高亮「女装」并列出子类；有商品关联的分类详情仍展示价格/属性面。
