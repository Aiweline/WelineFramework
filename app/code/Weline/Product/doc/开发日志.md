## 2026-08-30 保存品牌 404

- 根因：`Catalog::csrf()` 返回 `form_key`，而 `<w:form csrf="auto">` 写入的是 `csrf`（`Token::create`）；未登录时 ACL 未覆盖 `save-brand` 会落到控制器 CSRF 校验并 `noRouter(404)`。
- 修复：`csrf()` 改为返回 `csrf`；`saveBrand`/`disableBrand` 重命名为 `postSaveBrand`/`postDisableBrand`（`save-brand::POST`）；ACL 独立 source_id `brands:save` / `brands:disable`。
- 验证：未登录 POST `save-brand` → 302 登录；契约测 `ProductBrandAdminContractTest` + `ProductBrandSaveCsrfContractTest` 通过（锁定 csrf 字段名与 postSave* / ACL source）。
