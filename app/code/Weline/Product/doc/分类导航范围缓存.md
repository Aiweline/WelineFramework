# 分类导航范围缓存

2026-09-13：同网站、店铺、渠道先访问 19655 后访问 9555，分类导航继续指向先前端口。`StorefrontAllMenuCategoryTreeService::build()` 曾把 `Url::getFrontendUrl()` 的绝对 URL 写入范围共享树；显示 normalizer 保留完整 URL，因此无法在下一请求修正来源。

共享树现在只保存原始路由和分类节点数据，继续使用既有 `categoryMenuPolicy`、ScopeHotCache 进程 L1 与共享 L2。逻辑版本 v6 淘汰含旧绝对 URL 的 v5 数据。原始缓存键不增加 origin、请求 ID、普通路径或查询参数。

`navTree()` 保留既有对外完整 URL、节点层级、名称、ref、meta、图片和描述契约；后台编辑器候选等直接消费者也不需要改协议。树读取与 URL 物化整体放入现有 `rememberForRequest()`，其键通过 `KeyBuilder::environmentHash()` 包含冻结范围及版本、语言、货币和当前 origin，不包含普通页面路径；相同请求不重复构建 URL。URL 仍经过现有生成和重写逻辑，保留网站挂载路径和语言、货币前缀。这里没有新建私有缓存。

定向验证：`vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php --colors=never app/code/Weline/Product/test/Unit/Service/StorefrontCategoryNavigationOriginTest.php app/code/Weline/Product/test/Unit/Service/StorefrontAllMenuCategoryTreeServiceTest.php`。用真实 ProductCatalogQueryConsumer、StorefrontScopeHotCache、CachePool、Url/WlsRequest 和 Context，仅将存储及目录输入换成内存边界。覆盖 19655→9555→19655，原始共享数据不含 origin、跨请求 L2 复用、重复请求读取不重复 URL 重写、范围版本与语言切换。

部署时旧编译模板可能已经烘焙污染的分类 HTML；v6 只淘汰原始树，不能替代正式模板编译缓存失效和外层输出的范围 changed 失效。源码加载、正式失效和同 H2 双 origin 链接及浏览器验收由主任务统一执行，单测不代表实际验收通过。
