## 当前有效需求

### `REQ-PRODUCT-0014` 万能产品 v1.0：五类产品、完整后台与跨 Website 经营

- 来源与确认：用户确认主站存商品、获授权子站可复制；任意 Website 可自建并成为归属站；新建/复制默认选择目标 Website 的全部活动 Store；Eav 管属性定义，Product 管自己的商品/规格值。用户随后明确要求实施 `doc/万能产品完善计划.md`，并允许 WLS 等运行设施不可用时跳过，但跳过项不能当作通过。
- 核心模型：Product 是自动总货号的商品主体，1:N Offer；每个 Offer 有全局唯一 SKU。Website 是目录与经营事实边界，Store 默认继承并可覆盖；跨站复制保留同一全局身份但数据独立，不自动同步。
- 产品类型：`simple`、`configurable`、`virtual`、`downloadable`、`bundle` 五类内置；Subscription 通过所属模块的 Provider V2 扩展证明接入，不把订阅硬编码到 Product。
- 后台范围：统一商品列表、短流程新建、完整编辑器、EAV 属性值、规格矩阵、价格、分类、FileManager 媒体、Store、库存/配送、类型配置、发布诊断、分享/归属转让与审计；草稿可不完整，发布按 Provider 校验。
- 生命周期与治理：`draft → published ↔ disabled → archived`；运营不物理删除；类型只允许无引用草稿转换；SKU 别名永久保留；归属转让由原站发起、目标站确认。
- 迁移与兼容：V2 Product/Offer 注册表为权威身份；V1 resolver 兼容回读。正式 clone 已完成 26 Product / 26 Offer、0 missing、0 conflict 的幂等迁移与 cutover/rollback/final cutover，最终 `v2_authoritative` version 6。
- 验收标准：完整标准见 `doc/万能产品完善计划.md#五测试与完成门禁`。PostgreSQL 原子回滚与跨站复制矩阵已通过；独立 WLS 的 Master lease 故障使真实 HTTP/ACL/CSRF、五类前后台路径和 375/768/1024 Browser 证据暂不可得，因此总体仍为 IMPLEMENTING/RUNTIME_BLOCKED，不是 ACCEPTED。

### `REQ-PRODUCT-0006` Theme 不得抢占 Product slug 详情路由

- 来源与确认：2026-08-25 用户验收 `product/benq-screenbar` 详情页为空壳占位。
- 业务逻辑：已安装 `Weline_Product` 时，Theme 公共回退不得把 `product/{slug}` 改写为 `theme/frontend/policy` 空布局；详情由 Product Router → Detail Controller 承接，并使用 Theme `product` 布局壳。Theme 可视化预览通过 `theme_public_route=product/{slug}` 让 product-info 解析具体商品。
- 范围：`Weline_Theme\Controller\Router::isInstalledModuleOwnedPublicRoute`、商品详情 Controller 布局身份、`product-info` 的 `theme_public_route` 解析。
