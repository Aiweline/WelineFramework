- 店面详情图库：`product-info` 主图舞台含 `data-image-zoom` 透镜与侧向放大预览；缩略图/规格图库切换后同步放大源；主图（无角标）与带图规格选项（标「规格」）分层展示，规格图追加到画廊且不吞没主图；点击规格缩略图可反选右侧选项；点击规格选项时切换到对应规格预览图；商品视频与图片混排于画廊并可切换播放；`≤992px` 关闭悬停放大；多规格目录复用 Controller 已生成的 EAV catalog，`compactCatalogMedia` 将所有 Offer 共用图库只序列化一次、每个 Offer 仅保留规格差异图与主图，避免数百规格商品因重复媒体载荷返回空页；`collectAxisCodes`/`buildCatalog` 只暴露出现在 offer combination 的规格轴，产品级多选孤儿轴（如仅写在 `variant_axes` 的流行元素）不进入可点选规格区；下方详情区默认先「技术细节」后「关于该商品」；技术细节属性名优先 EAV 元数据/`__()`，容器够宽两列、过窄一列，超高约 15.5rem 以 `mask-image` 透明度淡出折叠，「展示更多 / 收起」可切换（不足高度不显示）。2026-09-05 已在内置浏览器对真实商品执行款式切换，URL、短 SKU 与本地规格主图同步更新。
- 店面卡片数据：`StorefrontProductWidgetCatalog` 优先展示 HF SKU，并以全部已发布目录补齐，兼容不带前缀的国际导入商品；卡片链接通过 `Url::getPrefix()` 保持当前 locale；`rating`/`review_count` 经可选 `Weline_Review::aggregatesForExternalUuids` 批量回填真实已通过评论（无假公式），无评论则空态不显示星级；catalog/category/search Offer 卡片整卡命中链接优先携带规格轴 option code（无组合时回退 `offer` UUID），详情页规格轴按该深链预选。
- 国际化商品投影：商品**标题**在不支持汉字的 locale 下会跳过汉字回退并改用 SKU/ID 中性英文名；Technical details 规格行优先 EAV 属性/选项 LocalDescription 当地名（可用 `scripts/remediate-eav-en-locals.php` 补 `en_US`），无当前 locale 当地名时回退默认/源文并仍展示；FileManager 商品媒体按目标语言、en_US、Website 默认元数据回退，真实像素不再因缺翻译变成占位图。
