# 汉服内容与视觉整改 R2

## 范围

`Product/scripts/remediate-hanfu-commerce-media-r2.php` 负责 28 个汉服分类的方图与横幅、3 组首页响应式横幅、3 个 SKU 的 25 张商品图，以及三个商品的中英文详情。脚本不创建新分类、不改变价格、库存或规格可选值。

## 文件资产边界

所有 87 张替换图必须先通过 `FileAssetLibraryInterface` 注册到 `local::filesystem::media`：

- 分类方图：`catalog/hanfu/r2/categories/icons/{code}.webp`，800×800；
- 分类横幅：`catalog/hanfu/r2/categories/banners/{code}.webp`，1500×300；
- 首页：`catalog/hanfu/r2/homepage/{slug}.webp` 与 `-mobile.webp`；
- 商品图：`catalog/hanfu/r2/products/{slug}/{file}.webp`。

每个 FileAsset 必须有 `zh_Hans_CN` / `en_US` 两条 reviewed/manual locale 元数据，并填写名称、alt、说明、caption；FileAsset metadata 必须保留 source、license、purpose、relations、review。分类引用通过 `ProductCategoryAttributeService` 写入，商品图库通过 `MediaRepository::syncProductScope` 迁移为 `asset://{asset_id}`，规格图片路径同步改为 R2 WebP。

## 商品事实边界

只写已核实的 SKU、品牌、面料标注、组合类型、颜色和尺码。不得补造尺寸表、洗护承诺、手工比例、产地、配件包含关系或历史朝代断言。套装与单件必须明确区分。

## 运行顺序

```bash
php app/code/Weline/Product/scripts/remediate-hanfu-commerce-media-r2.php --dry-run
php app/code/Weline/Product/scripts/remediate-hanfu-commerce-media-r2.php --apply
php app/code/Weline/Product/scripts/remediate-hanfu-commerce-media-r2.php --verify
# 仅在源码精确搜索与数据库均为零引用后：
php app/code/Weline/Product/scripts/remediate-hanfu-commerce-media-r2.php --cleanup
```

`--cleanup` 只允许删除 58 个旧分类 SVG 与 6 个 test-create 临时文件；商品原始 JPG 如仍被维护脚本引用则保留，不得提前删除。
