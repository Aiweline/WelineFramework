# Weline Product 模块 - Hook 文档

## Hook 信息

- **Hook 名称**：`Weline_Product::frontend::product::detail::after-gallery`
- **显示名称**：商品详情图库之后
- **功能说明**：商品详情页主图/图库区块之后（媒体列脚部）的扩展槽。分销分享已改回购买栏收起条（`after-add-to-cart`）；本槽保留给其它媒体相关扩展。

## 使用方法

在模块的 `view/hooks/` 目录下创建文件：`view/hooks/Weline_Product/frontend/product/detail/after-gallery.phtml`
