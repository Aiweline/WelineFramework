# Weline_Captcha 开发日志

## 2026-08-31 — lazy 注入丢失验证码布局样式

- 当前状态：`implemented`
- 问题：`captcha-lazy.js` 的 `replaceAnchor` 只保留 challenge HTML 的第一个元素，模板内联 `<style>` 被丢弃；供应商/询盘等 lazy 表单验证码图与刷新按钮各自占一行，需各页重复写 CSS。
- 修复：布局样式抽到 `view/statics/css/captcha-local.css`；`captcha-lazy.js` boot 时 `ensureStylesheet()`；`replaceAnchor` 额外 `hoistFragmentStyles()` 兼容旧响应；模板 `.weline-captcha-visual` 增加 `weline-captcha-row` 别名。
- 验收：任意 lazy 注入表单验证码图与「刷新」同一行，无需业务页重复纠正。

## 2026-08-29 — 验证码图与刷新按钮同一行

- 当前状态：`implemented`
- 问题：窄登录卡触发 `22rem` 换行，图/刷新/输入各自占一行。
- 修复：`weline-captcha-visual` 固定横向排图+刷新；输入单独一行；覆盖登录页按钮全宽。
- 验收：登录页验证码图与「刷新」同一行。

## 2026-08-29 — 自动注入即一律 lazy（与 required/auto 无关）

- 当前状态：`implemented`
- 问题：误把 `required`/`auto` 当成 SSR 路径，导致「注入验证码」不能自动 FPC 友好。
- 修复：`InjectCaptchaIntoForm` 凡注入只输出 lazy 占位+运行时，删除 SSR/`forbid`；`required`/`auto`/`lazy` 只决定是否注入。
- 验收：`required`/`auto` 单测期望 lazy host；注入 HTML 不含 `captcha_token`。

## 2026-08-29 — Captcha 根源支持 FPC lazy 运行时

- 当前状态：`implemented`
- 问题：各业务页各自复制 challenge 拉取/刷新逻辑，FPC 下 SSR 图码仍易被复用。
- 修复：新增 `view/statics/js/captcha-lazy.js`（`Weline.Captcha`）与 `LazyCaptchaClientRuntime`；`InjectCaptchaIntoForm` 在 `lazy`/`required`/`auto` 注入时 once 附带脚本；挑战仍走 `frontend/challenge` + forbid。
- 验收：任意 `captcha="lazy"` 表单无需业务定制 JS 即可加载/刷新；共享页 HTML 不含 `captcha_token`。

## 2026-08-29 — 登录验证码被缓存复用且 Challenge 500

- 当前状态：`implemented`
- 问题：登录页多次刷新仍同一 `captcha_token`（worker/共享缓存复用 SSR 挑战 HTML）；`/weline_captcha/frontend/challenge` 调 `json()` 500。
- 修复：SSR `required/auto` 注入前 `SharedResponseCachePolicy::forbid`；Challenge 改 `fetchJson` + forbid；登录改 `captcha="lazy"` 并由客户端拉取挑战；挑战 UI 增加刷新。
- 验收：Challenge JSON 每次新 token；登录页为 lazy host，刷新后图码变化。

## 2026-08-29 — 登录表单验证码标签未进请求模块词典

- 当前状态：`implemented`
- 问题：WLS 分层 Phrase 下 `LocalImageCaptcha` 用 `__()` 拼标签，英文站仍回落中文；与表单 `<lang>` 编译期烘焙不一致。
- 修复：挑战 UI 改为 `local-image-challenge.phtml`（`<lang>请输入图片中的验证码</lang>`）；`InjectCaptchaIntoForm` 渲染前 `addModule('Weline_Captcha')`。
- 验收：英文登录页验证码标签为 `Enter the code shown in the image`。

## 2026-08-26 — LocalImageCaptcha 哈希成本与懒加载模式

- 当前状态：`implemented`
- 问题：`password_hash(PASSWORD_DEFAULT)` 在本机约 400ms，header 等隐藏表单 SSR `captcha="required"` 拖垮整页 TTFB。
- 修复：本地图验证码改 bcrypt cost=5；`w:form captcha="lazy"` 只打标记，由客户端按需拉取挑战；保留 `Controller/Frontend/Challenge` 备用。
- 验收：`InjectCaptchaIntoFormTest` lazy 用例；LocalImageCaptcha render ≪100ms。
