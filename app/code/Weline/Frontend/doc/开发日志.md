## 2026-09-15 — query-bin「Invalid Weline binary magic」诊断加固

- 现象：主题编辑器 `theme.editorRequest` 偶发 `protocol_error: Invalid Weline binary magic (HTTP 200)`，预览/部件库卡住。
- 含义：HTTP 200 的响应体不是 `WQB1` 包（常见于 `fetch` 跟随 302 落到登录 HTML，或中间层返回 JSON/空体）。
- 修：`weline-api-worker.js` 对 query-bin 使用 `redirect: 'manual'` + `assertBinaryFetchResponse`；magic 失败时附带 `head_hex`/`head_ascii` 与 html/json/gzip/empty 提示；非二进制 JSON 错误尽量结构化透出。
- 契约：`WelineApiWorkerNonceContractTest::testWorkerRejectsQueryBinRedirectsAndSurfacesNonBinaryHeads`。
