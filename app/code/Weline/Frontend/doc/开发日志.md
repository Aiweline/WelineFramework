## 2026-09-01 — Dom 微核：属性门控按需加载

- 当前状态：`implemented`
- 背景：动态 JS 渲染节点首屏 `querySelector` 找不到；各处自写 MutationObserver 易风暴。需统一能力，但**不得**默认全站加载。
- 变更：
  - 新增 `weline-api-dom.js`（`Weline.Dom` / `WelineDomModule`）：`on` / `when` / `off` / `emit` + 声明式 `data-weline-when` / `data-weline-on`。
  - `weline.js` 薄探测：识别到上述属性或 `data-weline-load` 含 `dom` 时才 `load('dom')`；无标记时仅轻量发现，加载成功即 disconnect。
  - `frontend/weline.modules.js` 注册 `welineDom`，别名 `dom`。
- 用法：静态绑定无需 Dom；异步出现节点用 `data-weline-when` / `Weline.Dom.when`；未来子节点事件用 `data-weline-on` / `Weline.Dom.on`。
- 编译：`php bin/w resource:compile welineModules`。
- 权威：`Theme/doc/前端JS模块加载规范.md`；`doc/主题设计/模块加载系统使用指南.md`。

## 2026-08-30 — account 模块：浏览器在线自动续 Session

- 变更：`weline-api-account.js` 增加 `startOnlineKeepalive`：已登录且 `navigator.onLine` 时按间隔调用 `account.current` 触发会话滑动续期；offline 暂停、online 立即续一次；登录/注册/页头 signed-in/auth refresh 启动，登出或 current 未登录停止。间隔默认 240s，可用 `config.account.keepaliveIntervalMs` 覆盖。
- 版本：`2.0.9` → `2.0.10`。

## 2026-08-30 — 加购报 resolveModulesBaseUrl is not defined

- 当前状态：`fixed`
- 现象：点击「加入购物车」弹红字 `resolveModulesBaseUrl is not defined`。
- 根因：`ModuleLoader.loadModule` 回退路径调用了未定义的 `resolveModulesBaseUrl`；且 Frontend `weline.modules.js` 用 `"weline-api"` 等引号键，编译器未合并进 base，导致 `api`/`account` 总是走坏掉的回退。
- 修复：补 `getModulesBaseUrl()`；模块键改为裸标识符 `welineApi` 等并更新别名；重编译 `welineModules`。
- 验收：首页加购不再抛该 ReferenceError；Network 可拉到 `weline-api.js`。

## 2026-08-29 — 注册提交「模块 api 加载失败」

- 当前状态：`implemented`
- 根因链：
