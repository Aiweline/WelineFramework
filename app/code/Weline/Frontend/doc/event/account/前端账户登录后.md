## 迁移说明

前台登录成功后统一由 **Weline_Customer** 派发。购物车合并（Cart）、登录像素（Visitor）等消费方须监听 `Weline_Customer_Account_Login::login_after`。

本模块 `event.php` 保留本条目仅作废弃索引，指向 Customer 文档；新 Observer **禁止**再挂旧名。
