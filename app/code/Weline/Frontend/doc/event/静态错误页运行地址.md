# 静态错误页运行地址

Frontend 监听已有事件 `Weline_Framework_Http::response_ready`。事件携带 `response`（Framework HTTP Response），在最终响应发送前执行；事件定义见 Framework 的 `doc/event/http/最终响应就绪.md`。

`StaticErrorRuntimeTransport` 仅处理含 `weline-frontend-runtime-config` 的前台 404 响应。它通过当前 Request 和原生 URL 构造器更新配置中的前端、API 主机与 QueryBin 地址，使静态错误页通过当前访问域名及网站挂载路径请求 API。其他配置、部件 HTML、语言数据和静态资源地址保持原值。

注册排序为 50，先于 Websites 的最终响应范围引导。该观察器不读取布局编辑数据，不增加配置侧车文件，不修改 API 权限。
