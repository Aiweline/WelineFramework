## 当前有效需求

### `REQ-FRONTEND-0001` 前台 Weline UI 2.0 最小基础层

- 来源与确认：用户于 2026-08-21 确认前台只保留通用变量、色彩、排版、布局原语及实际路由组件，并要求旧通用 UI 依赖零兼容。
- 目标版本：`2.0.0`。
- 背景/问题：Frontend 当前包含 Bootstrap、jQuery、RequireJS、Vue、字体图标及示例资源副本，远超前台基础层所需。
- 业务逻辑：前台全局只加载 Weline foundation CSS 与 UI core；组件通过路由清单按需加载，业务请求继续走 `Weline.Api`。菜单等浮层只声明组件、锚点和语义 placement，由共享内核自动处理 visual viewport、safe area、翻转/限界、嵌套层级和移动端可用尺寸，页面不得复制坐标或断点算法。
- 范围：前台 Head/Footer、共享 token、基础排版和布局、当前页面实际使用的交互组件、旧静态仓库清理。
- 非目标：把后台完整组件包加载到前台；改变账号、会话、API 或站点主题业务规则。
- 数据/权限/安全：不新增持久化；消息和动态内容遵守 Weline UI 安全输出契约。
- 兼容/迁移：不保留 Bootstrap、jQuery、Vue、RequireJS、字体图标或旧 class/API；路由迁移完成后物理删除旧资源。
- 验收标准：foundation CSS `≤25 KB gzip`、首屏 UI JS `≤35 KB gzip`、全局 UI 请求 `≤3`，源码与网络均无禁用通用 UI 资源；375/768 下浮层完整位于 visual viewport/safe area 内、页面无横向滚动、触控目标不小于 44px，1024/1440 自动恢复桌面导航；重复开关不漂移，嵌套层与 Escape 顺序正确。
- WebUI/E2E：真实前台首页和 `/datatable/test` 覆盖三态、375/768/1024/1440、键盘、焦点、控制台和网络资源。
- 运营与支持影响：自定义前台主题必须改用 Weline token 与 `w-*`；2.0.0 不提供旧主题适配。
- 依赖与风险：业务模块可能直接引用 Frontend vendor 路径；必须由审计清单逐项迁移后再删除。
