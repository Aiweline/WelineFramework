## 当前有效需求

### `REQ-MEDIA-0001` 媒体 Query 身份取自已证明的 backend Worker 上下文

- 来源与确认：用户于 2026-08-18 在媒体管理页看到两个 `Internal server error.` toast；同意修复，并明确「admin 应该叫 backend」。
- 目标版本：`1.2.1`
- 状态：implemented
- 背景/问题：`media_manager` 的 `config/connector` 借用了 `ResumableTaskOwnerResolver`。该解析器要求 Worker backend 证明指纹与当前 backend Session 完全一致；一旦不一致就抛 `ResumableTaskAccessDeniedException`，QueryBin 再包装成 500。改为直接 `Session->start()` 仍会按 API Cookie 另起空会话，已登录页会误报「请先登录后台」。
- 用户与运营场景：已登录 backend 的用户打开「文件管理」，目录树与文件列表必须能加载；身份一律称 backend，不称 admin。
- 业务逻辑：QueryBin 路径优先读取已证明的 `FrontendWorkerExecutionContext` backend 用户 ID，不得再 start 一套 PHP Session。无 Worker 上下文时才回退已登录 backend Session。未登录返回 QueryBin 可识别的 401，不得伪装成 500。runtime_task 的 owner/lease 校验仍只用于可恢复任务，不用于打开目录。
- 范围：`MediaManagerQueryProvider` 身份解析、媒体管理页 connector/config 调用。
- 非目标：不改 AI 作图模型绑定；不改 runtime_task 协议；不改文件存储路径校验。
- 数据/权限/安全：未登录不得执行 connector/config/save；ACL 仍由 Query 描述符 `backend_acl` 把关。
- 兼容/迁移：无 Schema 变更；不升 `etc/module.php` 安装版本。
- 验收标准：backend 用户打开媒体管理页，connector 与 config 不再返回 `Internal server error.` 或误报未登录；能列出 Media Files 目录。
- WebUI/E2E：backend 登录 → 打开文件管理 → 目录树与网格可见，无红色 Internal server error toast。
- 运营与支持影响：无新配置。
- 依赖与风险：依赖 QueryBin 已对 `ResumableTaskAccessDeniedException` 做 401 映射，作为其它 provider 的安全网。

### `REQ-MEDIA-0002` 目录右键管理统一接入存储提供者

- 来源与确认：用户于 2026-08-22 要求目录树和媒体网格均支持右键删除、重命名等整目录管理，并通过提供者能力支持后续 OSS 扩展。
- 目标版本：`1.2.2`
- 状态：implemented
- 用户场景：backend 用户在左侧目录树或右侧媒体网格中右键目录，或在触摸屏点击对应目录“更多”按钮，即可打开同一套目录操作菜单；无需理解本地和对象存储的实现差异。
- 业务逻辑：所有非本地存储请求必须携带当前 `storage`，浏览、新建、重命名和删除统一调用 `StorageDirectoryManagerInterface`。UI 仅展示提供者声明可用的动作；不支持的上传、下载、预览不得误落到本地。
- 交互与无障碍：目录菜单必须使用全局 `Weline.UI` Menu 和 `w-menu` 语义皮肤，不得自带背景、边框、焦点或面板定位实现。右键点作为稳定虚拟锚点，由公共浮层内核根据 visual viewport 与 safe area 自动翻转、限界和在滚动/缩放/旋转后重排；同一点重复打开不得漂移。支持右键、触摸“更多”、菜单键、Shift+F10、方向键、Tab 和 Escape，并恢复键盘焦点。
- 安全：根目录不可删除/重命名；拒绝控制字符、`.`、`..` 和跨层路径；重命名不得覆盖已有目标；删除目录必须二次确认并明确包含全部内容。
- 范围：目录树与媒体网格目录操作、provider 路由、能力禁用、确认对话框。保留现有文件选择、上传、AI 作图和预览能力。
- 非目标：本批次不为远端存储实现上传、下载、缩略图或 AI 作图；这些动作通过 capability 明确禁用，而不是回退本地。
- 兼容/迁移：无 Schema 变更；不提供旧 UI 兼容层；不升安装版本。
- 验收标准：本地目录可创建、重命名、递归删除；配置的 OSS/S3 目录命令进入对应提供者；菜单在 light/dark/system 下自动消费 `--weline-theme-*` 语义 token，始终位于当前视觉视口内；刷新后无残留菜单或确认层。
- WebUI/E2E：backend 打开媒体管理 → 分别在左侧目录树与右侧媒体网格右键/点击更多 → 菜单均显示重命名和删除 → 当前目录操作后安全跳转 → 删除并确认 → 树与网格同步刷新且目录消失。

### `REQ-MEDIA-0003` 拖拽、粘贴上传与文件拖入目录

- 来源与确认：用户于 2026-08-22 要求媒体文件管理器支持把外部图片/文件拖入目录上传、直接粘贴剪贴板文件上传，以及把管理器内已有文件拖到目录中自动归档；用户随后明确确认“记录”。
- 目标版本：`1.2.3`
- 状态：implementing
- 用户场景：backend 用户可把系统文件拖到当前内容区，或在非输入控件焦点下粘贴剪贴板 File 项；也可拖动单个或已多选的普通文件到网格目录或目录树目标。
- 业务逻辑：外部 `Files` DataTransfer 进入当前内容区时调用现有上传命令；剪贴板只有实际 File 项时才接管 paste；内部拖动使用模块专用 MIME 标记并调用 connector `move`，不得落入上传路径。
- 能力与存储：本地声明 `move_file`；远端提供者未显式声明时可由 `rename_file` 推导，但所有非本地命令仍只调用 `StorageDirectoryManagerInterface`，能力不足即拒绝，绝不回退本地。
- 安全：仅移动普通文件；拒绝目录、符号链接、根、非法 hash、目标非目录、同目录和同名覆盖；批量移动先完整预检，失败时尽力回滚已完成项。
- 交互与无障碍：外部拖入和内部目录目标使用不同稳定高亮；上传进度暴露 progressbar；开始、成功与错误写入 `aria-live`；不以颜色作为唯一反馈，并遵循 reduced-motion。
- 范围：MediaManager connector、网格/目录树交互、模板、样式、i18n、聚焦单元契约与 backend E2E。
- 非目标：不移动目录；不覆盖目标同名文件；不为远端提供者新增上传能力；不改变文件选择、右键菜单、预览、删除或 AI 作图协议。
- 兼容/迁移：无 Schema 变更；不升安装版本；connector 继续使用已有 `target` 表示目标目录和 `targets` 表示源文件。
- 验收标准：外部拖入和剪贴板文件均出现在当前目录；内部拖到网格/树目录后源目录消失、目标目录出现，且 FileReader 上传计数不增加；纯文本粘贴与输入控件不被阻断。
- WebUI/E2E：backend 打开文件管理 → 创建测试目录 → 外部拖入文件 → 粘贴文件 → 把已上传文件拖进测试目录 → 进入目录确认 → 清理测试数据；执行 `MEDIAMANAGER-DROP-PASTE-MOVE-001`。

### `REQ-MEDIA-0004` 统一资源上传、磁盘选择与多语言元数据

- 来源与确认：用户于 2026-08-22 批准统一 FileAsset/Storage 方案，并进一步明确：文件右键菜单必须能查看元数据，选中文件后右侧详情栏也必须完整列出元数据；随后要求连同本轮审查发现的 API、WLS、安全、测试与文档遗漏一起修复。原计划编号 `REQ-MEDIA-0003` 已被当前工作树中先行确认的拖拽上传需求占用，本需求顺延为 `REQ-MEDIA-0004`，业务语义和目标版本不变。
- 目标版本：`1.3.0`。
- 状态：implementing。
- 业务逻辑：MediaManager 只负责编排资源库、规范磁盘选择、上传进度和资源选择；上传成功必须通过 FileManager 发布接口创建 FileAsset，并在允许业务选择前要求当前语言名称、默认 alt 和描述完整。批量上传逐文件收集并保存独立的显示名称、默认 alt 与描述，不得把第一个文件的文案复制给整批文件。
- 元数据详情：普通文件右键菜单提供“查看详情”；文件被选中时右侧详情栏同步展示文件名、MIME、大小、尺寸、磁盘、对象键、语言、显示名称、默认 alt、描述、caption、翻译状态、可选择状态和资源 ID。文件夹不出现文件元数据动作；空值使用明确占位，长文本可换行/复制，详情视图具备键盘焦点和屏幕阅读器语义。不得展示凭据、私有签名 URL 或内部敏感 metadata。
- 存储：`local::filesystem::media` 与扩展磁盘走相同 Storage/FileManager 公共接口；同一页面选择的资源可来自不同磁盘；远端故障不得回退本地。MediaManager 不得跨模块引用 FileManager/Storage 的具体 Model 或 Service。
- 上传与安全：浏览器业务请求只走 `Weline.Api.resource('media_manager')`；前后端共同校验允许类型、最大大小、单层文件名、目标目录和同名冲突，任何上传与移动都不得覆盖已有对象；非法非空 hash 必须返回“目标路径无效”，不得退化为根目录。
- WLS：上传输入与临时文件通过 Request/显式数据结构传递并在请求结束清理；MediaManager 业务代码不得读写 PHP 超全局或进程级可变请求状态，客户端断开、异常和 early response 仍执行 cleanup/abort。
- 兼容：旧路径选择保持只读兼容；新类型化选择返回 `asset_id` 和本地化预填元数据，不向 CMS/Theme 暴露对象路径或签名 URL。
- 验收：磁盘切换、本地与扩展磁盘 FileAsset 一致性、多语言必填、右键/选中详情、大小/类型/重名/非法 hash 拒绝、客户端断开、跨 Fiber 零串扰及真实后台上传和选择路径通过；聚焦单测必须加载 `app/code` 当前实现，可重复 E2E 覆盖网格/树移动、纯文本与输入控件粘贴不拦截、多选和冲突清理。
