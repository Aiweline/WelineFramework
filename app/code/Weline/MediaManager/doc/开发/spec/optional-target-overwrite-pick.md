# 上传/拖入可选指定覆盖目标（当前目录搜索）

## 澄清记录

| # | 问题 | 用户答复 | 结论 |
|---|------|----------|------|
| 1 | 产品面 | 只要自研文件管理器 | **MediaManager**；不改 ElFinder / WLS 面板 |
| 2 | 与冲突覆盖关系 | 冲突已能正确解决；不要改旧冲突流程 | **新增可选能力**；同名冲突对话框保持不动 |
| 3 | 期望效果 | 选择覆盖目标后，名字与元数据接到本次入站 | 等价同名覆盖：`replaceContent`，保留 `asset_id` + locale |
| 4 | 搜索范围 | 当前目录 | 仅当前工作目录文件（非目录，不递归） |
| 5 | 是否冲突驱动 | 不是；冲突早已做好 | 无冲突时也可主动指定 |
| 6 | 多文件 | 多文件就映射选择（仍可选） | **每个入站文件各自可选映射**一个当前目录目标；不选则该文件走新建 |
| 7 | 扩展名不同 | 沿用所有信息，只换物理图 | 强制沿用目标完整文件名（含扩展名）与全部元数据；只替换字节/技术字段 |
| 8 | AI 作图保存 | 可以 | AI 保存也提供同一套「可选指定覆盖目标」 |

## 目标

MediaManager 在上传、拖入、以及 AI 作图保存到当前目录时，提供**可选**的「指定覆盖目标」：在当前目录搜索并选择已有文件。选定后仅替换物理内容，目标的文件名与全部资源元数据保持不变（与现有同名覆盖效果一致）。

## 非目标

- 不修改现有「文件名已存在」冲突对话框与同名覆盖路径。
- 不在 ElFinder、WLS 面板实现。
- 不递归子目录、不跨目录选目标。
- 不强制必须选目标；未映射的文件走现有新建（及既有同名冲突）流程。

## 角色

- 后台操作员（已登录，具备 MediaManager 上传/AI 保存权限）

## 用户故事

As a 后台操作员, I want 上传/拖入/AI 保存时可选为每个文件映射当前目录里要覆盖的目标, so that 新图只换物理内容并完整沿用目标的名字与元数据。

## 验收标准（EARS）

1. WHEN 用户在 MediaManager 当前目录发起上传或拖入 THEN 系统 SHALL 提供可选入口，支持为每个入站文件在当前目录搜索并映射零或一个覆盖目标。
2. IF 某入站文件已映射覆盖目标并确认 THEN 系统 SHALL 仅替换该目标的物理内容，并沿用目标的完整文件名与全部资源元数据（含多语言文案、`asset_id`），效果与同名覆盖一致。
3. IF 某入站文件未映射覆盖目标 THEN 系统 SHALL 对该文件走现有新建上传流程（含既有同名冲突处理，行为不变）。
4. WHILE 选择覆盖目标 UI 打开 THEN 系统 SHALL 仅列出并按文件名过滤当前目录内的文件（非目录）。
5. WHEN 用户在 AI 作图保存流程中选择可选覆盖目标 THEN 系统 SHALL 使用与上传相同的映射语义（只换物理图，沿用目标全部信息）。

## 用例

### UC-1 单文件可选映射覆盖（主成功）

| 字段 | 内容 |
|------|------|
| 角色 | 后台操作员 |
| 前置 | 当前目录有 `hero.png`；本地有不同名 `shot.jpg` |
| 主成功步骤 | 1. 上传/拖入 `shot.jpg` 2. 为该文件搜索并映射 `hero.png` 3. 确认 |
| 备选 | 取消映射 → 新建；取消上传 → 无写入 |
| 期望结果 | `hero.png` 内容更新；文件名与元数据不变；不新建 `shot.jpg` |
| 映射 acceptance | `type=e2e` MediaManager 上传映射覆盖 |

### UC-2 多文件各自映射（可选）

| 字段 | 内容 |
|------|------|
| 角色 | 后台操作员 |
| 前置 | 当前目录有 A、B；拖入 X、Y |
| 主成功步骤 | 1. 拖入 X、Y 2. X 映射 A；Y 不映射 3. 确认 |
| 期望结果 | A 被替换；Y 按新建（或 Y 同名冲突走旧流程）；B 不变 |

### UC-3 AI 保存可选映射

| 字段 | 内容 |
|------|------|
| 角色 | 后台操作员 |
| 前置 | AI 生成图就绪；当前目录有目标文件 |
| 主成功步骤 | 1. AI 保存 2. 可选映射覆盖目标 3. 确认 |
| 期望结果 | 目标物理图更新；元数据全保留 |

### UC-4 回归：不映射 + 同名冲突

| 字段 | 内容 |
|------|------|
| 角色 | 后台操作员 |
| 前置 | 拖入与现有同名文件且未使用新映射 UI |
| 期望结果 | 既有冲突对话框行为不变 |

## 隐形需求摘要

- 写入走 `FileAssetLibraryInterface::replaceContent`（或 MediaManager 已封装等价路径）；禁止只写磁盘。
- 浮层/对话框用 Theme UI；禁止原生 `alert`/`confirm`。
- 文案 i18n + `i18n:collect`。
- UI：覆盖目标是拖入/粘贴才出现的居中可搜索选择层；底部状态栏（N items）始终贴在文件区底部。联合 `prototype` + `frontend-design` + `weline-theme-development`（Token）。
- Web feature：Browser WB-OP + Playwright 章通路 e2e + `e2e-plan-suite`。
