# 客户账户登录后

## 事件名称

`Weline_Customer_Account_Login::login_after`

## 触发时机

客户凭据验证完成、前台会话已经绑定客户身份且客户登录状态已经保存后同步触发。
Customer 的页面登录、账户查询登录和共享账户服务登录入口使用同一事件名。

## 事件载荷

事件数据是 `Weline\Framework\DataObject\DataObject`，包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `user` | `Weline\Customer\Model\Customer` | 当前已登录客户 |
| `request` | `Weline\Framework\Http\Request` | 当前 HTTP 请求 |
| `session` | `Weline\Framework\Session\Session` | 已建立客户身份的前台会话 |

观察者必须从事件数据读取当前身份，不得信任客户端提交的 `customer_id`。

## 观察者注册

```xml
<event name="Weline_Customer_Account_Login::login_after">
    <observer name="Vendor_Module::login_after"
              instance="Vendor\Module\Observer\LoginAfter"
              disabled="false"
              shared="true"
              sort="100"/>
</event>
```

## 执行与失败约定

- 这是登录请求内的同步通知事件；观察者应保持轻量并保证重复执行安全。
- 默认观察者异常会影响登录请求。非关键扩展应在自身边界内处理可恢复异常。
- 购物车等范围数据必须使用服务端会话身份和当前网站范围，不得由请求参数覆盖客户身份。
- 事件规约变更后运行 `php bin/w event:rebuild`，使观察者进入 `generated/events.php`。
