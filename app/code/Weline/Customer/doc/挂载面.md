# Weline_Customer 挂载面

> 本文件只列 **Account / Customer 作为提供方** 的挂载面清单。  
> **协议与编排权威**在 `Weline_Theme/doc/前端JS模块加载规范.md`（`Weline.mount` / `data-weline-mount`），不在本模块。

## 角色

| 角色 | 谁 | 做什么 |
|---|---|---|
| 框架 | `weline.js` → `Weline.mount` | **有声明才 boot/扫描**；加载 `mount-load`；等 `mount-after`；调 provide；`no_provider` 短重试 |
| 提供方 | 本模块 `account` + `customerLoginPanel` | 模块加载即 `provide`（不依赖当时 DOM 是否已有宿主）；login-panel 脚本自注册兜底 |
| 宿主消费方 | B2B / Cart / … | 只写属性；抽屉打开 `scan` + `waitFor`；成功后清回退文案 |

## 本模块挂载面

### `customer/login-panel`（推荐：业务抽屉完整登录）

| 项 | 说明 |
|---|---|
| 提供方 | `account-session.js` → `provide`；渲染 `account-login-panel.js`（亦可自 provide） |
| 能力 | **完整登录面板**：快捷登录（Google/Facebook）+ 账密表单 + 忘记密码/注册链接 |
| 推荐宿主 | `data-weline-mount-load="account,customerLoginPanel"` + `suppress-floating=1` |
| 登录成功 | 文档 fetch 登录 → `weline:account:frontend:login` → 回跳当前页 |
| 内嵌快捷 | 面板内嵌 `customer/social-quick` 槽（不二次框架 scan 外层） |

```html
<div data-weline-mount="customer/login-panel"
     data-weline-mount-load="account,customerLoginPanel"
     data-weline-mount-suppress-floating="1"
     data-i18n-title="登录"></div>
```

### `customer/social-quick`（仅快捷）

| 项 | 说明 |
|---|---|
| 提供方 | `account-session.js` + `account-social-quick.js` |
| 能力 | 仅 Google / Facebook 快捷按钮 |
| 用途 | 只需要快捷、不要账密表单时 |
