# 客户账户认证页原型（登录 / 注册 / 找回密码）

## 1. 设计原则

- 与默认主题 Weline UI 2.0 对齐：`w-card`、`w-form`、`w-field`、`w-input`、`w-button`、`w-select`、`w-alert`。
- 与 `forgot-password`（`w-auth-recovery`）视觉同源：居中卡片、图标标题区、统一间距与动效。
- 登录页保留布局层 `account.auth` 的语言切换工具栏（`auth-login-toolbar`），卡片内不再重复内联样式。
- 响应式断点：手机 `<640px`、平板 `≥768px`、桌面 `≥1024px`；卡片最大宽度 `27.5rem`。

### 交互说明

| 区域 | 行为 |
|------|------|
| 用户名 | `autocomplete=username`，Enter 聚焦密码 |
| 密码 | 眼睛按钮切换显示；Enter 提交 |
| 记住登录 | `w-select` 下拉：会话 / 6h / 1天 / 1周 / 1月 |
| 登录按钮 | API 可用时 AJAX；否则原生 POST；busy 态 spinner |
| 成功 | 按钮 success 态 → 800ms 后跳转 `redirect_url` |
| 失败 | `w-alert` danger + 卡片 shake |
| 第三方 | `Weline_Customer::frontend::account::login::providers` hook |
| 人机验证 | `w:form captcha="required" intent="customer.login"`；占位 `<div data-weline-form-captcha-slot></div>` 位于提交按钮上方 |

### 组件映射

| 原型元素 | 实现 |
|----------|------|
| 卡片容器 | `section.w-card.w-auth-login` + `data-w-component="account-login"` |
| 表单 | `w:form.w-form.w-auth-login__form#loginForm` |
| 字段 | `div.w-field` + `label.w-field__label` + `input.w-input` |
| 密码切换 | `button.w-button[data-tone=quiet]` + `data-w-password-toggle` |
| 提交 | `button.w-button.w-auth-login__submit[data-tone=primary]` |
| 页脚注册 | `footer.w-auth-login__footer` |

## 3. 与找回密码页一致性

```
w-auth-recovery          w-auth-login
─────────────────        ─────────────────
w-card 容器              w-card 容器
__header + icon          __header + icon
__messages               __messages
__form                   __form
__footer                 __footer + __social
```

共用 CSS 变量：`--weline-theme-primary-surface`、`--weline-space-*`、`--weline-radius-lg`。

## 4. Hook 向后兼容

第三方登录 hook（如 Multipass）仍输出 `.auth-form__provider`；登录页 social 区内用 CSS 将其映射为 outline 按钮样式，避免改动可选模块。
