# 选项标量投影优化

## 2026-09-13：移除只读 DTO 前的临时 ORM 水化

真实商品列表输入为 335 个已发布商品、335 个代表报价、15,913 条属性行。projectListing 不生成变体轴；分阶段探针显示首个公共目录约 67.12ms 中仅有 5 SQL / 5.30ms，不能将其误判为逐商品 SQL 回源。

进一步测得 catalogWithOptionScopes 为 61.78ms，包含 buildOptionsByAttribute 的 49.23ms。该方法读取上下文里已有的 2,672 条选项行（2,667 条共享行与 5 条私有行）时，items() 仍逐行 clone/reset/clearData/setData 成临时 Option ORM：累计 38.51ms，原始 rows 读取仅 1.35ms，0 SQL。前序修复已复用同请求的 Option DTO，当前缺陷是首次 DTO 投影仍经过无必要的 ORM 中间态。

最小修改只在 AttributeMetadataCatalog::buildOptionsByAttribute：通过已有 rows() 获取标量行，直接生成不可变 AttributeOptionMetadata。保留原有 option-projection 请求缓存、entity 与 scope_instance_id 查询边界、属性子集、语言本地值读取、编码污染回退、源值/代码/ID 回退、swatch 原样字符串与空值、按 ID/code 排序。scope_instance_id 仍是 EAV 产品实例隔离；items() 的可变模型消费接口保持原样。

本次未添加私有静态缓存、WLS 条目、失效协议或生产校验分支。EAV 元数据跨 worker 共享仍需完整 changed writer 覆盖，不能把本次转换优化描述为已完成共享目录缓存。
