## 2026-09-03 — Value 值表解析兼容 EntityDefinition 实体（1.1.10）

- 现象：Filters 侧栏无 EAV 属性面；`AttributeFilterService::getFilterableAttributes('product', …)` 抛「属性没有实体」。
- 根因：`product` 实体类 `ProductCatalogAttributeEntity` 实现 `EntityDefinitionInterface` 而非 `EavModel`；`hydrateAttribute` 无法 `current_setEntity`；`Value::getTable` 只走 `current_getEntity()`。
- 修复：`Value::getTable` 优先 `getEavEntity()->getCode()`，再回落 runtime entity；契约锁定回落顺序。
- 版本：`1.1.9` → `1.1.10`。

## 2026-09-03 — 属性组列表 PDO 报错与页面美化

- **现象**：`/eav/backend/attribute/group` 打开即 500；`PDOException: column entity_local.eav_entity_id does not exist`。属性集列表同因。
- **根因**：`EavEntity\LocalDescription` 主键 FK 列为 `id`，legacy `Attribute\Group::index` / `Attribute\Set::index` 误 join `entity_local.eav_entity_id`。
- **修复**：join 改为 `main_table.eav_entity_id=entity_local.id`；属性组列表/表单对齐 `w-eav-manager-page` + `w-card` 布局；契约测试 `AttributeGroupListContractTest` 锁定列名与壳层；搜索字段扩展与空态（`1.1.8`）。
- **版本**：`1.1.8`。

## 2026-08-29 — 选择属性集抽屉「不满足操作授权要求」

- **现象**：商品创建向导「选择属性集」属性结构加载失败；控制台 `BinQuery ERR call eav_admin.adminRequest 403`；同 Cookie HTTP `/eav/backend/manager/tree` 正常。
- **根因**：不在 EAV ACL/路由，而在 Backend Worker 鉴权：`FrontendWorkerBackendAttestationProvider` 与 `FrontendQueryGateway` 使用不同 `SessionFactory` 实例，principal 校验为空。
- **修复**：见 `Weline_Backend` 开发日志「BinQuery backend auth_error（SessionFactory 双实例）」；本模块无代码变更。

## 2026-08-29 — 属性集选择弹窗加载挂死

- **现象**：商品后台「选择属性集」选中节点后右侧长期「加载中」；控制台 `updateI18nScheduleButton is not defined`，并伴有 `eav_admin.adminRequest` BinQuery ERR。
- **根因**：定时翻译入口移除后挂载末尾仍调用已删除函数，导致 `eav-manager` 挂载抛错；`selectItem`/`renderForm` 的 `detailSequence` 竞态会吞掉后续错误，详情区无法退出 loading。
- **修复**：删除死调用；`renderForm` 支持复用 sequence 并自捕获错误；契约测试禁止 `updateI18nScheduleButton`；`theme:compile welineUi` 同步发布包。

## 2026-08-26 — compare_mode 与 Compare 集成

- **Schema**：`eav_attribute.compare_mode`（Migration `add_eav_attribute_compare_mode_20260826-v1.2.0.php`），枚举 `CompareMode`。
- **公开 API**：`AttributeMetadata::$compareMode`、`AttributeMetadataCatalogInterface::attributeIndexByEntityCode()`。
- **后台**：属性新建/编辑统一暴露可见/可筛选/可搜索/可比模式；`Manager::postAttributeSave` 校验并持久化。
- **消费方**：`Weline_Compare` 硬依赖 `Weline_Eav`，规格行高亮按元数据 `compare_mode` 决策。
- **Product bootstrap**：`ProductCatalogEavBootstrap` 为系统预置属性写入默认 `compare_mode` 并幂等回填。
