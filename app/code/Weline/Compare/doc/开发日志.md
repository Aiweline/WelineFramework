# Weline_Compare 开发日志

## 2026-08-26 — 对比页横向滑动与差异高亮

- **横向滑动**：商品列 `min-width: 13rem`，表格 `width: max(100%, 标签列 + N × 商品列)`；首列属性名 `position: sticky` 固定，多商品时可左右滑动。
- **差异高亮**：`CompareSpecificationMatrix::rowDiffers()` 检测各行值是否不同；价格/评分/SKU 与规格参数行添加 `storefront-compare__row--diff`，使用 `--weline-theme-primary` 主色标记。
- **差异高亮（修正）**：仅属性名（`storefront-compare__label--hit`）与有值的单元格（`storefront-compare__cell--hit`）使用主色文字，不再整行铺背景；空值 `—` 保持默认样式。
- **验证**：`CompareSpecificationMatrixTest` 增补 `differs` 与 `rowDiffers` 用例。

## 2026-08-26 — EAV compare_mode 规格高亮

- **依赖**：`Weline_Compare` 硬依赖 `Weline_Eav`（`etc/module.php` / `register.php`）。
- **Matrix**：`CompareSpecificationMatrix` 注入 `AttributeMetadataCatalogInterface`，读取 `product` 实体属性元数据；新增 `CompareNumericValueParser` 解析 `128GB`、`12 个月` 等数值。
- **高亮**：价格最低标红（独立逻辑）；`none` 不高亮；`diff` 主色标差异；`higher_better` / `lower_better` 最优单元格标红；数值解析失败降级为 `diff`。
- **模板**：规格行使用 `specLabelHighlightClass` / `specCellHighlightClass`，SKU 行无高亮。

## 2026-08-26 — 对比页版心与布局

- 对比页外层 `storefront-compare-layout` 全视口 breakout，内层 `storefront-compare` 使用 `--weline-layout-content-max-width` / `--weline-layout-content-padding-inline`，与页头 `.header-container`、分类页版心一致。

## 2026-08-26 — 对比页空列表修复

- **根因**：`Index::index()` 在 Theme `fetch_file_before` 激活 Website Cookie 作用域（`weline_compare_w0`）之前调用 `CompareService::list()`，读不到对比 Cookie，SSR 恒为空；底部栏由后续 API 读取同一 Cookie，故显示 4/4。
- **修复**：
  - 新增 `ComparePagePresenter`，在内容模板渲染阶段加载对比数据。
  - `CompareSessionStore` 增加 `$_COOKIE` 前缀回退读取（`weline_compare` / `weline_compare_w*`）。
- **验证**：单元测试 `CompareSessionStoreCookieReadTest`；对比页 SSR 与底部栏数据一致。

## 2026-08-26 — 嵌套 fetch 空输出修复

- **根因**：部件模板内嵌套 `fetch(shopper-actions)` 时，外层 `extract(EXTR_SKIP)` 保留 widget 占位字段（如 `product_id=0`、`show_wishlist=''`）；`??` 把空字符串当有效值，三个开关全为 false，partial 提前 `return`。
- **修复**：`ProductCardShopperActionParams` 增加 `resolveProductId` / `resolveFlag` / `fetchDictionary`；partial 只从 Template data 读取，空字符串回退默认（全开）。
- **补全**：Product 模块 `recommended-products`、`related-products`、`cross-sell` 部件接入 shopper 操作与可配置开关。
- **验证**：CLI 渲染 bestsellers 含 `btn-wishlist`；首页 curl 检出 24 处收藏按钮。

## 2026-08-26 — 全站商品卡片 shopper 操作统一

- 新增 `Theme/Helper/ProductCardShopperActionParams` 与片段 `partials/product/shopper-actions.phtml`。
- 所有 Theme 商品部件增加可配置开关：`show_wishlist` / `show_compare` / `show_quickview`（默认 `true`）。
- 覆盖：热销、推荐、新品、特价、猜你喜欢、向上销售、相关、最近浏览、交叉销售、产品轮播；以及 `card`/`grid` 片段、商品列表页与分类页卡片。
- 相关产品移除重复 wishlist 内联脚本，统一走 `product-card-actions.js`。

## 2026-08-26 — Quick View 弹窗修复

- **问题**：商品卡片「快速查看」点击后无弹窗（`Weline.UI.dialog.open` 因缺少 `data-w-component="dialog"` 静默失败）。
- **修复**：
  - Hook 弹窗补全 `data-w-component="dialog"` 与标准关闭动作。
  - `product-card-actions.js` 在 UI.dialog 打开失败时回退原生 `showModal()`；`<a class="btn-quickview">` 也拦截跳转。
  - 各 Theme 商品部件补全 `data-product-id`，相关产品快速查看由链接改为按钮。
- **验证**：首页热销产品卡片点击眼睛图标 → 弹出 Quick View 模态框（含图、价、简介、加购/详情/收藏/对比）。
