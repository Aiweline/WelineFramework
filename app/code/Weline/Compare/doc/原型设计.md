# 产品卡片交互原型（收藏 / 对比 / 快速查看）

## 1. 产品卡片悬浮操作区

```
┌─────────────────────────────┐
│  [♥]  ← 收藏 Wishlist        │
│  [⇄]  ← 对比 Compare         │
│  [👁] ← 快速查看 Quick View   │
│                             │
│      [ 商品主图 ]            │
│                             │
├─────────────────────────────┤
│ 商品名称（两行截断）          │
│ ★★★★☆ (128)                │
│ ¥299.00  ¥399.00            │
│ [ 加入购物车 ]               │
└─────────────────────────────┘
```

- 三按钮垂直叠放，悬停卡片时自右滑入（移动端常显）。
- 所有按钮必须带 `data-product-id`；可选 `data-product-url` 供兜底。

## 2. 快速查看弹窗（Quick View）

```
┌──────────────────────────────────────────────────────────┐
│ 快速查看                                            [×] │
├────────────────────┬─────────────────────────────────────┤
│                    │ 商品名称                            │
│   [ 大图轮播 ]      │ ★★★★☆ (128)                       │
│                    │ ¥299.00  省 ¥100                    │
│   ○ ○ ● ○          │ SKU: ABC-001                        │
│                    │ 简短描述…                           │
│                    │                                     │
│                    │ 数量 [ - 1 + ]                      │
│                    │ [加入购物车]  [查看完整详情 →]       │
│                    │ [♥ 收藏]  [⇄ 加入对比]              │
└────────────────────┴─────────────────────────────────────┘
```

- 使用 `Weline.UI.dialog` + `compare.quickView` API 拉取商品快照。
- 不跳转页面；ESC / 遮罩 / 关闭按钮可关闭。
- 失败时 toast 提示，保留「查看完整详情」链接。

## 3. 对比底栏（Compare Bar）

```
┌────────────────────────────────────────────────────────────┐
│ 对比 (2/4)  [图1][图2]  [清空]  [开始对比 →]              │
└────────────────────────────────────────────────────────────┘
```

- 固定在视口底部，`z-index` 高于页头下拉。
- 最多 4 件；满员时 toast「对比栏已满」。
- 「开始对比」跳转 `/compare`。

## 4. 对比页 `/compare`

```
┌──────────┬──────────┬──────────┬──────────┐
│          │ 商品 A   │ 商品 B   │ 商品 C   │
├──────────┼──────────┼──────────┼──────────┤
│ 图片     │ [img]    │ [img]    │ [img]    │
│ 价格     │ ¥299     │ ¥199     │ ¥399     │
│ 评分     │ 4.5      │ 4.0      │ 4.8      │
│ SKU      │ A-01     │ B-02     │ C-03     │
│ 操作     │ [移除]   │ [移除]   │ [移除]   │
└──────────┴──────────┴──────────┴──────────┘
```

## 5. 模块边界

| 能力 | 模块 | Query Provider |
|------|------|----------------|
| 收藏列表 | `Weline_Wishlist` | `wishlist` |
| 对比 + 快速查看 | `Weline_Compare` | `compare` |
| 商品快照 | `Weline_Product` | `StorefrontCatalogViewService` |

前台统一由 `product-card-actions.js` 事件委托处理，避免每个 widget 重复脚本。
