# Weline_Faq 需求

## 当前需求

- FAQ 文章页（含 SPI，如 `/faq/b2b-wholesale`）成功路径须 `fetch` 内容模板以触发 Theme FAQ 布局链，禁止裸 `return ''` 导致 HTTP 200 空 body。
- `/faq` Hub（`page_type=faq`）SEO head 须输出 `og:image` 与 `og:image:alt`（无页级分享图时可用 Organization.logo / 品牌默认图），避免 SEO 面板 FAIL。
- **1.0.0 万能 FAQ**：实体问答 SPI（`FaqTypeProvider`）+ `weline_faq_item` 存储 + 后台 CRUD + 商品详情 `product-faq` 槽/部件 + Search 索引 + 商品页 SEO FAQ 注入；Hub 种子数据写入 `type_code=site` / `entity_uuid=site`；CMS `path_group` help→faq 迁移。
- **1.0.4 PDP 三层范围**：默认 FAQ 按网站→店铺→渠道继承（`faq_key` 更具体覆盖；下级 `disabled` 抑制）；商品 FAQ 跟实体；SystemConfig `faq/pdp/merge_enabled` + `faq/pdp/active_pack`（`scope=website,store,channel`）；四套模板种子 retail/cross_border/virtual/b2b；PDP widget 与 SEO 共用 `FaqPdpResolveService`；搜索跳过 `type=template`。
- **1.0.6 中英文种子齐全**：模板 pack 与 site Hub 种子至少写入 `zh_Hans_CN` + `en_US`；遗留空 `locale_code` 中文行迁移为 `zh_Hans_CN`，避免英文店面回落到中文。
- 保持模块现有公开行为（`/faq` 命名空间、CMS PageKind、Hub 模板）；新增或变更需求须在实现前记录于此。
