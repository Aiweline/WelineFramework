# Weline Queue 模块 - 队列继续事件

## 概述

`Weline_Queue::continue` 是 `QueueDispatchService::requeueQueueSafely()` 确认成功后的
通知事件，不是继续前的拦截点。

## 成功边界

- 只有无 active/dirty attempt 的 Queue 可按完整快照 CAS 写为
  `pending + finished=0`，并清理 `pid/dispatch_token/dispatch_until`。
- `running`、Worker 启动窗口、残留 fence 或并发快照变化都会失败，且不派发事件。
- 入口为后台 `queue_admin.action/batchAction` 的 confirmed 成功分支；旧 Controller
  GET 写路由只返回 `410`，不再改变 Queue。

该操作不探测、不终止 Worker。如果存在活动代次，应先使用安全 stop 或 takeover。

## 事件数据

```php
[
    'queue' => $queue,
]
```

`queue` 是重新加载的 post-state，其状态为 `pending`、`finished=0`、`pid=0`，
dispatch fence 为空。是否会自动执行仍取决于 `auto`；事件本身不派发 Worker。

## 监听示例

```xml
<event name="Weline_Queue::continue">
    <observer name="Your_Module::queue_continue"
              instance="Your\Module\Observer\QueueContinueObserver"
              disabled="false"
              shared="true"
              sort="100"/>
</event>
```
