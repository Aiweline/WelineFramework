# Weline Queue 模块 - 队列操作事件

## 概述

`Weline_Queue::{action}` 只是文档占位符，不存在从请求 `action` 任意派发的
通配事件。当前固定操作事件为：

- `Weline_Queue::add`
- `Weline_Queue::edit`
- `Weline_Queue::takeover`
- `Weline_Queue::reset`
- `Weline_Queue::continue`
- `Weline_Queue::stop`
- `Weline_Queue::delete`

## 派发边界

- `add`：主表、EAV 属性和消费者校验在同一事务提交后派发。
- 后台表单 `edit`：只在 clean-pending 业务字段 CAS、EAV 属性写入与校验
  同事务提交后派发。
- Query `takeover`：成功后依次派发 `takeover` 与 `edit`；后者是兼容事件。
- `reset/continue/stop/delete`：只在对应安全服务返回 `confirmed=true` 后派发。
- 任何 CAS 竞争、身份不明、进程释放未确认或事务回滚路径都不派发成功事件。

这些事件都是 after-success 通知，不是前置拦截点。

## 事件数据

```php
[
    'queue' => $queue,
]
```

`delete` 的 `queue` 是与条件删除完全一致的删除前快照；其他事件传递重新加载的
post-state。观察者不应再改写 Worker ownership 字段。

## 监听示例

```xml
<event name="Weline_Queue::edit">
    <observer name="Your_Module::queue_edit"
              instance="Your\Module\Observer\QueueEditObserver"
              disabled="false"
              shared="true"
              sort="100"/>
</event>
```
