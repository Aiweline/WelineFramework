## 2026-09-21 — 修 getData 未声明 payment_method 导致 Unknown worker 循环（1.5.20）

- 根因：续付 `getData` 传了 `payment_method`，但 frontend worker 描述未声明该参数 → `Unknown frontend worker param: payment_method`；失败触发 `scheduleReload` → `location.reload` 死循环刷 toast。
- 修：`getData` params 增加可选 `payment_method`；`framework:compile` + `server:reload`；FE 遇该校验错误时剥参重试一次，且校验类错误禁止 hard reload。
- 版本：`1.5.19` → `1.5.20`。

## 2026-09-21 — 续付支付 chrome：空车 blocked 仍注入 + 快路径（1.5.19）

- 根因补充：空车 `checkout_blocked` 时 getData 跳过 `ensureMethodPresent`；`findMethod` 先拉全量支付列表过慢，adopt 超时后前端曾裸拼 `fake_card`。
- 修：selected `payment_method` 时无论 blocked 都 ensure；已知 code（fake_card 等）走 static chrome，跳过慢列表；FE 发现裸 code/无 logo 时用 adopt HTML 覆盖。
- 版本：`1.5.18` → `1.5.19`。
