## 2026-09-08 — API 文档手工 Authorization 调用修复

- 需求：使用 API 文档页面创建、编辑及回读多语言产品；修复阻止该流程的文档工具缺陷。
- 根因：`renderRestTest` 仅在渲染时根据已存登录 Token 固定按钮动作，手工填写 `Authorization` 后仍打开登录框；最小复现为登录框 1 次、网络发送 0 次。
- 修复：调用按钮统一进入 `runRest`，读取当前请求头后判断凭据。受保护接口没有已存 Token 且没有非空手工 Authorization 时保持登录流程；已有手工凭据不被自动 Token 覆盖。服务端权限及同批已有传输修复保持原义。
- 验证：定向 JavaScript 回归：手工 Authorization、无凭据登录、已有 Token 注入、手工凭据优先共 4 项通过；此测试隔离了网络传输，不等于浏览器验收。实际页面引用的脚本禁止缓存回读 HTTP 200，78,954 字节，SHA-256 与当前源码一致。
- 未完成：浏览器控制连接的导航、DOM/无障碍读取、截图均超时，内置浏览器入口也未能取得页面；尚未从页面执行产品创建、编辑和回读，已请求恢复 Weline Chrome 的控制连接。本次未生成新的测试授权或产品。
