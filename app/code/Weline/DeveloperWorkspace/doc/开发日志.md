## `1.3.1` — 前台框架 Tab 改走 panelRequest（2026-08-25）

- 需求 ID：`REQ-DEVELOPERWORKSPACE-0003`
- 事实：`loadRoutes` 等调用 `adminRequest`，前台触发「Operation authorization requirements are not satisfied.」。
- 变更：routes/trace/db explain → `devToolFetchJson`/`developerWorkspaceRequest`；FPC HEAD → `fetch`。
- 测试：`DeveloperWorkspaceAdminQueryProviderTest::testDevToolPanelFrameworkApisPreferPanelRequestBridge`

## `1.3.1` — 超大 HTML 仍注入 lazy bootstrap（2026-08-25）

- 需求 ID：`REQ-DEVELOPERWORKSPACE-0002`
- 事实：`/categories` HTML ≈1.39MB > 默认 1MB，`shouldSkipForResponseSize` 早退导致无面板 bootstrap。
- 变更：体积闸仅跳过完整面板；`shouldUseLazyPanel()` 路径始终注入迷你 loader。
- 测试：`DevToolPanelObserverTest::testOversizedHtmlStillInjectsLazyBootstrapPath`
- 验收：强制 MISS 后 `/categories` 含 `data-weline-panel-bootstrap`；键入 `weline` 可开面板。
