# 文档表唯一键去重

## 主路径

监听 `Weline_Framework_Setup::before_schema_diff_commit`，由 `BeforeSchemaDiffCommitObserver` 调用 `DocumentUniqueKeyHealer`，在 SchemaDiff 创建 UNIQUE 索引之前幂等去重。

## 补路径

`Setup/Upgrade.php`（模块 version ≥ 1.3.1）再次调用同一 Healer，防御漏网数据。

## 表与策略

| 表 | 唯一键 | 保留 |
|---|---|---|
| document_catalog | name+pid | max(id)；document.category_id 先 remap |
| document | module_name+file_path | 非空 updated_at 最新，再 id；子表 remap |
| document_translation | source_document_id+locale | max(id) |
| document_catalog_translation | catalog_id+locale | max(id) |
| document_translation_job | target_type+target_id+locale+source_hash | max(id) |

冲突行备份到 `{table}_dedupe_bak_YYYYmmddHHMMSS`；备份失败不删除。
