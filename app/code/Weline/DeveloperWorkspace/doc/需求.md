### `REQ-DEVELOPERWORKSPACE-0002` 超大 HTML 仍注入 DevTool lazy bootstrap

- 来源与确认：用户于 2026-08-25 反馈前台页面键入 `weline` 不再加载开发面板。
- 背景/问题：`DevToolPanelObserver` 在响应超过 `dev_tool.max_response_bytes`（默认 1MB）时整段跳过注入；`/categories` 等 PLP 约 1.39MB，导致无 `data-weline-panel-bootstrap`，快捷词失效。
- 业务逻辑：体积闸仅跳过完整面板 HTML；lazy 模式下仍注入迷你 bootstrap/loader，使键盘 `weline` 可按需拉取面板。
- 范围：`DevToolPanelObserver` 注入路径与契约测试、本需求/开发日志。
- 非目标：不抬高默认 `max_response_bytes`；不把完整面板内联进超大响应。
- 验收标准：超大 HTML MISS 响应含 `data-weline-panel-bootstrap`；单元契约覆盖 oversized→lazy 路径；键入 `weline` 可加载面板。

- 来源与确认：用户于 2026-08-25 反馈前台 DevTool 点击「框架」出现 toast「Operation authorization requirements are not satisfied.」。

- 验收标准：前台打开「框架 → 路由」无鉴权 toast；契约测试禁止上述 adminRequest 直调。
