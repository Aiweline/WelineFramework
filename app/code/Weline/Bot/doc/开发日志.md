## 2026-09-09 — 修正 zh 词典倒置污染全局文案（1.0.1）

- 现象：中文后台 GEO 等模块弹窗出现 Success / Saved successfully。
- 根因：`i18n/zh_Hans_CN.csv` 将「保存成功」「成功」等中文键误译成英文，全局合并后覆盖正确译法。
- 修：纠正保存成功/成功/删除成功/状态已更新等倒置项，并补 Saved successfully→保存成功。
- 版本：`1.0.0` → `1.0.1`
