# 需求 · Weline_CjDropshipping

作为 `Weline_Dropship` 的默认供应商实现：鉴权探活、拉品 Snapshot、createOrderV3、运费试算、Webhook parse。不拥有 listing 真源。

订单沙盒：配置 `dropship/channel/cj/order_sandbox` 开启后，推单 `createOrderV3` 传 `isSandbox=1`；创建成功后自动 confirmOrder → `simulatePay` → 写运单 → 状态 400/500/600。非法短 storage 降级商家物流时起点国用 CN（勿用仓映射目的国）；推进步骤遵守 CJ QPS。

Webhook：壳保留全部 topic 解析（ORDER/LOGISTIC/MAKEUP/PRODUCT/STOCK/PRIVATE_ORDER/DISPUTE）。**沙盒真推**以订单状态为主；**沙盒不可用**：`disputes/create`（`The Sandbox account is not supported for this feature.`）。勿因沙盒无纠纷关掉 `webhook_dispute`。详见 [功能现状.md](功能现状.md) 矩阵。
