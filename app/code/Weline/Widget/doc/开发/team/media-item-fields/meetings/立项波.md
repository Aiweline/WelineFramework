## 已从用户原话关闭（不再追问）

- 多文件选择与单文件选择用同一套 UI。
- 每个文件项可扩展标题、副标题、按钮等信息，值装在 item 上。
- item 上这些字段要能配置多语言。
- 使用组件时指定 item 字段的 UI。
- 范围是以后同类部件设置，不限这一处 Banner，也不只打回填补丁。

## 待决问题

主题编辑器主路径用 JS `.array-item` 卡片；布局配置用 Widget `ArrayType`。选图已经都进 file-picker，项外壳和子字段多语言包装没有统一。两套都成立且互斥。

## 选项

1. 项外壳只留 Widget `ArrayType` 契约。主题编辑器停用 `renderFallbackArrayItem`。调用方只声明 type 与 item 字段。不新建平行选图控件。
2. 新 `media_items` schema 仍复用 file-picker，但卡片外壳仍须二选一，新 type 消不掉第二套 UI。

## 表态

- 需求分析：异议保留。Q1–Q5 里使用面、单文件是否同一 item、字段 UI 指定位置，用户原话已能关闭；多语言交互跟外壳绑定，不单独再问。不能替用户选外壳。
- 领域探查：同意选项 1 作为推荐。否决「再写一套选图控件」和「Theme 直接 new Widget Service」。外壳归属本人不能拍板。
- 项目经理：同意选项 1 为推荐。按「两套扩展点互斥」停工，等用户选边。

## 决议

2026-09-19 用户确认选项 1：项外壳只留 Widget 数组项；主题编辑器不再自绘第二套卡片；单文件和多文件都用现有 file-picker；字段 UI 在参数声明里指定。

停工解除。下一波是技术方案（Plan），架构师出方案。尚未写业务码。

异议保留：无。选项 2 未采纳。
