## 表态

- 后端：同意。Theme 已用 `Weline_Widget::query` 的 `getConfigForm` 取 HTML，不必 new Widget Service。`expandParams` 与 `renderTranslatableWrap` 已在这条链上。
- 前端：异议。浏览器白名单只分发 `/theme/backend/widget/paramrender/form` → `getConfigForm`。`paramrender/field` / `renderField` 没有分发。`apiText` 已是 `theme.editorRequest`，不是 fetch。替代：数组表单只走这条已接通查询，再 `Weline.Widget.Params.mount`。
- 测试：同意。UC-1 / UC-1a 仍可做 `type=e2e`。现有 hydrate 源码契约不能代替 e2e。

## 决议

采纳前端替代，接口冻结为：

- 数组项 HTML 只许 `ArrayType` 的 `.w-param-array`。
- 主题编辑器发现参数里有数组项时，只用已接通的 `theme.editorRequest` → `paramrender/form`（`getConfigForm`）取整表 HTML，然后 `Params.mount`。
- 不调用 `renderField`，不把 `paramrender/field` 新纳入白名单，不用原生 fetch。
- 这条路径失败时不得再回退 `renderFallbackArrayItem`。
- 不含数组的表单仍可走本地生成。单个文件参数仍是 `MediaImageType`，不改成数组。

异议已吸收，不保留第二套卡片。
