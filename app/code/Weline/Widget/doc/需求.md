## REQ-WIDGET-0001 可配置部件参数

### 需求

Widget 参数系统必须根据参数定义渲染可编辑控件，并保持各参数类型的值处理、校验和预览能力。Theme 等宿主通过公开的参数表单边界获取表单时，不得丢失参数定义或把有配置项的部件渲染为空态。

图片参数必须保留以下既有配置路径：

- 从宿主提供的同源媒体管理器选择图片；
- 从本地上传图片；
- 直接输入图片 URL；
- 已有图片可预览和清除。

### 范围与非目标

- 范围：`Weline\Widget\Ui\ParamType` 的参数控件契约，以及公开参数表单渲染结果与宿主 UI 的兼容标记。
- 非目标：不改变媒体文件权限、上传限制、文件存储策略、Theme 布局保存规则或发布流程。

### 验收标准

1. 有参数定义的部件表单展示对应字段，不显示“无可配置项”。
2. `image` 参数同时展示媒体库选择、上传和 URL 输入入口。
3. 媒体库选择入口使用宿主提供的同源连接地址；取消选择不得改写参数值。
4. 选择图片后回填 URL 并更新预览；清除后恢复空态。
5. 参数值继续通过类型自身的校验与处理，不因 UI 兼容标记放宽 URL 或数据安全规则。

### 权限、安全与数据

- 媒体管理器的认证、授权和文件范围继续由宿主媒体模块负责。
- Widget 只渲染控件和接收返回值，不新增直连业务 HTTP 请求。
- 图片值仍只接受相对路径、有效 URL 或 `data:image/`；本次不改变持久化结构。

### 依据与决策

- `doc/README.md` 已将“参数配置”列为 Widget 核心能力。
- `Ui/ParamType/ImageType.php` 已提供选择、上传、URL、预览和清除控件。
- 用户于 2026-08-22 明确确认该能力此前可用，并要求恢复。
- 兼容修复应复用现有媒体管理器控件契约，不新建第二套选择器或请求通道。
