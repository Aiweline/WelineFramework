### `REQ-SEARCH-PROJ-BATCH` Search 投影增量批消费

- 来源与确认：用户确认治本——增量保持异步，改为批消费，消除每事件 PHP CLI 冷启动风暴。

- 范围：`Weline_Search` 消费者/Drainer + 依赖 `Weline_Queue` 批消费调度契约。
- 非目标：不改同步请求路径；不改投影 CAS/幂等语义。
