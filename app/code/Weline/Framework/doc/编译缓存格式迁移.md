# 编译缓存格式迁移

## 2026-09-13：路径映射与物理目录同步迁移

实际默认站点已解析为 9555，但既有物理编译目录仍烘焙了旧分类和促销 URL。仅把路径映射中的 compile_scope_schema 改成 context-env-v2 不足以排除旧产物：重新计算映射后，Template::stableTemplateCompileDirectory() 仍生成同一个物理目录。

TraitTemplate 现在用唯一私有常量 TEMPLATE_COMPILE_SCOPE_SCHEMA = context-env-v3，同时供 viewEnvironmentCacheSuffix() 的路径映射和 stableTemplateCompileDirectory() 的目录哈希使用。格式升级后，两层缓存同步自然 miss，模板按现有编译流程生成新产物；不执行全量模板清理，也不修改已生成文件。

现有范围、语言、货币、网站 URL、主题与 hooks 摘要维度保持原样；请求 ID、请求路径和查询参数不参与替代已解析环境。版本固定表示编译格式，不随价格、词典或业务资源代次增加目录。

定向验证：在 TemplateCompileOriginScopeTest 的真实环境 fixture 中重建已知 v2 物理目录。修改前目录与当前结果相同，新增断言失败；修改后验证旧目录及 v2 路径映射不再复用，并保留原有来源隔离、目录幂等及请求身份无关断言。正式命令 vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php app/code/Weline/Framework/Test/Unit/View/TemplateCompileOriginScopeTest.php 通过 1 个测试、10 个断言；三份 PHP 文件语法检查与限定文件 git diff --check 均通过。服务加载与默认站点实际页面验收由主任务继续完成，不把单测视为运行验收。
