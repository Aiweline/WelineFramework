# 店面范围就绪门禁

`Weline_Framework::App::storefront_scope_ready_gate` 在前台请求的 Website、Store、SalesChannel
范围安装完成后派发，执行时早于缓存键冻结与任何 Full Page Cache 查询。

观察者只应执行必须依赖已冻结 `ScopeIdentity` 的轻量、只读、fail-closed 门禁。观察者不得改写
范围身份、派发控制器、启动 Session、执行业务集成或生成可缓存页面内容。

事件数据：

- `navigation_scope`：当前 `StorefrontNavigationScope`；后台、静态或延迟范围请求可能为 `null`。
- `scope_identity`：当前已冻结 `ScopeIdentity`；未安装店面范围时可能为 `null`。

Scope 维护、店面封禁等安全检查应使用本事件，确保缓存命中与缓存未命中遵循相同门禁。
