# 应用上下文就绪通知

事件：`Weline_Framework::App::application_context_ready`。

位置：`App::applyParsedUrl()`，在既有 `storefront_scope_ready_gate` 返回后、缓存身份冻结及任何正式 FPC 查询之前。该通知让使用方按已安装的范围构造中性应用输入，不新增拒绝门禁、发布状态或另一套请求运行时。

事件数据：

- `area`：本次宿主请求区域 `frontend` 或 `backend`。
- `scope_identity`：现 RequestContext 中的不可变 ScopeIdentity，后台可能为 null。
- `navigation_scope`：已解析 StorefrontNavigationScope，后台可能为 null。

使用方 observer 只负责自己拥有的应用配置及已验证身份，向现 RequestContext 安装不可变中性 DTO。框架不读业务模型，不决定网站使用哪一个主题。安装正式 `runtime` 输入不得以 URL 的 theme_id/editor_mode/purpose 改写正式选择。

该事件没有后台登录或目标权限的保证；不能在这里凭浏览器 scope 声明授权编辑。后台网站编辑使用现 `Weline_Framework_Router::route_before`（网站 observer 排在 ACL sort=1 之后），再校验真实目标的 VIEW/UPDATE 权限；主题资产编辑由 Theme 的资产权限入口负责；后台界面引用由系统配置使用方负责。正式、编辑、Token 预览与资产示例输入各自固定用途，不能覆盖本次已安装的正式输入。

使用方改动配置的实际失效与版本资源校验沿归属模块公开契约完成，不在此通知中跨模块直调内部 Service/Model，也不写 generated 注册文件。
