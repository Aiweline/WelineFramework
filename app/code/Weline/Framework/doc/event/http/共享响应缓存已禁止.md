# Weline_Framework::response::shared_cache_forbidden — 共享响应缓存已禁止

## 事件说明

`SharedResponseCachePolicy::forbid()` 已对当前请求写入浏览器侧
`Cache-Control: private, no-store…` 并标记共享 FPC 不可入库后触发。

可选观察者（如 `Weline_Cdn`、`Weline_Server`）在确认 `cache_control` / 响应头含
`no-store` 后，写入**各自供应商**的边缘或旁路头。业务模块（Theme 等）只应调用
`forbid()`，禁止直写 `CDN-Cache-Control` / `Cloudflare-*` / `X-Wls-Fpc-Status`。

## 事件类型

**Integration Event**

## 触发时机

`SharedResponseCachePolicy::forbid()` 写完 HeaderCollector 之后、返回调用方之前。

## 数据格式

```php
[
    'reason' => 'theme_layout_solidify_fallback_original', // 可选：本次原因
    'reasons' => ['theme_layout_solidify_fallback_original'], // 累计原因
    'cache_control' => 'private, no-store, max-age=0, must-revalidate',
]
```

## 观察者约定

1. 若 `cache_control`（或 HeaderCollector 上的 `Cache-Control`）不含 `no-store`，应 no-op。
2. 只写本供应商拥有的头；不得改业务 HTML。
3. 失败不得打断 `forbid()`（派发侧已吞异常）。
