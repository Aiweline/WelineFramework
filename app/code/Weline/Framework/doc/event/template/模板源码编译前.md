# 模板源码编译前

`Weline_Framework_Template::before_compile` 在 `Template::tmp_replace()` 进入普通 Taglib 编译前触发。文件模板、`getFetchFileFromSource()` 固定源字节和虚拟模板共用该入口；Framework 不依赖任何主题模块。

事件载荷是 `DataObject`，Observer 通过 `$event->getData('data')` 读取。

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `content` | string | 原始模板源码；可用 `setData('content', ...)` 替换 |
| `tplFile` | string | 原始源路径，用于模块来源、相对引用与错误定位 |
| `template` | Template | 当前请求模板实例，普通模板数据和 `$this` 语义不变 |

观察者只能把源码转换成普通模板或 PHP 调用。不得在此执行页面查询、渲染组件、读取请求中的持久布局树，或把当前实例的动态数据固入编译缓存。转换应在相同源码和编译环境下确定，并能处理嵌套调用。

注册使用模块 `etc/event.xml`，监听上述精确名称。编译产物沿用语言与环境分区的 `com_*`，摘要来自同次读取的原始字节；观察者注册配置也参与编译缓存标识。编译后事件仍为 `Weline_Framework_Template::after_compile`。

`Template::pinSource(logicalPath, sourceBytes, originPath, contextKey)` 将读取与后续编译分离；`getFetchFileFromSource()` 返回普通编译文件，`fetchSourceHtml()` 通过当前 Template 执行。源字节修订使用不同内容地址，并经临时文件原子替换发布；旧修订晚编译不能覆盖新修订。来源模块保存在模板实例上下文，嵌套渲染后恢复，不修改或复制 Request。
