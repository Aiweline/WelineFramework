# Weline_Framework_Phrase::dictionary_collect

Phrase 请求词典收集事件：允许模块向当前请求贡献运行时词典层。

## 触发时机

当前请求第一次执行 `__()`、`Parser::parse()` 或 `Parser::parseKey()` 时触发，同一请求作用域只触发一次。词典提供方（如 PageBuilder 页面控制器）在建立或清理自己的请求词典上下文后，可调用 `\Weline\Framework\Phrase\EventDictionary::refresh()` 使下一次 Phrase 调用重新收集。

## 事件数据

```php
$eventData = [
    'request_id' => $requestId,
    'locale' => $locale,
    'modules' => $modules,
    'layers' => [],
];
```

## 词典层结构

Observer 只能向 `layers` 追加词典层，不得移除或修改其他 owner 的层：

```php
[
    'owner' => 'GuoLaiRen_PageBuilder',   // 贡献方模块名（必填）
    'name' => 'page',                     // 层名（site/page 等）
    'scope_key' => 'pb:12:380:en_US:siteHash:pageHash',
    'mode' => 'exclusive',                // overlay 或 exclusive
    'priority' => 200,                    // 数值越大越优先（页面层覆盖公共层）
    'hash' => '...',                      // 词典内容哈希
    'words' => ['联系我们' => 'Contact Us'],          // source_text => 译文
    'keyed_words' => ['entry-key' => 'Contact Us'],  // entry_key => 译文
    'error' => null,
]
```

## 合并规则

- `overlay` 层与 Framework 现有词典叠加（事件层优先，未命中回退既有词典路径）。
- 存在 `exclusive` 独占层时：只使用该 owner 的层；不加载模块 CSV、全局语言包或数据库全局词典；缺词返回默认语言原文。
- 层按 `priority` 升序合并，高优先级层覆盖低优先级层（如页面层 200 覆盖公共层 100）。
- 两个不同 owner 同时声明 `exclusive` 视为作用域冲突：开发环境抛出异常，生产环境记录错误并对全部词返回原文。
- 词典提供方读取失败时应仍提供空独占层，禁止错误回退到全局词典。

## 隔离约束

- 事件词典只存在于请求作用域（Fiber/Request Context），不得进入只按 `locale + modules` 区分的全局 Phrase 缓存。
- 该事件是 Phrase 扩展点，不是 Framework 主动查询业务模块；Framework 不调用业务模块 Service 或 Model。

## 相关

- `Weline_Framework_Phrase::dictionary_ready_after`：词典组装完成诊断事件。
- `Weline_Framework_Phrase::word_missing`：缺词通知事件。
- `Parser::parseKey(string $entryKey, string $fallbackSource, mixed $args = null)`：按 entry_key 精确取词。
- 旧事件 `Weline_Framework::get_words_file` 保持兼容。
