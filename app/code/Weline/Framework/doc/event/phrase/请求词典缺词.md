# Weline_Framework_Phrase::word_missing

请求事件词典缺词通知。

## 事件数据

```php
[
    'request_id' => '...',
    'locale' => 'en_US',
    'scope_key' => 'pb:12:380:en_US:siteHash:pageHash',
    'source_text' => '联系我们',
    'entry_key' => null,   // parseKey() 缺词时为 entry_key，__() 缺词为 null
    'owners' => ['GuoLaiRen_PageBuilder'],
]
```

## 规则

- 只在存在事件词典层的请求中触发。
- 同一请求内相同缺词只通知一次。
- 不传占位符实际值，避免记录用户数据。
- 词典提供方只应记录缺词，不得在访客请求中调用 AI 或修改发布词典。
- Phrase 最终返回默认语言原文并继续处理占位符。
- Observer 异常不能影响页面输出（Framework 捕获并记录到 phrase 日志）。
