# Weline_Framework_Phrase::dictionary_ready_after

请求事件词典组装完成后派发。

## 用途

只用于诊断、性能记录和前端词典快照准备。

## 事件数据

```php
[
    'request_id' => '...',
    'locale' => 'en_US',
    'scope_key' => 'pb:12:380:en_US:siteHash:pageHash',
    'mode' => 'exclusive',
    'owners' => ['GuoLaiRen_PageBuilder'],
    'layer_hashes' => ['site' => '...', 'page' => '...'],
    'word_count' => 120,
    'keyed_word_count' => 138,
]
```

## 约束

- Observer 不得修改词典。
- Observer 不得重新查询、调用 AI 或写入发布词典。
- Observer 异常不能影响页面输出（Framework 捕获并记录到 phrase 日志）。
