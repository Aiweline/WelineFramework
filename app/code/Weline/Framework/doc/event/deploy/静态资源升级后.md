# 事件：`Weline_Framework_Deploy::upgrade_after`

`php bin/w deploy:upgrade`（`Weline\Framework\Console\Console\Deploy\Upgrade`）在静态双树铺平、权限归一，以及（未 `skip_invalidation` 时）FPC deploy 世代 bump 之后派发。

## 载荷

| 键 | 说明 |
|----|------|
| `tree_changed` | 本轮是否写入了与目标不同的静态字节 |
| `skip_invalidation` | 是否跳过 FPC bump（如 Mode\Set 已强失效） |
| `args` / `data` | 命令入参 |

## 典型观察者

- 截至 2026-10-31，`app/code` 下已无模块在本事件上注册观察者（`grep -rn "Weline_Framework_Deploy::upgrade_after" app/code --include=*.xml` 无命中）。Framework 侧仍照常派发。

`deploy:upgrade` 不再挂 Theme 观察者：`Weline_Theme::deploy_upgrade_purge_layout_entities` 已于 2026-10-31 从 `Theme/etc/event.xml` 解绑，
因此本事件收尾既不清 `var/runtime/theme-layout-entities/`，也不重固化主题产物。主题产物由 `php bin/w theme:update` 构建；
主题观察者 `SetupUpgradeAfterPurgeLayoutEntities` 现只挂 `setup:upgrade`。

权威：`app/code/Weline/Theme/doc/布局固化与默认注入.md` §3.4。
