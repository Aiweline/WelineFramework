# 汇审 — 公开文案槽与 HTML 缓存入库闸

日期：2026-09-21  
模块：Weline_Framework `2.5.120`  
结论：通过（本波目标）

## 需求 / 架构

技术方案会冻结：模块码泄漏不是 about 单页问题，收敛为两个框架不变量。

1. 公开文案槽（`title` / `meta.title` / `meta_title` / `controller_title`）不得保存 `Vendor_Module` 标识。
2. 进程级 HTML 缓存（FPC / hook / reusable）共用 `HtmlCacheAdmission`：拒绝毒化 body，不改写后入库。

撤掉按症状补丁：`Response::setBody` scrub、about 专用 FPC 正则、about H1 核化写死。

`work_kind=bugfix`（框架正确性），`fe_be_scope=BE+布局护栏`，UI 技能 skip（无视觉改版）。

## 修复

1. `EmbeddedPageTitle`：`sanitizePublicSlots` / `htmlAdmissible` / `isInternalIdentifier`；`isModulePlaceholder` 保留。
2. `Template::setData` / extract 前清洗公开槽；hook / reusable 写前 `HtmlCacheAdmission::admit`。
3. `FullPageCacheCoordinator` 三路径（publish / hit / stale）统一 `HtmlCacheAdmission::admit`。
4. `ControllerFetchFileBefore::sanitizeRuntimeLayoutParams` 改调同一闸。
5. Theme / hanfu about：H1 恢复为清洗后的 `$title`，空或模块码则源语「关于我们」回退。
6. `WidgetI18n` 拒绝模块码译文（`isInternalIdentifier`）。
