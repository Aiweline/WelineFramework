## P1 — 高（机制副作用 / 热路径 backlog）

### P1-1 · homepage fail-open 默认 + deferred 窗口（保留默认 · 残余窗口）

| 字段 | 内容 |
|------|------|
| **现象** | `ready_gate_homepage_fail_open` 默认 `'1'`；`storefront_deferred_warmup_enabled` 默认 `'0'`；fail-open/未 HIT 时强制 deferred |
| **为何不合理** | 架构师 M3：**同意保留** fail-open（可用性优先，禁回退严格 READY prime）。残余不合理：READY→deferred 完成前的**公网首击窗口**仍可全量 SSR；flag 默认关靠耦合强制，运维可读性差 |
| **证据** | `WlsRuntime`；`surfaces.md` R2；架构师 msg-2 M3 |
| **建议归属席** | **后端**（保证 deferred/`/` 首槽/公网 Host/真 HIT 不回退）+ 文档澄清；**勿**改默认 fail-open=0 当「修不合理」 |

### P1-2 · Process L1 挤出 + legacy 全清叠加（M5）

| 字段 | 内容 |
|------|------|
| **现象** | Process FPC：`MAX_ITEMS=128`、`MAX_BYTES=32MB`；多 MB warmup 可挤掉首页 L1；本窗 `/` 连续两次直连仍 MISS，`/products` #2 才 HIT |
| **为何不合理** | 预热保活不足 → receipt-missing / 二次 SSR。架构师 M5：带 epoch 的 L1 合法；**更危险**是 legacy 全清广播清空跨 Worker 热层 → 人为冷瀑布（与 I18n/Website/Theme 全清叠加） |
| **证据** | `FullPageCacheCoordinator` L1252–1254、L72–73、L3144–3167；本机直连；架构师 msg-2 M5 |
| **建议归属席** | **架构师**（L1 保活 + 禁无 epoch 袋）+ **后端** + **I18n/Theme**（收敛全清） |

### P1-3 · 出站 `private, no-store`（观测副作用 · **非 FPC 设计错误**）

| 字段 | 内容 |
|------|------|
| **现象** | 入池快照后对**当次 SSR 出站**统一 `Cache-Control: private, no-store…`；冷 MISS 探针必见 no-store；入池头不变 |
| **为何不合理** | **机制意图正确**（防 Nginx 把 MISS 正文当 edge 毒缓存；架构师 M2：**异议「当缺陷」/同意「有副作用」**）。不合理在**观测面**：探针/运维易把出站 no-store 误读成「FPC 坏了」；与「敏感页才 no-store」文档口径易混。**禁**为好看头去掉该防护 |
| **证据** | `FullPageCacheCoordinator::publishResponse` L570–576；契约 UT；本机直连 MISS 头；架构师 msg-2 M2 |
| **建议归属席** | **架构师/文档**（拆口径：「MISS 出站装饰 ≠ 入池失败」）+ 验收纪律 |

### P1-4 · status/owner 不对称（UX · 禁假 HIT）

| 字段 | 内容 |
|------|------|
| **现象** | Owner Worker#1=`adopted/hot`；peer Worker#2 长期 `fail-open/hit=false` |
