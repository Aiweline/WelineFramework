## 汇审 · 改产品是否令该页/FPC 失效（2026-09-21 团队实测）

### 架构结论（Team:架构师）

| 环节 | 状态 |
|------|------|
| 后台改商品 → `ProductSearchProjectionMutationCoordinator` → `w_changed(product_search_projection)` | 设计正确 |
| `ProductSearchProjectionChangedType` recipe：`bump_namespaces`(sync) + `purge_fpc_urls`/`cdn`(after_commit) | 已挂 |
| `impact.namespaces=website/{code}/catalog`；店面键向量本就含 catalog | 已对齐 |
| 业务旁路整池清 | 已从 Coordinator 路径去掉 |

### 实测证据（Team:测试）

样本商品：`product_id=179` ·  
`/product/hua-chao-ji-2023xin-kuan-nu-han-fu-tao-xi-zhong-gong-xiu-hua-da-xiu-sh-6dbce2f7`

| 探针 | 结果 |
|------|------|
| `ChangedPipeline.process` 后 catalog 代次 | **会涨**（例 8325→8326…8330）且 CLI 指纹变 |
| `publishAndWait` namespace invalidate | Worker×2 可 **ACK applied=true** |
| 经 nginx `:9555/` 观察 HIT→MISS | **未观察到 MISS**；持续 `x-weline-fpc: HIT` + `src=process` + `edge=UPDATING/STALE`，约 5–10ms |
| PDP FPC 头 | 多数 **无** `x-weline-fpc`；偶发 504/慢；无法做 HIT→MISS |
| Extra 侧车 | 曾 **NO_SIDECAR**；已收集；`public_path_patterns` 曾被 `[^\n*]` 截断 `*`（已修） |

### 缺口（Team:后端 / 架构师）

1. **`NamespaceBumpCapability` 原先只 bump 库、不 publish IPC**；本回合已补 `committedCallbacks` → `RuntimeNamespaceInvalidationPublisher`，并打开 `publisher_enabled`。
2. **即便 Worker ACK 已 applied，经公网 Host 仍看不到 MISS** → 首页 process receipt / nginx edge UPDATING / keep-warm 瞬时回填 需继续拆（直连 Worker `:19655` 超时，shared_fd 拓扑）。
3. **`FpcCapability` URL 定向删键弱**（无 `deleteMatching` 时靠猜键）；正确性仍绑 ns。
4. **完整 `coordinator.execute` + event dispatch** 易长时间卡在大数组拷贝（i18n/Search 路径）；管线本身可秒级完成。
5. Extra 解析：`ExtraCollector` 自身注释曾误扫；`@Extra` 行不可用 `[^\n*]`（已修）。

### 团队裁决

**不能宣称「改后端产品后该 PDP/首页 FPC 已实测失效」。**  
只能宣称：写路径会 bump catalog，且 IPC publish 可被 Worker ACK；**端到端页面失效（HIT→MISS）本回合未证成。**

后续硬门槛：nginx 旁路或 Worker 内观测下，对同一 URL 打出明确 MISS，再宣称验收通过。
