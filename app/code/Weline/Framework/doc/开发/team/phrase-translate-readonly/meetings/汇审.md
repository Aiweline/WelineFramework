# 汇审 — phrase-translate-readonly

- 日期：2026-09-21
- 范围：`Weline_Framework` Phrase `__()` 读路径；版本 `2.5.134`
- 问题：setup:upgrade 卡在 `Weline_Visitor::ensure_dashboard_pages`（约 235s），采样为 `zend_array_dup`；Postgres 挂着 `w_i18n_locale_dictionary` 整表查询（词典约 273 万行 / 845MB）
- 方案：翻译函数只读文件/缓存；缺词原样返回；收集/DB hydrate/AI 移出翻译路径；删除旧 `dictionary_collect` / `word_missing` / `dictionary_ready_after` 事件与死分支
- 证据：
  - UT：Phrase 相关 **105 tests / 493 assertions PASS**
  - 复现：`VisitorDashboardPageInstaller::ensurePages()` **~547ms / success=true**（修复前同路径约 235s）
- 结论：通过；非 `w_pixel` 事件表备份问题
- 残余：AI/DB 词典需先 publish 到 `generated/language/*.php`；菜单等显式 `prefetchWords` / `prefetchGlobalDictionaryModules` 写入的缓存可被 `__()` 只读消费，翻译热路径不再自动 hydrate / collect
