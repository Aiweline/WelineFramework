## 待决问题

Worker 散落进程袋 + 多语词典在高压下易 OOM；希望统一进缓存类、智能淘汰；共享缓存服务不动。

| 选项 | 内容 | 结论 |
|------|------|------|

## 决议（冻结）

### 架构一句话

把可重建进程 memo 收成 Framework **`ProcessMemoryStore`（热度管容量、请求/Fiber 钉住管压力保护、locale 桶管词典）**；Adapter L1 仍走 **`MemoryStoreInterface`**；压力回收走 **`MemoryReclaimableRegistry` + Guard**；显式清理走 **`ProcessCacheResetter`**；共享 L2 / Memory **服务侧不动**；**永久禁止** CachePool `processStore`。

### 分层

```text
业务 / Phrase /（后期）FPC-L1·HotCache·菜单
        │
        ▼
 ProcessMemoryStore ──adapter──► MemoryReclaimableRegistry
        │
        ├── heat：容量 LRU
        ├── pin：请求/Fiber 作用域（压力下 pin>0 不删）
        └── bucket：locale（重语种默认 ≤4）

 Adapter.localCache ──► MemoryStoreInterface
        │                    ▲
        │                    └── ObjectManager.relieve（W1=Policy，禁 soft 盲清）

 Guard soft0.70 / hard0.85 / drain
        └── Resetter(MEMORY_PRESSURE) + Reclaimable +（hard）FPC last-resort

 Shared L2：CachePool → Adapter → WLS Memory 服务（本波只读）
```

### 淘汰序（硬）

`pin_count` 升序 → `heat` 升序 → 大字节优先。  
soft：pin=0 半清；hard：pin=0 全清再目标字节；不新增 0.90 阈值。

### 波次

| 波 | 范围 | 门禁 |
|----|------|------|
| W0 | 本文档 + 规格 + 契约 UT 骨架 | 无行为变更 |
| **W1** | `ProcessMemoryStore` + Policy；OM relieve Policy 化；WlsMemoryAdapter 压力对齐 | pin 与 Policy **同批**；服务侧零 diff |
| **W2** | Phrase 袋迁 Store + locale 桶 | 重语种≤4；事务 ephemeral |
| W3 | FPC-L1 / HotCache / 菜单 | 须 W1+W2 稳定 + 单独安全过目 |
| W4 | 扫尾禁平行 static | 汇审 |

### 否决项

1. CachePool `processStore`  
2. 改共享 Memory 服务淘汰  
3. 业务平行 static LRU  
4. 用 zval/lease 代替请求作用域 pin  
5. `!canCompactProcessCaches()` 时清袋  
6. soft 清 FPC L1  
7. ProcessMemoryStore 再实现 MemoryStoreInterface（与 Adapter 语义撞车）
