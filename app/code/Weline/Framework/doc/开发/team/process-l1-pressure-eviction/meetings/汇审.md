## Title×locale 修复（2.5.131 + Seo 1.2.96 + Theme 2.2.509）

结论：**已修复**（探针硬失败清零）

### 根因
1. Theme `unsetData` 后 Partials head 丢失 controller title  
2. `PageSeoContextResolver::routeTitle` 把 URL 末段人化成英词（`contact`→`Contact`，`guide`→`Guide`）抢占 `<title>`  
3. 并发下更易复现：H1 中文正确、`<title>` 英词（埋点 `latin_title_on_zh`）

### 修复
| 模块 | 变更 |
|------|------|
| Seo `1.2.96` | `routeTitle()` 恒空；契约 UT |
| Theme `2.2.509` | `publishPageTitleToSeoBag`；Policy 壳 `WidgetI18n::label` |
| Customer/Currency | title 用 WidgetI18n + 发布 SEO 袋 |
| Framework `2.5.131` | Phrase `ParserRequestState` Fiber 隔离；`State::getLang` 路径优先 |

### 验收
- UT：`RouteTitleNotHumanizedPathContractTest` + `ParserFiberRequestStateIsolationTest` PASS  
- 交叉（guide/contact/terms/activity/currency，`__title_locale=1`）：**`title_locale_mismatch_n=0`**  
- 残余软项：个别 currency 轮次 title 回退站点名（非英词串语种），另波可收

## Title×locale 埋点（2.5.128）

- 类：`View/Helper/TitleLocaleProbe`；闸门 `__title_locale=1` / MemDiag / dynamicObservability
- 响应头：`X-Weline-Title-Locale`、`X-Weline-Title-Locale-Mismatch`
- UT：`TitleLocaleProbeTest` **7/22 PASS**
- 交叉（guide/terms/contact/activity/currency/about，72 jobs）：`seen=60`，**`mismatch=2` 硬失败**  
  - `/zh_Hans_CN/guide` → `latin_title_on_zh|Guide`  
  - `/zh_Hans_CN/customer/contact` → `latin_title_on_zh|Contact`  
- 串行单次 `/zh_Hans_CN/guide?__title_locale=1`：`mismatch=0`（`指南`）——串扰为**并发复现**

埋点已能抓住串扰；根因修复另波。

脚本：`Test/Manual/cache_isolation_locale_cross_correctness.py`  
规模：6 语 × 15 路由（含 FAQ/条款/指南/活动/货币/联系我们/商品/搜索/分类）+ PDP + 后台登录；conc=40；rounds=5；**850 jobs**；HTTP 200=749。

| 断言 | 结果 |
|------|------|
| `theme_placeholder_leak`（about H1 模块码） | **0** |
| `cross_locale_content_h1`（about 串另一语 H1） | **0** |
| FE↔BE / PDP 串 slug | **0** |
| `identity_unstable_across_rounds`（同 URL 多轮 title 漂移） | **失败 ×26** |

不稳定样例（文档 `<title>` 串语种，非 about H1）：

- `/zh_Hans_CN/guide`：`指南` ↔ `Guide`
- `/en_US/guide`：`指南` ↔ `Guide`
- `/de_DE/activity`：`活动专题` ↔ `Seite`
- `/fr_FR/customer/contact`：`Nous contacter` ↔ `Contact`

结论：Phrase/about 闸在交叉下稳住；**政策/指南/活动/货币/联系我们等页的 document title 仍有跨语种缓存串扰**，需另开波修 meta/title×locale 入库键（与 W1 Phrase 袋不同面）。

报告：`/tmp/cache_isolation_locale_cross_correctness.json`
