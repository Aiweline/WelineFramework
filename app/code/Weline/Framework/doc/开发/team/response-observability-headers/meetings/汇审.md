## 产品定义（完成即闭环）

店面匿名 GET 在观测闸门关闭时，响应头仅允许：

| 允许 | 说明 |
|------|------|
| 标准 HTTP / nginx | `server` `date` `content-*` `vary` |
| 安全头 | `x-frame-options` `x-content-type-options` `x-xss-protection` 等 |
| 缓存身份 | `x-weline-fpc` `x-wls-fpc-status` `x-wls-edge-cache` |
| 请求追踪 | `x-weline-request-id`（动态/MISS） |
| 会话 | `set-cookie`（业务契约，非观测） |

**禁止（闸门关时）：** Worker 身份/资源、`X-Powered-By`、`X-WLS-Performance-*`、`First-Render`/`Warmup`/`Controller-Cache`、公网 `X-Wls-Nginx-Config`、`Process-Time`/`Server-Timing`/`SSL-Engine`、`Redirect-Cookies`、Admin `X-WLS-Admin-*` 性能头。

**明确不在产品范围：** Set-Cookie 清场策略本身（会话绑定）。
