## 2. 机制冻结（硬）

### B′ — 默认 owner deferred **禁止**多语全量页面 SSR 计入必跑墙钟

| | |
|--|--|
| **默认** | `locale_idle` 全量 HTML SSR **预算 = 0**（推荐 env：`wls.worker.storefront_locale_idle_budget` 默认 `0`） |
| **允许** | （可选后续）**cheap probe** 模式：仅轻量探测（禁全页 body SSR）；须独立开关且不得冒充 FPC HIT |
| **Provider** | `FpcWarmupProviderInterface` **仍可声明** locale 路径；编排层记入 `locale_deferred_paths`；**默认不执行**全量 SSR |
| **必跑墙钟口径** | owner deferred 必跑 = `pre_critical` + critical `/`+`/products` seal + `post_critical_heavy`（+既有 idle-gate）；**不含**多语全量 HTML SSR |
| **绝对目标（建议 · 性能席可收紧）** | 必跑墙钟 ≤**3–5s** 量级，或以 critical 两路径+种袋为准；复审以性能席绝对值为准 |

### 明确否决 / 禁止

| 禁止 | 理由 |
|------|------|
| 假 HIT | 继承硬；空投影/未暖 locale ≠ HIT |
| 关整个 deferred | fail-open 仍依赖 owner critical 暖；关 deferred 无法保首 HIT |
| 平行袋 | 继承硬 |
| 把「移到 idle」当已解决绝对墙钟 | idle 全量 SSR 仍占 owner 事件循环 = 仍是缺陷 |
| 永久挤掉 `/products`（`max_paths=1`） | 继承 B 否决 |

### 与 P3–P6「B」关系

- 近处女窗 `localeBudget=0`（critical 先 seal）**保留**。
- **纠正**：`localeIdleBudget` **不得**再默认继承 `max_paths−critical`；默认 **0**，与 `localeBudget` 脱钩。
- 显式 env &gt;0 才允许 ops 打开有界全量 locale SSR（非本波默认；打开后须接受墙钟与 CPU 风险，且禁假 HIT）。
