## 2. 机制冻结（硬）

### O1 — `locale_idle_skipped`（或未跑 locale SSR）后 **不得**默认同成本再跑 `post_locale` 全量 bag（硬 · **本波主线**）

| | |
|--|--|
| **裁定** | 当本轮 **未执行** locale 全量 HTML SSR（含 stage `locale_idle_skipped`，或 `localeList` 空且未跑 locale FPC）时，**禁止**默认再跑与 skip 前同成本的 `primeDeferredStorefrontHotCacheBags('post_locale')` 全量 seed |
| **允许** | **skip**（打 stage 日志即可）· **peek-only** 轻触 · **no-op stage**（如 `post_locale_skipped` / `post_locale_noop`，须含 reason：`locale_idle_skipped` / `locale_ssr_not_run`） |
| **仍允许全量 post_locale 的条件** | 仅当本轮 **实际跑过** locale FPC SSR（`localeIdleBudget>0` 且 `localeList` 非空并进入 `runStorefrontFpcWarmupInternal(locale…)`）之后，为抗 eviction 的 **有界 retouch**；且不得假 HIT |
| **必跑墙钟口径（更新）** | 继承 B′：`pre_critical` + critical `/`+`/products` + `post_critical_heavy`（+idle-gate）；**不含**多语全量 SSR；**亦不含**「locale 已 skip 后的同成本 post_locale 全量 bag」 |
| **绝对目标** | `done.elapsed_ms` **≤5000**（推荐 **≤3000**）；复审看绝对值；**禁**相对 11294/P4/P6 伪加速比 |
| **归属** | **后端** · `WlsRuntime::runDeferredStorefrontCriticalWarmup`（≈1562 邻域） |
| **扩展点** | 既有 BagWarmup **Interface**；不新建 Event；不新建平行袋 |
