# HTTP 状态回执页渲染

事件名：`Weline_Framework_Http::error_page_render`

在 `ErrorPageRenderer` 加载 `pub/errors/{code}.php` 之前触发，供站点/模块整页覆盖或改写文案。

## 数据字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `status_code` | int | HTTP 状态码 |
| `status_text` | string | 标准英文短语 |
| `message` | string | 运行时消息 |
| `page_title` / `page_lead` / `page_hint` | string | 展示文案 |
| `home_href` | string | 首页链接 |
| `request_id` | string | 请求 ID |
| `detail` | string | 开发细节 |
| `is_dev` | bool | 是否开发态 |
| `html` | string | 观察者写入非空则整页覆盖 |

## 示例

```php
public function execute(Event &$event): void
{
    $data = $event->getData();
    if ((int)($data['status_code'] ?? 0) !== 404) {
        return;
    }
    $event->setData('html', '<!DOCTYPE html><html><body>自定义 404</body></html>');
}
```

站点文件覆盖优先路径：`pub/errors/404.php`（见 `pub/errors/README.md`）。
