## `2.4.0` — HTTP 状态回执页可定制

- 当前状态：`implemented`
- 需求 ID：`REQ-FRAMEWORK-0005`
- 范围：`ErrorPageRenderer`、`NoRouterException`、`WlsRuntime`、`HtmlRenderer` 生产页、`pub/errors/{400,401,403,404,410,429,500,502,503,default,_shell}`、事件 `Weline_Framework_Http::error_page_render`。无 schema 变更。
- 事实/发现：旧模板 `echo 404`；WLS 二次 include 未注入 `$msg`，生产出现纯文本三字节正文。

## `2.4.0` — QueryBin 不得把 runtime_task 拒绝伪装成 500

- 当前状态：`implemented_validated`
- 需求 ID：`REQ-FRAMEWORK-0004`
- 范围：`QueryBin` 对 `ResumableTaskAccessDeniedException` 映射为 401；无 schema 变更。
- 事实/发现：媒体管理 `media_manager.connector/config` 返回 500 `Internal server error.`，日志为 `Runtime task backend authority no longer matches the Session.`。
- 实现：在通用 `Throwable` 之前拦截该异常，返回 `backend_attestation_invalid`。
- 验收：`QueryBinResumableAccessDeniedMappingTest` 2/2。2026-08-18 内置 Browser，test 登录文件管理：`connector open` 返回 Media Files / 5 files / tree 3，`config` 成功，页面无红色 toast。

## `2.4.0` — 直连非标准端口 Session Cookie 身份

- 当前状态：`implemented_validated`
- 需求 ID：`REQ-FRAMEWORK-0003`
- 范围：`WlsRequest` 在 Host 省略端口时回退直连 `WLS_PORT`；`SessionCookieNameResolver` 同步回退；设备校验失败补脱敏日志。无 schema 变更。
- 事实/发现：同机 `https://host:9555` 后台登录后访问 ACL，`auth.log` 出现 `acl_not_logged_in` 且 Session 仍有其它键、认证键被清。curl 对比同一登录 URL：HTTP/2 Host 带端口发 `WELINE_SESSID_9555`，Host 不带端口发 `WELINE_SESSID`。
- 实现：非受信直连且 Host 无端口时用 `WLS_PORT` 写入 `HTTP_HOST`/`SERVER_PORT`；受信代理仅在显式转发 80/443 时保持协议默认，不得仅凭 `X-Forwarded-Proto` 当成 443。
- 验收：`SessionCookieNameResolverTest` 5/5；登录页/ACL HTTP/1.1 与 HTTP/2、Host 带/不带端口均只发 `WELINE_SESSID_9555` + `SameSite=None; Partitioned`。2026-08-18 内置 Browser：登录后连点 ACL 角色、媒体管理、ACL 新增、仪表盘再回 ACL 角色，均保持登录，未再 302 到 `not_logged_in`。

## `2.4.0` — 网站有效货币解析契约

- 当前状态：`implemented_validated`
- 需求 ID：`REQ-FRAMEWORK-0002`
- 范围：`State::getCurrency()`、网站默认货币回退及聚焦回归；无 schema 变更。
- 事实/发现：网站默认及允许币种均为 USD 时，遗留 `user.currency=CNY` 仍被无条件采纳，导致默认商品与搜索路由显示 CNY 0.00；显式 `/USD` 路由正常。
- 实现：保留显式 URL 币种优先级；用户偏好通过当前网站允许集合校验；新增与默认语言对称的网站默认货币解析；在重建 `RequestContext` 前归一化币种；修正 `Env::system/router/dev()` 通过 `Env::get()` 读取大写默认值时被误认为模块名的歧义。
- 验收：先以失败用例复现 `expected USD / actual CNY` 及大写默认值返回 `null`；实现后 21 个聚焦测试 / 94 个断言通过，9514 的默认商品、搜索、详情、购物车、结账前置页及四种本地化路径均使用 USD，控制台 0 error / 0 warning。
