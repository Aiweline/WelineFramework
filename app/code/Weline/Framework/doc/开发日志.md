## 2026-09-17 — 绝对 URL redirect 空 params 不再尾随 &（2.5.97）

- 问题：`redirect(https://...?node=…)` 且 `$params=[]` 时拼出 `...?node=…&`。
- 修：`PcController::redirect` 仅在 query 非空时追加。
- 版本：`2.5.96` → `2.5.97`。

## 2026-09-17 — getBackendUrl `*` 空展开防 404（2.5.96）

- 问题：`*/admin/...` 在 Request router 为空时变成 `/admin/...`（缺模块 frontName），再叠加 locale 成 `/{lang}/admin/...` → 404。
- 修：`expandModuleStarPath` 回退模块 `etc/env.php` router / 模块名末段；`getBackendUrl` 改走该助手。
- 版本：`2.5.95` → `2.5.96`。

## 2026-09-17 — AbstractModel UPDATE 回写禁止整表覆盖（2.5.95）

- 问题：`checkUpdateOrInsert` 更新后 `setData($changedOnly)` 整表替换 `_model_fields_data`，未变更字段（如 Website `code`）从内存消失；默认站保存首页路由时抛「网站身份无效」。
- 修：按字段 `setData($field, $value)` 合并回写。
- 版本：`2.5.94` → `2.5.95`。

## 2026-09-17 — 客户登录独立 Session Cookie（WELINE_CUSTOMER_SESSID）

- 问题：前后台共用 `WELINE_SESSID`，主题预览与真实客户登录交织导致反复掉线。

## 2026-09-17 — trustedReuse 登记失败不清除现有登录（2.5.93）

## `2.4.0` — 请求 authority 与 Session Cookie 身份
