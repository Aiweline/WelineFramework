# 控制面资源变更目录

本文维护控制面资源的写入事实、缓存动作和异步反馈接入状态。交易型资源另行评审，不通过通用 Model hook 自动发布。

状态：`已接入` 表示 Producer 与至少一个真实消费者已通过 Outbox/Queue 验证；`部分接入` 表示已有领域事件或局部缓存动作；`待接入` 表示仍缺少可靠 ResourceChange。

## 统一约束

- Producer 必须在 Framework 默认主库受管事务中完成业务写入、revision 和 `w_changed()`。
- `website_id=0/code=default` 是合法默认站；全局控制面资源使用该上下文，真实 scope 保存在安全快照。
- payload 只保存白名单字段；秘密值只记录变化状态或 SHA-256，不保存明文。
- 外部网络、文件发布、WLS IPC、CDN 和健康检查只能位于 afterCommit 或 async Delivery。
- 连续 upsert 使用 `coalesce=latest`；delete/publish/unpublish 与安全撤销是 barrier。
- Queue、Delivery、Outbox、Session、心跳、日志、编辑器锁和预览 Token 不作为业务 ResourceChange Producer。

## 交易资源边界

Order/Checkout 已有创建、支付、发货、退款、取消和状态机事件；第一期不重复发布通用 ResourceChange。后续只评审现有事件是否具备同事务可靠投递、幂等、重放和敏感数据最小化能力。
