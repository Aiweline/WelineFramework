# 异步观察者与资源变更测试矩阵

> 对应工程计划 `PLAN-ASYNC-RESOURCE-C0AA2965-R2` 的长期回归入口。用例编号与计划 §8.2 一致。

## 固化原则

- 纯逻辑和输入契约用 PHPUnit 单元测试，不依赖网络、队列进程或生产数据。
- ORM、事务、队列竞争与崩溃窗口使用独立数据库/进程的集成门禁，完成后清理数据。
- 后台交互使用模块 E2E，通过 `php bin/w e2e:run` 运行，禁止复用 9501。
- 混合版本 WLS、真实 FPM 和三数据库方言是发布环境门禁；未提供环境时不降级为“已覆盖”。

## 集成与发布环境门禁

| 计划用例 | 环境 | 必须保留的证据 |
|---|---|---|
| TX01–TX03、STORE01 | MySQL/PostgreSQL/SQLite 独立 schema | 物理 commit/rollback、savepoint、rollback-only、无残留行 |
| EVT03、STORE03 | Queue provider 存在/缺失/构造失败 | Outbox 行、诊断去重、Framework 可启动 |
| STORE02、QUEUE01–QUEUE04、COAL01 | 双 Relay/双 Worker/可定向终止子进程 | 唯一 queue/delivery/token、lease/fencing、崩溃窗口恢复、无重复执行 |
| CACHE01–CACHE03、FPC01–FPC02 | 双站点、专用 WLS；CACHE03 追加真实 FPM | generation/@clock 单调、目标站 miss/对照站 hit、旧构建不污染新键 |
| ZERO01–ZERO02、WEB01–WEB04 | 可恢复的 default/normal website 和关联表 | 0 语义、逐步失败全回滚、删除快照、事件顺序、精准缓存失效 |
| WLS01–WLS04 | 唯一实例名/端口；WLS04 需独立双版本 staging | accepted/completed、ACK identity、READY 收敛、reload/replacement、mixed-version fail closed |
| UI01–UI03、BR01 | 专用 WLS + 后台 ACL 账号 | HTTP/Browser 结果、可见内容、console/pageerror、实例状态 |
| DOC01 | 完整 diff + Browser `file://` 或文档页 | 文档与命令/状态/接口一致，i18n 不回退 |

```bash

php vendor/bin/phpunit --bootstrap app/bootstrap_phpunit.php <test-files...>

# 收集/运行后台 E2E
php bin/w e2e:run app/code/Weline/Framework/Test/E2E/backend/async-event-delivery.spec.js --list --project=chromium
php bin/w e2e:run app/code/Weline/Framework/Test/E2E/backend/async-event-delivery.spec.js --project=chromium
```

E2E 执行前必须启动唯一命名、端口 `>=9502` 的专用 WLS；自动验证后停止实例。
