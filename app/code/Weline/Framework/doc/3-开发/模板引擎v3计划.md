| # | 目标 | 可度量判据 |
|---|---|---|

## 3. 架构（五层，单向依赖）

```
Source(.phtml)
 ├─① Lexer    只切分不替换 → Fragment[] = Text | Php | Tag | Inline
 ├─② Parser   标签嵌套 → 树（不解析属性语义）→ Node[]
 ├─③ Resolve  标签名 → TagDescriptor；属性 → TypedAttr
 ├─④ Lower    Node → Stmt[]（唯一允许"生成"的阶段）
 └─⑤ Emit     Stmt[] → PHP 源码 + SourceMap → com_*.phtml
```

命名空间：`Weline\Framework\View\Compiler\`（与将被删除的 `View\Taglib\*` 解耦）。

```
View/Compiler/
├── Lexer/    Fragment.php Lexer.php TextFragment.php PhpFragment.php Span.php
├── Parser/   Node.php TextNode.php PhpNode.php TagNode.php InlineNode.php Parser.php
├── Tag/      TagDescriptor.php AttributeSpec.php Registry.php
│   ├── Builtin/  LangTag.php HookTag.php IconTag.php SlotTag.php ...
│   └── Adapter/  ModuleTagAdapter.php      ← 86 个 TaglibInterface 的零改动桥
├── Ir/       Stmt.php Emitter.php Scope.php SourceMap.php
├── Runtime/  TagRuntime.php                ← 运行期唯一出口
└── Shadow/   ShadowCompiler.php Comparator.php Report.php
```

**关键设计（与外部 §4.2 一致，实施时不得简化）**

1. **PHP 是一等片段**：`PhpFragment` 保留原始字节（含 `<?php`/`?>`），标签扫描只在 `TextFragment` 的 `<` 上做 ⇒ `isOffsetInsidePhp()`、`PhpExtractor` 这类占位符往返不再需要。
2. **`TagDescriptor` 是唯一定义源**：`name/aliases/attributes/paired/selfClosing/stage/ownsChildren/lower(Closure)`；`lower()` 返回 `Stmt[]`，不返回字符串。
3. **`Stmt` 树**：`Echo/If/Foreach/Include/RawPhp/Capture/Assign/Block`；`CaptureStmt` 用结构替代 `FiberOutputBuffer::beginCapture/endCapture` 的手写配对。
4. **`Scope::temp()`** 生成带模板指纹的变量名（`$__wf_<fp8>_<name>`），结构性解决嵌套 com 共享 `obFileInner` 作用域的变量撞名。
5. **`TagRuntime::render()` 是运行期唯一出口**，不再回传原始属性串给 `Taglib`。

## 4. 兼容与迁移：影子编译

**核心：不证明等价，测量等价。**

```
Template::compileSourceBytes()
 ├─ 旧路径：Taglib::compile() → com_*.phtml → 渲染（唯一真相）
 └─ template.engine.shadow=true 时：
      v3 再编译一次（内存，不落盘）
      ├─ 行为：旧产物 HTML vs 新产物 HTML → 字节比对
      └─ 产物：规范化 diff → var/compile/shadow/<hash>.diff
```

开关（`app/etc/env.php`）：

```php
'template' => ['engine' => [
    'v3'     => false,                        // 总闸
    'tags'   => ['lang', 'string', 'count'],  // 已转正标签组
    'shadow' => ['if', 'foreach', 'hook'],    // 只影子不生效
]],
```

转正四条（全满足才从 `shadow` 移到 `tags`）：

| 门禁 | 判据 |
|---|---|
| S1 | 新产物渲染 HTML 与旧产物**字节相同**（忽略 `<!-- -->`） |
| S2 | 标签组语料出现 ≥100 次 |
| S3 | diff 白名单外差异 = 0 |
| S4 | 灰度机连续 72h 无差异 |

**风险登记（实施时逐条对照）**

| # | 风险 | 缓解 |
|---|---|---|
| R1 | `lang` 静态镜像漂移 | `lang` 单组先做，镜像逻辑原样搬运 |
| R2 | `w:hook` 的 `<else/>` 语义丢失 | `HookNode{body, elseChildren}` + golden case |
| R3 | 模块回调返回串含 `@static(...)` 未被二次解析 | 保持现状语义，A2 白名单显式记录 |
| R4 | 嵌套编译 source map 错位 | `SourceMap` 按 `(templateId, span)` 二级索引 |
| R5 | 捕获层级变化 | 保留 `FiberOutputBuffer` 原语，只改配对方式 |
| R6 | 双编译器缓存串味 | `compile_id` 加 `compiler=v3`；bump `CompilerGeneration` |
| R7 | 多会话共用工作副本 | 不碰 `generated/`；`taglib:collect` 产物只读 |
| R8 | 删死代码撞契约测试 | 删前 `grep` 测试；契约测试随实现同波改并在 PR 说明 |

## 8. 已确认的实测边界（2026-10-20，别再重复踩）

1. **模板 OPcache 编译不是瓶颈**：12 个 com 模板冷编译合计 **5.4 ms**（`dev/tmp/pa1-opcache-probe.php`）。冷 worker 的 2 s 不在编译 `.phtml`。
2. **热路径没有可省的编译**：`compileSourceBytes()` 在 identity 命中时直接 return；v3 的收益只在冷编译（G4）。
3. **`renderRuntimeTag` 几乎不在运行期命中**：当前维度编译语料仅 5 处、首页 layout 为 0（`<w:hook>` 编译期 bake）。PA-4 的「30 hook × 34.7 µs」建模不成立。
4. **P-1 已把编译链 51.5% 的成本拿掉**（`isOffsetInsidePhp` 改 C 层 `strpos`，expand 1.297→0.119 ms）⇒ v3 的剩余空间是 `PhpExtractor`(21%) + `AstBuilder`(17%)，做之前先用 §2.5 的基线复核。

**本轮修的根因（都影响真实模板，不是测试特例）**

1. **`{{x|默认值}}` 插值**：旧 `CodeGenerator::parseVariablePath()` 把单竖线当 `??` 回退，`||` 不拆；新 `ExpressionParser::path()` 逐字复刻（含 `default:` 过滤器）。语料 28 处，直接阻塞 `js:part`。
2. **引号内 `@lang`**：旧 `adjustLangInlineAttributeContext()` 在 token 被成对引号包住时**消费引号**并切 `InlinePhraseMarker::emit(词, true)`；这发生在 HTML 属性、JS 字符串等所有文本上下文。Parser 现在记录 `InlineNode::quoted()`，`LangTag` 据此切属性标记模式；`block` 属性里由 `LowerContext::inline()` + `BlockTag` 复刻。
3. **S1 探针按引用假绿**：旧 `Taglib::compile(Template &$t, string &$content)` 会就地改写源码（内联展开）。原 `tpl-v3-tag-s1.php` 直接传 `$s`，新管线拿到的是**已被旧链展开过的源码**，导致 URL 族/`block` 出现「假绿/假红」。已改为传副本；URL 族（985/1103/34/23/6）复验仍 100%，不是假绿。
4. **`block` 形状**：成对空内容会多 `'0' => ''`；自闭合才带 `,$vars=['x'=>&$x,]`（按引用传局部变量名，不取值）；成对但空内容 + 属性内联标签时旧 AST 走自闭合分支（有子内容则仍成对）。
5. **`local` 状态**：`Local::$ids` / `$bulkModalRendered` 是跨编译静态状态；旧/新各编译一次前必须回到同一初始态。另 `Url` 构造器首次调用返回冷启动回退 `http://localhost/en_US/...`、第二次起才用网站默认；S1 先预热，旧/新看同一状态。
