# 模板运行时引擎（ViewEngine）

权威实现：`Weline\Framework\View\Engine\*`。Taglib v2 仍负责 `.phtml` → `com_*.phtml`；本引擎只消费编译产物。

## 架构

| 组件 | 职责 |
|------|------|
| `ViewEngine` | 编排 resolve + render mode |
| `TemplateResolver` | `getFetchFile` / 已编译路径识别 |
| `CaptureSession` | `FiberOutputBuffer` 活动捕获谓词 |
| `RenderContext` | 跨切 RequestContext 键名 |
| `HookRuntime` | getHook：stream vs string |
| `EngineFlags` | `view.engine.v2` 切核 / 回滚 |
| `Template` | 薄 Facade：`fetch` / `getHook` / 新 API `resolve`·`include`·`capture` |

## 三种渲染模式

| 模式 | API | 行为 |
|------|-----|------|
| `stream` | 活动捕获下的 `fetch` / `ViewEngine::stream` | `include` 进当前帧，无嵌套 begin/end |
| `capture` | `fetchHtml` / `capture` / 无捕获时的 `fetch` | 外层一次捕获，返回 string |
| `include` | `include($compiledOrLogical, $data)` | 列表热路径：resolve 一次后循环 include |

**硬规则：** 打开捕获后，子 `fetch` / `getHook` **默认 stream**；仅显式 `capture` / `view.hook.require_string_result` / Hook 装饰路径才嵌套字符串捕获。禁止「拼字符串时误走 stream 弄乱 DOM」。

## 旗标回滚

- 默认：`view.engine.v2` = true（走 ViewEngine）
- 回滚：`app/etc/env.php` 设 `'view.engine.v2' => false`，或 RequestContext `view.engine.v2` = false
- 回滚后 `fetch` 走 Template 内联 legacy 路径（语义对齐）

## 列表热路径开发规则

1. **禁止**在 `foreach` 热路径对固定 partial 反复 `fetch`/`fetchHtml`（嵌套 capture）。
2. 优先：`$path = $this->resolve('Module::…');` 循环内 `$this->include($path, $data);`
3. 或 Helper 出 HTML / 数据契约，模板只 echo。
4. 可用 Taglib：`<w:partial-once path="Module::…/card.phtml" var="$_w_card"/>` 外提路径变量。
