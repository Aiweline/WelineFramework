# Taglib 使用指南

## 基本用法

### 编译模板

```php
use Weline\Framework\View\Taglib;
use Weline\Framework\View\Template;

$taglib = new Taglib();
$template = new Template();

$content = '<block template="header.phtml"/>';
$compiled = $taglib->compile($template, $content, 'page.phtml');
```

### 注册自定义标签

```php
// 编译期标签
$taglib->registerTag('hello', function(array $params) {
    $name = $params['name'] ?? 'World';
    return "Hello, {$name}!";
});

// 使用
// <hello name="Weline"/>
// 输出: Hello, Weline!
```

### 注册运行期标签

```php
// 运行期标签（动态内容）
$taglib->registerRuntimeTag('current-time', function(array $params) {
    return date('Y-m-d H:i:s');
});

// 使用
// <current-time/>
// 输出: 2026-01-31 12:00:00
```

## 内置标签

### 控制流标签

```html
<!-- if 标签 -->
<if condition="$show">
    Content to show
</if>

<!-- foreach 标签 -->
<foreach items="$items" as="$item">
    <div><?= $item ?></div>
</foreach>
```

### 模板标签

```html
<!-- block 标签 -->
<block template="components/header.phtml"/>

<!-- lang 标签 -->
<lang>Hello World</lang>
```

### 统一表单标签

Weline 模板中的表单统一使用显式 `<w:form>`。它会输出浏览器原生 `<form>`，并接入
CSRF、Captcha、服务端扩展事件和浏览器挂载事件：

```html
<w:form method="post"
        action="@var($saveUrl)"
        class="editor-form @var($extraClass)"
        intent="content.save">
    ...
</w:form>
```

支持标准表单属性、`data-*`、`aria-*` 与 `novalidate`。`csrf` 默认 `auto`，因此 POST
自动注入 CSRF；`captcha` 默认 `off`，普通表单不会出现验证码。需要验证的入口必须显式使用
`captcha="auto"` 或 `captcha="required"`：前者只在 POST 表单注入，后者声明强制验证语义。
启用后，Google Enterprise 可用时使用 Google 挑战，否则使用框架本地图形挑战。已有手工
CSRF 字段时设置 `csrf="off"`。

```html
<w:form method="post"
        action="/customer/account/login"
        captcha="required"
        intent="customer.login">
    ...
</w:form>
```

Captcha 标签只负责渲染挑战；业务提交入口仍必须用同一个 `intent` 调用
`CaptchaManagerInterface::verifySubmission()` 复验。

## 标签动态属性

禁止在 `<w:*>` 属性中嵌入 `<?= ?>` / `<?php ?>`。动态值使用 `@var(...)`、
`@lang(...)` 或对应 URL 内联标签：

```html
<w:form action="@backend-url('module/backend/item/save')"
        data-record-id="@var($item['id'])">
    ...
</w:form>

<w:block class="@var($containerClass)"/>
```

普通原生 HTML 元素仍可按 PHP 模板语法输出，但优先在进入属性前完成值计算，并在输出边界转义。

## 命名空间标签

支持带命名空间的标签：

```html
<!-- 格式: prefix:module:tag -->
<w:seo:account:select id="account"/>

<!-- 映射到: Weline\Seo\Taglib\AccountSelect::callback() -->
```

## 场景映射与全量目录

模板里做站点/语言/文件/编辑器等选择器时，先调用 MCP `resolve_task_context` 检索 `Weline_Taglib`，禁止手写裸 select：

- `app/code/Weline/Taglib/doc/README.md`
- `app/code/Weline/Taglib/doc/如何自定义Tag.md`

新增标签后必须同步更新归属模块文档；MCP 会在下一次调用前自动刷新索引。

选择器浮层定位复用 `Weline\Framework\View\Taglib\Support\FloatingDropdownEmitter`（`window.WelineTaglibFloatingDropdown`），闭包在标签输出内；不要依赖 Theme.js 的 `WelineSmartDropdown`，也不要在各标签里复制内联定位算法。

## 自定义编译优化

### 添加编译通道

```php
use Weline\Framework\View\Taglib\Compiler\Pass\CompilePassInterface;
use Weline\Framework\View\Taglib\Ast\ProgramNode;

class MyOptimizationPass implements CompilePassInterface
{
    public function process(ProgramNode $ast): ProgramNode
    {
        // 自定义优化逻辑
        return $ast;
    }
    
    public function getName(): string
    {
        return 'my-optimization';
    }
    
    public function getPriority(): int
    {
        return 100;
    }
}

$taglib->addCompilePass(new MyOptimizationPass());
```

## 最佳实践

1. **避免在循环中编译** - 编译是耗时操作，应该缓存结果
2. **使用命名空间标签** - 便于管理和查找标签实现
3. **静态内容优先** - 尽量使用静态属性，动态属性会延迟到运行期
4. **利用缓存** - 生产环境启用 APCu 获得最佳性能
