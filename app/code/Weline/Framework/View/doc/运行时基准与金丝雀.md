# ViewEngine Phase 0：基准与金丝雀页

采集方式（本机）：对验收 Host 请求，读响应头 `x-wls-first-render-total-ms`（或等价 TTFB），并在 DEV/trace 下统计 `TemplateRenderRouteTrace` span：`fetch_html` / `fetch_stream` / `hook_stream` / `ob_file` / `engine_include`。

## 金丝雀页清单

| ID | URL（相对 Host） | 关注点 |
|----|------------------|--------|
| C1 | `/products` | PLP N 卡 SSR；卡壳一次 capture，子路径 stream/include |
| C2 | `/`（首页货架） | 货架卡面 batch / Hook 购买钮 |
| C3 | 单商品 PDP（任意上架 SKU） | Hook 装饰 / string 模式未回归 |
| C4 | Taglib 抽样（含 `<w:icon>` / `<lang>` / slot 的页面） | 视觉与编译金样 |

默认 Host：`https://p05113ef3.test.weline.com`（以本机 `server:status` 为准）。

## 基准字段

每次采集写入 `dev/session/` 或 Agent Store：

- `http_code` / `ttfb_s` / `total_s` / `bytes`
- `x-wls-first-render-total-ms`（若有）
- 卡数抽样（`product-card` / `data-product-id` 计数）
- span 计数（有 trace 时）：`fetch_html`、`fetch_stream`、`hook_stream`、`ob_file`、`engine_include`

## UC 对齐（计划验收）

- **UC-1**：`/products` 嵌套 `fetch_html`/`ob_file` 相对本基准显著下降（卡壳一次 capture，子 stream/include）。
- **UC-2**：单卡加购/立即购买 DOM 顺序与按钮 data 契约不变。
- **UC-3**：编辑器/preview Hook 装饰路径仍可用。
- **UC-4**：Taglib 抽样页视觉一致。
