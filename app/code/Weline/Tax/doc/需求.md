## 当前有效需求

### `REQ-TAX-0002` 税率多源聚合同步（保守合并）

- 来源与确认：用户批准「免费并集冲突取较高税率 + 可选专业 API 覆盖」。
- 目标版本：`2.1.6`。
- 行为：离线 sync 写入 `TaxRule`；免费 Provider 并集去重取 max；专业源对返回管辖区覆盖；热路径不拉远程。
- 入口：SystemConfig `tax/ratesync/*`、ControlCenter 税率同步、`tax:ratesync`、Cron `tax_rate_aggregate_sync`。
- 验收：本机 sync 出现欧盟 `DE|`；关 vatcomply 仅 static；假 professional 可覆盖 `DE|`。

### `REQ-TAX-0003` 价内税同国不价外加收销售税

- 来源与确认：用户确认商品标价已含税费；结账价外再加 13% 属双计。
- 目标版本：`2.1.8`。
- 行为：`tax/general/prices_include_tax` 默认开；收货国=默认管辖区国时 `CheckoutTaxAdvisor` 销售税加收额为 0；跨境目的地税/DDU 关税预估不变。
- 验收：国内结账税费行 0；价外模式仍可算 13%；US|CA 仍可算目的地税。

### `REQ-TAX-0004` 多国结账税费策略与可上线种子

- 来源与确认：用户要求各国按情况处理税费，种子可上线即用，并真机验证。
- 目标版本：`2.1.9`。
- 行为：跨境默认不价外加目的地销售税；DDU 按国别收关税/进口税预估；`collect_sales_tax_countries` 可选代收；`tax:seed-defaults` upsert 多国税率。
- 验收：CN 税费 0；DE+DDU 仅进口税费无销售税双计；US+DDU 仅关税；GB 不阻断；种子 revision≥3 含 DE/GB/AU/JP/US。

### `REQ-TAX-0005` 税务运行开关支持渠道 Scope

- 来源与确认：用户确认渠道级也要能开关收税/代收配置。
- 目标版本：`2.1.14`。
- 行为：SystemConfig `tax/general/*` 允许 `global,website,store,channel`；结账按请求 `channel_id` 解析继承；`enabled` 与 rollout 同时满足才算税；`collect_sales_tax_countries` / 价内税可按渠道覆盖。
- 非目标：海关实缴通道；改 Incoterm/DDU 预估算法。
