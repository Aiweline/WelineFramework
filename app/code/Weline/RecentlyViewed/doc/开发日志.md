## 2026-09-18 — 卡片映射透传会话货币（1.0.12）

- 审图：`web_ui` / `ui_shot`；英文 + USD 会话下最近浏览价格前缀仍渲染 `CNY`。
- 根因：私有 `mapOffer` 未透传 `currency`，`<w:product:card>` 缺字段默认 CNY。
- 变更：`cards()` 改为 `ProductCardRenderer::fromStorefrontOffer`（与分类/目录一致）；保留 `source_slug`→`slug` 归一。
- 验证：`RecentlyViewedServiceTest` / `RecentlyViewedWidgetContractTest`；PDP Browser 禁缓存抽查 USD。
- 版本：`1.0.11` → `1.0.12`。

## 2026-09-14 — 最近浏览卡片 URL 优先 slug（1.0.9）

- 问题：列表卡片已改 `/product/{slug}` 后，最近浏览仍可能落回 `/product/{id}`（依赖 catalog offer 的 slug；mapOffer 未带 `source_slug`/卡片 `slug` 字段）。
- 变更：`RecentlyViewedService::mapOffer` 归一化 `slug|source_slug` 并写入卡片；模板缺 `url` 时按 slug 回填，locale 前缀与猜你喜欢一致防重复。
- 验证：`RecentlyViewedServiceTest` / `RecentlyViewedWidgetContractTest` / Product `ListingSummarySlugUrlContractTest`；PDP Browser 禁缓存抽查最近浏览链接。
- 版本：`1.0.8` → `1.0.9`。
