# Weline_RecentlyViewed 功能现状

| 能力 | 入口 | 说明 |
|---|---|---|
| 浏览记录写入 | `Observer/ProductViewedObserver` ← `Weline_Product::product_viewed` | Cookie MRU，最多 24 |
| 列表/卡片 | `Service/RecentlyViewedService` | 按 MRU 解析已发布报价卡片 |
| 店面展示 | `recently-viewed` 部件 | `default_injections` → `product-recently-viewed` |
| 空态 | 部件模板 | `data-testid="recently-viewed-empty"`，禁止空白 HTML |
