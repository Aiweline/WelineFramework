# Weline_RecentlyViewed 功能现状

| 能力 | 入口 | 说明 |
|---|---|---|
| 浏览记录写入 | `Observer/ProductViewedObserver` ← `Weline_Product::product_viewed` | Cookie MRU，最多 24 |
| 列表/卡片 | `Service/RecentlyViewedService` | 按 MRU 解析已发布报价；店面按 id `livePublishedOffersForProduct`；卡片 URL 优先 `slug`/`source_slug`，缺省才回退 `/product/{id}` |
| 店面展示 | `recently-viewed` 部件 | `default_injections` → `product-recently-viewed`；默认 `limit=24`；卡片 `<w:product:card density="standard" class="wpc-listing-card wrv-card">`；主题编辑器预览用 `ThemeDemoCatalog` |
| 空态 | 部件模板 | `data-testid="recently-viewed-empty"` + `hidden`/`aria-hidden`，店面不展示；禁止空白 HTML |
| 版本 | `etc/module.php` | `1.0.11` |
