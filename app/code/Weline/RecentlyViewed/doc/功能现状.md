# Weline_RecentlyViewed 功能现状

| 能力 | 入口 | 说明 |
|---|---|---|
| 浏览记录写入 | `Observer/ProductViewedObserver` ← `Weline_Product::product_viewed` | Cookie MRU，最多 24 |
| 列表/卡片 | `Service/RecentlyViewedService` | 按 MRU 解析已发布报价；店面按 id `livePublishedOffersForProduct`（避免全量 catalog） |
| 店面展示 | `recently-viewed` 部件 | `default_injections` → `product-recently-viewed`；默认 `limit=24`；卡片 `<w:product:card density="shelf">`；主题编辑器预览用 `ThemeDemoCatalog` |
| 空态 | 部件模板 | `data-testid="recently-viewed-empty"`，禁止空白 HTML |
| 版本 | `etc/module.php` | `1.0.6` |
