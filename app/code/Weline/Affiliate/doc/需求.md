# Weline_Affiliate 需求

## 当前需求

- 保持模块现有公开行为；新增或变更需求须在实现前记录于此。
- 页脚「合作信息」扩展槽默认展示「我要推广」：部件 `footer-promote-link` 经 `default_injections` 注入 Theme `footer-partner-links`，链接到分销前台入口 `/affiliate`。
- 商品详情页购买栏与列表「快捷规格加购」弹窗均展示同一「分销分享」区块（`after-add-to-cart` hook）；`product_id` 须从 `storefront_offer` / `StorefrontOfferResolver` 解析，不得仅依赖请求参数 `product_id`。
- **分销分享异步水合（confirmed）**：PDP/弹窗分销区不得依赖整页 SSR 登录态（FPC 常为游客壳）。须等前台账户会话（`WelineAccountModule` / `account-session`，含浏览器缓存）处理后再请求分享链接；分享结果写入浏览器（sessionStorage）按客户+商品复用，避免每次后台请求。登录/登出事件刷新面板并清理浏览器分享缓存。
- **游客态分销广告（confirmed，1.0.14）**：未登录时不得展示空链接框与灰掉的「复制/分享」。须展示分销广告文案（利益说明）+ outline CTA「登录前往申请分销」（对齐批发「登录后使用批发」）；登录 URL 携带 `redirect_url=/affiliate`，登录后进入申请/分销中心。
- **游客免费平台分享（confirmed，1.0.15→1.0.17）**：未登录默认展示 FB/X/LinkedIn/WhatsApp **官方 logo 图标**作为默认分享入口（提升信任）；点击分享当前商品页 URL（无佣金追踪）。禁止用「也可以直接免费分享」文案替代图标。已登录分销态平台目标切换为 tracking 链接。
- **店面启停配置（confirmed，1.0.14）**：后台「分销配置」页用 SystemConfig 声明 + `<w:config:embed>` 开关 `product_share_enabled`（global/website/store）；关闭后 Hook 不渲染分销分享。禁止业务页手写开关存库。配置保存经 SystemConfig `ResourceChange` → `w_changed` 使 `storefront/config` 缓存代次失效（与批发配置同源）。
