# Weline_Affiliate 功能现状

## 悬浮面板规则 / 范围配置 / 登录边界（人工增补，2026-10-25）

- 模板 SSR 输出 `Service/AffiliateRuleService` 解析出的当前范围规则：`rule_title` + `rule_summary` 逐行条目；游客展开即可阅读，不调用登录态接口。
- `affiliate-float.js` 先 `checkFrontendUserLogin()`：游客只渲染规则、登录提示与 `/affiliate` CTA；已登录才 `getMySummary({}, {silent:true})`，展示 `level_name`、`commission_rate`、`status`、`pending_commission`、`referral_link`。
- 规则字段：`rule_title`、`rule_summary`、`default_commission_rate`、`level_name`，作用域 `global,website,store,channel`；SystemConfig 回退链渠道 → 店铺 → 网站 → 全局，网站默认向下覆盖。
- `default_commission_rate` 用于新创建分销账户（默认 0.10，旧行为不变）；已有账户费率不变。
- 入口统一使用存在的 `affiliate` 路由；游客登录带 `redirect_url=/customer/account/index#affiliate`，修复 `affiliate/customer/affiliate` 404。

## 游客默认社媒分享图标（人工增补，1.0.16→1.0.17）

- 去掉「也可以直接免费分享」文案；SSR 直接输出带 SVG logo 的四平台图标。
- 游客点击 = 当前商品 URL 默认分享；JS `syncDefaultPlatformHrefs` 只更新 href，禁止空列表清空图标；登录分销后换 tracking。
- 1.0.17：modules 缓存戳 + 平台区顶部分隔与加大 logo，避免水合后图标消失。

## 游客免费平台分享（人工增补，1.0.15）

- 游客广告下方常驻平台图标；分享目标为当前商品 URL（`data-free-share-url` / `location`），无 tracking、不记 outbound。
- （1.0.16 起取消「免费分享」提示文案，改为 logo 图标主信号。）

## 分销分享游客广告 + 启停配置（人工增补，1.0.14）

- 游客：`data-affiliate-share-guest` 广告标题/正文 + `登录前往申请分销` CTA（`redirect_url` → `/affiliate`）。
- 已登录：隐藏广告，展示链接区并异步水合分享结果。
- 后台「分销配置」：`Controller/Backend/Config` + `<w:config:embed fields="product_share_enabled">`；`AffiliateStorefrontPolicy` 读 ConfigStore；关闭则 Hook return。
- 配置变更：SystemConfig save → `w_changed(system_config)` / `storefront/config` 命名空间，FPC 代次失效。

## 分销分享异步水合（人工增补，1.0.13）

- Hook 壳 `after-add-to-cart.phtml` + `affiliate-product-share.js`：`data-weline-load="api,account,affiliateProductShare"`。
- 先等账户会话（含 `weline_frontend_session_user`），再拉/缓存分享链接（`sessionStorage` key `weline_affiliate_product_share_v1`）。
