## 2026-09-09 — 分销分享对齐账户异步会话 + 本地缓存（1.0.13）

- 审图分流：`web_ui` + `ui_shot`（顶栏已登录「We Line」，分销区仍「请先登录。」）。
- 根因：分享脚本一加载就打 `getProductShareLinks`，未等 `account-session`；FPC/游客壳下易与顶栏缓存水合不一致。

- 契约：`AffiliateProductShareHookContractTest`。
- 版本：`1.0.12` → `1.0.13`。

## M3 框架迁移（2026-08-27）

从 WeShop `9b0a4ddee` 恢复并迁移为 `Weline_Affiliate`：命名空间、表前缀 `weline_affiliate_*`、前台账户 Hook、Query Provider、后台菜单与 P0 行为修复。

### 事件映射（WeShop → Weline）

| WeShop 事件 | Weline 事件 | Observer | 状态 |
|---|---|---|---|
| `WeShop_Customer::register_after` | `Weline_Frontend_Account_Register::register_after` | `CustomerRegisteredObserver` | 启用 |
| `WeShop_Checkout::order_created` | `Weline_Checkout::checkout::create_order::after` | `CheckoutOrderCreatedObserver` | 启用 |
| — | `Weline_Order::order_created` | `CheckoutOrderCreatedObserver` | 启用（补充订单项载荷） |
| `WeShop_Order::payment_status_changed` (`paid`/`refunded`) | `Weline_Order::order_paid` / `Weline_Order::order_refunded` | `OrderPaymentStatusChangedObserver` | 启用 |
| `WeShop_Order::order_status_changed` | `Weline_Order::order_status_changed` | `OrderStatusChangedObserver` | 启用 |
| `WeShop_Order::cancelled` | `Weline_Order::order_cancelled` | `OrderCancelledObserver` | 启用 |
| `WeShop_Social::share_after` | `Weline_Social::share_after`（规约占位） | `SocialShareAfterObserver` | **禁用**（上游事件未发布） |
| `WeShop_Product::product_viewed` | `Weline_Product::product_viewed`（规约占位） | `ProductViewedObserver` | **禁用** |
| `WeShop_Wishlist::add_to_wishlist_after` | `Weline_Wishlist::add_to_wishlist_after`（规约占位） | `WishlistAddAfterObserver` | **禁用** |
| `WeShop_Review::review_created` | `Weline_Review::review_created`（规约占位） | `ReviewCreatedObserver` | **禁用** |
| `WeShop_Cart::add_to_cart_after` | `Weline_Cart::add_to_cart_after`（规约占位） | `CartAddAfterObserver` | **禁用** |

订单相关 Observer 通过 `AffiliateOrderEventPayloadBuilder` 从 `Weline_Order` 模型补齐 `order_items` / `order_summary`。

### P0 修复

- 分销账户删除改为软删除（`deleted_at` + `status=disabled`），列表与汇总默认排除已删记录。
- `Delete::get()` 仅提示并跳转，不修改数据；`Delete::post()` 调用 `AffiliateService::softDeleteAffiliate()`。
- 佣金比例存储为 0–1 小数；后台表单输入 decimal，列表展示 `×100%`。
- 注册 `AffiliateQueryProvider`（前台）与 `AffiliateAdminQueryProvider`（后台 `listAffiliates` / `getSummary`）。

### UI / 扩展

- Widget：`affiliate-center`（`Weline_Widget`）。
- Hook：`Weline_Affiliate::frontend::account::index::affiliate`，挂载于 `account.sidebar` / `account.sidebar.content`。
- 样式：`view/statics/css/affiliate-account.css`，使用 Theme token（`--color-primary` 等）。

### 后台

- 菜单：`Weline_Backend::marketing_group` / order `50` / ACL `Weline_Affiliate::commerce:affiliate:programs`（万能分销）。
