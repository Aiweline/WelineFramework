## 2026-09-03 — 应用 Tab 去掉收藏「推荐/+」收藏夹

- 当前状态：`implemented`
- 问题：应用 Tab「收藏夹」显示推荐 `+`（未安装），预览顶栏已有收藏入口。
- 根因：顶栏由 `header-wishlist-icon` Hook 常驻交付，同时 `wishlist-icon` 声明 `default_injections`（`required:false`）进入应用 Tab。
- 变更：保留 Hook 交付；移除 `wishlist-icon` 的 `default_injections`；`SlotRendererService` 保留无既有 markup 时前置插入能力（手动拖入去重）；契约与 hook 文档对齐；版本 `1.0.9` → `1.0.10`（Theme `2.2.108` → `2.2.109`）。
- 验证：`WishlistHeaderWishlistIconHookTemplateTest`；`WidgetDefaultInjectionWishlistMultipleSlotTest`；主题编辑器应用 Tab 不再出现该推荐卡；预览顶栏仍有收藏。
