# Weline_Wishlist 需求

## 当前需求

- 个人中心「我的收藏」入口必须走 `customer/account/index#wishlist`，仅由本模块 `account.sidebar` / `header-account-links` / `wishlist-icon` 写入。
- 账户分区内容由本模块 `account.sidebar.content` Hook 渲染现有收藏列表模板。
- 禁止独立公开路径 `/wishlist`、禁止菜单指向 `wishlist/frontend/index` 等非 `customer/` 前缀路径；Theme 不得硬编码收藏入口（须经 `header-wishlist-icon` Hook）。
- 默认顶栏收藏由 `header-wishlist-icon` Hook 交付；`wishlist-icon` **不得**声明 `default_injections`，避免应用 Tab 显示「推荐/+」与顶栏已展示冲突。手动拖入布局时允许，SlotRenderer 须与 Hook markup 去重。
- 收藏 Cookie 中的商品若无法解析为前台已发布 offer（下架/删除/失效），在 `list` / `listPage` / `count` / `add` 读取或写入路径自动剔除并写回 Cookie，使列表、角标与「共 N 件」计数一致；`add` 拒绝无效商品。
