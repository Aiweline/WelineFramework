# Taglib 场景映射表

> **写任何 HTML / 模板控件前必读。** 能用官方 Taglib 或 Hook 时，禁止手写等价原生控件。

## 写 HTML 前决策流

```text
1. 是用户可见文案？ → <lang> / @lang()，禁止 HTML 内 __()
   · 源文含逗号？ → <lang>…</lang> 或加引号 @lang('a, b')；禁止 @lang{a, b}（编译 ParseError）
2. 是领域控件（语言/站点/文件/表格/ACL 等）？ → 查下表，禁止裸 <select>/<input>
2b. 是站内跳转 href/action？ → @url / <url> 或 PHP Url::getUrl；禁止 '/' . $path
3. 是页面插槽/可运营块？ → Hook 或 Widget，不是 Taglib 也不是裸 div
4. 是布局骨架？ → layout/partial/component/widget，读 Theme 开发总指南
5. 仅当 1–4 都不满足 → 才写原生 HTML，并在 TaskContract 说明原因
```

## 浮层与交互

- 标签内下拉/浮层：用 `FloatingDropdownEmitter` / `WelineTaglibFloatingDropdown`，**禁止**往 Theme.js 塞标签专属交互。
- 主题明暗：优先 `data-w-theme-preference`，见 Theme 文档。

## 新增标签后

同一任务内更新本表、[README.md](./README.md)、[如何自定义Tag.md](./如何自定义Tag.md)，并执行 `php bin/w taglib:catalog:generate`。
