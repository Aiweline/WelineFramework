## 2026-09-08 — Scope 禁用态 hover title + 触发器 title（1.1.6）

- 问题：主题编辑器锁定 scope 时 `disabled` 按钮不弹原生 title；初渲 trigger 缺 `title`。
- 修复：button/容器写 `title`；`syncSelection` 同步 root；禁用 trigger `pointer-events:none` 让悬停落到带 title 的壳上。
- 版本：`1.1.5` → `1.1.6`

## 2026-09-06 — taglib:collect 误裁 `Search.php` 类名（1.1.4）

- **问题**：`rtrim($path, '.php')` 按字符集裁剪，把 `Search.php` 变成 `Searc`，导致 `w:search` 从未进 `generated/taglibs.php`。
- **修复**：改为按 `.php` 后缀截断（`substr(..., -4)`）。
- **版本**：`1.1.3` → `1.1.4`

## 2026-09-01 — scope 回填分类 pending/ready

- **问题**：scope 先于分类控件就绪时，仅靠短重试仍可能漏填芯片。
- **修复**：`pendingCategoryById` 暂存；监听 `weline:catalog-category-select-ready` 再 `setValue(silent)`；`static:compile welineUi` 同步 Theme 组件。
- **版本**：`1.1.3`

## 2026-09-01 — scope 回填分类多选芯片

- **问题**：`applyValue` 只写空 hidden、不刷新 `catalog:category:select` 芯片，导致分类草稿不回填。
- **修复**：识别 `data-catalog-category-select-value` 时调用 `WelineCatalogCategorySelect[id].setValue(..., {silent:true})`；普通文本仍在空值时写值并派发 `input`。
- **版本**：`1.1.2`

## 2026-09-01 — scope 自动保存失败刷屏

- **问题**：商品创建页 `product_create_draft` 自动保存提示 `Backend request failed.`；Network 大量失败 `scope?scope=product_create...`。根因一是 `taglib/backend/scope` 路由缺失导致 404 前台页；根因二是 `scope-persistence` 在 load 失败后从 `loadedScopes` 删除，分类选择等 DOM 重绘经 MutationObserver 风暴重试并反复 toast。
- **修复**：刷新 Taglib 路由；`scope-persistence.js` 增加 `loadFailedScopes`（失败不重试）、`toastedScopes`（同 scope 只 toast 一次）、`scheduleDiscover` 防抖。
- **版本**：`1.1.1`
