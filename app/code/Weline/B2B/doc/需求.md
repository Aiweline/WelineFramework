### `REQ-B2B-0002` Cart+Order 双类型 Registry；B2B 自动注册 `tob`；可卸载且零热路径探测税

- 来源与确认：2026-09-07 用户确认 ToC/ToB 一期计划（双 SPI、可卸载、零性能税）。
- 目标版本：ToC/ToB 一期。
- 背景/问题：现状 Cart/Order 无售卖类型 SPI；若硬依赖 B2B，未安装或卸载后零售会挂或产生探测税。
- 用户与运营场景：未装 B2B 时纯零售；安装后可切批发；卸载后零售继续，历史 tob 单只读 fail-soft。
- 业务逻辑：
  - `Weline_Cart` / `Weline_Order` **各自**内置类型 SPI + Registry + 内置 `toc`；**永不** `requires` `Weline_B2B`。
  - B2B 启用后经 extends **自动向双边**注册 `tob`；切换 `tob` 整链走 B2B 下单；切回 `toc` 走零售全款。
  - 未安装：Registry=`{toc}`；加车/`presentLine`/Assembler/Checkout **不得** `class_exists` / ObjectManager 探测 B2B，零反射扫、零 miss 重试税。
  - 卸载：去掉 tob Provider 与相关配置/缓存；零售继续；历史 `order_type=tob` 徽章 fail-soft「历史批发」，写路径（审批/尾款）不可用。
  - 可选协作仅用接口 + Noop /「未注册则分支不存在」；B2B 观察者仅模块启用时挂 `etc/event.xml`。
- 范围：类型 SPI/Registry、B2B 双注册、安装卸载语义、热路径性能约束、后台筛选选项=当前已注册 types。
- 非目标：见下文「一期非目标」。
- 验收标准：未装 B2B 时仅 `toc` 且热路径无 B2B 探测；已装时双边 `has('tob')`；卸载后零售可用且历史 tob 只读 fail-soft。

### `REQ-B2B-0003` SellingModePolicy（Website/Store + 商品 EAV）；会话仅偏好已注册 code

- 来源与确认：2026-09-07 ToC/ToB 一期锁定决策。
- 业务逻辑：
  - Website/Store 开关与商品 EAV 决定有效售卖模式；Channel 覆盖与现有 rollout fail closed 一致。
  - `SellingTypeResolver` 为唯一写入路径：code ∈ 双边 Registry；tob 时经**可选** membership Interface（缺模块则无法选 tob）。
  - 会话/`selling_mode` **仅**偏好；不得直接赋予未注册或未解析的 `cart_type`/`order_type`；**不**复用 `business_code` / OrderStatuses。
  - 含价缓存 vary：`website + store + channel + locale + currency + selling_mode`；tob 另加 `group_id`/membership 版本。
- 验收标准：未注册 code 无法写入车/单；会话直赋失败；商品级关闭 toc/tob 时加购拒绝（`product_selling_mode_disabled`）。

### `REQ-B2B-0004` ToB 身份：membership 申请；后台指定组；禁客户端 `group_id`

- 来源与确认：2026-09-07；不改 `CustomerAccountService::register`。
- 业务逻辑：
  - ToB 用 B2B **membership 申请** + 审核；**不是** `Customer::register` 赋类型/组。
  - 仅后台批准时 `CustomerGroupStore::assignCustomer` 写入 membership；申请单**不接受**客户端 `group_id`。
  - 切到 tob 无 membership → 引导申请；tob 强制已登录；禁止游客 tob 车。
- 验收标准：前台无法自选等级刷价；未登录无法进入 tob 车；注册账户不写入 toc/tob 字段。

### `REQ-B2B-0005` ToB 全面禁折；定金 30%；`hang_status` 挂单流

- 来源与确认：2026-09-07 折扣与定金政策锁定。
- 业务逻辑：
  - **ToB 全面禁折**：Promotion theme deal、Marketing 规则/满减、优惠券、会员再叠折均不生效；价目即为成交价。运费模板一期可保留，**不定金基数**，运费进尾款。
  - **定金基数**：拆单后该张 Order **禁折后含税商品小计** × 30%；订单头记录 `goods_subtotal_minor` / `deposit_amount_minor` / `balance_amount_minor`。
  - **挂单时序**：`awaiting_deposit` →（定金支付成功 + reserve）→ `awaiting_merchant_approval` →（通过）→ `awaiting_balance` →（尾款付清）→ 既有 paid；驳回窗截止于尾款前。
  - 主状态沿用 Order 机；生命周期用 B2B `hang_status` + `payment_status=partial`；双 Intent（deposit|balance）；tob submit **不定金前短租预占**，定金成功后再 `reserve`。
  - 审批仅在 `hang_status=awaiting_merchant_approval` 可点。
- 验收标准：tob 路径无券/满减/deal；定金金额按禁折后含税小计 30%；先定金后审批再尾款闭环。

## 一期非目标

与 ToC/ToB 一期计划一致，明确不做：

- 平行 `B2BCart` / `B2BOrder` 模块
- 只向 Cart 或只向 Order 单边注册 `tob`
- Cart/Order/Checkout 硬依赖 `Weline_B2B`（未装必须可零售）
- 热路径探测/硬依赖 `Weline_B2B`（未装或卸载后必须零性能税零售）
- 用 OrderStatuses 或 `business_code` 冒充售卖类型
- session/`selling_mode` 直接赋予未注册或未解析的 `cart_type`/`order_type`
- 在 Customer 账户注册时写入 toc/tob 类型字段
- ToC/ToB 商品混在同一辆车；游客 ToB 车
- ToB 单位价与 Promotion deal 叠折；ToB 适用 Marketing 满减/优惠券/会员再叠折
- 脱离 Theme 的自研前台/后台 UI 或第三方组件库；将 prototype 扔弃视觉直接并入店面
- 信用账期、线下尾款、按 Store 复制整张价目
- 破坏 P4C quote/snapshot 不可变语义
- 以破坏方式改写既有 Order/Cart 事件字段
- 尾款付清后的商家反悔全额退（二期）
