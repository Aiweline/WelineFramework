## 2026-09-02 — 加购 Network 失败：asset:// 漏出 mini-cart

- 当前状态：`fixed`
- 现象：点击加入购物车后 Network 出现由 `mini-cart-icon.js` 发起、名称为 UUID、状态失败的请求。
- 根因：Cart 行 `image` 持久化为 FileManager `asset://UUID`；`getCart` 直出；迷你购物车 `img.src` 触发 `ERR_UNKNOWN_URL_SCHEME`。合并加购时也不刷新 `image`，旧协议会一直粘住。
- 修复：`CartService::summary` 出口消毒（`asset://` 与其它非 http(s) 协议置空）；`add` 合并行刷新 `image`/`sku`；Product snapshot 出站解析（既有）；Theme `mini-cart-icon.js` 拒绝不可展示协议。
- 验收：`CartServiceTest` 新增摘要消毒与合并刷新用例；Browser 复验 `getCart` / mini-cart 无 `asset://`。

## 2026-08-28 — 结账页 Worker nonce / 购物车预计优惠递归 OOM

- 当前状态：`fixed`
- 现象：结账冷加载出现 `Worker nonce has already been used.`，摘要空车；WLS Worker 在 `CartQueryProvider` / `CartService` 路径 OOM（512MB）。
- 根因：`getCart` → `enrichSummaryWithDiscountPreview` → `buildDiscountPreview` → `resolveStorefrontSummary` → `getCart` 在存在 `guest_token` 时无限递归；nonce 在业务执行前已消费，崩溃/重放后客户端看到 nonce 复用错误。
- 修复：`buildDiscountPreview` 支持传入已加载 summary；`enrichSummaryWithDiscountPreview` / `storefrontSummaryPayload` 复用 summary，禁止再入 resolve。
- 验收：契约测试 `CartQueryProviderDiscountPreviewRecursionContractTest`；Browser 加购后打开结账无 nonce 红字且摘要有商品。
