## 2026-08-30 — 游客无 guest_token 时 getV2Cart 误报错

- 当前状态：`fixed`
- 现象：登录页等未加购场景下 mini-cart 调用 `cart.getV2Cart`，BinQuery 红字 `cart_guest_token_required` / business_error（游客加购需要 guest_token）。
- 根因：`getCart` 经 `cartKey` 对空 token 抛错；该校验只适合加购/变更，不适合只读拉空车。
- 修复：`CartV2Service::getCart` 在无客户且无 guest_token 时返回空车成功摘要；加购等变更路径仍要求 token。
- 验收：`CartV2ServiceTest::testGetCartWithoutGuestTokenReturnsEmptySummary`；登录页 `getV2Cart` 不再 ERR。

## 2026-08-29 — 导出亚马逊加购面板供批量加购复用

- 当前状态：`fixed`
- 问题：Product「经常一起购买」批量加购无法复用单件加购的 `.w-amz-cart-added` 面板。
- 修复：`WelineCartPurchaseActions.showCartAddedNotice` 导出 `showAmazonCartAddedNotice`；`body-end` / 买盒脚本缓存版本抬升。
- 验收：FBT 全部加入后出现与单件加购同款小计/去结算/查看购物车面板。

## 2026-08-28 — 结账页 Worker nonce / 购物车预计优惠递归 OOM

- 当前状态：`fixed`
- 现象：结账冷加载出现 `Worker nonce has already been used.`，摘要空车；WLS Worker 在 `CartQueryProvider` / `CartV2Service` 路径 OOM（512MB）。
- 根因：`getV2Cart` → `enrichSummaryWithDiscountPreview` → `buildDiscountPreview` → `resolveStorefrontSummary` → `getV2Cart` 在存在 `guest_token` 时无限递归；nonce 在业务执行前已消费，崩溃/重放后客户端看到 nonce 复用错误。
- 修复：`buildDiscountPreview` 支持传入已加载 summary；`enrichSummaryWithDiscountPreview` / `storefrontSummaryPayload` 复用 summary，禁止再入 resolve。
- 验收：契约测试 `CartQueryProviderDiscountPreviewRecursionContractTest`；Browser 加购后打开结账无 nonce 红字且摘要有商品。

## 2026-08-28 — 库存不足提示按场景点名

- 当前状态：`fixed`
- 问题：详情页买盒再写「商品名库存不足」多余；「经常一起购买 → 全部加入购物车」不点名则无法判断是哪一件。
- 修复：Product 快照仍返回通用「商品库存不足」；`CartV2Service` / `CartService` 在通用/空 message 时升级为「「%{1}」库存不足」；库存打满/下调文案继续带商品名；Cart 英文 `商品库存不足` → `Out of stock`。
- 关联：详情模板隐藏通用库存 message，只保留 Temporarily out of stock 等买盒状态。
